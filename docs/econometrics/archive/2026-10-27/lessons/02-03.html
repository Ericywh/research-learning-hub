一、通俗理解

上一课用普通最小二乘法（OLS）寻找一条使样本残差平方和最小的直线。本课回答一个不同的问题：这条直线究竟解释了价格差异的多少？
假设两组汽车价格相差很大，而仅凭重量作出的预测仍与真实价格相距甚远，即使回归斜率显著，模型也未必能准确描述样本价格差异。拟合优度（goodness of fit）衡量模型预测值与样本观测值的贴合程度；最常用的指标是决定系数 R²。
理解 R² 可以从两个基准出发：完全不考虑重量时，用所有汽车的样本平均价格预测每辆车；加入重量后，改用回归模型预测。如果回归后的残差平方和明显小于“只预测均值”产生的平方误差，说明重量对样本内价格差异具有一定解释能力。注意，这里的“解释”是统计意义上的拟合，而不是因果识别。

二、核心理论与公式

对含截距项的OLS回归，定义总平方和 SST、残差平方和 SSE，则

$$R^2=1-\frac{SSE}{SST} =1-\frac{\sum_{i=1}^{n}(y_i-\hat y_i)^2}{\sum_{i=1}^{n}(y_i-\bar y)^2}.$$

其中，$\hat y_i$ 是模型预测值，$\bar y$ 是样本均值，n 为有效观测数。要求因变量不全相同，即 SST\>0。含截距OLS的样本内 R² 介于0与1之间；越接近1，样本内平方误差相对于均值基准减少得越多。
普通 R² 有一个局限：在同一样本、同一因变量下，给OLS模型添加解释变量不会使 R² 下降，即使新变量没有实质价值。因此常同时报告调整后的决定系数：

$$\bar R^2=1-(1-R^2)\frac{n-1}{n-k-1},$$

k 为不含截距的解释变量个数，要求 n\>k+1。调整后 R² 对增加变量施加自由度惩罚，可能为负，但仍不是预测性能或因果有效性的充分证据。

三、实证案例与数据

继续使用 Stata 官方1978年汽车示例数据 auto.dta，原始数据包含74条车型记录。被解释变量 price 为美元价格，weight 为磅重，mpg 为每加仑英里数。为了比较模型，统一保留这三个变量均非缺失的记录，并定义 weight100=weight/100。
比较模型A（价格对重量的一元回归）与模型B（在模型A基础上加入油耗指标 mpg）。两模型的因变量、估计样本与OLS方法保持一致，均使用HC1异方差稳健标准误。我们观察 R² 和调整后 R² 的变化，但不把新增变量带来的拟合改善解释为因果效应。数据来源：Stata官方示例数据说明；Stata Press auto.dta。

四、Stata与Python实现

Stata：

Stata
clear all
use "https://www.stata-press.com/data/r19/auto.dta", clear
* 两个模型使用同一完整样本
keep if !missing(price, weight, mpg)
generate double weight100 = weight / 100
count

* 模型A：一元OLS，HC1稳健标准误
regress price weight100, vce(robust)
display "模型A R2 = " %8.5f e(r2)
display "模型A 调整R2 = " %8.5f e(r2_a)

* 手动核对决定系数
predict double ehat, resid
egen double mean_price = mean(price)
generate double sse_i = ehat^2
generate double sst_i = (price - mean_price)^2
quietly summarize sse_i, meanonly
scalar SSE = r(sum)
quietly summarize sst_i, meanonly
scalar SST = r(sum)
display "手算 R2 = " %8.5f (1 - SSE/SST)

* 模型B：加入mpg，样本与稳健协方差设定不变
regress price weight100 mpg, vce(robust)
display "模型B R2 = " %8.5f e(r2)
display "模型B 调整R2 = " %8.5f e(r2_a)

Python：

Python
import numpy as np
import pandas as pd
import statsmodels.api as sm

url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url)[["price", "weight", "mpg"]].dropna().copy()
df["weight100"] = df["weight"] / 100
y = df["price"]

# 模型A：含截距OLS，HC1异方差稳健标准误
XA = sm.add_constant(df[["weight100"]])
a = sm.OLS(y, XA).fit(cov_type="HC1")
SSE = np.sum(a.resid ** 2)
SST = np.sum((y - y.mean()) ** 2)
print("有效样本量：", len(df))
print("模型A：", a.rsquared, a.rsquared_adj)
print("手算R2：", 1 - SSE / SST)
print("模型A系数与稳健标准误：", a.params, a.bse)

# 模型B：相同样本与HC1设定，新增mpg
XB = sm.add_constant(df[["weight100", "mpg"]])
b = sm.OLS(y, XB).fit(cov_type="HC1")
print("模型B：", b.rsquared, b.rsquared_adj)
print("模型B系数与稳健标准误：", b.params, b.bse)

运行后，应先核对两软件的有效样本量及变量定义，再比较系数、R²、调整后R²与HC1标准误。手算 R² 应与软件输出一致（允许浮点误差）。稳健标准误影响系数推断，不改变相同OLS估计的拟合值、残差或 R²。 本课未实际运行上述程序，因此不报告具体回归结果。

五、初学者避坑

误区一：R²高说明存在因果关系。 R²只刻画样本内拟合；遗漏变量、反向因果和共同趋势都可能使R²较高。要识别重量对价格的因果效应，仍需额外研究设计和识别假设。
误区二：R²高就说明样本外预测好。 样本内拟合可能包含过拟合，评价预测能力需要留出测试集或交叉验证。不同因变量、不同样本的R²也不宜机械比较。
误区三：R²越大，新增变量越有用。 在同样本含截距OLS中，新增解释变量使R²不下降是数学性质，不是新变量具有经济意义的证据。调整后R²可以下降，变量是否保留还取决于理论、模型目标和识别策略。

六、今日练习

概念题： 为什么在相同样本的含截距OLS回归中，加入一个解释变量后R²不会下降？这能否证明新变量重要？
参考答案： 新模型包含旧模型作为特例，OLS最小化的残差平方和不可能增加，而同一样本的SST不变，所以R²不下降。不能据此证明变量具有统计、经济或因果重要性。
实操／解释题： 延续上一课三组数据 (x,y)=(1,2)、(2,3)、(3,5)，已知OLS预测式为 $\hat y=1/3+1.5x$。计算 SSE、SST 与 R²，并解释其含义。
参考答案： 三个残差依次为 $1/6,-1/3,1/6$，故 SSE=1/6；样本均值 $\bar y=10/3$，SST=14/3；因此 $R^2=1-(1/6)/(14/3)=27/28\approx0.9643$。它表示相对于用样本均值预测，线性回归使这三个观测的样本内平方误差减少约96.43%，并不意味着x造成y的96.43%变化。
