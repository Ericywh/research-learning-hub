一、通俗理解

上一课区分了OLS点估计、外生性假设和标准误。本课进一步回答：回归得到一个非零系数，究竟有多少证据表明总体中的相应系数不等于零？

例如，汽车重量的估计系数为正，并不意味着总体重量系数一定为正。样本不同，估计值也会变化。t检验将估计值与其抽样不确定性放在一起衡量：相对于标准误，估计值离原假设规定的数值有多远？

检验通常从原假设（null hypothesis，记为H₀）出发，例如“控制车身长度后，重量的总体线性回归系数为零”。备择假设（H₁）则可以是“不等于零”（双侧）或“高于/低于某值”（单侧）。本课只讨论事先确定的双侧检验。

二、核心理论与公式

对含截距OLS模型中的第j个系数，检验H₀：βⱼ=βⱼ₀，t统计量为：

\[t=\frac{\widehat\beta_j-\beta_{j0}}{\widehat{se}(\widehat\beta_j)}\]

其中，β̂ⱼ是估计系数，βⱼ₀是原假设指定的数值，分母是该估计量的标准误。绝对值越大，样本估计与原假设相对于估计不确定性的偏离越明显。

p值是在原假设及检验所需概率模型成立时，得到至少同样极端检验统计量的概率；它不是“原假设为真的概率”。预先选定显著性水平α=0.05，若双侧p值小于0.05，则拒绝H₀；否则称“未拒绝”，而不是“证明H₀成立”。

与检验对应的双侧置信区间为：

\[\widehat\beta_j\ \pm\ t_{n-k-1,\,1-\alpha/2}\,\widehat{se}(\widehat\beta_j)\]

这里n为有效样本量，k为不含截距的解释变量数；t分位数对应n−k−1个残差自由度。若区间不包含βⱼ₀，对应双侧检验通常拒绝该原假设。

在经典同方差、条件正态等适当条件下，传统OLS t检验具有精确的小样本t分布。本课使用HC1异方差稳健标准误，其有效性通常依赖零条件均值、适当抽样/弱依赖和大样本条件；软件采用t分布计算p值与区间属于有限样本近似，不能宣称精确。

三、实证案例与数据

继续使用Stata Press公开的1978年汽车教学数据 auto.dta，原始文件有74条车型记录。变量为价格 price（美元）、重量 weight（磅）及车身长度 length（英寸），并定义 weight100=weight/100。仅保留这三个变量均非缺失的观测，两套软件使用同一完整案例样本。

研究问题是：在给定长度时，重量与价格的条件线性关联是否具有反对零系数的统计证据？这不是随机试验；即使拒绝零系数，也不能据此声称改变重量必然导致价格变化。

公开数据：Stata Press auto.dta。

4.2 Python

点击展开 Python 完整代码
import pandas as pd
import statsmodels.api as sm

url = "https://www.stata-press.com/data/r19/auto.dta"
cols = ["price", "weight", "length"]

# 与Stata一致的完整案例样本
df = pd.read_stata(url)[cols].dropna().copy()
df["weight100"] = df["weight"] / 100

y = df["price"]
X = sm.add_constant(df[["weight100", "length"]])

# HC1稳健协方差；use_t=True使用残差自由度的t分布
fit = sm.OLS(y, X).fit(cov_type="HC1", use_t=True)

print("有效样本量：", len(df))
print("重量系数：", fit.params["weight100"])
print("HC1标准误：", fit.bse["weight100"])
print("t统计量：", fit.tvalues["weight100"])
print("双侧p值：", fit.pvalues["weight100"])
print("95%置信区间：", fit.conf_int().loc["weight100"].tolist())

运行后核对两套软件的样本量、系数、HC1标准误、t值、p值及置信区间。仅比较软件默认输出时要留意：statsmodels未设置use_t=True可能采用正态近似，而Stata regress, vce(robust)使用残差自由度。

五、初学者避坑

误区一：p\<0.05就说明因果效应存在。 t检验检验的是指定模型中的总体系数，不能验证零条件均值、排除混杂或证明因果识别成立。

误区二：p>0.05就说明没有关联。 “未拒绝”可能源于估计不精确、样本量不足或真实效应较小；应同时检查估计值和区间宽度。

误区三：统计显著等于经济重要。 极小的系数在大样本中也可能显著。判断经济意义需要结合单位、效应大小和研究背景；事后反复更换模型寻找显著性还会破坏检验的名义错误率。

六、今日练习

概念题： 某研究得到双侧p值0.03，能否说“原假设有3%的概率是真的”？如果研究是观察性数据，能否直接称为因果效应？

参考答案： 都不能。p值是在原假设及模型条件成立时衡量数据极端程度的概率，不是原假设的后验概率；观察性回归的显著系数也不自动具备因果解释。

计算题： 纯教学例子中，重量系数估计值为120美元/100磅，HC1标准误为50，检验H₀：β=0。假设双侧5%临界值近似为2.0，计算t值和近似95%区间。

参考答案： t=120/50=2.4；近似区间为120±2.0×50，即\[20,220\]美元/100磅。由于\|t\|>2.0且区间不含零，在题设近似临界值下拒绝H₀；这仍不是重量的因果效应证据。
