一、通俗理解

本节围绕多重插补这一核心问题展开。多重插补需建立合理的条件模型形成多套填补数据，再按Rubin规则组合系数与插补内外方差。

稳健统计推断要审查抽样、缺失、测量、控制集合与多重检验。许多核心假设不能仅由同一份数据检验通过。理解方法时首先要区分总体参数、样本估计量和软件结果；一个模型能够运行，不代表研究问题已经被正确识别。读回归表前先确认观测单位、变量单位、比较对象与可观察证据。

直觉上问：这次比较改变了什么，哪些其他条件被控制，以及剩余不确定性来自抽样、设定还是无法观测的反事实？这些问题有助于防止只看显著性星号就作出超出证据范围的解释。

二、核心理论与公式

多重插补需建立合理的条件模型形成多套填补数据，再按Rubin规则组合系数与插补内外方差。 本课可用以下数学表达式把估计对象和条件写清：

\[\overline\theta=\frac1M\sum_{m=1}^M\widehat\theta_m\]

式中概率、期望、变换或估计系数的含义取决于具体变量与目标人群。模型是否可识别、估计器是否一致以及标准误是否正确，分别需要对应的秩条件、分布或误差结构假设。不能以更换HC1或增加样本量自动替代这些前提。

稳健统计推断要审查抽样、缺失、测量、控制集合与多重检验。许多核心假设不能仅由同一份数据检验通过。如果研究问题对应预测，需报告样本外表现；如果对应因果干预，必须另外定义潜在结果与处理分配机制。统计量的显著性不能推导出不存在遗漏变量、选择偏误或错误测量。

三、实证案例与数据

本课使用Stata官方汽车数据及透明构造的缺失模式。数据来源：Stata Press公开文件。核心变量为：价格price、重量weight、油耗mpg，并按固定行号将部分结果人为标为缺失以演示处理流程。

人为缺失只用于练习操作，不能证明现实数据满足MAR或MNAR，也不能代表真实插补性能。从原始数据到估计样本，应先检查缺失编码、变量量纲、重复观测和筛选标准；如果按主体或年份分组，还应检查键是否唯一。代码产生的结果只有在实际运行后才能引用。本次不报告没有经过计算核验的估计值、置信区间和检验p值。

四、Stata与Python实现

下列示例使用相同数据源或确定性数据生成过程，显示本节可复核的准备、估计或诊断步骤。对于尚未实现的方法专属估计与方差合并，正文会明确保留其限制。

Stata

展开 Stata 完整代码
use "https://www.stata-press.com/data/r19/auto.dta", clear
keep if !missing(price,weight,mpg)
gen double target=price
replace target=. if mod(_n,10)==0
misstable summarize target weight mpg
mi set mlong
mi register imputed target
mi register regular weight mpg
mi impute chained (regress) target=weight mpg, add(5) rseed(20261027)
mi estimate: regress target weight mpg

Python

展开 Python 完整代码
import numpy as np,pandas as pd,statsmodels.api as sm
from sklearn.experimental import enable_iterative_imputer
from sklearn.impute import IterativeImputer
df=pd.read_stata("https://www.stata-press.com/data/r19/auto.dta",convert_categoricals=False)
df=df[["price","weight","mpg"]].dropna().copy()
df["target"]=df.price.astype(float)
df.iloc[9::10,df.columns.get_loc("target")]=np.nan
completed=IterativeImputer(random_state=20261027).fit_transform(df[["target","weight","mpg"]])
print("插补后数值示例:",completed[:5])
# 单次插补不等于完整的Rubin多重插补方差合并

Stata执行多重插补，Python仅演示一次迭代填补；两端不属于完整等价推断，正式研究需独立实现多套填补与Rubin合并。核对两端结果时要检查观察数、类别编码、误差修正和默认自由度，而不是为了更小的p值任意选取软件。

五、初学者避坑

误区一：忽视模型与数据类型是否匹配。多重插补需建立合理的条件模型形成多套填补数据，再按Rubin规则组合系数与插补内外方差。这会改变参数的经济意义或有效比较集合。

误区二：把统计显著性误解为识别假设已经成立。稳健统计推断要审查抽样、缺失、测量、控制集合与多重检验。许多核心假设不能仅由同一份数据检验通过。基于观察数据的OLS、FE与其他模型仍需额外论证条件。

误区三：没有说明软件与样本的差别。Stata执行多重插补，Python仅演示一次迭代填补；两端不属于完整等价推断，正式研究需独立实现多套填补与Rubin合并。发表或提交分析前必须保留代码版本、数据来源、筛选数量、标准误结构和不利结果。
