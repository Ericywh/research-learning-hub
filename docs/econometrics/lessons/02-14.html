一、通俗理解

汽车价格与车重、车长、油耗之间有统计关联。但车重与车长也可能高度相关：只看一辆车更重，很难分清价格变化究竟与重量还是车身长度相关。多重共线性就是解释变量之间存在较强线性依赖，使我们难以精确区分各自的条件关联。它并不自动意味着模型有内生性，更不能据此宣称系数有偏。完全共线性导致设计矩阵不满列秩、系数不能唯一识别；不完全共线性则通常体现为估计精度下降。

二、核心理论与公式

令价格为因变量，车重、车长、每加仑英里数为解释变量，含截距的模型为：

\[price_i=\beta_0+\beta_1weight_i+\beta_2length_i+\beta_3mpg_i+u_i.\]

对第 j 个非截距解释变量，先用其他解释变量（含截距）对它做辅助回归，得到决定系数 R²_j。其方差膨胀因子为：

\[VIF_j=\frac{1}{1-R_j^2},\quad \operatorname{Var}(\hat\beta_j\mid X)=\frac{\sigma^2}{\sum_i(x_{ij}-\bar x_j)^2(1-R_j^2)}.\]

右侧方差分解要求线性模型满列秩、给定X误差同方差且不相关；若采用异方差稳健标准误，该分解不再是稳健方差的精确表达式。VIF仍可作为设计矩阵的共线性诊断。固定其他量，R²_j越接近1，信息越少，系数标准误可能越大。共线性与外生性是两个不同问题。

三、实证案例与数据

采用Stata官方1978年汽车数据 auto.dta（74辆汽车，12个原始变量），仅使用 price、weight、length、mpg 四列的完整观测。price为价格，weight为磅数，length为英寸，mpg为燃油经济性。比较车重和车长的VIF，并观察二者同时进入回归时的系数精度。样本规模较小，仅作教学演示；不是随机分配的因果实验。数据说明：https://www.stata.com/links/stata-basics/example-datasets/ 。

Python · 展开可复制代码

import pandas as pd

import statsmodels.api as sm

import statsmodels.formula.api as smf

from statsmodels.stats.outliers_influence import variance_inflation_factor



# Stata官方1978汽车数据；与Stata选择相同变量及完整观测

url = "https://www.stata-press.com/data/r19/auto.dta"

cols = ["price", "weight", "length", "mpg"]

df = pd.read_stata(url)[cols].dropna().copy()

print("样本量:", len(df))

# 与Stata regress, vce(robust)相对应的HC1协方差

fit = smf.ols("price ~ weight + length + mpg", data=df).fit(cov_type="HC1")

print(fit.summary())

# VIF计算必须包含截距列，但不解释截距VIF

X = sm.add_constant(df[["weight", "length", "mpg"]], has_constant="add")

for j, name in enumerate(X.columns):

    if name != "const":

        print(name, variance_inflation_factor(X.to_numpy(), j))

五、初学者避坑

1. 不要把VIF大于5或10当作自动删除变量的硬性标准。删去理论上必要的控制变量可能引入遗漏变量偏误；应先判断变量是否有独立理论含义，再看估计目标与置信区间。

2. 不能把高共线性解释成系数必然有偏。若外生性成立且设计矩阵满列秩，OLS仍可无偏；若外生性不成立，降低VIF也不能修复因果识别。

3. 两两相关系数低不代表不存在多元线性依赖；VIF需将某一列对其余所有解释变量回归。VIF也不能替代异方差、异常值或模型设定诊断。

六、今日练习

概念题：两个解释变量VIF都很高，能否直接断定OLS估计有偏并删除其中一个？<br />答案：不能。VIF衡量设计矩阵的线性依赖与潜在精度损失，不检验外生性；删变量必须有理论与识别依据。

计算题：某变量辅助回归R²=0.90，求VIF，并说明在同方差、固定该变量总离差平方和与误差方差的比较基准下，标准误相对无共线性基准扩大多少倍。<br />答案：VIF=1/(1−0.90)=10；标准误的比例为√10≈3.16。该比例不应机械用于比较两个实际重估模型，因为残差方差和其他条件可能改变。
