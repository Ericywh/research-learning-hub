一、通俗理解

为什么同样工作一小时，不同劳动者的工资会不同？教育年限、累计工作经验、当前岗位任职年限，以及工会身份、婚姻状态等，都可能与工资有关。但这些变量往往彼此相关：教育较多者的职业经历可能不同，工会成员也可能集中在特定行业。因此，仅把工资对教育做一元回归，与同时控制其他可观测特征的多元回归，回答的不是完全相同的问题。

本课把前14节知识合并成一次完整实操：明确研究问题，筛选样本，定义变量，估计两个OLS模型，使用稳健标准误，并解释系数、置信区间和联合检验。这里研究的是条件统计关联，不是教育、工会或婚姻对工资的因果效应。

二、核心理论与公式

设 \(wage_i\) 为正的小时工资，\(grade_i\) 为已完成教育年级，\(ttl\_exp_i\) 为累计工作经验年数，\(tenure_i\) 为现岗位任职年数，\(union_i\) 和 \(married_i\) 为0/1变量；\(D_{2i},D_{3i}\) 表示种族类别2和3，类别1作为参照组。完整模型为：

\[\ln(wage_i)=\beta_0+\beta_1grade_i+\beta_2ttl\_exp_i+\beta_3tenure_i+\gamma_1union_i+\gamma_2married_i+\delta_2D_{2i}+\delta_3D_{3i}+u_i.\]

在其他解释变量保持不变时，\(\beta_1\) 是教育年级增加一单位对应的条件平均对数工资差；对应条件几何平均工资的精确百分比差为：

\[100\bigl(e^{\beta_1}-1\bigr)\%,\qquad \text{当 }|\beta_1|\text{ 较小时近似为 }100\beta_1\%.\]

OLS需设计矩阵满列秩；若要把系数解释为结构性因果效应，还需有可信的外生性和识别论证。HC1稳健协方差针对异方差下的渐近推断，并不修复内生性；在独立抽样及适当矩条件下使用更为合理。

三、实证案例与数据

使用Stata官方教学数据 NLSW88（1988年美国青年女性纵向调查摘录），原始文件有2,246条记录、17个变量。数据是经处理的调查摘录，Stata提醒其示例数据可能为教学目的修改，不应据此作现实政策推断。本课只保留 \(wage>0\) 且 \(grade\)、\(ttl\_exp\)、\(tenure\)、\(union\)、\(married\)、\(race\) 均非缺失的观测。最终样本量由代码实际输出，不预填数值。

数据文件：Stata Press NLSW88；官方示例数据说明。两个软件读取同一网址，避免因版本或缺失值处理不同导致样本不一致。

四、Stata与Python实现

先在同一完整样本上估计 \(\ln(wage)\) 对 \(grade\) 的简单回归，再加入经验、任职年限、工会、婚姻与种族类别。Stata的 <code>vce(robust)</code> 与Python的 <code>cov_type="HC1"</code> 在相同设计矩阵和样本下采用可比的HC1类标准误。比较教育系数、稳健标准误、置信区间与 \(R^2\)，再联合检验工会和婚姻两个系数是否为零。代码未经本次运行，以下不报告任何估计数值。

Python · 展开可复制代码
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

# 与Stata读取完全相同的公开教学数据版本
url = "https://www.stata-press.com/data/r19/nlsw88.dta"
df = pd.read_stata(url, convert_categoricals=False)
cols = ["wage", "grade", "ttl_exp", "tenure", "union", "married", "race"]

# 工资为正且所有建模变量非缺失：与Stata保持相同口径
df = df.loc[df["wage"] > 0, cols].dropna().copy()
df["lnwage"] = np.log(df["wage"])
print("完整样本量：", len(df))
print(df[["wage", "grade", "ttl_exp", "tenure"]].describe())

# race=1为基准组；union、married为0/1变量
m1 = smf.ols("lnwage ~ grade", data=df).fit(cov_type="HC1")
m2 = smf.ols(
    "lnwage ~ grade + ttl_exp + tenure + union + married + "
    "C(race, Treatment(reference=1))", data=df
).fit(cov_type="HC1")

for name, fit in [("单变量模型", m1), ("多变量模型", m2)]:
    print("\n", name, "N=", int(fit.nobs))
    print(fit.summary())
    print("95%稳健置信区间：\n", fit.conf_int())

print("grade精确百分比：", 100*(np.exp(m2.params["grade"])-1))
print("union、married联合Wald检验：", m2.f_test("union = 0, married = 0"))

阅读输出时先核对两个模型的样本量是否一致，再区分“控制变量后系数变化”和“发现遗漏变量偏误”这两个不同判断。后者需要更强的模型与识别假设。

五、初学者避坑

  1. 样本选择：本数据仅涉及调查中的女性，并且分析只包括有正工资、关键变量完整的观测。不能推广到全部劳动者；就业选择与缺失机制也可能影响解释。
  2. 系数解释：\(\ln(wage)\) 的系数不是工资金额变化。对二元变量也应使用 \(100(e^{\hat\gamma}-1)\%\) 解释条件几何平均工资的比例差；若解释算术平均工资，需要额外分布或再转换假设。
  3. 推断与因果：HC1允许一定形式的异方差，但不能消除能力、家庭背景、行业选择等未观测混杂。显著性不等于经济重要性，\(R^2\) 较高也不等于识别成功。

六、今日练习

CONCEPT · 概念题

概念题：将 \(ttl\_exp\) 和 \(tenure\) 加入回归后，\(grade\) 的估计系数发生变化，是否足以证明原模型存在教育的因果偏误？

查看参考答案

答案：不足以。系数变化说明控制变量改变了条件比较；是否构成因果偏误还取决于这些变量的角色、外生性、选择机制与正确设定。工作经验甚至可能是教育影响工资的中介，控制后目标效应也会改变。

APPLICATION · 计算题

计算题：假设某次回归得到教育系数 \(\hat\beta_1=0.08\)（纯假设，不是NLSW88结果），教育年级多一年对应的条件几何平均工资精确百分比差是多少？

查看参考答案

答案：\(100(e^{0.08}-1)\%\approx8.33\%\)；线性近似为8%，不应写成工资必然上涨8.33%。
