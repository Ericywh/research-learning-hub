一、通俗理解

本课研究《RDD带宽选择与估计》的核心问题。RDD带宽决定局部比较的偏差和方差，选取带宽与多项式阶数应有可说明的原则。理解这一问题时，不应从软件命令倒推出研究设计，而应先确定研究对象、估计量和数据提供的变异。识别假设、比较对象和统计推断构成解释结果的共同基础。判断统计关联是否可以上升为因果解释，必须给出额外可辩护的识别条件。

直觉上先问“相对于哪个对照，改变了什么、未观测因素是否可比”，再写回归方程。即使数据非常多或结果显著，也不能省略这一步。对于方法不匹配的公开示例，宁可明确使用教学模拟，也不能伪装为可信的现实因果证据。

二、核心理论与公式

本节重要的数学表达式如下。RDD带宽决定局部比较的偏差和方差，选取带宽与多项式阶数应有可说明的原则。式中的下标、参数和条件必须由数据结构与研究目的界定。涉及潜在结果时，要区分可观察结果和反事实；涉及协方差或条件均值时，应明确是总体假设还是样本估计。任何公式只有在相应外生性、满秩、时间结构或连续性条件下才具备预期的识别意义。

\[\widehat\tau(h)=\widehat m_+(c;h)-\widehat m_-(c;h)\]

检验与估计所需的矩条件、概率模型或识别假设要与这里的对象一致：完全共线性影响参数可识别性；异方差主要影响常规协方差估计；内生性则可能破坏OLS的一致性。不要以为使用HC1就能同时解决这些问题。

四、Stata与Python实现

以下Stata和Python采用相同数据文件或相同透明模拟公式，目的是让估计流程可以复核。不能将未实际执行的程序输出标记为“已运行”。

Stata

展开 Stata 完整代码
clear
set obs 201
gen double i=_n
gen double running=(i-101)/25
gen byte treat=running>=0
gen double y=1+.3*running+1.2*treat+.2*sin(i)
keep if abs(running)<=1
regress y i.treat##c.running, vce(robust)

Python

展开 Python 完整代码
import numpy as np,pandas as pd
import statsmodels.formula.api as smf
i=np.arange(1,202,dtype=float);r=(i-101)/25
d=(r>=0).astype(int);y=1+.3*r+1.2*d+.2*np.sin(i)
df=pd.DataFrame({"y":y,"running":r,"treat":d})
df=df[df.running.abs()<=1]
fit=smf.ols("y ~ C(treat)*running",df).fit(cov_type="HC1")
print(fit.summary())

两端是相同确定性模拟数据上的局部线性示范，不能替代RDD稳健偏差校正和实际阈值不可操纵的论证。若两端自由度、小样本修正或处理变量定义不同，应先核对这些选择，再比较系数和标准误；不能为了获得更小p值而选择软件。
