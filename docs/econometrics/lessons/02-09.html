第2章·第9节｜虚拟变量

全课程第16课 / 共120课 · 原授课日期：2026-10-22

历史授课内容整理版（非逐字原文）。未实际执行的软件结果不予虚构。

一、通俗理解

回归模型既可以使用重量、长度这样的连续变量，也能纳入汽车是否进口、企业是否获得补贴、地区是否实施政策等二分类特征。把条件成立的观测编码为1、另一组编码为0，就得到虚拟变量（dummy variable）。例如在1978年汽车样本中，以foreign=0表示国产车，foreign=1表示进口车。与单纯比较两组均价不同，加入重量和长度后，回归中的进口车系数表示在控制这两个变量条件下的价格预测差异。这是模型中的条件关联，不自动表示进口身份使汽车价格提高。

二、核心理论与公式

以国产车为基准组，设重量按100磅计量，长度按英寸计量，考虑含截距的加性OLS模型：

\[price_i=\beta_0+\beta_1foreign_i+\beta_2weight100_i+\beta_3length_i+u_i.\]

如果条件均值函数满足上述线性加性形式，且保持重量与长度固定，则两组的条件预测差异为：

\[E(price\mid foreign=1,W,L)-E(price\mid foreign=0,W,L)=\beta_1.\]

模型把这一差异约束为固定值；若两组具有不同重量斜率，则应在下一课加入交互项。系数识别需要满列秩，统计关联并不自动满足因果所需的外生性条件。

三、实证案例与数据

使用Stata Press官方1978年汽车示例数据auto.dta，原始数据为74条汽车记录。变量为price（美元）、foreign（二值：0国产、1进口）、weight（磅）和length（英寸）。两端程序均仅保留四列无缺失的观测，再构造weight100=weight/100；最终有效样本量以程序实际输出为准。样本为教学资料，不能代表今天整个汽车市场，也不是进口身份因果效应的识别设计。

Python

点击展开 Python 完整代码
import pandas as pd
import statsmodels.api as sm

url = "https://www.stata-press.com/data/r18/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
cols = ["price", "foreign", "weight", "length"]
df = df[cols].dropna().copy()
df["foreign"] = df["foreign"].astype(int)
df["weight100"] = df["weight"] / 100
X = sm.add_constant(df[["foreign", "weight100", "length"]])
fit = sm.OLS(df["price"], X).fit(cov_type="HC1", use_t=True)
print("有效样本量：", len(df))
print("两组观测：", df["foreign"].value_counts().sort_index())
print(fit.summary())
print("进口车系数及95%置信区间：",
      fit.params["foreign"], fit.conf_int().loc["foreign"].tolist())

两个软件采用相同样本、含截距OLS、基准组和HC1设定；未经实际运行，不填造回归系数或显著性结果。

五、初学者避坑

误区一：把水平模型的进口车系数解释成百分比。本课因变量price的单位为美元，系数也以美元计量。

误区二：在含截距模型里同时纳入互斥且完备的两组虚拟变量。由于两列之和为1，它们与截距列完全共线，应省去一个基准类别。

误区三：把控制重量与长度后的组间差异解释成进口身份的因果作用。品牌、配置、质量等遗漏变量可能仍然构成混杂。

六、今日练习

概念题：为什么含截距OLS不能同时估计国产车、进口车两个互斥且完备的虚拟变量系数？

参考答案

两个虚拟变量逐行相加等于截距列1，设计矩阵不满列秩；应保留一组作为基准类别。

计算题：纯教学例子中，若进口车的估计系数为1800，该怎样解释？

参考答案

在线性加性规格中，重量、长度相同条件下，进口车拟合价格比国产车高1800美元。该数字为构造例子，并非运行结果，也不是因果效应。
