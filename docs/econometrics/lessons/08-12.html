一、通俗理解

本节围绕统计可靠性综合审查这一核心问题展开。统计可靠性审查要同时覆盖采样、变量、缺失、估计方法、误差结构、识别假设和代码可复现。

稳健统计推断要审查抽样、缺失、测量、控制集合与多重检验。许多核心假设不能仅由同一份数据检验通过。理解方法时首先要区分总体参数、样本估计量和软件结果；一个模型能够运行，不代表研究问题已经被正确识别。读回归表前先确认观测单位、变量单位、比较对象与可观察证据。

直觉上问：这次比较改变了什么，哪些其他条件被控制，以及剩余不确定性来自抽样、设定还是无法观测的反事实？这些问题有助于防止只看显著性星号就作出超出证据范围的解释。

二、核心理论与公式

统计可靠性审查要同时覆盖采样、变量、缺失、估计方法、误差结构、识别假设和代码可复现。 本课可用以下数学表达式把估计对象和条件写清：

\[\widehat\theta\pm c_\alpha\widehat{SE}(\widehat\theta)\]

式中概率、期望、变换或估计系数的含义取决于具体变量与目标人群。模型是否可识别、估计器是否一致以及标准误是否正确，分别需要对应的秩条件、分布或误差结构假设。不能以更换HC1或增加样本量自动替代这些前提。

稳健统计推断要审查抽样、缺失、测量、控制集合与多重检验。许多核心假设不能仅由同一份数据检验通过。如果研究问题对应预测，需报告样本外表现；如果对应因果干预，必须另外定义潜在结果与处理分配机制。统计量的显著性不能推导出不存在遗漏变量、选择偏误或错误测量。

三、实证案例与数据

本课使用Stata官方1978年汽车示例auto.dta。数据来源：Stata Press公开文件。核心变量为：价格price、重量weight、油耗mpg、进口标记foreign，示例展示研究数据完整案例与OLS推断。

这里是通用的数据工作流和基线回归，不构成该高级统计主题的专用因果识别。从原始数据到估计样本，应先检查缺失编码、变量量纲、重复观测和筛选标准；如果按主体或年份分组，还应检查键是否唯一。代码产生的结果只有在实际运行后才能引用。本次不报告没有经过计算核验的估计值、置信区间和检验p值。

四、Stata与Python实现

下列示例使用相同数据源或确定性数据生成过程，显示本节可复核的准备、估计或诊断步骤。对于尚未实现的方法专属估计与方差合并，正文会明确保留其限制。

count

Python

展开 Python 完整代码
import pandas as pd,statsmodels.formula.api as smf
df=pd.read_stata("https://www.stata-press.com/data/r19/auto.dta",convert_categoricals=False)
df=df[["price","weight","mpg","foreign"]].dropna()
r=smf.ols("price ~ weight + mpg + C(foreign)",df).fit(
 cov_type="HC1",use_t=True)
print("N:",len(df));print(r.summary())

同一公开数据的OLS代码可以核对样本、变量定义和HC1标准误；DAG、敏感性或论文写作的识别工作不能仅凭该OLS完成。核对两端结果时要检查观察数、类别编码、误差修正和默认自由度，而不是为了更小的p值任意选取软件。

五、初学者避坑

误区一：忽视模型与数据类型是否匹配。统计可靠性审查要同时覆盖采样、变量、缺失、估计方法、误差结构、识别假设和代码可复现。这会改变参数的经济意义或有效比较集合。

误区二：把统计显著性误解为识别假设已经成立。稳健统计推断要审查抽样、缺失、测量、控制集合与多重检验。许多核心假设不能仅由同一份数据检验通过。基于观察数据的OLS、FE与其他模型仍需额外论证条件。

误区三：没有说明软件与样本的差别。同一公开数据的OLS代码可以核对样本、变量定义和HC1标准误；DAG、敏感性或论文写作的识别工作不能仅凭该OLS完成。发表或提交分析前必须保留代码版本、数据来源、筛选数量、标准误结构和不利结果。
