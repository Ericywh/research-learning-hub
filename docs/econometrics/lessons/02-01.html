一、通俗理解

为什么同样是汽车，有的价格高，有的价格低？我们先只研究一个因素：汽车重量与价格之间有什么关系。把每辆汽车画成一个点，横轴是重量，纵轴是价格，通常会看到一群并不完全排成直线的点。一元线性回归就是用一条直线概括两者的平均线性关系。
“一元”指模型只有一个解释变量；“线性”指预测价格随重量变化的斜率是常数；“回归”指用样本数据估计这种关系。它回答的是“重量多100磅，预测价格平均相差多少”，而不是“把汽车人为加重100磅，就一定涨价多少”。

二、核心理论与公式

总体模型写为：

$$price_i=\beta_0+\beta_1 weight100_i+u_i$$

其中，$price_i$是第$i$辆汽车的美元价格，$weight100_i$是重量除以100后的数值（单位：100磅），$\beta_0$是重量为零时直线的截距，通常没有现实经济解释；$\beta_1$是重量增加100磅时的线性预测价格差；$u_i$是没有被重量解释的其他价格因素，如品牌、性能和配置。
用样本估计后，得到预测式：

$$\widehat{price}_i=\hat\beta_0+\hat\beta_1 weight100_i$$

帽号表示由数据估计出来的数值；实际价格减去预测价格叫残差。本课先学会读斜率与画拟合线，下一课再解释普通最小二乘法（OLS）如何确定这条线。
要让斜率具有稳定的统计意义，需要观测之间的抽样机制适当、重量有变化、模型形式适合研究目的。若希望把斜率解释为因果效应，还需要更强的零条件均值假设：在给定重量后，误差项中影响价格的因素与重量不再系统相关，即$E(u_i\mid weight100_i)=0$。汽车品牌、发动机配置可能同时影响重量和价格，因此这一条件未必成立。异方差稳健标准误只能改善部分推断，不能修复这一识别问题。

三、实证案例与数据

使用Stata官方1978年汽车示例数据auto.dta，它是汽车车型的截面数据：每行是一款车型，不是同一车型跨年的记录。原始数据有74条记录；本课仅用price（美元）和weight（磅），并删除这两列的缺失值。数据地址：https://www.stata-press.com/data/r19/auto.dta 。
问题：较重的汽车是否通常卖得更贵？ 我们估计的是样本中的线性关联，不能仅凭这一个回归证明重量导致价格变化。

四、Stata与Python实现

4.1 Stata

Stata
* 加载Stata官方汽车数据
sysuse auto, clear
keep if !missing(price, weight)
generate weight100 = weight / 100

* 一元线性回归，采用HC1型异方差稳健标准误
regress price weight100, vce(robust)

* 散点与样本拟合直线
twoway (scatter price weight100) ///
       (lfit price weight100), legend(off)

读输出时重点看weight100的系数：正数表示较重车型的预测价格较高；负数则相反。系数单位是“美元/100磅”。$R^2$表示这条样本拟合线解释了多少比例的样本价格离差平方和，并不表示因果解释力。

4.2 Python

先安装依赖：pip install pandas matplotlib statsmodels

Python
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.formula.api as smf

# 读取与Stata相同的数据，统一样本和变量
url = "https://www.stata-press.com/data/r19/auto.dta"
d = pd.read_stata(url, convert_categoricals=False)
d = d[["price", "weight"]].dropna().copy()
d["weight100"] = d["weight"] / 100

# 相同的一元模型，HC1稳健标准误对应Stata的vce(robust)
m = smf.ols("price ~ weight100", data=d).fit(cov_type="HC1")
print(m.params)
print(m.bse)
print("R² =", m.rsquared, "样本量 =", int(m.nobs))

# 画散点与拟合线
x = d["weight100"].sort_values()
plt.scatter(d["weight100"], d["price"], alpha=0.7)
plt.plot(x, m.predict(pd.DataFrame({"weight100": x})))
plt.xlabel("重量（100磅）")
plt.ylabel("价格（美元）")
plt.tight_layout()
plt.show()

两套代码使用相同的样本、变量和含截距模型；HC1的有限样本调整也与这里的Stata稳健标准误口径对应。本次没有实际执行回归，因此不提供未经核验的系数、标准误或显著性结论。你运行后应比较两套软件的斜率、样本量及标准误。

五、初学者避坑

  1. 单位不能忽略。 $weight100$增加1，代表重量增加100磅，不是1磅；换单位会改变斜率的数值，不改变拟合结果。
  2. 拟合线不经过每个点。 残差反映实际价格与拟合价格的差异；残差大不必然意味着数据错误。
  3. 一元回归不能自动识别因果。 高价车型也可能因为更大、更豪华而更重，遗漏因素会影响斜率的因果解释。

六、今日练习

概念题： 一元回归中$\hat\beta_1=150$，解释变量是$weight100$。应如何解释？可以直接说“加重汽车使价格上涨150美元”吗？
实操题： 把Python代码中的print(m.params)改成只打印重量系数，并计算“重量相差200磅时的预测价格差”的表达式。
参考答案：

  1. 斜率150表示重量相差100磅的车型，其线性预测价格相差150美元；不能直接作因果解释，因为零条件均值假设未获证明。此处150仅为练习假设值，不是本数据的估计结果。
  2. print(m.params["weight100"])；预测价格差为2 * m.params["weight100"]美元，因为200磅对应$weight100$相差2。
