第3章·第4节｜双向因果和同时性

一、通俗理解

鱼市场中，价格上升可能使消费者减少购买，这是需求规律；但当天捕捞量减少也会同时推高价格、压低成交量。我们看到的价格和数量，是供给与需求共同作用后的市场均衡结果。直接把成交量对价格做回归，斜率未必是需求曲线的斜率。

所谓双向因果，是两个经济变量存在相互作用；同时性更具体，指多个内生变量在同一个方程组中联合决定。研究者在回归式左边写“数量”、右边写“价格”，不会让价格自动成为外生变量。需要把经济行为方程与市场均衡条件分开理解。

二、核心理论与公式

考虑线性供需系统，其中 \(P_i\) 是价格，\(Q_i^d,Q_i^s\) 是需求量和供给量，\(u_i^d,u_i^s\) 分别为需求、供给冲击，\(b,d>0\)：

\[Q_i^d=a-bP_i+u_i^d,\qquad Q_i^s=c+dP_i+u_i^s,\qquad Q_i^d=Q_i^s.\]

联立均衡条件可得：

\[P_i=\frac{a-c+u_i^d-u_i^s}{b+d}.\]

因此价格包含需求冲击 \(u_i^d\)。在冲击相互独立且需求冲击方差非零时，价格与需求方程误差正相关，需求方程的OLS外生性条件失效；其斜率可能比真实的负需求斜率更接近零，甚至变号。推导依赖线性系统、稳定的均衡关系及冲击假设；现实市场还可能存在动态调整、预期与测量误差。

区分“需求曲线移动”和“沿需求曲线移动”是本课的关键。识别需求弹性通常需要只移动供给、不直接改变需求的外生变异，例如有充分依据的天气冲击；工具变量的相关性和排除限制必须另行论证。

三、实证案例与数据

使用Wooldridge计量经济学教材数据包的Fulton Fish Market（纽约富尔顿鱼市场）数据，来源为Graddy（1995）的市场研究。公开CSV含97条日度观测，变量包括数量加权平均价格 \`avgprc\`、总成交量 \`totqty\`、星期一至星期四指示变量 \`mon\`、\`tues\`、\`wed\`、\`thurs\`，以及此前两天海浪高度指标 \`wave2\`。周五作为省略的基准日。

数据：公开CSV；变量说明（Wooldridge数据包）。

保留上述变量均非缺失、价格和数量为正的日观测，生成价格和数量的自然对数。先估计数量—价格关联，再用海浪指标解释价格的变化。后者仅作供给冲击相关性的探索，不构成有效工具变量的证明；日度数据还可能有序列相关，HC1不能替代时间序列稳健推断。

四、Stata与Python实现

两端使用同一CSV、同一筛选、同一含截距OLS模型及HC1异方差稳健标准误。以下代码未实际运行，不填报估计系数或显著性结果。

Stata

* 富尔顿鱼市场：同一公开CSV与共同样本
clear all
set more off
import delimited "https://raw.githubusercontent.com/vincentarelbundock/Rdatasets/master/csv/wooldridge/fish.csv", clear varnames(1)

keep if !missing(avgprc, totqty, mon, tues, wed, thurs, wave2)
keep if avgprc > 0 & totqty > 0
gen double lnprice = ln(avgprc)
gen double lnqty   = ln(totqty)
count

* 均衡数量对价格的条件关联，HC1
regress lnqty lnprice mon tues wed thurs, vce(robust)

* 海浪与均衡价格的条件关联；不是IV估计
regress lnprice wave2 mon tues wed thurs, vce(robust)

Python

# pip install pandas numpy statsmodels
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

url = "https://raw.githubusercontent.com/vincentarelbundock/Rdatasets/master/csv/wooldridge/fish.csv"
df = pd.read_csv(url)
cols = ["avgprc", "totqty", "mon", "tues", "wed", "thurs", "wave2"]
df = df.dropna(subset=cols).copy()
df = df.loc[(df["avgprc"] > 0) & (df["totqty"] > 0)].copy()
df["lnprice"] = np.log(df["avgprc"])
df["lnqty"] = np.log(df["totqty"])
print("共同样本量：", len(df))

# 与Stata相同的OLS、HC1及t参考分布
m1 = smf.ols("lnqty ~ lnprice + mon + tues + wed + thurs",
             data=df).fit(cov_type="HC1", use_t=True)
m2 = smf.ols("lnprice ~ wave2 + mon + tues + wed + thurs",
             data=df).fit(cov_type="HC1", use_t=True)
print(m1.summary())
print(m2.summary())

比较两端样本量、系数及HC1标准误；若将第一式的价格系数直接称为需求价格弹性，便忽略了同时决定机制。第二式也不能仅凭显著性证明海浪满足工具变量排除限制。

五、初学者避坑

  1. 把市场均衡点的回归斜率当作结构性需求曲线斜率，混淆了均衡关联与需求响应。
  2. 认为增加星期虚拟变量或使用HC1即可消除同时性；这些操作不改变价格与结构冲击的相关机制。
  3. 认为天气与价格显著相关就一定是有效工具变量；仍需论证天气不直接影响需求，并考虑动态相关与其他渠道。

六、今日练习

概念题： 为什么在鱼市场数据中，直接回归成交数量对价格通常不能识别需求价格弹性？

答案： 供给与需求冲击共同决定均衡价格和数量；价格可能与需求结构误差相关。OLS得到的是均衡数据的条件线性关联，不能直接视为沿需求曲线移动的因果效应。

计算题： 在线性供需系统中，设 \(b=2\)、\(d=3\)，其他条件不变，需求冲击增加1单位，均衡价格变化多少？

答案： 由第二个公式，价格增加 \(1/(2+3)=0.2\) 单位。需求冲击进入均衡价格，直观说明价格不是独立于需求误差形成的。数值为教学假设，不是鱼市场数据估计结果。
