一、通俗理解

假设我们用受教育年限解释工资。回归系数可能同时反映教育与工资的关系，以及能力、家庭背景等未观测因素的影响。如果这些因素既影响工资，又与教育相关，回归中的“教育变量”便与误差项相关，这就是线性结构模型中的典型内生性。样本再大，也不能仅凭普通最小二乘法（OLS）把教育系数解释为教育的因果回报。

关键区别在于：OLS总能计算一条拟合直线，但“拟合得好”“系数显著”与“识别出因果效应”是三个不同命题。内生性关心的是模型对目标参数的识别是否可靠，不只是标准误大小。

二、核心理论与公式

设$x_i$包含截距及所有解释变量，$u_i$是结构误差，目标参数为$\beta$。常用的外生性矩条件是：

y_i=x_i^{\prime}\beta+u_i,\qquad E[x_i u_i]=0.

如果样本满足适当的大数定律、有关矩存在，且$Q=E[x_i x_i^{\prime}]$可逆，则OLS的概率极限为：

\operatorname{plim}\widehat\beta_{OLS}=\beta+Q^{-1}E[x_i u_i].

第二项说明内生性如何造成渐近偏差：只要$E[x_i u_i]\ne0$，通常就无法一致估计结构参数。条件均值为零$E[u_i\mid x_i]=0$是上述正交条件的充分条件，但并非同一概念。有限样本偏差与不一致也不能混为一谈。实际研究中的常见来源包括遗漏共同决定因素、解释变量测量误差、双向因果或同时性，以及特定样本选择机制；它们是否存在必须结合具体模型判断。

即使改用HC1稳健标准误，也只是调整异方差条件下的方差估计，不能消除$E[x_i u_i]\ne0$。此时围绕结构参数的常规$t$检验和置信区间可能缺乏有效依据。

三、实证案例与数据

使用Stata公开教学数据NLSW88，它是美国青年女性纵向调查的1988年截面提取数据，原始文件约2246条观测。变量包括小时工资wage、受教育年限grade、累计工作经验ttl_exp、任职年限tenure及年龄age。两套代码均仅保留这五个变量非缺失且工资为正的观测，并构造工资对数；最终回归样本量以运行后输出为准。

比较“教育、经验、任职年限”和“再加入年龄”的两个工资方程。教育系数变化可用于理解控制变量与模型设定的敏感性，却不能证明年龄是遗漏混杂因素，也不能证明加入年龄后教育已外生。数据没有直接观测能力等潜在因素，而且样本只覆盖特定女性群体，不能直接外推总体或认定教育因果效应。

Python

# pip install pandas statsmodels
# NLSW88：与Stata读取同一个公开.dta文件；代码未在此运行
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

url = "https://www.stata-press.com/data/r17/nlsw88.dta"
df = pd.read_stata(url, convert_categoricals=False)
cols = ["wage", "grade", "ttl_exp", "tenure", "age"]
df = df.dropna(subset=cols).copy()
df = df.loc[df["wage"] > 0].copy()
df["lnwage"] = np.log(df["wage"])
print("共同样本量：", len(df))
m1 = smf.ols("lnwage ~ grade + ttl_exp + tenure", data=df).fit(cov_type="HC1")
m2 = smf.ols("lnwage ~ grade + ttl_exp + tenure + age", data=df).fit(cov_type="HC1")
print(m1.summary())
print(m2.summary())
print("grade系数变化：", m2.params["grade"] - m1.params["grade"])

读结果时依次检查共同样本量、grade系数变化、HC1标准误及置信区间。系数变化本身既不是内生性检验，也不是因果效应的估计。若要识别教育回报，仍须讨论可信的外生变异或工具变量及其识别假设。

五、初学者避坑

1. OLS残差与样本解释变量正交，是含截距OLS的代数性质；不能据此推断总体结构误差外生。 2. 增加控制变量可能减少遗漏偏误，也可能引入碰撞变量或后处理偏误；不能以“控制得越多越好”替代因果结构分析。 3. 稳健标准误解决的是特定方差估计问题，不会修复内生性；显著的回归系数也不自动具有因果含义。

六、今日练习

概念题： 回归后发现教育年限与OLS残差的样本协方差为零，能否据此认定教育外生？

答案： 不能。OLS一阶条件本来就要求样本残差与回归变量正交；外生性要求的是未观测结构误差满足相应总体矩条件，两者不同。

计算题： 在含截距的一元结构模型中，若$\operatorname{Var}(x)=4$，$\operatorname{Cov}(x,u)=1$，且适用概率极限公式，OLS斜率的渐近偏差是多少？改用HC1标准误会改变它吗？

答案： 渐近偏差为$\operatorname{Cov}(x,u)/\operatorname{Var}(x)=1/4=0.25$；HC1只影响方差估计，不改变OLS斜率点估计及其概率极限。
