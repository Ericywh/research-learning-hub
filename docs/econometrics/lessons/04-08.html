1 · 核心问题与推导

不同时间实施政策时，TWFE可能用已处理队列作其他队列的对照。效应随队列或暴露时间异质时，比较会污染目标，甚至出现负隐含权重。组别时间方法先定义ATT(g,t)，以从未处理或尚未处理者为对照，估计单元后透明聚合。本课实验用从未处理组与g−1基期构造简单组别时间差分，帮助理解目标量；它不等于完整CS-DID的双重稳健估计和影响函数推断。

2 · 公式与统计前提

ATT(g,t)=E[Y_t−Y_g−1|G=g]−E[Y_t−Y_g−1|G=∞]

尚未处理对照要排除预期窗口；不同聚合权重对应不同目标，不能无说明地混用。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
rng=np.random.default_rng(20261027);N=900;T=9
cohort=np.repeat([3,5,99],N//3);a=rng.normal(size=N)
y=np.zeros((N,T))
for t in range(T):y[:,t]=a+.3*t+np.where(t>=cohort,1+.4*(t-cohort),0)+rng.normal(size=N)
rows=[]
for g in [3,5]:
    for t in range(g,T):
        delta=y[:,t]-y[:,g-1]
        att=delta[cohort==g].mean()-delta[cohort==99].mean()
        rows.append((g,t,att,1+.4*(t-g)));print('g,t,ATT,true',rows[-1])
print('Never-treated control, no covariates. Educational ATT(g,t), not full CS-DID inference.')

version 17.0
clear all
set more off
set seed 20261027
* Synthetic teaching data. Stata and NumPy RNG streams differ.
set obs 900
gen long id=_n
gen int g=cond(id<=300,3,cond(id<=600,5,99))
gen double a=rnormal()
expand 9
bysort id: gen long t=_n-1
gen double y=a+.3*t+cond(t>=g,1+.4*(t-g),0)+rnormal()
xtset id t
foreach cohort in 3 5 {
    local base=`cohort'-1
    by id: egen double ybase=max(cond(t==`base',y,.))
    gen double change=y-ybase
    forvalues period=`cohort'/8 {
        regress change i.g if t==`period' & (g==`cohort' | g==99), vce(robust)
    }
    drop ybase change
}
