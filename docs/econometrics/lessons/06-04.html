一、通俗理解

本节围绕平稳性与单位根这一核心问题展开。平稳性讨论随机过程的均值、方差和自协方差随时间是否稳定。单位根过程常使通常的回归统计量具有非标准分布。

面板与时间序列模型的统计对象不同，不能机械使用同一估计器。FE着重组内变异，非线性与分位数模型则改变了结果尺度。理解方法时首先要区分总体参数、样本估计量和软件结果；一个模型能够运行，不代表研究问题已经被正确识别。读回归表前先确认观测单位、变量单位、比较对象与可观察证据。

直觉上问：这次比较改变了什么，哪些其他条件被控制，以及剩余不确定性来自抽样、设定还是无法观测的反事实？这些问题有助于防止只看显著性星号就作出超出证据范围的解释。

二、核心理论与公式

平稳性讨论随机过程的均值、方差和自协方差随时间是否稳定。单位根过程常使通常的回归统计量具有非标准分布。 本课可用以下数学表达式把估计对象和条件写清：

\[E(Y_t)=\mu,\quad\operatorname{Cov}(Y_t,Y_{t-k})=\gamma(k)\]

式中概率、期望、变换或估计系数的含义取决于具体变量与目标人群。模型是否可识别、估计器是否一致以及标准误是否正确，分别需要对应的秩条件、分布或误差结构假设。不能以更换HC1或增加样本量自动替代这些前提。

面板与时间序列模型的统计对象不同，不能机械使用同一估计器。FE着重组内变异，非线性与分位数模型则改变了结果尺度。如果研究问题对应预测，需报告样本外表现；如果对应因果干预，必须另外定义潜在结果与处理分配机制。统计量的显著性不能推导出不存在遗漏变量、选择偏误或错误测量。

三、实证案例与数据

本课使用透明AR(1)教学模拟（确定性生成）。两套代码包含全部确定性构造公式，不把模拟数据说成真实经济样本。核心变量为：等间隔120个时点的y及其一期滞后量，构造公式在两端一致。

模拟AR(1)并不是现实宏观时间序列；单位根与协整须改用合适的多变量数据。从原始数据到估计样本，应先检查缺失编码、变量量纲、重复观测和筛选标准；如果按主体或年份分组，还应检查键是否唯一。代码产生的结果只有在实际运行后才能引用。本次不报告没有经过计算核验的估计值、置信区间和检验p值。

四、Stata与Python实现

下列示例使用相同数据源或确定性数据生成过程，显示本节可复核的准备、估计或诊断步骤。对于尚未实现的方法专属估计与方差合并，正文会明确保留其限制。

Stata

展开 Stata 完整代码
clear
set obs 120
gen t=_n
tsset t
gen double y=0
forvalues j=2/120 {
  quietly replace y=.6*y[`j'-1]+sin(`j'*1.2) in `j'
}
regress y L.y, vce(robust)

Python

展开 Python 完整代码
import numpy as np,pandas as pd,statsmodels.api as sm
y=np.zeros(120)
for i in range(1,120): y[i]=.6*y[i-1]+np.sin((i+1)*1.2)
df=pd.DataFrame({"y":y,"lag":np.r_[np.nan,y[:-1]]}).dropna()
r=sm.OLS(df.y,sm.add_constant(df.lag)).fit(cov_type="HC1")
print(r.summary())

本例演示自回归结构而非正式协整估计。时间序列存在误差相关时，HC1未必提供适当推断，应另核查HAC或模型创新项结构。核对两端结果时要检查观察数、类别编码、误差修正和默认自由度，而不是为了更小的p值任意选取软件。

五、初学者避坑

误区一：忽视模型与数据类型是否匹配。平稳性讨论随机过程的均值、方差和自协方差随时间是否稳定。单位根过程常使通常的回归统计量具有非标准分布。这会改变参数的经济意义或有效比较集合。

误区二：把统计显著性误解为识别假设已经成立。面板与时间序列模型的统计对象不同，不能机械使用同一估计器。FE着重组内变异，非线性与分位数模型则改变了结果尺度。基于观察数据的OLS、FE与其他模型仍需额外论证条件。

误区三：没有说明软件与样本的差别。本例演示自回归结构而非正式协整估计。时间序列存在误差相关时，HC1未必提供适当推断，应另核查HAC或模型创新项结构。发表或提交分析前必须保留代码版本、数据来源、筛选数量、标准误结构和不利结果。
