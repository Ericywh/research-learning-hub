一、通俗理解：一起变化，不等于因果

上一节发现重量较大的汽车通常价格更高。那么，把汽车加重100磅，能提高售价吗？

不能直接这样判断。不同汽车之间的价格差异，不等于同一辆汽车改变重量之后的价格变化。较重的汽车可能本来就属于更高级别，具有更大尺寸、更丰富配置与不同品牌定位。它们与价格共同变化，可能形成重量和价格之间的正相关。

相关关系（Correlation）

观察到一个变量较大时，另一个变量通常也较大或较小。

因果关系（Causation）

在明确定义干预之后，改变一个因素是否造成结果变化。

相关衡量观测分布中的关系，因果衡量干预后的潜在结果。描述和预测可以利用相关关系；因果结论则需要额外的识别条件。

二、核心理论与公式

2.1 相关系数

ρXY = Cov(X,Y) / [σXσY]

皮尔逊相关系数描述两个随机变量之间的线性关联，需要两个变量有有限且非零的方差。系数的范围是−1至1；正值代表正向线性关联，负值代表负向线性关联，接近零表示线性关联较弱，但并不排除非线性关系。相关系数不能确定因果方向。

2.2 反事实与潜在结果

τ100 = E[Pi(w+100) − Pi(w)]

如果能够清楚定义“仅以某种方式将汽车重量从w磅增加100磅”的干预，Pi(w)与Pi(w+100)分别表示两种干预状态下的潜在价格。两者之差是单位层面的因果效应，对适当总体取平均得到平均效应。

这一表达还依赖干预的一致性与潜在结果可比较性。对于同一辆汽车，我们通常只能观察到其中一个实际状态下的价格，无法同时观察两种状态。这就是反事实问题。此外，添加配重与升级动力系统造成的增重，可能是不同干预，不能简单认为100磅是唯一要素。

三、为什么相关不等于因果？

3.1 一个假设性的因果结构

教学性因果图，表示一种需要检验和论证的可能机制，不是现有数据已经证实的因果图。

即使重量本身不改变价格，只要更高级别车型同时更重、更贵，也可能出现正相关。

3.2 可手算的四辆车

假设两辆小型车分别重2000磅与2200磅，售价均4000美元；两辆大型车分别重3500磅与3700磅，售价均8000美元。合并四辆车，重量与价格明显正相关；在每个车型组内部，重量变化却没有对应价格变化。

注意：这四条记录只是用于理解混杂的虚构教学例子，并非真实汽车数据；它不能用于证明实际汽车市场中重量无因果效应。

四、真实数据实证：1978 Automobile Data

本节继续使用 Stata 官方公开的 auto.dta，包含74条车型记录和12个原始变量，属于单期截面教学数据；不需要注册即可读取。

本节变量：price（美元价格），weight（磅），mpg（燃油效率，每加仑英里数），length（英寸）与 foreign（国产/进口分类）。

已有公开Stata演示显示：price与weight的样本相关系数约0.5386；weight与mpg约−0.8072。 这两组数字来自公开Stata记录，不是本次在软件中重新运行得到的日志。

这说明该样本中重量与价格存在中等强度的正向线性关联，重量与燃油效率存在较强的负向线性关联。它们都不能自动被解释为因果效应。

五、软件实现：相关与控制变量

使用同一份数据，先计算相关系数，再比较简单回归与控制车身长度的多元回归。下方可以切换Stata与Python代码。

5.2 Python

如有需要，安装：pip install pandas matplotlib statsmodels

import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm

url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
data = df[
    ["price", "weight", "mpg", "length", "foreign"]
].dropna()

# 样本相关系数
print(data[["price", "weight", "mpg"]].corr())

# 简单回归
X1 = sm.add_constant(data[["weight"]])
m1 = sm.OLS(data["price"], X1).fit()

# 额外控制车身长度
X2 = sm.add_constant(data[["weight", "length"]])
m2 = sm.OLS(data["price"], X2).fit()

print("Simple model:")
print(m1.summary())
print("With length controlled:")
print(m2.summary())

# 真实车型散点，按国产/进口分组
for group, subset in data.groupby("foreign"):
    label = "Foreign" if group == 1 else "Domestic"
    plt.scatter(subset["weight"], subset["price"],
                label=label, alpha=0.7)

plt.xlabel("Weight (lbs)")
plt.ylabel("Price (USD)")
plt.title("Car weight and price by origin")
plt.legend()
plt.show()

5.3 怎样解释控制变量后的结果？

比较两次回归中的 weight 系数。如果加入 length 后系数改变，表示控制长度后得到的条件线性关联与原先的简单关联不同。但是，这并不说明所有混杂因素已经被排除。

品牌、车型定位、发动机性能等其他变量仍可能影响重量和价格；甚至某些变量是否应该控制，也必须根据因果结构判断。“多加一个控制变量”不是“获得因果效应”的充分条件。

结果审慎说明：除公开资料已核实的相关系数外，本节不把未实际执行的多元回归系数与图形冒充软件运行结果。按上述代码可生成真实样本散点图和输出。

六、初学者避坑指南

  • 相关系数高不等于因果效应大：相关是标准化的线性关联指标，而因果依赖具体干预。
  • 相关系数接近零不代表完全无关系：可能存在非线性联系。
  • 控制变量并非越多越好：合适的控制需要理论支持，错误控制也可能产生偏差。

七、今日练习与参考答案

理论题：冰淇淋销量和溺水事故同时增加，能否断言冰淇淋导致溺水？（点击查看）

不能。炎热天气可能同时促进冰淇淋销售和游泳活动，并使溺水风险增加。气温、季节和活动人口可能是混杂因素。相关性不能单独确立因果方向。

实操题：比较 regress price weight 和 regress price weight length，为什么结果仍不能称为因果效应？（点击查看）

运行：

regress price weight
regress price weight length

系数即使发生改变，也不能证明所有混杂已消除；品牌、发动机性能和车型定位等未观测因素可能影响两者。需要依赖研究设计、因果假设和可辨认的干预来支持因果解释。具体系数差异以软件实际输出为准。
