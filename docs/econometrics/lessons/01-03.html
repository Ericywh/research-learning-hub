截面、时间序列和面板数据

一、通俗理解：观察的是谁，在什么时候？

研究企业投资时，可以比较1935年不同企业的投资额，也可以追踪一家企业从1935年到1954年的投资变化，还可以同时观察多家企业在多年中的变化。这三种研究的变量名称或许相同，但每一行数据代表的对象和时间不同，所含信息及统计依赖也不同。

识别数据结构，先问两句话：“一行数据记录哪个单位？”“它记录的是哪个时间点？”

第1、2课的汽车数据，每个车型只出现一次，属于典型的截面数据。本节使用一份同时带有企业编号和年份的数据，亲手观察三种结构怎样相互联系。

二、三种最常用的数据结构

类型一行数据代表主要研究问题本课例子
截面数据 Cross-section某时期的一个单位企业之间有何差异？1935年的10家企业
时间序列 Time series同一对象的一个时间点投资如何随时间变化？第1家企业20年的投资
面板数据 Panel某单位在某时间点的一次观测不同企业如何随时间共同或各自变化？10家企业×20年

横截面主要利用“单位之间”的变化；时间序列利用“同一对象随时间”的变化；面板数据兼有单位间差异和单位内随时间的变化。

使用面板并不自动得到因果识别，但它允许研究者在满足相应假设时处理某些不随时间改变的单位特征。数据结构决定能做什么、不能直接做什么。

三、核心理论与公式

3.1 面板数据的双下标

yit   (i=1,…,N; t=1,…,T)

i 表示企业，t 表示年份。例如，y1,1935 代表第1家企业在1935年的投资。若每家企业都有相同T期、单位—时间组合不重复、数据无缺口，就构成平衡面板，记录数为 N × T。若一些企业缺少年份，则属于非平衡面板，不能简单套用N×T。

3.2 企业内部的相邻期变化

Δyit = yit − yi,t−1

这个差值比较同一家企业相邻两个观察年份的投资。只有两个时期确实相邻、数值口径一致时，才能解释为“一年内变化”；在存在年份缺口时必须先核对年份。差分有时能去掉不随时间改变的企业特征，却不一定消除随时间变化的混杂因素。

四、真实数据：Grunfeld企业投资数据

我们采用Stata官方grunfeld.dta。这是经典的美国企业投资教学数据，含10家企业、1935—1954年连续20年的年度记录，共200条观测，属于强平衡面板。Stata官方文档使用它演示面板数据分析。这里的年份是历史资料年份，不是2026年的企业调查。

主要字段：company 企业编号、year 年份、invest 投资、mvalue 企业市值、kstock 资本存量；Stata版本还含time。原始Grunfeld资料有多种流传版本，各软件内置副本也不一定相同，因此本节的Python和Stata都读取同一个Stata官方URL，避免样本差异。

五、结构示意与可手算例子

本图数据均为教学构造的示意数值，并非Grunfeld原始观测。横向看A公司的三个年份是时间序列；纵向看1935年两家公司是截面；全表即面板。

假设A公司1935年投资100、1936年130，B公司分别为200、180，那么A公司的相邻期变化是130−100＝30，B公司为180−200＝−20；两者变化之差为50。这是描述性的变化差异，不应在没有处理组、对照组、平行趋势等设计的情况下称为政策因果效应。

6.2 Python

首次运行安装：pip install pandas matplotlib

import pandas as pd
import matplotlib.pyplot as plt

url = "https://www.stata-press.com/data/r19/grunfeld.dta"
df = pd.read_stata(url)
keep = ["company", "year", "invest", "mvalue", "kstock"]
data = df[keep].dropna().copy()

# 联合主键不能重复
assert not data.duplicated(["company", "year"]).any()
data = data.sort_values(["company", "year"])

print("观测数:", len(data))
print("企业数:", data["company"].nunique())
print("年份数:", data["year"].nunique())
print("每家企业记录数:")
print(data.groupby("company")["year"].nunique())

# 同一年多家企业：截面
cross = data.loc[data["year"] == 1935]
print(cross[["company", "invest", "mvalue"]])

# 同一家企业跨年：时间序列
series = data.loc[data["company"] == 1].copy()
series["dinvest"] = series["invest"].diff()
print(series[["year", "invest", "dinvest"]].head())

# 全部公司、全部年份：面板
panel = data.set_index(["company", "year"])
print(panel.head())

# 两家企业的真实投资时间变化
for cid in [1, 2]:
    a = data.loc[data["company"] == cid]
    plt.plot(a["year"], a["invest"],
             marker="o", label=f"Company {cid}")
plt.xlabel("Year")
plt.ylabel("Investment (dataset units)")
plt.title("Grunfeld panel: two firms over time")
plt.legend()
plt.tight_layout()
plt.show()

Python用两个键 ["company","year"] 表示面板；groupby 检查各公司年份覆盖情况；diff计算按年份排序后的公司内投资变化。

6.3 应该如何阅读输出？

Stata官方文档已经确认这份示例是10家企业、1935—1954年的强平衡面板。按逻辑，1935年的截面应有10条记录，单家企业的时间序列应有20条记录，完整面板应有200条记录。差分后每家企业的首年没有前一期，因此投资差分的有效记录为10×19＝190条（前提是原数据没有额外缺失且时间连续）。

这里展示的是基于公开数据结构可核验的数量关系，不是本次环境重新运行Stata/Python的输出。软件运行后应检查实际结果。如果某年缺失、主键重复或其他条件不满足，以上数量不能机械套用。

七、初学者最常见的三个误区

  • 观测数不等于独立样本量。 200条企业—年份记录来自10家企业，连续年份可能相关，不能在所有统计推断中当成200条独立抽样记录。
  • 同一年多家公司不叫时间序列。 有“year”字段不代表就是时间序列，要看每条记录是否追踪同一个对象。
  • 面板不会自动带来因果结论。 公司内部变化仍可能受到共同经济冲击及随时间改变的因素影响。

八、练习与参考答案

概念题：调查20家医院在2025年的床位数，以及调查同一家医院2015—2025年的床位数，分别是什么数据？

前者是在固定年份比较不同医院，是截面数据。后者是同一家医院随时间重复观测，是时间序列。如果同时追踪20家医院在2015—2025年的床位数，则是医院—年份面板。

实操题：用Grunfeld数据提取1940年的截面，核对观测数；再计算公司1在1936年相对1935年的投资变化。

Stata：

count if year == 1940
list company invest if year == 1940
list company year invest if company == 1 & inlist(year, 1935, 1936)

Python：

print(data.loc[data["year"] == 1940].shape[0])
a = data.loc[(data["company"] == 1) &
             data["year"].isin([1935, 1936])]
print(a[["year", "invest"]])
print(a.sort_values("year")["invest"].diff())

应得到1940年10条截面记录。Stata早期官方公开演示中的公司1投资，1935年为317.6、1936年为391.8，因此其变化为74.2（数据原始单位）。正式运行时以所读r19文件的输出核实，避免其他Grunfeld版本的差异。
