一、通俗理解

本节围绕《描述统计与可视化》建立从研究问题到估计条件的清晰逻辑。描述统计与可视化应揭示变量分布、样本构成及组别差异，不能取代识别假设验证。

本节重点不是背诵软件命令，而是弄清：需要哪些可观测信息，哪些结论来自模型自身，哪些结论需要额外的经济学与统计学假设。由研究问题进入可复现的数据字典、样本构造、基准估计、识别与结果报告。

在正式实证之前，先确认目标参数、数据结构及比较对象。即使模型拟合较好，也不能自动把相关性解释为因果效应；如果识别假设未被充分论证，应将结果限定为描述性或模型条件下的关联。

二、核心理论与公式

以下是本节预编稿的核心数学对象，正式授课时还须补充符号定义、推导步骤与该方法特有的识别条件。

\[\overline X=\frac1n\sum_iX_i\]

描述统计与可视化应揭示变量分布、样本构成及组别差异，不能取代识别假设验证。 公式中的概率、期望或参数关系应结合目标样本与模型口径解释，而不能不经检验地机械套用。需要特别区分总体假设、可观察证据以及估计量的抽样性质；若条件不成立，应重新界定能识别的统计量。

Python

展开Python代码
import pandas as pd
import statsmodels.formula.api as smf
url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
cols = ["price","weight","mpg","foreign"]
df = df[cols].dropna().copy()
fit = smf.ols("price ~ weight + mpg + C(foreign)", data=df).fit(
    cov_type="HC1", use_t=True)
print("有效样本量：", len(df))
print(fit.summary())
# 本基线不能替代本课专属识别与稳健性检验

运行前应确认数据文件能够下载、软件依赖已安装、变量含义符合研究目标。没有实际执行的软件输出一律不填造；若两端估计采用不同协方差修正，应先统一而不是比较显著性星号。

五、初学者避坑

误区一：把“描述统计与可视化”视为任意样本都适用的固定程序。描述统计与可视化应揭示变量分布、样本构成及组别差异，不能取代识别假设验证。

误区二：模型系数显著即认定识别成功。外生性、共同趋势、有效工具或完整抽样等条件必须按方法分别论证。

误区三：只提供回归表而忽略样本筛选、变量口径和标准误类型。合理的可复现流程要同时记录数据版本、代码、软件环境和结果不确定性。

六、今日练习

概念题：本节《描述统计与可视化》的核心统计对象是什么？仅凭一张显著性回归表为什么不能判断对应方法的关键假设已经成立？

概念题参考答案

描述统计与可视化应揭示变量分布、样本构成及组别差异，不能取代识别假设验证。 显著性检验只能检验指定模型下的特定原假设，不能直接验证研究设计或数据生成过程的全部条件。

计算或应用题：研究流程中原有100条观测，按事先规则保留82条。计算删失比例，并说明应如何记录样本变化。

计算或应用题参考答案

减少18条，占18%。应列出筛选条件、对应删失条数及其对变量分布的影响，不根据结果显著性临时更改规则。
