第2章·第5节｜偏回归系数与教育回报

一、通俗理解

上一课在回归中同时纳入汽车重量和长度，发现一个系数的含义取决于其他解释变量。本课转向教育与工资：受教育年限较长者往往工资较高，但工作经验、任职年限和年龄也与工资有关。偏回归系数是指在模型中剔除其他控制变量所能线性解释的部分后，目标解释变量与结果变量剩余变化之间的线性斜率。
直觉上，可以先用工作经验等变量预测教育年限，再用同一组变量预测工资；把两次预测都未解释的部分拿来比较，得到的教育斜率与完整多元OLS中的教育系数相同。这不是另一种因果识别方法，而是同一个OLS估计量的另一种表达。

二、核心理论与公式

设定含截距的半对数工资方程：

$$\ln(wage_i)=\beta_0+\beta_1grade_i+\beta_2ttl\_exp_i+\beta_3tenure_i+\beta_4age_i+u_i.$$

其中 wage 为正的小时工资，grade 为已完成的受教育年级数，ttl_exp 为累计工作经验，tenure 为当前岗位任职年限，age 为年龄。(beta_1) 是其他三个变量给定时，教育增加一个年级对应的条件对数工资差异；小系数时约为 (100beta_1%)，精确百分比变化为 (100[exp(beta_1)-1]%)。
Frisch–Waugh–Lovell（FWL）定理给出：

$$\widehat\beta_1=\frac{\sum_i\widetilde{grade}_i\widetilde{\ln(wage)}_i}{\sum_i\widetilde{grade}_i^2}.$$

波浪号表示分别对截距、经验、任职年限、年龄做OLS回归后的残差。该等式要求同一样本、相同控制变量及完整模型满列秩；若教育被控制变量完全线性解释，分母为零，系数不可识别。FWL是有限样本代数恒等式，不依赖因果外生性；统计推断和因果解释则另需相应假设。

三、实证案例与数据

使用Stata Press官方示例数据 nlsw88.dta，源自1988年美国女性劳动力纵向调查的截面摘录。公开版本原始记录为2,246条；本课只保留 wage、grade、ttl_exp、tenure、age 均非缺失且 wage\>0 的记录，实际有效样本量由代码报告，不预设结果。数据及变量定义可核查：Stata Press Release 19数据目录、nlsw88.dta原始文件。该文件用于教学，不宜未经抽样设计核查直接推断总体教育回报。

四、Stata与Python实现

两套代码均估计同一含截距OLS模型，完整模型均使用HC1异方差稳健标准误；FWL残差回归只用来核对点估计，不将其默认标准误冒充完整模型的稳健标准误。
Stata：

Stata
clear all
* 读取官方数据并统一样本
use "https://www.stata-press.com/data/r19/nlsw88.dta", clear
keep if !missing(wage, grade, ttl_exp, tenure, age) & wage > 0
generate double lnwage = ln(wage)
count

* 完整模型：HC1稳健标准误
regress lnwage grade ttl_exp tenure age, vce(robust)
scalar b_full = _b[grade]
display "完整模型教育系数：" b_full

* FWL：分别剔除相同控制变量
regress lnwage ttl_exp tenure age
predict double ry, resid
regress grade ttl_exp tenure age
predict double rx, resid
regress ry rx, nocons
display "FWL教育系数：" _b[rx]

Python：

Python
import numpy as np
import pandas as pd
import statsmodels.api as sm

url = "https://www.stata-press.com/data/r19/nlsw88.dta"
cols = ["wage", "grade", "ttl_exp", "tenure", "age"]
df = pd.read_stata(url)[cols].dropna().copy()
df = df.loc[df["wage"] > 0].copy()
df["lnwage"] = np.log(df["wage"])

y = df["lnwage"]
X = sm.add_constant(df[["grade", "ttl_exp", "tenure", "age"]])
full = sm.OLS(y, X).fit(cov_type="HC1")

# FWL残差化：同一样本、同一组控制变量
Z = sm.add_constant(df[["ttl_exp", "tenure", "age"]])
ry = sm.OLS(y, Z).fit().resid
rx = sm.OLS(df["grade"], Z).fit().resid
b_fwl = np.dot(rx, ry) / np.dot(rx, rx)

print("有效样本量：", len(df))
print("完整模型教育系数：", full.params["grade"])
print("完整模型HC1标准误：", full.bse["grade"])
print("FWL教育系数：", b_fwl)

运行后核对两种教育系数是否仅有浮点舍入差异，并比较Stata与Python的完整模型系数和HC1标准误。本次未实际运行Stata或Python，不报告未经核实的回归数值。

五、初学者避坑

误区一：把教育系数直接称为教育的因果回报。 能力、家庭背景、教育选择与就业选择可能同时影响受教育年限和工资；控制经验、任职年限、年龄仍不足以保证外生性。
误区二：把半对数系数直接当作工资增加的美元数。 它描述条件对数工资差异；百分比近似还需要考虑系数大小。
误区三：认为FWL残差回归自动复制完整模型的标准误。 点估计相等，但简单残差回归的自由度修正与完整模型不同。报告HC1标准误应使用完整模型。

六、今日练习

概念题： 为什么FWL残差化能够得到与完整多元OLS相同的教育系数？这是否解决了教育的内生性？
参考答案： 残差化分别移除了控制变量在教育和工资上的线性投影，剩余斜率恰好等于完整OLS中教育的偏回归系数。这是投影代数性质，不保证教育与结构误差独立，也不消除未观测能力等内生性来源。
计算题： 某纯教学示例中，残差化后的教育值为（−1，0，1），残差化后的对数工资值为（−0.08，0，0.08）。求教育偏回归系数并解释。
参考答案： 分子为0.16，分母为2，因此系数为0.08。在模型条件比较意义下，教育增加一个年级对应的对数工资差异为0.08，约等于8%的工资差异；精确比例约为8.33%。该例为构造数字，不是nlsw88的估计结果，更不能据此宣称因果效应。
