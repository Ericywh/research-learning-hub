多重检验与FDR

同时检验许多命题时，偶然显著会增多。FDR控制错误发现比例的期望，不是每个结论为假的概率。

具体例子：独立零假设各以5%拒绝，检验20项预期会有1项误拒；这不是保证恰好出现1项。

零假设与p值

零假设是待检验的参数限制。p值是在零假设与模型条件成立时，出现同样或更极端统计量的概率。

具体例子：p=0.03不等于零假设为真概率3%，也不等于效应很大；还需效应量、区间与研究设计。

置信区间

由数据按一个程序构造的区间。95%覆盖率指相同规则重复抽样时，约95%的区间覆盖固定真值。

具体例子：某次区间是否含真值已确定但未知；频率学派不把95%直接说成该固定参数落入本次区间的概率。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

安慰剂要对应具体威胁，例如虚假时间检验趋势误设，负向对照检验不应受影响的渠道。不显著不能排除所有混杂。Oster型分析以系数与R²变化，在比例选择和Rmax等附加假设下评估未观测选择，不是无假设界。BH把排序p值与iq/m比较，在独立或适当正依赖下控制FDR。FDR是错误发现比例的期望，不是每个发现为假的后验概率。分析应预先明确主要结果与检验族，不能筛选后假装只有一次检验。

2 · 公式与统计前提

k=max{i:p_(i)≤iq/m}；拒绝排序前k项

数据驱动选择检验族改变误差控制含义。显著性不等于实际重要性，应报告效应量和区间。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
from statsmodels.stats.multitest import multipletests
p=np.array([.01,.04,.2])
reject,adjusted,_,_=multipletests(p,alpha=.05,method='fdr_bh')
assert reject.tolist()==[True,False,False]
print('BH reject',reject,'adjusted p',adjusted)
print('Assume independent or suitable positive dependence; not posterior false probabilities')
