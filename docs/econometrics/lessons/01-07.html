一、通俗理解

研究“汽车越重，价格是否越高”时，原始数据通常不能直接用于回归：需要先检查字段、删除相关变量的缺失值、构造统一单位、观察分布，再估计模型。Python中的 DataFrame（数据框） 是按行、列组织的数据表：每行是一辆车型记录，每列是价格、重量等变量。pandas 负责数据整理，matplotlib 负责画图，statsmodels 负责统计建模。Python的优势不是自动得出因果结论，而是可以把数据处理和估计写成一份可重复运行的程序。

二、核心理论与公式

描述统计先回答“样本的典型水平是多少”。价格的样本均值为：

$$ \bar p=\frac{1}{n}\sum_{i=1}^{n}price_i $$

其中 \(n\) 是非缺失价格记录数。均值容易受到极端高价车型影响，因此还应检查最小值、最大值与标准差。

随后考察控制产地类别后的条件线性关系：

$$ price_i=\alpha+\beta\,weight100_i+\gamma\,foreign_i+u_i $$

weight100=weight/100，所以 \(\beta\) 的单位是“美元/100磅”；foreign 为0/1变量，\(\gamma\) 表示在重量相同的模型条件下，进口与国产车型的预测价格差。OLS（普通最小二乘法）选择系数，使样本残差平方和最小。系数可被计算需要解释变量无完全共线性；要作可信的统计推断还需合适的抽样与误差条件；要作因果解释则需要更强的外生性等识别条件。

三、实证案例与数据

继续使用Stata官方1978年汽车数据 auto.dta，原始数据有74条车型记录、12个变量，属于截面数据。研究变量为价格 price（美元）、重量 weight（磅）、产地 foreign（0国产、1进口）。Stata用 sysuse auto 读取；Python从Stata Press公开数据地址读取同一数据。两端都只保留这三个变量的完整观测，避免软件默认缺失处理造成样本不一致。官方示例报告原始样本的平均价格约6165美元、平均重量约3019磅；本课不虚构未运行的回归系数。

四、Stata与Python实现

4.1 Stata

* 读取官方汽车数据并固定共同样本
sysuse auto, clear
keep if !missing(price, weight, foreign)
* 查看总体描述统计与按产地分组的价格
summarize price weight
bysort foreign: summarize price
* 以100磅为单位构造重量变量
generate weight100 = weight/100
* 绘制价格—重量散点图
scatter price weight
* 产地控制变量；异方差稳健标准误
regress price c.weight100 i.foreign, vce(robust)

bysort foreign: 表示先按产地分组，再分别执行命令；i.foreign 告诉Stata把产地视为分类变量。回归结果重点看 weight100 的系数、稳健标准误及样本数。

4.2 Python

先安装依赖：pip install pandas matplotlib statsmodels。

import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.formula.api as smf

# 读取与Stata相同的官方数据，保留产地数值编码
url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
# 选择变量、去除缺失值，并生成每100磅重量
d = df[["price", "weight", "foreign"]].dropna().copy()
d["weight100"] = d["weight"] / 100
# 描述统计及分组均值
print(d[["price", "weight"]].describe())
print(d.groupby("foreign")["price"].agg(["count", "mean"]))
# 绘制散点图
d.plot.scatter(x="weight", y="price")
plt.tight_layout()
plt.show()
# 相同线性模型；HC1稳健标准误
fit = smf.ols("price ~ weight100 + C(foreign)", data=d).fit(
    cov_type="HC1"
)
print(fit.summary())

dropna() 删除所选变量存在缺失的行；groupby() 计算各产地组统计量；C(foreign) 指定分类变量。两种软件在相同样本、编码和模型下，点估计应一致；Stata的 vce(robust) 与Python的 HC1 对应常用异方差稳健协方差估计。若标准误出现差异，先核对样本、变量编码和自由度处理，而不是直接认定某个软件算错。

五、初学者避坑

其一，混淆“读取成功”与“数据可用”。 应检查数据类型、缺失和异常值；本例不能因为显示74行，就默认任何变量都完整。

其二，忽视分类变量编码。 Python若直接写 + foreign，在本例0/1变量下点估计仍相同，但对有三个及以上类别的变量不能照搬；应使用 C()。

其三，把稳健标准误当作因果识别。 它主要调整不确定性估计，不能消除遗漏变量、反向因果或样本选择偏差。

六、今日练习

概念题： DataFrame、dropna() 与 groupby() 分别负责什么？

实操题： 某车型 weight=3200 磅，weight100 等于多少？如何用Python分别计算国产、进口汽车的平均价格？

参考答案： DataFrame是行列数据表；dropna() 删除指定字段存在缺失的观测；groupby() 按类别汇总。3200/100=32；执行 d.groupby("foreign")["price"].mean() 即可得到两组样本均价，不必预先猜测数值。
