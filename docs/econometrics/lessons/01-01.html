一、通俗理解

一辆汽车的重量越大，它的价格就越高吗？

现实中，汽车价格与重量、品牌、配置、发动机性能、尺寸等因素都有关系。观察若干车型，如果发现较重的车型往往更贵，这说明重量和价格可能存在正向统计关联，却不能马上断定“增加重量导致价格上涨”。较重的汽车可能同时具有更好的配置，而配置也影响价格。

计量经济学以经济问题为出发点，将统计方法、经济理论和实际数据结合起来，对经济现象进行定量分析，并在适当识别条件下回答因果问题。

计量研究常回答三个层次的问题：描述（重量和价格是否相关）、预测（已知重量能否预测价格）、因果（只改变重量会不会改变价格）。这三类问题需要的证据并不完全一样。统计估计可以刻画数据规律，但经济解释尤其是因果解释，还依赖研究设计与假设。

二、核心理论与公式

pricei = β0 + β1weighti + ui

其中，i 表示第 i 条汽车记录；price 是汽车价格（美元），weight 是汽车重量（磅）；β0 是截距，β1 是线性斜率；u 是没有被重量这一解释变量解释的部分。

误差项不是计算错误。汽车价格还与品牌、配置等因素有关，简单模型没有纳入这些信息，因此存在未解释的价格差异。

pricêi = β̂0 + β̂1weighti

帽子表示从样本估计的参数与拟合价格。如果估计斜率为2，表示样本中重量相差1磅对应的拟合价格相差约2美元，而不是单独增重1磅必然让价格上涨2美元。

条件与边界：重量必须有变化，直线只能概括线性关系。要将回归解释为总体条件均值还需适当的模型与抽样假设；常规标准误推断还涉及误差条件和样本依赖结构。即使统计推断成立，也不自动满足因果识别要求。

4.2 Python

首次使用在终端安装：pip install pandas numpy matplotlib statsmodels

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import statsmodels.api as sm

# 与Stata读取同一份公开数据
url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url)
df = df[["price", "weight"]].dropna()
print(df.describe())

X = sm.add_constant(df[["weight"]])
y = df["price"]
model = sm.OLS(y, X).fit()
print(model.summary())
print(model.conf_int(alpha=0.05))

x_line = np.linspace(df.weight.min(),
                     df.weight.max(), 100)
y_line = (model.params["const"] +
          model.params["weight"] * x_line)
plt.scatter(df.weight, df.price, alpha=0.7)
plt.plot(x_line, y_line)
plt.xlabel("Weight (lbs)")
plt.ylabel("Price (USD)")
plt.title("Car price and weight")
plt.show()

pandas读取数据，statsmodels执行OLS，numpy与matplotlib帮助绘制散点及拟合直线。

4.3 双软件对照与结果解释

Stata的 regress 默认含截距，Python的 sm.OLS 需要显式调用 sm.add_constant。同样样本与常规OLS设定下，系数和常规标准误原则上应相同，可能存在显示精度差异。

公开教学示例给出的估计结果（不是本次代码实际运行记录）：

估计指标结果
weight斜率2.0441
截距约 −6.7074
weight标准误0.3768
95%置信区间[1.2929, 2.7953]
p值小于0.001
R²0.2901
样本量74

系数：样本中重量相差100磅，拟合价格相差约204.41美元。标准误：0.3768反映系数估计的不确定性；95%置信区间在相应统计条件下反映估计精度。p值：小于0.001是对零斜率假设的统计证据，不能解释为原假设为真的概率。R²：0.2901说明回归直线在样本中解释了约29%的价格总变异，不代表29%的因果解释力。

解释警戒线：汽车重量可能与尺寸、品牌、配置共同变化。显著的回归系数仍是统计关联，而非增加重量的因果效应。

五、初学者避坑指南

  • 显著不等于因果：小p值不能消除遗漏变量和其他混杂因素。
  • 拟合良好不等于研究可靠：预测准确和因果识别是不同的研究目标。
  • 软件输出一致需验证设定：特别检查数据筛选、缺失值、截距以及标准误算法是否一致。

理论题：教育年限与工资正相关，能否证明多接受一年教育会导致工资上涨？（点击看答案）

不能。 个人能力、家庭背景和机会等因素可能同时影响教育与工资。相关性不自动提供因果效应估计。
