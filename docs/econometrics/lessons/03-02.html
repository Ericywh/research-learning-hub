第3章·第2节｜遗漏变量偏差

原纲正式课程 · 七模块 · Stata与Python

授课日期：2026-10-31。全课程第24课 / 共120课。建议学习时间：10—15分钟。

一、通俗理解

研究教育年限与工资的关系时，假设真实工资方程还受到累计工作经验影响。如果经验既与工资有关，又与教育年限相关，而我们把经验排除在回归之外，教育系数便可能“代替”经验解释一部分工资差异。这就是遗漏变量偏差（omitted-variable bias，OVB）的直觉。遗漏因素仅影响工资还不够；它必须与教育在控制其他变量后仍有相关性，才会通过这条路径影响教育系数。

要区分两件事：删掉一个变量后系数变化，是可以在样本中直接观察的统计事实；这种变化是否代表对真实因果效应的偏差，还需要完整模型外生性等额外假设。上一课介绍内生性，本课解释其中一种具体机制。

二、核心理论与公式

设因变量为对数小时工资，核心解释变量为教育年限，可能遗漏的变量为累计经验，其他控制变量为任职年限和年龄。考虑完整线性模型：

\[\ln(wage_i)=\beta_0+\beta_1 grade_i+\beta_2 ttl\_exp_i+\gamma_1 tenure_i+\gamma_2 age_i+u_i\]

其中 $\beta_1$ 是保持经验、任职年限及年龄不变时教育与对数工资的条件线性关系；若要赋予因果含义，还须论证 $E[u_i\mid grade_i,ttl\_exp_i,tenure_i,age_i]=0$ 等识别条件。

记短模型省略 $ttl\_exp$ 后的教育系数为 $\widetilde b_1$，长模型教育与经验系数分别为 $\widehat b_1,\widehat b_2$；$\widehat\delta$ 是把累计经验回归于教育、任职年限和年龄所得的教育系数。相同样本、含截距且设计矩阵满秩时，OLS满足精确恒等式：

\[\widetilde b_1-\widehat b_1=\widehat b_2\widehat\delta\]

它来自Frisch–Waugh–Lovell定理：先剔除其他控制变量的线性投影，再考察教育与遗漏经验的剩余关联。在完整模型外生且常规大样本条件成立时，右边的总体对应量才可解释为短模型的渐近遗漏变量偏差。方向由两个因子的乘积决定；其中一个为零，便不存在由该变量引起的这项偏差。

三、实证案例与数据

沿用上一课的公开教学数据 Stata NLSW88（1988年女性调查截面提取）。原始文件约2246条记录，含小时工资 $wage$、教育年限 $grade$、累计工作经验 $ttl\_exp$、任职年限 $tenure$、年龄 $age$。来源及变量说明亦见 NLSW88数据文档。

分析单位为个人；只保留五个变量均非缺失且工资大于零的观测，并对工资取自然对数。比较短模型（教育、任职年限、年龄）与长模型（再加累计经验），再以辅助回归核对系数差的代数分解。该数据不是随机教育实验，完整模型未必满足因果识别条件，因此不能把系数差直接当作教育因果回报的真实偏差。

四、Stata与Python实现

两套代码下载同一数据、执行相同筛选、含截距OLS，均使用HC1异方差稳健标准误。Python明确使用t分布以便与Stata的回归推断口径更接近；由于软件数值精度等差异，输出以实际运行核验为准。以下程序未经本次运行，不报告任何虚构系数。

Stata

* 公开NLSW88，完整案例，工资为正
clear all
set more off
use "https://www.stata-press.com/data/r17/nlsw88.dta", clear
keep if !missing(wage, grade, ttl_exp, tenure, age) & wage > 0
gen double lnwage = ln(wage)
count

* 短模型：遗漏累计经验
regress lnwage grade tenure age, vce(robust)
scalar b_short = _b[grade]

* 长模型：加入累计经验
regress lnwage grade ttl_exp tenure age, vce(robust)
scalar b_full = _b[grade]
scalar b_exp = _b[ttl_exp]

* 辅助回归：累计经验对教育及其他控制变量
regress ttl_exp grade tenure age, vce(robust)
scalar delta = _b[grade]

display "系数差：" %10.6f (b_short-b_full)
display "代数分解：" %10.6f (b_exp*delta)

Python

# pip install pandas statsmodels numpy
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

url = "https://www.stata-press.com/data/r17/nlsw88.dta"
df = pd.read_stata(url, convert_categoricals=False)
cols = ["wage", "grade", "ttl_exp", "tenure", "age"]
df = df.dropna(subset=cols).copy()
df = df.loc[df["wage"] > 0].copy()
df["lnwage"] = np.log(df["wage"])
print("共同样本量：", len(df))

short = smf.ols("lnwage ~ grade + tenure + age", df).fit(
    cov_type="HC1", use_t=True)
full = smf.ols("lnwage ~ grade + ttl_exp + tenure + age", df).fit(
    cov_type="HC1", use_t=True)
aux = smf.ols("ttl_exp ~ grade + tenure + age", df).fit(
    cov_type="HC1", use_t=True)

print(short.summary())
print(full.summary())
print("系数差：", short.params["grade"] - full.params["grade"])
print("代数分解：", full.params["ttl_exp"] * aux.params["grade"])

预期两条“系数差”和“代数分解”在数值误差范围内相等。这是OLS代数恒等式，不是内生性检验。应记录共同样本量、两个教育系数、经验系数及其置信区间，再判断变化方向；稳健标准误不改变系数差。

五、初学者避坑

  1. 相关不等于偏差。 遗漏变量须同时与结果有关，并在给定其余控制变量后与核心解释变量相关；单看两个变量的简单相关系数不足以判断多元模型中的偏差方向。
  2. 系数变化不等于因果纠偏。 新增变量可能是混杂因素，也可能是中介、碰撞变量或测量有误的代理变量；不能采用“控制越多越好”的机械策略。
  3. 稳健标准误不能修复遗漏变量偏差。 HC1只调整方差估计；样本选择、模型设定和外生性仍需单独讨论。

六、今日练习

概念题： 如果累计经验影响工资，但在控制年龄与任职年限后，与教育年限的剩余线性相关为零，省略经验是否会产生上述教育系数的遗漏变量偏差？

答案： 在相同样本、线性OLS和满秩条件下，$\widehat\delta=0$，由恒等式知两模型教育系数相等。若完整模型还满足外生性，经验不会通过这一路径造成渐近遗漏变量偏差；但不能因此认定不存在其他内生性来源。

计算题： 某教学假设中，长模型经验系数为 $0.12$，辅助回归中教育系数为 $-0.25$。短模型教育系数比长模型高还是低？相差多少？

答案： $0.12\times(-0.25)=-0.03$，短模型教育系数比长模型低0.03。这是给定假设数值的代数计算，并非NLSW88的实证结果。
