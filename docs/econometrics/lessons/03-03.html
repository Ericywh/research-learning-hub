一、通俗理解

回归使用的数据未必等于研究者真正想测量的变量。例如，汽车真实重量为3000磅，登记数据却因录入、四舍五入或仪器误差变成3150磅。若用错误的重量解释价格，OLS会把测量误差当作重量本身的变动，斜率可能偏离真实变量对应的线性投影系数。

要分清两个问题：数据是否测量准确，以及回归能否识别因果效应。即使没有测量误差，汽车重量与价格的回归也不能自动解释为重量对价格的因果作用。今天重点研究解释变量测量误差对OLS的影响。

二、核心理论与公式

设真正的解释变量为 $x_i$，记录到的数据为 $w_i$，测量误差为 $v_i$；结果变量为 $y_i$，结构扰动为 $u_i$：

$$ y_i=\alpha+\beta x_i+u_i,\qquad w_i=x_i+v_i. $$

若观测独立同分布、二阶矩有限，$\operatorname{Var}(x_i)>0$，且 $\operatorname{Cov}(x_i,u_i)=\operatorname{Cov}(x_i,v_i)=\operatorname{Cov}(u_i,v_i)=0$，那么将 $y_i$ 对 $w_i$ 作含截距OLS回归时：

$$ \operatorname{plim}\widehat\beta_w =\beta\frac{\operatorname{Var}(x_i)} {\operatorname{Var}(x_i)+\operatorname{Var}(v_i)}. $$

分式称为可靠性比率，介于0与1之间。在这些经典条件下，斜率向零收缩，称为衰减偏误。若测量误差与真实变量、结构扰动相关，或模型包含多个解释变量，偏差方向不一定向零。若测量误差只出现在因变量，且与解释变量正交，OLS斜率通常仍一致，但误差方差和推断精度会受到影响。

三、实证案例与数据

使用Stata官方1978年汽车教学数据 auto.dta。原始数据有74辆汽车，观测单位为汽车，变量 <code>price</code> 为价格（美元），<code>weight</code> 为重量（磅）。仅保留两变量均非缺失的记录，实际样本量由代码输出。

我们把原始 <code>weight</code> 视为教学中的基准测量值，再用确定性正弦、余弦扰动生成 <code>weight_observed</code>。这样两套软件可严格复现同一扰动。它只是人为误录情景，不能据此声称扰动满足经典独立性，也不保证本次样本一定发生衰减。

四、Stata与Python实现

两套代码使用相同数据、相同筛选、含截距OLS与HC1异方差稳健标准误。分别估计 <code>price ~ weight</code> 与 <code>price ~ weight_observed</code>，比较斜率和置信区间；代码未经本次运行，不报告估计数值。

Stata

展开 Stata 完整代码
* 官方汽车数据；保留相同的完整案例
clear all
set more off
use "https://www.stata-press.com/data/r17/auto.dta", clear
keep if !missing(price, weight)

* 构造可跨软件复现的人工测量扰动
gen long obs_id = _n
gen double v = 250*sin(7*obs_id) + 150*cos(11*obs_id)
quietly summarize v, meanonly
replace v = v - r(mean)
gen double weight_observed = weight + v
count

* 基准重量回归：HC1稳健标准误
regress price weight, vce(robust)
scalar b_base = _b[weight]

* 含测量误差重量回归：相同样本
regress price weight_observed, vce(robust)
scalar b_noisy = _b[weight_observed]
display "斜率变化 = " %10.6f (b_noisy-b_base)

Python

展开 Python 完整代码
# pip install pandas numpy statsmodels
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

url = "https://www.stata-press.com/data/r17/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
df = df.dropna(subset=["price", "weight"]).copy()

# 与Stata相同的行号和扰动生成公式
i = np.arange(1, len(df) + 1)
v = 250*np.sin(7*i) + 150*np.cos(11*i)
df["weight_observed"] = df["weight"] + v - v.mean()
print("共同样本量：", len(df))

# OLS + HC1；t分布参考与Stata常规输出接近
base = smf.ols("price ~ weight", data=df).fit(
    cov_type="HC1", use_t=True
)
noisy = smf.ols("price ~ weight_observed", data=df).fit(
    cov_type="HC1", use_t=True
)
print(base.summary())
print(noisy.summary())
print("斜率变化：",
      noisy.params["weight_observed"] - base.params["weight"])

五、初学者避坑

  1. 经典衰减结论需要严格的正交条件；在多元回归、非经典测量误差中不能直接套用。
  2. HC1稳健标准误只修正方差估计的异方差问题，不能消除测量误差造成的斜率不一致。
  3. 把代理变量与真实变量混同，或者把“加入噪声后系数变小”直接称为因果偏误，都会误读模型。重复测量、外部验证样本或合适工具变量才可能提供进一步识别信息，但各自也有条件。

六、今日练习

概念题： 如果工资因变量存在均值为零、与教育及结构扰动正交的记录误差，教育系数是否必然出现经典衰减偏误？

查看参考答案

答案： 不会。经典衰减主要针对解释变量的测量误差；满足正交条件时，因变量的加性测量误差不改变斜率一致性，但会增大残差变异，影响估计精度。

计算题： 若真实模型斜率 $\beta=2$，$\operatorname{Var}(x)=400$，$\operatorname{Var}(v)=100$，并满足经典条件，使用误测解释变量的OLS斜率概率极限是多少？

查看参考答案

答案： 可靠性比率为 $400/(400+100)=0.8$，所以 $\operatorname{plim}\widehat\beta_w=2\times0.8=1.6$。渐近偏差为 $-0.4$。这些是练习设定值，不是汽车数据的估计结果。
