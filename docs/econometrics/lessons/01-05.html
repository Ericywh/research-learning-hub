第1章·第5节｜完整计量研究流程（全课程第5课 / 共120课）

2026年10月11日，预计10—15分钟。

今日研究问题： 汽车越重，价格是否越高？怎样把一句直觉判断变成可以复现、且不过度宣称因果关系的计量研究？

一、从一个疑问到研究设计

前四课讨论了计量经济学的任务、相关与因果、数据结构和统计推断。现在把这些知识连起来。汽车重量与价格的散点图可能呈上升趋势，但它只是研究起点。正式研究必须说明研究对象、目标参数、数据来源、模型设定、识别假设与结论边界。完整研究流程不是“找数据—跑回归—看p值”，而是先确定问题，再判断数据能够回答到什么程度。

二、七步研究流程

研究问题 → 估计目标 → 数据与样本 → 数据核查 → 描述分析 → 模型估计 → 报告与复现

第一步，限定研究问题。 本课只研究1978年Stata教学样本中不同车型的重量和价格是否存在正向线性关联。74款车型并不是已证实的概率随机样本，不能自动推广至整个汽车市场。

第二步，明确估计目标。 描述性问题是“重量相差100磅的车型，模型预测价格相差多少”；因果问题则是“给同一辆车增加100磅重量，会改变多少售价”。这两种目标必须分开。

第三步，分析机制与识别条件。 较重车型可能同时具有更大的尺寸、更丰富的配置和不同的品牌定位。控制变量的选择应有经济学依据，不能为了让某个系数显著而反复修改模型。

第四步，确定数据与变量。 使用Stata官方1978 Automobile数据，共有74条车型记录、12个原始变量。price是美元价格，weight是磅，length是英寸车身长度，foreign区分国产与进口。该数据属于单期截面，不能凭空设定面板固定效应。

第五步，核查样本并描述分布。 检查变量类型、缺失值、极端值、样本数量与散点图。如果使用完整案例样本，必须说明删除了哪些缺失记录及剩余样本数。

第六步，估计与诊断。 先做简单回归，再加入事先说明的车身长度和产地分类。比较系数、置信区间、样本数，并采用异方差稳健标准误。稳健标准误不等于消除了遗漏变量偏差。

第七步，透明报告。 记录数据URL、软件代码、变量单位、筛选规则、标准误类型和识别局限。不显著结果也应如实报告，避免只呈现支持原先判断的模型。

三、两个核心公式

公式1：控制变量后的线性关联模型

$$ \mathrm{price}_i=\alpha+\beta\mathrm{weight}_i+\gamma\mathrm{length}_i+\delta\mathrm{foreign}_i+u_i $$

β的单位是美元/磅；100β表示在其他模型变量不变时，重量相差100磅对应的线性预测价格差。OLS可以估计线性投影系数；要赋予β因果含义，还需要定义干预、论证混杂控制等更强的识别条件。

公式2：潜在结果框架中的因果目标

$$ \tau_{100}=E\left[Y_i(w+100)-Y_i(w)\right] $$

Y_i(w)表示将同一辆车的重量通过明确方式设为w时的潜在价格。添加配重与升级发动机可能是不同干预，不能只凭“增加100磅”定义因果处理。观察性截面回归中的显著系数无法自动识别这个因果量。

四、可手算的数值示意

假设某个完全虚构的教学模型估计β=2.5美元/磅，那么重量差100磅对应的模型预测价格差为2.5×100=250美元。这个数字只说明单位换算，既不是本课真实汽车数据的估计值，也不是增重的因果效应。实际数值必须通过软件读取。

五、Stata实操

本节在同一份1978年汽车数据上比较简单回归和加入控制变量的回归。

summarize price weight
regress price weight
clear all
sysuse auto, clear
describe price weight length foreign
misstable summarize price weight length foreign
keep if !missing(price, weight, length, foreign)
count
correlate price weight
twoway (scatter price weight) (lfit price weight)
regress price c.weight, vce(robust)
estimates store m1
regress price c.weight c.length i.foreign, vce(robust)
estimates store m2
estimates table m1 m2, b(%9.3f) se(%9.3f) stats(N r2)
generate weight100 = weight/100
regress price c.weight100 c.length i.foreign, vce(robust)

把weight改为weight100只是单位变换：新系数应为原系数的100倍，t统计量和p值不变。

六、Python：同一数据复现

Python先从课程中提供的Stata官方数据链接下载auto.dta到工作目录，再执行下列代码。Stata的sysuse auto读取相同的官方教学数据；运行前应核对版本和观测数。

import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.formula.api as smf

df = pd.read_stata("auto.dta", convert_categoricals=False)
data = df[["price", "weight", "length", "foreign"]].dropna().copy()
data["weight100"] = data["weight"] / 100

print("N:", len(data))
print(data.describe())
print("Correlation:", data["price"].corr(data["weight"]))

m1 = smf.ols("price ~ weight", data=data).fit(cov_type="HC1")
m2 = smf.ols(
    "price ~ weight + length + C(foreign)", data=data
).fit(cov_type="HC1")
m3 = smf.ols(
    "price ~ weight100 + length + C(foreign)", data=data
).fit(cov_type="HC1")

print(m1.summary())
print(m2.summary())
print("Weight100:", m3.params["weight100"])
print("95% CI:", m2.conf_int().loc["weight"].tolist())

plt.scatter(data["weight"], data["price"], alpha=0.7)
plt.xlabel("Weight (lbs)")
plt.ylabel("Price (USD)")
plt.title("1978 automobile sample")
plt.tight_layout()
plt.show()

Stata的vce(robust)与Python的HC1通常可对照，但要核对虚拟变量编码、软件版本和完整案例样本。本次没有实际运行上述两套程序，不展示未经核实的回归系数或p值。

七、怎样解释结果？

可以写：“在1978年汽车教学样本中，价格与重量呈正向线性关联；控制车身长度与产地分类后，报告重量系数、HC1稳健标准误及95%置信区间。”只有运行后才能补入具体估计值。不能写“增加重量提高售价”，因为品牌、配置与车型定位等因素可能同时影响重量和价格，控制length和foreign不能证明混杂已被消除。

八、三个常见误区

  • 先跑回归再找问题：容易产生选择性报告，应事先说明研究问题与主要模型。
  • 控制变量越多越好：错误控制中介变量或碰撞变量也可能引入偏差。
  • p值小就是因果证据：统计显著性不能替代研究设计，也不等于经济重要性。

九、今日练习与参考答案

概念题： 一篇论文只报告“weight系数显著为正”，没有说明样本、控制变量与识别假设，它缺少什么？

答案： 缺少研究对象、目标参数、数据口径、样本筛选、模型设定、标准误及识别论证。仅凭显著性无法推出因果关系。

实操题： 将weight改为weight100=weight/100，保持样本及其他控制变量不变，新系数和p值应如何变化？

答案： 新系数为原weight系数的100倍，表示每100磅对应的条件预测价格差异；t统计量绝对值和p值不变。用Stata与Python运行并核对。
