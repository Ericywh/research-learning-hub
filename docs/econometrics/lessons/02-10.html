一、通俗理解

上一课的虚拟变量允许进口车与国产车的预测价格有不同截距，却默认两组的“重量—价格”斜率相同。这个限制可能过强：重量每增加100磅，对不同类型汽车的价格关联未必相同。交互项就是允许某个解释变量的系数随另一变量而变化。

例如，若仅回归价格对重量和进口身份，模型中“进口车”的系数是固定价差；加入“进口身份×重量”后，价差成为重量的函数。两条回归线可以不平行。因此不能再单独读出进口虚拟变量系数，就断言进口车普遍贵或便宜多少。

二、核心理论与公式

设 \(D_i\) 为进口车指示变量（进口=1，国产=0），\(W_i\) 为重量（单位：100磅），\(L_i\) 为车长（英寸），\(P_i\) 为价格（美元）。包含两个主效应与交互项的条件均值模型为：

\[E(P_i\mid D_i,W_i,L_i)=\beta_0+\beta_1D_i+\beta_2W_i+\beta_3(D_iW_i)+\beta_4L_i.\]

固定重量与车长，进口车相对国产车的条件预测价差，以及两组重量斜率分别是：

\[\Delta(W)=\beta_1+\beta_3W;\quad s_{D=0}=\beta_2,\qquad s_{D=1}=\beta_2+\beta_3.\]

所以 \(\beta_3\) 是两组重量斜率之差，而非“进口车总体溢价”。\(\beta_1\) 对应 \(W=0\) 的组间差异，零重量汽车不具现实意义。解释模型需有满列秩、组内重量变异及合理的函数形式；在两组重量共同支持区间外外推尤其应谨慎。OLS系数是样本条件关联；若缺少进口身份可视为外生的识别依据，不得作因果解释。

三、实证案例与数据

使用 Stata Press公开的1978汽车数据 auto.dta。原始数据记录74辆汽车，包含价格、重量、长度和进口身份。本课只使用 <code>price</code>、<code>foreign</code>、<code>weight</code>、<code>length</code> 均非缺失的完整案例，并定义 <code>weight100=weight/100</code>。实际有效样本量由程序统计，不预先假定。

两套软件估计相同的带截距OLS模型：<code>price ~ foreign + weight100 + foreign×weight100 + length</code>，并使用HC1异方差稳健协方差估计。阅读结果时先看交互项是否支持斜率差异，再计算特定重量下的组间条件价差。可以想象在横轴“重量”、纵轴“预测价格”的图上，两组各有一条斜率不同的直线；同一重量处的垂直距离就是 \(\Delta(W)\)，而非因果效应。

Python（可复制运行）

展开 Python 代码
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

# 与Stata读取同一数据，按相同变量删除缺失值
url = "https://www.stata-press.com/data/r18/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
df = df[["price", "foreign", "weight", "length"]].dropna().copy()
df["weight100"] = df["weight"] / 100
print("有效样本量：", len(df))
print(df["foreign"].value_counts().sort_index())

# * 表示两个主效应及其交互项；HC1稳健协方差
res = smf.ols(
    "price ~ foreign * weight100 + length", data=df
).fit(cov_type="HC1", use_t=True)
print(res.summary())

# 线性组合：3000磅时的进口车-国产车条件价差
names = res.model.exog_names
R = np.zeros(len(names))
R[names.index("foreign")] = 1
R[names.index("foreign:weight100")] = 30
print(res.t_test(R))

# 固定长度与重量，分别预测两组汽车的价格
grid = pd.DataFrame(
    [(d, w, 180) for w in (20, 30, 40) for d in (0, 1)],
    columns=["foreign", "weight100", "length"]
)
grid["predicted_price"] = res.predict(grid)
print(grid)

核对三件事：交互项系数与HC1标准误是否对应；3000磅时 <code>lincom</code> 与 <code>t_test</code> 是否一致；预测组合是否落在数据的合理支持范围。这里不填写未经运行的系数、显著性或样本量。

五、初学者避坑

误区一：只放交互项，不放主效应。 删除 \(D\) 或 \(W\) 通常施加额外限制，除非理论明确要求，否则应使用包含主效应的完整模型。

误区二：把 \(\beta_1\) 当作平均组间差异。 交互模型的差异随 \(W\) 变化。若把重量中心化为 \(W-30\)，虚拟变量主效应就可解释为3000磅处的条件价差，但不会改变拟合值。

误区三：交互项不显著就认定任何重量下都无组间差异。 \(\beta_3=0\) 检验的是斜率相同；\(\Delta(W)=0\) 检验的是指定重量下的组间价差，后者必须把两个系数的协方差纳入标准误。

六、今日练习

概念题： 为什么在含“进口身份×重量”交互项的模型中，不能把进口车虚拟变量的主效应称为“进口车平均贵多少”？

答案： 组间条件价差为 \(\beta_1+\beta_3W\)，随重量而变；主效应 \(\beta_1\) 只代表重量为零时的差异，通常既不是样本平均重量处的差异，也不是平均因果效应。

计算题： 某教学模型设 \(\hat\beta_1=-600\)、\(\hat\beta_3=80\)，重量单位为100磅。求2000磅、3000磅时进口车相对国产车的条件预测价差。

答案： 2000磅时 \(W=20\)，\(-600+80\times20=1000\) 美元；3000磅时 \(W=30\)，\(-600+80\times30=1800\) 美元。两者相差800美元，表示组间条件价差随重量增加而变化。数值仅为构造例题，不是汽车数据的估计结果。
