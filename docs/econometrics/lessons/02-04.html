控制变量

回归中同时纳入的其他变量，用于指定比较条件；是否应控制要由研究目标与因果关系决定。

具体例子：比较同经验者的教育工资差，经验是控制变量；但控制培训后取得的证书可能截断培训作用渠道。

混杂

一个处理前因素同时影响处理选择与结果，使处理组和对照组本来就不同。

具体例子：能力同时影响教育和工资，会使教育—工资关联混入能力差异。仅“相关”不是认定混杂的充分因果依据。

投影与正交

投影是在可用变量张成的空间内寻找最靠近y的拟合；正交意味着向量内积为零。

具体例子：把点向直线作垂线，垂足是投影。回归几何发生在样本向量空间，不是简单的两个变量散点图。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

FWL定理把“保持控制变量不变”转成可核验的残差化操作。将x对控制矩阵Z回归得到rₓ，将y对同一Z回归得到rᵧ，rᵧ对rₓ的无截距回归系数等于完整模型中的x系数。两步必须使用相同样本和控制空间。系数相同不意味着直接读取残差回归的默认标准误也相同，完整模型的自由度和协方差应保留。FWL是代数定理，不保证控制集合有因果合理性；中介和碰撞点可能改变目标或制造偏差。

2 · 公式与统计前提

bₓ=(x′M_Zx)⁻¹x′M_Zy；M_Z=I−Z(Z′Z)⁻¹Z′

删失或缺失造成两步样本不同会破坏核验。控制变量清单不能替代识别设计。

3 · 图示与研究含义

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
rng=np.random.default_rng(20261027)
n=800
z=rng.normal(size=n); x=.6*z+rng.normal(size=n)
y=1+2*x+.8*z+rng.normal(size=n)
X=np.column_stack([np.ones(n),x,z])
b=np.linalg.lstsq(X,y,rcond=None)[0]
Z=np.column_stack([np.ones(n),z])
rx=x-Z@np.linalg.lstsq(Z,x,rcond=None)[0]
ry=y-Z@np.linalg.lstsq(Z,y,rcond=None)[0]
fwl=rx@ry/(rx@rx)
P=X@np.linalg.solve(X.T@X,X.T)
assert abs(fwl-b[1])<1e-10
assert np.max(np.abs(P@P-P))<1e-10
assert np.max(np.abs(X.T@(y-X@b)))<1e-8
fit=sm.OLS(y,X).fit(cov_type='HC1')
print('OLS',b,'FWL',fwl,'HC1 SE',fit.bse)
print('Joint Wald',fit.wald_test(np.array([[0,1,0],[0,0,1]]),scalar=True))

5 · 专属练习与参考答案

只残差化y而保留原x，一般还能得到相同斜率吗？

展开答案与依据

一般不能。需同时对x残差化；x与Z列空间正交等特殊情形例外。
