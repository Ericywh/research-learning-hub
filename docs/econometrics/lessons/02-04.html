一、通俗理解

前几课用汽车重量预测价格，并以OLS估计斜率、用R²评价样本内拟合。但较重的汽车通常也更长、配置可能不同。若只回归价格与重量，重量系数可能同时反映车身长度等因素与价格的共同变化。多元线性回归是在同一个方程中纳入多个解释变量，考察某个变量在其他纳入变量给定时与结果的条件线性关联。
例如，在相同车身长度条件下比较不同重量汽车的预测价格，与不区分长度直接比较汽车价格，是两个不同的统计问题。“控制长度”是模型中的条件比较，不意味着研究者真的将汽车长度固定，也不自动实现因果识别。

二、核心理论与公式

以汽车价格为因变量、重量和长度为解释变量，设定：

$$price_i=\beta_0+\beta_1weight100_i+\beta_2length_i+u_i.$$

这里 weight100 是以100磅计量的重量，length 是英寸长度；β₁是长度保持不变时，重量每增加100磅对应的条件线性预测差异，β₂类似。OLS要求解释变量矩阵满列秩才能唯一估计系数；把β₁解释为因果效应还需要额外的外生性、干预定义等识别条件。
为什么控制变量后斜率可能变化？在总体线性投影中，若误差与两个解释变量均正交，且 Var(weight100)\>0，则仅回归重量所得总体斜率满足：

$$\beta_{1,\mathrm{simple}}=\beta_1+ \beta_2\frac{\operatorname{Cov}(weight100,length)} {\operatorname{Var}(weight100)}.$$

第二项反映遗漏长度带来的斜率差异。它是线性投影的代数关系；是否构成因果意义上的遗漏变量偏误，仍取决于模型与识别假设。

三、实证案例与数据

沿用Stata官方1978年汽车示例数据 auto.dta，原始文件有74条车型记录。使用 price（美元）、weight（磅）、length（英寸），生成 weight100=weight/100。先统一删除这三个变量的缺失值，再比较模型A（仅重量）与模型B（重量和长度）。两者均含截距，使用相同有效样本与HC1异方差稳健标准误。样本是教学示例，不应直接当作随机抽取的汽车总体样本。数据来源：Stata官方auto.dta。

四、Stata与Python实现

Stata（同一样本、HC1稳健标准误）：

Stata
clear all
* 读取官方示例数据，统一完整案例样本
use "https://www.stata-press.com/data/r19/auto.dta", clear
keep if !missing(price, weight, length)
generate double weight100 = weight / 100
count

* 模型A：价格对重量的一元回归
regress price weight100, vce(robust)
estimates store A

* 模型B：增加车身长度
regress price weight100 length, vce(robust)
estimates store B

* 比较两组估计、稳健标准误与拟合优度
estimates table A B, b(%9.3f) se(%9.3f) stats(N r2)

Python（同一数据、同一HC1协方差设定）：

Python
import pandas as pd
import statsmodels.api as sm

# 与Stata相同的完整案例样本
url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url)[["price", "weight", "length"]].dropna().copy()
df["weight100"] = df["weight"] / 100
y = df["price"]

# 显式加入截距，使用HC1异方差稳健标准误
X_a = sm.add_constant(df[["weight100"]])
X_b = sm.add_constant(df[["weight100", "length"]])
a = sm.OLS(y, X_a).fit(cov_type="HC1")
b = sm.OLS(y, X_b).fit(cov_type="HC1")

print("有效样本量：", len(df))
for name, model in [("A", a), ("B", b)]:
    print(name, "系数：\n", model.params)
    print(name, "HC1标准误：\n", model.bse)
    print(name, "R²：", model.rsquared)

观察加入length前后 weight100 系数的大小、方向及稳健标准误。样本内R²不会因新增解释变量而下降；HC1改变的是协方差估计与统计推断，不改变OLS点估计。上述代码未在本次执行，因此不虚构系数、p值或样本筛选后的观测数。

五、初学者避坑

误区一：“控制越多越好。”不恰当控制中介变量、碰撞变量或处理后变量，可能改变研究目标甚至引入偏误；控制变量应由研究问题和因果结构决定。
误区二：“加入控制变量后系数稳定就证明因果。”稳定性只是有限的模型诊断，不能排除未观测混杂、反向因果或测量误差。
误区三：“控制后系数变化必然说明原模型错误。”系数变化也可能来自解释变量相关性、模型设定或样本改变。本课刻意固定样本，排除最后一种机械差异。

六、今日练习

概念题： 多元回归中的“控制车身长度”是否等于把汽车长度真实固定？为何不能直接将重量系数解释为因果效应？
参考答案： 不是。它表示在给定长度条件下进行模型中的线性比较；真实干预可能改变其他汽车特征，且未观测混杂等识别问题仍存在。
实操／解释题： 假设某教学例子中，多元模型的重量系数β₁=80、长度系数β₂=400，而长度对重量的总体线性投影斜率为0.25。求只回归重量时的总体斜率，并说明能否据此断言重量的因果效应。
参考答案： 简单回归斜率=80+400×0.25=180；与多元回归的差额为100。该计算描述线性投影系数差异，不能单凭它确认重量的因果效应。
