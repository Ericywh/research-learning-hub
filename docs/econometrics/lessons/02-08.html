一、通俗理解

上一课的t检验回答“某一个回归系数是否为零”。但研究问题常常涉及一组系数。例如，汽车重量和车身长度分别与价格有关，我们更想问：控制截距后，重量与长度这两个变量是否整体具有线性解释力？

不能简单地观察两个单独t检验的p值，再推断联合检验结果。重量和长度通常相关，两个系数估计量之间也可能存在协方差。即使单项检验都未达到5%显著性，联合检验仍可能拒绝原假设；反之亦然。

F检验用于检验多个线性约束是否同时成立。它检验的是指定回归模型中的统计假设，不自动说明这些变量具有因果作用。

二、核心理论与公式

考虑含截距模型：汽车价格对重量（单位100磅）和车身长度进行OLS回归。我们提出两个同时成立的约束：

\[H_0:\ \beta_{\mathrm{weight100}}=0,\quad\beta_{\mathrm{length}}=0;\qquad H_1:\ \text{至少一个系数不为零}.\]

一般地，将需要同时检验的 $q$ 个线性约束写为 $R\beta=r$。使用HC1异方差稳健协方差矩阵，联合Wald检验的F型统计量为：

\[F_W=\frac{(R\widehat\beta-r)^\top\left[R\widehat V_{\mathrm{HC1}}R^\top\right]^{-1}(R\widehat\beta-r)}{q}.\]

其中，$\widehat\beta$ 是OLS系数向量，$R$ 为约束矩阵，$r$ 为约束值，$\widehat V_{\mathrm{HC1}}$ 为系数估计量的HC1稳健协方差矩阵。要求回归设计矩阵满列秩、约束独立且括号中的矩阵可逆。

本例有 $q=2$ 个约束。若样本量为 $n$、解释变量数为 $k=2$，软件通常以 $F_{2,n-3}$ 作为参考分布计算p值。对HC1稳健Wald检验，这一般是依赖适当大样本条件的近似，而不是精确小样本F分布。 在单个约束且采用一致协方差估计时，F型Wald统计量等于相应t统计量的平方。

三、实证案例与数据

继续使用Stata Press公开的1978年汽车教学数据 auto.dta，原始文件包含74条车型记录。变量为 price（美元）、weight（磅）和 length（英寸），构造 weight100=weight/100。只保留三个原变量均非缺失的观测；有效样本量由代码计算，不预设筛选结果。

本课联合检验“在该线性模型中，重量和长度的总体斜率是否同时为零”。即使检验拒绝原假设，也只能说明模型层面的条件线性关联具有统计证据，不能将其直接解释为改变重量或长度的因果效应。

数据来源：Stata Press auto.dta。

四、Stata与Python实现

两套代码使用相同数据、样本、含截距OLS模型、HC1稳健协方差，以及两个相同的线性约束。均未在本课实际运行，不报告未经核实的F值或p值。

4.1 Stata

点击展开 Stata 完整代码
clear all
* 读取公开数据并统一完整案例样本
use "https://www.stata-press.com/data/r19/auto.dta", clear
keep if !missing(price, weight, length)
generate double weight100 = weight / 100
count

* HC1异方差稳健标准误的OLS
regress price weight100 length, vce(robust)

* 联合原假设：两个斜率同时等于零
test weight100 = 0
test length = 0, accumulate

* 直接一次性联合检验，结果应与上面一致
test weight100 length
display "联合F统计量：" r(F)
display "联合检验p值：" r(p)

4.2 Python

点击展开 Python 完整代码
import pandas as pd
import statsmodels.api as sm

url = "https://www.stata-press.com/data/r19/auto.dta"
cols = ["price", "weight", "length"]
df = pd.read_stata(url)[cols].dropna().copy()
df["weight100"] = df["weight"] / 100

y = df["price"]
X = sm.add_constant(df[["weight100", "length"]])

# 与Stata一致的HC1稳健协方差
fit = sm.OLS(y, X).fit(cov_type="HC1", use_t=True)

# 两个斜率同时为零的联合Wald F检验
joint = fit.wald_test(
    "weight100 = 0, length = 0",
    use_f=True,
    scalar=True
)

print("有效样本量：", len(df))
print("系数：", fit.params)
print("联合F统计量：", joint.statistic)
print("分子自由度：", joint.df_num)
print("分母自由度：", joint.df_denom)
print("联合检验p值：", joint.pvalue)

比较时应核对样本量、F统计量、自由度及p值。Stata的 vce(robust) 和Python的 cov_type="HC1" 采用相应的有限样本缩放。不要把经典同方差条件下基于残差平方和的F检验与这里的稳健Wald F检验混为一谈。

五、初学者避坑

误区一：两个单项t检验都不显著，联合F检验必然不显著。 错。联合检验利用了系数之间的协方差，不能只根据单项p值判断。

误区二：稳健F检验在任意小样本中都服从精确F分布。 错。HC1稳健推断通常依赖大样本近似；样本量较小或高杠杆点明显时尤其需要谨慎。

误区三：联合拒绝零系数就证明存在因果作用。 错。检验本身不验证外生性，也不能排除遗漏变量、反向因果和选择问题。

六、今日练习

概念题： 两个变量各自的双侧t检验p值均大于0.05，是否意味着检验“两个系数同时为零”的联合F检验一定不能拒绝？为什么？

参考答案： 不一定。联合统计量还取决于两个系数估计量的协方差；分别检验与联合检验的拒绝域不同。应直接对两个约束进行联合检验。

计算题： 一个纯教学例子中，两项系数估计为 $(2,1)^\top$，其稳健协方差矩阵为 $\operatorname{diag}(1,4)$。检验两个总体系数同时为零，计算F型Wald统计量。若题设5%临界值为3.2，应如何判断？

参考答案： 两个约束的二次型为 $2^2/1+1^2/4=4.25$；除以约束数 $q=2$，得到 $F_W=2.125$。因为 $2.125<3.2$，在题设临界值下不拒绝联合原假设。该数字为构造案例，不是汽车数据的回归结果。
