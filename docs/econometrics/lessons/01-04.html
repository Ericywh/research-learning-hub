一、研究问题与统计直觉

第1课我们观察到，1978年汽车数据中价格的样本均值约为6165美元。现在假设研究者想检验“相关汽车总体的平均价格是否为6000美元”。样本均值与6000之间相差约165美元，但单看差额无法判断证据强弱：如果价格本身差异很大，均值会有抽样波动；如果样本容量足够大，均值又可能估计得较精确。由此引出六个概念：期望描述理论中心，方差描述分散程度，协方差描述共同变化，标准误描述估计量的抽样波动，假设检验提出可检验的统计命题，p值则衡量数据在原假设下有多极端。

本节仍使用Stata官方1978 Automobile Data，重点不是背定义，而是把它们串成一次规范的统计分析。

二、六个概念的分工

期望 E(X) 是随机变量的理论平均水平；样本均值是利用观察值估计期望的统计量。方差 Var(X) 描述随机变量围绕期望的平方偏离，标准差是方差的平方根。协方差 Cov(X,Y) 描述两个变量相对于各自均值的共同变化方向：正值表示倾向同向变化，负值表示倾向反向变化，但不意味着因果关系。

标准误（SE） 与标准差不同：标准差描述单个观测值的分散，标准误描述某个估计量在重复抽样时的变化。假设检验 从原假设H₀出发，依据统计量及其在H₀下的分布判断数据是否与之相容。p值 是在H₀和模型假设成立时，观察到当前或更极端检验统计量的概率；它不是H₀为真的概率。

三、两个公式组与成立条件

E(X)=μ；Var(X)=E[(X−μ)²]；
Cov(X,Y)=E[(X−μₓ)(Y−μᵧ)]

期望要求相应矩存在，方差与协方差通常要求有限二阶矩。样本方差、样本协方差常用n−1作分母，以在独立同分布抽样条件下估计总体量。

SE(x̄)=s/√n；t=(x̄−μ₀)/(s/√n)

其中s是样本标准差，n是有效观测数，μ₀是原假设给定的均值。简单标准误公式需要独立同分布与有限方差等条件。若总体正态，H₀下t统计量严格服从自由度n−1的t分布；非正态总体通常需要依赖大样本近似。存在聚类或时间依赖时，标准误不能直接照搬。

四、真实数据与可复核计算

本课使用Stata官方 auto.dta，为1978年74款汽车的教学截面数据，包含12个原始变量。价格price以美元计，重量weight以磅计。公开Stata输出显示价格样本均值为6165.257美元，样本标准差为2949.496美元，样本量74。由这些公开的四舍五入汇总统计可算出：均值标准误约342.872美元。

设H₀：μ=6000，H₁：μ≠6000，显著性水平α=0.05。手算t≈(6165.257−6000)/342.872≈0.482，自由度73，双侧p≈0.631。按t分布计算的95%置信区间约为[5482，6849]美元。由于p>0.05且6000落在区间内，在上述统计模型下不能拒绝H₀，但不能据此证明总体均值恰好等于6000。

来源：威斯康星大学社会科学计算中心公开Stata输出；Stata官方数据说明。p值与区间是根据公开汇总统计计算的近似数值，并非本次实际运行Stata或Python所得的日志。

五、95%区间的数值示意

图中坐标与区间端点按比例绘制；这是由已公开汇总统计计算的教学图，不是软件运行截图。95%置信区间的含义是：在抽样模型与区间构造方法有效时，重复抽样形成的区间长期约有95%覆盖真实固定参数；不是本次参数有95%概率位于区间内。

必须强调，这74条车型记录未被证明是从某个明确总体随机抽取的概率样本。因此这里的显著性检验是在假定抽样模型成立时的教学示范，不能直接推广为1978年所有汽车的总体结论，也不能作因果解释。

summarize报告样本均值与标准差；协方差命令计算价格与重量共同变化；ttest对总体均值6000执行双侧单样本检验；ci means给出均值置信区间。histogram绘制真实样本价格分布，叠加的正态曲线只是参照，不证明价格服从正态分布。

七、Python代码：核对同一个检验

安装依赖：pip install pandas numpy scipy matplotlib

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
data = df[["price", "weight"]].dropna()
x = data["price"].to_numpy()
n = len(x)
mean = np.mean(x)
sd = np.std(x, ddof=1)
se = sd / np.sqrt(n)
print("n, mean, SD, SE:", n, mean, sd, se)
print("Sample covariance:", data.cov())
result = stats.ttest_1samp(x, popmean=6000)
print("t and p:", result.statistic, result.pvalue)
ci = stats.t.interval(.95, df=n-1, loc=mean, scale=se)
print("95% CI:", ci)
plt.hist(x, bins=12, edgecolor="white")
plt.axvline(mean, linestyle="--", label="Sample mean")
plt.axvline(6000, linestyle=":", label="Null mean")
plt.xlabel("Price (USD)")
plt.ylabel("Count")
plt.legend()
plt.show()

这里ddof=1确保Python使用与Stata相同的样本标准差约定。SciPy单样本t检验的默认备择假设为双侧；若源数据与缺失处理一致，两种软件应给出一致的t值、p值与置信区间。

八、常见误区

误区一：把标准差2949美元和均值标准误343美元当成同一个指标。前者描述车型价格差异，后者在特定抽样假设下描述均值估计的不确定性。

误区二：把p≈0.631解释为“原假设有63.1%的概率正确”。p值条件于原假设，并非原假设的后验概率。

误区三：把“不能拒绝H₀”解释为“已证明两者相等”。如果研究目的是论证差异足够小，需要预先设定实质性容许差异并采用适当的等效性分析。

九、今日两道练习与答案

概念题：标准差和标准误分别描述什么？为什么p值不是原假设为真的概率？

标准差描述观测值的离散程度，标准误描述估计量在重复抽样中的变化。p值的定义是P(数据至少同样极端 | H₀及模型)，不是P(H₀ | 数据)；两种条件概率不能互换。

计算题：给定n=74、均值6165.257、标准差2949.496，检验H₀: μ=6000，α=0.05。

SE=2949.496/√74≈342.872；t≈0.482；自由度73，双侧p≈0.631。由于p>0.05，不能拒绝H₀；不能说已证明总体均值等于6000。Stata可用ttest price == 6000，Python可用stats.ttest_1samp(x, 6000)复核。

十、知识卡片与进度

记住：中心看期望，波动看方差，共变看协方差，估计精度看标准误，证据判断看检验和p值。任何推断都离不开抽样与模型假设。统计显著性不等于经济重要性，更不等于因果效应。
