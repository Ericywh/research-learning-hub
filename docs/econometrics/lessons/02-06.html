一、通俗理解

上一课用偏回归系数解释“控制其他变量”后的教育与工资关联。但OLS能算出一个系数，并不意味着它一定无偏，也不意味着软件给出的标准误可靠。经典线性回归假设就是连接“如何计算系数”与“能够怎样解释、推断系数”的一组条件。

以汽车价格为例，重量和车身长度都可能与价格相关。若汽车品牌、配置等未观测因素既影响价格又与重量有关，那么重量系数可能混入这些因素的作用。即使残差图看起来很规整，也不能据此认定不存在遗漏变量问题。相反，误差波动随汽车重量增加而扩大，主要影响传统标准误的有效性；在零条件均值等条件仍成立时，OLS点估计未必因此产生偏误。

因此，要分别检查模型是否可估计、系数是否具有目标解释、标准误是否支持可靠推断，而不能笼统地问“OLS假设是否全部满足”。

二、核心理论与公式

设含截距的多元线性模型为：

\[price_i=\beta_0+\beta_1weight100_i+\beta_2length_i+u_i\]

其中，price为美元价格，weight100为以100磅计量的重量，length为英寸长度，u为未纳入方程的因素。

最关键的识别条件之一是零条件均值：

\[E(u_i\mid X)=0\]

这里X表示包含所有观测解释变量的设计矩阵。它要求在给定这些变量时，误差的条件期望为零；仅有样本OLS残差均值为零，并不能证明该假设成立。

常见的其他条件包括：模型对参数线性且设定与研究对象相符；样本的抽取或依赖结构能够支持所采用的概率推断；解释变量不存在完全多重共线性（设计矩阵满列秩）；相关变量具有必要的有限矩。经典同方差条件要求给定X时各观测误差的方差相同，经典无误差相关条件还要求不同观测误差的条件协方差为零。

在零条件均值、满秩、同方差且误差不相关等适当条件下，OLS具有高斯—马尔可夫意义下的最佳线性无偏性质（BLUE）。误差正态性并非BLUE所必需；它常用于小样本精确t、F推断的附加条件。采用HC1异方差稳健标准误可以放松同方差要求，但仍需要适当的独立性或弱依赖与大样本条件，不能修复内生性。

三、实证案例与数据

继续使用Stata Press公开的1978年汽车教学数据 auto.dta（原始文件74条车型记录）。变量为price、weight、length，生成weight100=weight/100。只保留三个原变量均非缺失的观测；最终有效样本量由程序输出，不预先编造。

数据文件：https://www.stata-press.com/data/r19/auto.dta

本课比较传统标准误与HC1稳健标准误，并绘制残差—拟合值图。图形只用于发现可能的异方差或函数形式问题，不能验证零条件均值。该数据是教学示例，不能不加论证地视为某一明确汽车总体的随机样本。

4.2 Python

点击展开 Python 完整代码
import pandas as pd
import statsmodels.api as sm
import matplotlib.pyplot as plt

url = "https://www.stata-press.com/data/r19/auto.dta"
cols = ["price", "weight", "length"]
df = pd.read_stata(url)[cols].dropna().copy()
df["weight100"] = df["weight"] / 100

y = df["price"]
X = sm.add_constant(df[["weight100", "length"]])

# 同一样本、同一OLS点估计
ordinary = sm.OLS(y, X).fit()
robust = sm.OLS(y, X).fit(cov_type="HC1")

print("有效样本量：", len(df))
print("OLS系数：\n", robust.params)
print("传统标准误：\n", ordinary.bse)
print("HC1稳健标准误：\n", robust.bse)

# 残差图仅作诊断，不证明外生性
plt.scatter(robust.fittedvalues, robust.resid)
plt.axhline(0, linestyle="--")
plt.xlabel("拟合价格")
plt.ylabel("OLS残差")
plt.show()

两种估计的系数和样本内R²应相同；标准误可能不同。Stata的vce(robust)与statsmodels的HC1采用相应的有限样本缩放，但软件默认的检验分布、p值处理未必完全相同。本次未运行代码，不报告具体系数、p值或诊断图结论。

五、初学者避坑

误区一：残差均值为零就证明外生性。 含截距OLS的样本残差和为零是计算恒等式，而零条件均值是关于未观测误差与解释变量关系的总体假设。

误区二：异方差使OLS系数必然有偏。 异方差主要破坏经典同方差标准误和BLUE效率结论；是否有偏取决于外生性等条件。

误区三：用了稳健标准误就能做因果推断。 HC1只调整协方差估计，不能消除遗漏变量、反向因果或选择偏误。残差图也无法证明这些问题不存在。

六、今日练习

概念题： 为什么“样本OLS残差与重量的内积为零”不能证明零条件均值？HC1能否解决遗漏变量内生性？

参考答案： 前者是OLS正规方程产生的样本代数性质，后者是关于总体误差条件期望的假设。HC1改变标准误估计，不改变系数，也不能消除遗漏变量内生性。

计算与解释题： 假设某个教学样本的两个解释变量为x₁=(1,2,3)，x₂=(2,4,6)，模型还含截距。能否分别估计两者的OLS系数？如果误差存在异方差，改用HC1能否解决这个问题？

参考答案： 不能，因为x₂=2x₁，两列完全线性相关，设计矩阵不满列秩，两个斜率无法唯一确定。HC1只修改标准误，不会改变矩阵秩；应依据研究问题删除或重新定义一个冗余变量，而不是仅更换标准误。
