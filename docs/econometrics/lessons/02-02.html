一、通俗理解

上一课用直线描述汽车重量与价格的关系，但究竟怎样选出这条线？普通最小二乘法（Ordinary Least Squares，OLS）给出一个明确标准：比较每辆汽车的实际价格与直线预测价格之间的差距，选择使这些差距的平方和最小的截距和斜率。
每个差距称为残差。平方使正负偏差不能相互抵消，并对较大偏差给予更高权重。OLS求得的是样本中最贴合这一标准的直线，不是逐点穿过所有观测的直线，更不是自动成立的因果关系。

二、核心理论与公式

对于第 i 辆汽车，记价格为 y_i、重量为 x_i，预测价格为 a+b x_i。OLS的目标是：

$$(\hat\beta_0,\hat\beta_1)=\underset{a,b}{\arg\min}\sum_{i=1}^{n}(y_i-a-bx_i)^2.$$

其中 n 为有效观测数，a 是候选截距，b 是候选斜率；帽号表示样本估计值。若包含截距且 x_i 不全相同，最优解为：

$$\hat\beta_1=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2},\qquad \hat\beta_0=\bar y-\hat\beta_1\bar x.$$

分子反映重量与价格的共同变动，分母反映重量自身的变动。分母为零时，所有重量相同，无法单独估计斜率。含截距的OLS还有两个样本性质：残差之和为零，残差与解释变量的样本乘积和为零；这是优化结果，不是“模型正确”的证据。

三、实证案例与数据

继续使用Stata官方1978年汽车示例数据 auto.dta，变量 price（美元）与 weight（磅）。原始数据有74条车型记录；两软件都仅保留这两列非缺失的观测。来源：https://www.stata-press.com/data/r19/auto.dta 。
先看一个可手算的小例子：三组观测为 (x,y)=(1,2)、(2,3)、(3,5)。平均值分别是2与10/3。按上式，斜率为1.5、截距为1/3，拟合值依次为11/6、10/3、29/6，残差依次为1/6、−1/3、1/6。残差和为零，但各点仍不一定落在直线上。这组数字仅用于演示计算，不是汽车数据的回归结果。

Python
import pandas as pd
import statsmodels.formula.api as smf
import matplotlib.pyplot as plt

# 同一数据、同一变量和缺失值处理
d = pd.read_stata(
    "https://www.stata-press.com/data/r19/auto.dta",
    convert_categoricals=False
)
d = d[["price", "weight"]].dropna().copy()

# 与Stata vce(robust)对应的HC1标准误
m = smf.ols("price ~ weight", data=d).fit(cov_type="HC1")
d["yhat"] = m.fittedvalues
d["ehat"] = m.resid
print("n =", int(m.nobs))
print("系数：", m.params)
print("稳健标准误：", m.bse)
print("残差和：", d["ehat"].sum())

ax = d.plot.scatter(x="weight", y="price", alpha=0.7)
d.sort_values("weight").plot(x="weight", y="yhat", ax=ax, legend=False)
plt.tight_layout()
plt.show()

五、初学者避坑

把OLS理解成“误差最小”。 它最小化的是样本残差平方和，不是每个残差的绝对值，也不保证样本外预测误差最小。
把OLS计算条件等同于因果识别条件。 重量有变异即可帮助求出斜率，但若车型配置同时影响重量和价格，系数仍可能含有遗漏变量偏误。要解释为因果效应，还需合适的识别假设，例如零条件均值。
以为稳健标准误能修正斜率偏误。 HC1允许一定形式的异方差下进行稳健推断，但不消除内生性；推断还依赖适当的抽样独立性或其他抽样结构假设。

六、今日练习

概念题： 为什么OLS要平方残差？“残差和为零”是否足以说明拟合良好？
实操题： 对三组观测 (1,2)、(2,3)、(3,5)，求OLS斜率和截距，并给出 x=4 时的预测值。
参考答案
概念题：平方防止正负残差抵消，并使较大偏差受到更大惩罚；含截距OLS的残差和本来就为零，不能据此判断拟合质量。
实操题：斜率1.5、截距1/3；x=4时预测值为 1/3+1.5×4=19/3≈6.33。该值属于样本范围外预测，解释时还需注意外推风险。
