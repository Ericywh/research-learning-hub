先把概念讲清楚，再读公式

本课可分两次学习：先读以下解释和例子；能说清含义后，再读原理与公式，代码可以第三次再做。暂时看不懂公式，不必跳过概念直接复制命令。

平行趋势

若没有处理，处理组和对照组的平均结果变化应可比较。它不是要求政策前水平相同。

具体例子：处理组8到13，对照组6到8，DID为(13−8)−(8−6)=3；若处理组本来就涨得更快，该3不能直接归于政策。

反事实

同一个对象在另一种处理状态下本来会出现的结果。现实中通常无法同时观测两个状态。

具体例子：参加培训者工资8000，不代表培训带来8000；还需知道他未培训时本来能挣多少。

处理效应

比较潜在结果Y(1)与Y(0)的差。ATE平均全体，ATT平均实际处理者，LATE平均特定工具影响的依从者。

具体例子：培训可能对自愿报名者更有效，所以ATT不必等于ATE。不能仅因都叫“平均效应”就互换。

1 · 核心问题与推导

DID计算处理组前后变化再减去对照组变化。识别要求无处理潜在结果的平均趋势相同，而非两组政策前水平相同。无预期、稳定组成、无溢出等条件下，对照变化可构造处理组无政策反事实。单位与时间固定效应不能自动让这一反事实可信。模拟应明确处理组、实施时点、真实效应与共同冲击；模拟估计与预设真值比较仅检验程序和机制，不是现实政策证据。

2 · 公式与统计前提

ATT=(Ȳ_T,post−Ȳ_T,pre)−(Ȳ_C,post−Ȳ_C,pre)

事前趋势不拒绝只能提供有限支持，尤其功效不足时不能作为平行趋势证明。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
rng=np.random.default_rng(20261027);N=160;T=8
id=np.repeat(np.arange(N),T);time=np.tile(np.arange(T),N)
treated=(id<N//2).astype(int);post=(time>=4).astype(int)
tau=np.maximum(time-3,0)*.5
y=np.repeat(rng.normal(size=N),T)+.2*time+treated*tau+rng.normal(size=N*T)
df=pd.DataFrame(dict(y=y,id=id,t=time,treated=treated,post=post))
static=smf.ols('y ~ treated:post+C(id)+C(t)',df).fit(cov_type='cluster',cov_kwds={'groups':id})
names=[]
for k in range(-4,4):
    if k==-1:continue
    name='event_'+('m'+str(-k) if k<0 else 'p'+str(k));names.append(name)
    df[name]=((time-4==k)&(treated==1)).astype(int)
event=smf.ols('y ~ C(id)+C(t)+'+'+'.join(names),df).fit(cov_type='cluster',cov_kwds={'groups':id})
print('static DID',static.params['treated:post'])
for name in names:print(name,event.params[name],event.bse[name])
print('pre joint',event.wald_test('event_m4=event_m3=event_m2=0',scalar=True))

clear all
set more off
set seed 20261027
* Synthetic teaching data. Stata and NumPy RNG streams differ.
set obs 160
gen long id=_n
gen double a=rnormal()
gen byte treated=id<=80
expand 8
bysort id: gen long t=_n-1
gen byte post=t>=4
gen double y=a+.2*t+treated*max(t-3,0)*.5+rnormal()
xtset id t
xtreg y i.t c.treated#c.post, fe vce(cluster id)
local events
forvalues j=0/7 {
    if `j'!=3 {
        gen byte ev`j'=(t==`j')*treated
        local events `events' ev`j'
    }
}
xtreg y i.t `events', fe vce(cluster id)
test ev0 ev1 ev2
* ev3 omitted = relative time -1. Coefficients now form an actual dynamic path.
