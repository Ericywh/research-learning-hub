第3章·第5节｜异方差检验与稳健标准误

全课程第27课 / 共120课 · 预计10—15分钟

一、通俗理解

回归汽车价格时，大型车和小型车的价格预测误差未必同样分散。若车辆重量增加后，价格残差的波动范围也扩大，就可能存在异方差（heteroskedasticity）：误差的条件方差随解释变量而变化。

可以把OLS想成寻找一条最能拟合平均价格的直线。异方差改变的是直线周围“云团”的宽度。若解释变量外生且满足适当矩条件，OLS系数仍可一致；但把所有观测的误差波动都视为相同，通常会算错标准误，进而影响t检验和置信区间。

本课要区分三个问题：残差图是否提示异方差、正式检验是否拒绝同方差、采用HC1后推断如何改变。三者提供的信息并不相同。

二、核心理论与公式

在含截距的线性模型中，设 \(x_i\) 为包含解释变量的列向量，\(u_i\) 为误差项。同方差假设与异方差情形可写为：

\[\operatorname{Var}(u_i\mid x_i)=\sigma^2\quad\text{或}\quad\operatorname{Var}(u_i\mid x_i)=\sigma_i^2.\]

在独立观测、\(E[u_i\mid x_i]=0\)、设计矩阵满秩及适当矩条件下，HC1估计OLS系数协方差矩阵：

\[\widehat V_{HC1}=\frac{n}{n-k}(X^\top X)^{-1}\left(\sum_{i=1}^{n}x_ix_i^\top\widehat u_i^2\right)(X^\top X)^{-1}.\]

其中 \(n\) 是样本量，\(k\) 是包含截距的参数个数，\(\widehat u_i\) 为OLS残差。HC1保留原OLS点估计，只调整协方差估计。

检验方面，Koenker型Breusch–Pagan方法将残差平方对解释变量做辅助OLS，取 \(LM=nR^2_{\mathrm{aux}}\)。在同方差原假设及适当独立性、矩条件下，该统计量渐近服从自由度等于辅助回归非截距变量数的卡方分布。

三、实证案例与数据

使用Stata Press官方1978年汽车教学数据 auto.dta，原始文件含74辆汽车。变量为价格 price（美元）、重量 weight（磅）、油耗 mpg（英里/加仑）、进口标记 foreign（0/1）。

两种软件均只保留这四个变量无缺失的汽车，估计价格对重量、油耗和进口标记的含截距OLS。残差—拟合值散点图用于观察波动模式；再用相同的残差平方辅助回归计算Koenker型BP统计量。

汽车样本并非随机处理实验；回归结果描述条件关联。代码未在本次授课中执行，样本量和检验结果以实际运行输出为准。

四、Stata与Python实现

两套代码使用同一公开文件、同一完整案例筛选、相同OLS设计矩阵与HC1标准误；辅助回归均采用残差平方对原三个解释变量回归，以便比较LM统计量。Stata默认的其他异方差检验选项不一定与这一版本相同。

Stata

Stata 可复制代码
* 公开汽车数据：与Python使用相同样本
clear all
set more off
use "https://www.stata-press.com/data/r19/auto.dta", clear
keep if !missing(price, weight, mpg, foreign)
count

* 含截距OLS；Stata的vce(robust)为HC1
regress price weight mpg foreign, vce(robust)
predict double ehat, resid
predict double yhat, xb
twoway scatter ehat yhat, yline(0)

* Koenker型BP检验：辅助回归残差平方
gen double ehat2 = ehat^2
quietly regress ehat2 weight mpg foreign
scalar LM = e(N)*e(r2)
display "BP/Koenker LM = " %9.4f LM
display "chi2(3) p-value = " %9.5f chi2tail(3, LM)

Python

Python 可复制代码
# pip install pandas numpy statsmodels scipy
import pandas as pd
import statsmodels.formula.api as smf
from scipy.stats import chi2

url = "https://www.stata-press.com/data/r19/auto.dta"
df = pd.read_stata(url, convert_categoricals=False)
cols = ["price", "weight", "mpg", "foreign"]
df = df.dropna(subset=cols).copy()
print("共同样本量：", len(df))

# 与Stata完全相同的含截距OLS和HC1标准误
m = smf.ols("price ~ weight + mpg + foreign", data=df).fit(
    cov_type="HC1", use_t=True
)
print(m.summary())

# 用同一OLS残差构造Koenker型BP的nR²统计量
df["ehat2"] = m.resid ** 2
aux = smf.ols("ehat2 ~ weight + mpg + foreign", data=df).fit()
lm = len(df) * aux.rsquared
print("BP/Koenker LM =", lm)
print("chi2(3) p-value =", chi2.sf(lm, 3))

运行时核对共同样本量、OLS系数、HC1标准误、LM统计量和p值。若拒绝同方差，表示这一检验针对的方差限制与数据不相容；未拒绝也不等于证明同方差。

五、初学者避坑

1. 把异方差当成OLS系数一定有偏。 若条件均值外生，异方差主要影响常规标准误和效率；内生性是另一个问题。

2. 认为HC1会修复遗漏变量或时间相关。 HC1不改变系数，也不能自动处理组内相关、序列相关。

3. 把检验p值当作是否使用稳健标准误的唯一开关。 检验可能功效不足；推断方案应结合抽样方式、数据依赖结构及研究设计预先确定。

六、今日练习

概念题： 在解释变量外生、观测独立的前提下，发现异方差后，为什么不必重新计算OLS系数，却应重新考虑标准误？

答案： OLS系数仍是同一平方和最小化问题的解；常规同方差协方差公式不再适用。HC1根据残差平方估计异方差下的协方差，不改变OLS点估计。

计算题： 某次辅助回归的样本量为80，\(R^2_{mathrm{aux}}=0.10\)，有3个非截距解释变量。计算Koenker型BP的LM统计量，并说明如何判断。

答案： \(LM=80\times0.10=8\)，与自由度为3的卡方分布比较；5%临界值约为7.815，因此在渐近近似下拒绝同方差原假设。这是教学假设数据，不是汽车样本的运行结果。
