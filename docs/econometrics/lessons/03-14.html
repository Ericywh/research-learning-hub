聚类

一组观测共享冲击，组内不视为独立。聚类标准误允许同组误差相关，通常仍要求不同组适当独立。

具体例子：学校政策影响整校学生，不能把2000名学生都当2000次独立政策分配；学校数也决定信息量。

样本

实际观察到的一组单位。样本能否代表总体取决于抽样与失访过程，不能只看人数。

具体例子：只调查大学毕业生，即使有一万人，也不能自动代表全部劳动者。

标准差与标准误

标准差描述个体数据的离散；标准误描述估计量在重复抽样中的波动。两者回答不同问题。

具体例子：工资差异很大，但若独立样本很多，平均工资仍可估得较精确。独立同分布时均值SE约为SD/√n。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

同校学生共享教师与制度环境，独立信息可能主要来自学校数。聚类方差把每组得分先加总，再取不同组之间的外积。聚类层级应根据抽样设计、处理分配和误差相关来源确定，不能按哪种结果更显著选择。组数趋于无穷且无单组支配样本，是常见渐近论证的重要条件；增加组内人数不能替代增加独立组。多维聚类处理交叉相关，但相应维度也需足够信息。

2 · 公式与统计前提

Ŝ_cluster=n⁻¹Σ_g(Σ_i∈g xᵢeᵢ)(Σ_i∈g xᵢeᵢ)′

少量聚类或极少处理组时常规修正可能不足，应考虑设计适配的随机化推断、CR2或wild cluster bootstrap。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
rng=np.random.default_rng(20261027);G=80;m=20
group=np.repeat(np.arange(G),m)
x=np.repeat(rng.normal(size=G),m)+rng.normal(size=G*m)
y=1+2*x+np.repeat(rng.normal(size=G),m)+rng.normal(size=G*m)
X=sm.add_constant(x)
hc=sm.OLS(y,X).fit(cov_type='HC1')
cl=sm.OLS(y,X).fit(cov_type='cluster',cov_kwds={'groups':group,'use_correction':True})
assert np.allclose(hc.params,cl.params)
print('G=',G,'HC1 SE',hc.bse,'cluster SE',cl.bse)

5 · 专属练习与参考答案

20校每校100人与200校每校10人，能保证政策效应精度一样吗？

展开答案与依据

不能。组内共同冲击下后者通常有更多独立信息，实际还取决于分配、组内相关和组大小。
