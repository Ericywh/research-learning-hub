先把概念讲清楚，再读公式

本课可分两次学习：先读以下解释和例子；能说清含义后，再读原理与公式，代码可以第三次再做。暂时看不懂公式，不必跳过概念直接复制命令。

选择与删失

选择决定谁进入可见样本；删失知道对象存在，但只知道结果超出某界。截断则连界外对象也不出现在数据中。

具体例子：只调查就业者工资是选择问题；低于3000一律记3000是左删失；完全不记录低工资者是截断。

样本

实际观察到的一组单位。样本能否代表总体取决于抽样与失访过程，不能只看人数。

具体例子：只调查大学毕业生，即使有一万人，也不能自动代表全部劳动者。

期望

随机变量的概率加权平均。条件期望E[Y｜X=x]表示在X取给定值时的总体平均，而非某一个人的必然结果。

具体例子：工资只有4000和8000且概率各一半，期望为6000；并不要求有人恰好挣6000。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

只观察就业者工资时，选择可能与未观测工资因素相关。Heckman先建模被观察概率，在联合正态等假设下通过逆米尔斯比修正条件误差均值。可信的排除变量影响选择但不直接影响结果，比只靠函数形式更有说服力。截断、删失、选择缺失是不同机制。分位数回归最小化非对称绝对损失，估计条件分位数，不是在某类固定低收入人群中做OLS；同一人的条件排名可随协变量变化。

2 · 公式与统计前提

ρτ(u)=u[τ−1(u<0)]；bτ=argminΣρτ(yᵢ−xᵢ′b)

Heckman不是所有缺失的通用修复；条件分位数系数差异不自动是个人处理效应异质性。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
from scipy.special import ndtr
from scipy.stats import norm
rng=np.random.default_rng(20261027);n=6000
x,z=rng.normal(size=(2,n));v=rng.normal(size=n)
u=.6*v+.8*rng.normal(size=n);y=1+2*x+u
d=(.3+.4*x+.8*z+v>0) # z excluded from outcome by construction
sel=sm.Probit(d,np.column_stack([np.ones(n),x,z])).fit(disp=False)
eta=np.column_stack([np.ones(n),x,z])@sel.params
lam=norm.pdf(eta)/np.clip(ndtr(eta),1e-10,1)
X=sm.add_constant(x)
naive=sm.OLS(y[d],X[d]).fit()
two=sm.OLS(y[d],np.column_stack([X[d],lam[d]])).fit()
qr=sm.QuantReg(y,X).fit(q=.25)
print('naive slope',naive.params[1],'Heckman two-step slope',two.params[1])
print('Point estimates only: second-step OLS default SE is not Heckman-corrected')
print('conditional quantile .25',qr.params)

gen byte observed=(.3+.4*x+.8*z+v>0)
gen double y=latent_y if observed
heckman y x, select(observed=x z) twostep
qreg latent_y x, quantile(.25)

5 · 专属练习与参考答案

只记录高于阈值者与将低于阈值者记为阈值，有何区别？

展开答案与依据

前者是截断，低值个体完全缺失；后者为删失，仍知道这些个体存在及结果低于阈值。
