CLT与学生化

CLT描述中心化并按√n放大后的随机波动；学生化是再除以估计标准差，让统计量有可用的参考分布。

具体例子：√n(均值−μ)极限方差是σ²，继续除以一致估计的σ才得到标准正态。依赖和重尾可能使常见CLT不适用。

抽样分布

固定总体及抽样规则，反复抽取同样大小样本，每次计算估计量，所有可能结果形成的分布。

具体例子：把1000次样本均值画直方图，画的是均值的抽样分布，不是1000个人工资的分布。

依分布收敛

一列随机量的分布逐渐接近某个极限分布，记作→d；不等于随机量本身趋近某个常数。

具体例子：CLT研究√n(均值−μ)的分布形状；未经缩放的均值则可依概率趋近μ，两者讨论不同对象。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

CLT描述中心化并放大后的抽样分布，不是原始数据变成正态。回归中需要对得分xᵢuᵢ检查矩与依赖条件。若n⁻¹/²Σxᵢuᵢ趋于N(0,S)，Q̂趋于非奇异常数Q，Slutsky给出√n(b−β)的极限方差Q⁻¹SQ⁻¹。以一致估计的渐近标准差学生化，统计量趋于N(0,1)。Slutsky不要求两项独立，但替换量必须趋于常数；除法要求该常数非零。不存在普遍的n>100门槛，近似速度取决于偏态、重尾、杠杆与有效独立信息。

2 · 公式与统计前提

√n(b−β) →d N(0,V)；(bⱼ−βⱼ)/SÊ(bⱼ) →d N(0,1)

模拟覆盖率本身有抽样波动。R次实验的标准误约√[p(1−p)/R]，不能保证恰好95%。

3 · 图示与研究含义

查看实际Monte Carlo直方图及数值结果。比较的是重复抽样的统计量分布。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import csv
from pathlib import Path
rng=np.random.default_rng(20261027)
R=1000; rows=[]; hist=[]
for n in [30,200,2000]:
    bs=[]; ts=[]
    for r in range(R):
        x=rng.uniform(0,4,n)
        u=x*(rng.exponential(size=n)-1) # E[u|x]=0; heteroskedastic, skewed
        y=1+2*x+u
        xc=x-x.mean(); den=xc@xc
        b=xc@y/den; e=y-(y.mean()-b*x.mean())-b*x
        se=np.sqrt(n/(n-2)*np.sum(xc**2*e**2))/den
        bs.append(b);ts.append((b-2)/se)
    bs=np.array(bs);ts=np.array(ts)
    cover=np.mean(np.abs(ts)<=1.96)
    row=dict(n=n,bias=float(bs.mean()-2),sd=float(bs.std(ddof=1)),
             rmse=float(np.sqrt(np.mean((bs-2)**2))),coverage=float(cover),
             mcse=float(np.sqrt(cover*(1-cover)/R)))
    rows.append(row);print(row)
    counts,edges=np.histogram(ts,bins=np.linspace(-4,4,33))
    hist.append((n,counts))
out=Path(__file__).resolve().parent/'results';out.mkdir(exist_ok=True)
with (out/'asymptotics.csv').open('w',newline='') as f:
    w=csv.DictWriter(f,fieldnames=list(rows[0]));w.writeheader();w.writerows(rows)
# Actual Monte Carlo histograms; no hand-drawn density presented as results.
svg=['<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 960 330" role="img" aria-label="Monte Carlo studentized statistics">','<rect width="960" height="330" fill="#f8fafb"/>']
for panel,(n,counts) in enumerate(hist):
    for j,c in enumerate(counts):
        h=220*c/max(counts)
        svg.append(f'<rect x="{panel*320+15+j*9}" y="{270-h}" width="8" height="{h}" fill="#247c80"/>')
    svg.append(f'<text x="{panel*320+18}" y="30">n={n}, R={R}</text><text x="{panel*320+18}" y="302">t scale: -4 to 4</text>')
svg.append('</svg>');(out/'clt.svg').write_text(''.join(svg),encoding='utf-8')

version 17.0
clear all
set more off
set seed 20261027
* Synthetic teaching data. Stata and NumPy RNG streams differ.
capture program drop experiment
program define experiment, rclass
    syntax, N(integer)
    drop _all
    quietly set obs `n'
    gen double x=runiform(0,4)
    gen double u=x*(rexponential(1)-1)
    gen double y=1+2*x+u
    quietly regress y x, vce(robust)
    return scalar b=_b[x]
    return scalar t=(_b[x]-2)/_se[x]
end
foreach n in 30 200 2000 {
    simulate b=r(b) t=r(t), reps(1000) nodots: experiment, n(`n')
    gen double covered=abs(t)<=1.96
    summarize b t covered
    histogram t, normal name(n`n', replace) title("n=`n', R=1000")
}
