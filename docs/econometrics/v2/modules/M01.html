反事实

同一个对象在另一种处理状态下本来会出现的结果。现实中通常无法同时观测两个状态。

具体例子：参加培训者工资8000，不代表培训带来8000；还需知道他未培训时本来能挣多少。

处理效应

比较潜在结果Y(1)与Y(0)的差。ATE平均全体，ATT平均实际处理者，LATE平均特定工具影响的依从者。

具体例子：培训可能对自愿报名者更有效，所以ATT不必等于ATE。不能仅因都叫“平均效应”就互换。

识别

在给定假设下，理想地知道总体数据分布后，能否唯一确定目标参数。识别先于有限样本估计。

具体例子：若工资同时受教育和未观测能力影响，教育与工资的相关性本身不能唯一确定教育的因果作用。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

观察到的工资差包含教育作用，也可能包含能力和家庭背景的选择。描述任务报告关系，预测任务评价新样本误差，因果任务必须先定义干预。三种任务可以使用同一条回归式，却需要不同的证据。令Y(1)、Y(0)表示接受和不接受处理的潜在结果，实际只能观察其中一个。处理组与对照组均值差等于ATT加选择偏差E[Y(0)|D=1]−E[Y(0)|D=0]。随机分配在设计上切断这一选择差异，观察性回归则需额外识别假设。研究总体、处理时间、结果窗口都应先于估计确定。

2 · 公式与统计前提

ATE=E[Y(1)−Y(0)]；ATT=E[Y(1)−Y(0)|D=1]

SUTVA要求处理版本明确且无相关个体间干扰；随机分配不保证实际接受处理，差异失访也可能破坏可比性。

进阶讲义 · 均值差的识别分解

推导与成立条件

在处理组结果均值中加上再减去E[Y(0)|D=1]，第一部分成为E[Y(1)−Y(0)|D=1]，第二部分成为未处理潜在结果的组间差。观测均值差因此只在选择偏差为零时等于ATT。随机分配识别分配效应；存在不依从时，实际接受处理的比较重新带有选择。

工作例题与研究判断

若处理者在未处理时本来比对照者少挣2，而观测差为3，ATT=5。选择偏差可以向下，不能默认所有观察性差异都夸大效应。

实验报告要求

运行本页实验前，写出目标参数、数据生成机制和所用协方差。保存基准输出，再改变一个与本课结论直接相关的条件，比较估计值、标准误或覆盖率。解释变化来自识别、有限样本波动还是推断方法。模拟结果仅用于检验指定机制；若脚本未实现某项高级推断，应明确记录并参照方法文档补做，不能把输出标签当作实现证据。

3 · 图示与研究含义

观测均值差 = ATT + 未处理潜在结果的选择偏差

图为概念示意；数值结论以运行代码和明确的数据来源为准。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
rng=np.random.default_rng(20261027)
n=800
z=rng.normal(size=n); x=.6*z+rng.normal(size=n)
y=1+2*x+.8*z+rng.normal(size=n)
X=np.column_stack([np.ones(n),x,z])
b=np.linalg.lstsq(X,y,rcond=None)[0]
Z=np.column_stack([np.ones(n),z])
rx=x-Z@np.linalg.lstsq(Z,x,rcond=None)[0]
ry=y-Z@np.linalg.lstsq(Z,y,rcond=None)[0]
fwl=rx@ry/(rx@rx)
P=X@np.linalg.solve(X.T@X,X.T)
assert abs(fwl-b[1])<1e-10
assert np.max(np.abs(P@P-P))<1e-10
assert np.max(np.abs(X.T@(y-X@b)))<1e-8
fit=sm.OLS(y,X).fit(cov_type='HC1')
print('OLS',b,'FWL',fwl,'HC1 SE',fit.bse)
print('Joint Wald',fit.wald_test(np.array([[0,1,0],[0,0,1]]),scalar=True))

5 · 专属练习与参考答案

处理组均值10、对照组7，未处理潜在结果的组间差为2，ATT是多少？

展开答案与依据

ATT=10−7−2=1。均值差本身不能排除选择偏差。
