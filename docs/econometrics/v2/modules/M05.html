M05 · 交互项、对数与二次项

先把概念讲清楚，再读公式

本课可分两次学习：先读以下解释和例子；能说清含义后，再读原理与公式，代码可以第三次再做。暂时看不懂公式，不必跳过概念直接复制命令。

交互项

允许一个变量的条件效应随另一变量取值改变。它是变量乘积，不能只解读乘积系数而忽略主效应。

具体例子：y=1+2x+3z+4xz，x斜率在z=0时为2，在z=1时为6。

梯度与导数

导数是一个输入微变时函数的局部变化率；梯度把多参数的各偏导数排成向量。

具体例子：g(b)=exp(b)，导数仍为exp(b)；g(b₁,b₂)的误差取决于两个偏导及b₁、b₂的协方差。

期望

随机变量的概率加权平均。条件期望E[Y｜X=x]表示在X取给定值时的总体平均，而非某一个人的必然结果。

具体例子：工资只有4000和8000且概率各一半，期望为6000；并不要求有人恰好挣6000。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

含交互项时主效应只表示另一变量取零时的条件斜率。E[y|x,z]=β₀+β₁x+β₂z+β₃xz的x边际效应为β₁+β₃z。二次项的驻点为−β₁/(2β₂)，只有β₂非零且驻点落在支持域内才值得解释。二次曲线没有曲率改变符号的拐点，不能把驻点称为拐点。半对数模型中的精确比例变化是exp(β)−1；将预测对数直接指数还原一般不是条件均值，仍需处理误差指数项。

2 · 公式与统计前提

∂E[y|x,z]/∂x=β₁+β₃z；x*=−β₁/(2β₂)

样本范围外的驻点属于外推；交互效应标准误须包含系数协方差。

进阶讲义 · 函数形式与不确定性

推导与成立条件

交互模型的条件斜率为β1+β3z，其方差为Var(b1)+z²Var(b3)+2zCov(b1,b3)。因此只看交互系数的显著性不能判断某个z处效应是否显著。对数结果模型满足E[Y|X]=exp(Xβ)E[exp(u)|X]，直接指数化遗漏第二项。

工作例题与研究判断

取Var(b1)=.04、Var(b3)=.01、Cov=−.01、z=2，斜率方差=.04，标准误=.2。忽略协方差会得到错误区间。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
rng=np.random.default_rng(20261027);n=1600
x=rng.uniform(0,6,n)
y=1+2*x-.3*x*x+rng.normal(size=n)*(1+.2*x)
X=np.column_stack([np.ones(n),x,x*x])
fit=sm.OLS(y,X).fit(cov_type='HC1')
b=fit.params;V=fit.cov_params()
g=-b[1]/(2*b[2]);G=np.array([0,-1/(2*b[2]),b[1]/(2*b[2]**2)])
se=np.sqrt(G@V@G)
def target(b):return -b[1]/(2*b[2])
h=1e-5
fd=np.array([(target(b+np.eye(3)[j]*h)-target(b-np.eye(3)[j]*h))/(2*h) for j in range(3)])
assert np.max(abs(G-fd))<1e-5
print('Stationary point, not inflection:',g,'Delta SE:',se,'support:',(x.min(),x.max()))

5 · 专属练习与参考答案

β₁=4、β₂=−0.5，x只在0到2之间，能否宣称x=4最优？

展开答案与依据

驻点为4，但在支持域外。可报告区间内斜率与预测，不能宣称观测证据支持该最优点。
