M35 · DML与交叉拟合残差化

先修：M03,M24 · 核心讲义v1 · 建议45分钟，实验及延伸另计

推导前提图示代码练习验收映射

1 · 核心问题与推导

部分线性模型中，令m(X)=E[D|X]、l(X)=E[Y|X]，在训练折学习这两个函数，在留出折计算残差并构造正交得分。其对干扰函数误差的一阶敏感性抵消，交叉拟合减弱过拟合依赖。有效根号n推断仍需识别、重叠、矩界与干扰误差乘积足够快趋零；并非随意换一个预测器即可。全样本训练后再切折属于信息泄漏，不能称交叉拟合。DML扩展FWL思想，但不会创造处理外生性。

2 · 公式与统计前提

E[(D−m(X)){Y−l(X)−θ(D−m(X))}]=0

未测混杂不会消失；聚类或面板分折与协方差要保留依赖。教学实验用多项式学习器示范，不冒称完整通用软件包。

3 · 图示与研究含义

图为概念示意；数值结论以运行代码和明确的数据来源为准。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
rng=np.random.default_rng(20261027);n=3000
x=rng.normal(size=(n,3));B=np.column_stack([np.ones(n),x,x*x,x[:,0]*x[:,1]])
d=.5*x[:,0]+x[:,1]**2+rng.normal(size=n)
y=2*d+x[:,0]**2+.4*x[:,2]+rng.normal(size=n)
fold=np.empty(n,int);fold[rng.permutation(n)]=np.arange(n)%5
rd=np.zeros(n);ry=np.zeros(n)
for k in range(5):
    train=fold!=k;test=~train
    bd=np.linalg.lstsq(B[train],d[train],rcond=None)[0]
    by=np.linalg.lstsq(B[train],y[train],rcond=None)[0]
    rd[test]=d[test]-B[test]@bd;ry[test]=y[test]-B[test]@by
b=rd@ry/(rd@rd);psi=rd*(ry-b*rd)
se=np.sqrt(np.mean(psi**2)/n)/np.mean(rd**2)
print('Cross-fit polynomial nuisance PLR',b,'SE',se,'true theta 2')

gen double d=.5*x1+x2sq+rnormal()
gen double y=2*d+x1sq+.4*x3+rnormal()

sort shuffle
gen byte fold=mod(_n,5)
gen double rd=.
gen double ry=.
forvalues k=0/4 {
    quietly regress d x1 x2 x3 x1sq x2sq x3sq cross if fold!=`k'
    predict double pd, xb
    replace rd=d-pd if fold==`k'
    drop pd
    quietly regress y x1 x2 x3 x1sq x2sq x3sq cross if fold!=`k'
    predict double py, xb
    replace ry=y-py if fold==`k'
    drop py
}
regress ry rd, noconstant vce(robust)
