M13 · 遗漏变量、测量误差与联立性

先把概念讲清楚，再读公式

本课可分两次学习：先读以下解释和例子；能说清含义后，再读原理与公式，代码可以第三次再做。暂时看不懂公式，不必跳过概念直接复制命令。

遗漏变量偏差

被遗漏因素影响结果且与已入式解释变量相关时，回归系数可能混入该因素的作用。

具体例子：真式y=βx+2a+u，若Cov(x,a)=0.3、Var(x)=1.5，遗漏a的标量斜率极限偏差为0.4。

外生性

解释变量与误差之间满足特定正交或条件均值限制。不同模型要求不同，不是“变量来自系统外面”的日常说法。

具体例子：若能力影响工资，又与教育相关，遗漏能力后E[u｜教育]可能不为零。仅换稳健SE不能解决。

混杂

一个处理前因素同时影响处理选择与结果，使处理组和对照组本来就不同。

具体例子：能力同时影响教育和工资，会使教育—工资关联混入能力差异。仅“相关”不是认定混杂的充分因果依据。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

省略能力a时，教育斜率混入能力与教育的共同变异。y=βx+γa+u中，遗漏偏差为γCov(x,a)/Var(x)。经典测量误差x*=x+v要求v与x、u不相关，简单回归斜率被乘以信度Var(x)/[Var(x)+Var(v)]，向零衰减。非经典误差、多个带误差变量或非线性模型不能套这一结论。联立性来自x与y共同决定，改标准误或增加n不能解决。教育回报示例必须实际把教育放入回归，不能仅在标题提及。

2 · 公式与统计前提

plim b_遗漏=β+γCov(x,a)/Var(x)

可能内生不等于已经证实内生，需要制度与测量过程证据。模拟只演示指定机制，不是经验事实。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
rng=np.random.default_rng(20261027);n=20000
ability=rng.normal(size=n);education=12+.6*ability+rng.normal(size=n)
logwage=1+.08*education+.3*ability+rng.normal(size=n)
short=sm.OLS(logwage,sm.add_constant(education)).fit()
full=sm.OLS(logwage,np.column_stack([np.ones(n),education,ability])).fit()
predicted=.3*np.cov(education,ability,ddof=0)[0,1]/np.var(education)
print('Education included in both equations')
print('short,full, predicted OVB',short.params[1],full.params[1],predicted)
measured=education+rng.normal(size=n)
print('Measurement error slope',sm.OLS(logwage,sm.add_constant(measured)).fit().params[1])

5 · 专属练习与参考答案

γ=2、Cov(x,a)=0.3、Var(x)=1.5，遗漏偏差多少？

展开答案与依据

0.4。若经典测量信度为0.8、真斜率1.5，带误差回归的极限为1.2。
