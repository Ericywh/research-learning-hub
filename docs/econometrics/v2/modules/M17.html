本课可分两次学习：先读以下解释和例子；能说清含义后，再读原理与公式，代码可以第三次再做。暂时看不懂公式，不必跳过概念直接复制命令。

两阶段最小二乘

先用完整工具空间预测内生变量，再用被工具解释的变动估计结构关系。

具体例子：第一步预测教育，第二步分析工资；手动第二步OLS可得到点估计，但其默认SE不能直接当正确IV标准误。

投影与正交

投影是在可用变量张成的空间内寻找最靠近y的拟合；正交意味着向量内积为零。

具体例子：把点向直线作垂线，垂足是投影。回归几何发生在样本向量空间，不是简单的两个变量散点图。

工具变量

利用一项影响处理、但不通过其他渠道影响结果且满足外生条件的变量，提取可解释的处理变动。

具体例子：随机发培训邀请会提高参加率；要用作工具，还需邀请本身不直接提高工资等条件，不能只看第一阶段显著。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

第一阶段把内生解释变量投影到完整工具空间，外生控制变量应同时进入结构式与工具空间。第二阶段利用这些可预测变动估计结构参数。手动将预测x放入OLS可还原点估计，但默认方差错误：结构残差为y−Xb，不是y−X̂b。控制函数将第一阶段残差带回结构式，在适当假设下提供另一种处理内生性的路径。DWH检验解释依赖工具有效等条件，不拒绝也可能仅因功效低。

2 · 公式与统计前提

b_2SLS=(X′P_ZX)⁻¹X′P_Zy

线性模型的控制函数等价性不能无条件推广至非线性模型；第二阶段普通OLS默认SE不能作为IV标准误。

进阶讲义 · 2SLS的矩阵与方差

推导与成立条件

将X投影为Xhat=P_ZX，再回归得到(X′P_ZX)⁻¹X′P_Zy。结构残差应为e=y−Xb。独立异方差下系数协方差为A⁻¹X′P_Z diag(e²)P_ZX A⁻¹，其中A=X′P_ZX。手工第二阶段用y−Xhat b会误估结构误差。

工作例题与研究判断

若工具矩阵含外生控制而结构式遗漏同一控制，模型目标发生变化。比较手工点估计与专用IV估计应固定样本、工具及截距处理。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
from scipy.stats import chi2
rng=np.random.default_rng(20261027);n=3000
z1,z2,c=rng.normal(size=(3,n))
x=.5+.6*z1+.4*z2+.7*c+rng.normal(scale=.5,size=n)
u=(.7*c+rng.normal(scale=.5,size=n))*(1+.5*abs(z1))
y=1+1.5*x+u
X=np.column_stack([np.ones(n),x]);Z=np.column_stack([np.ones(n),z1,z2])
D=Z.T@X/n;q=Z.T@y/n
def estimate(W):return np.linalg.solve(D.T@W@D,D.T@W@q)
W1=np.linalg.inv(Z.T@Z/n);b1=estimate(W1)
mom1=Z*(y-X@b1)[:,None];S1=mom1.T@mom1/n
W2=np.linalg.inv(S1);b2=estimate(W2)
mom2=Z*(y-X@b2)[:,None];S2=mom2.T@mom2/n
A=np.linalg.inv(D.T@W2@D)
V=A@D.T@W2@S2@W2@D@A/n
g=mom2.mean(axis=0);J=n*g@W2@g
print('2SLS',b1,'two-step GMM',b2,'robust SE',np.sqrt(np.diag(V)))
print('J',J,'df',Z.shape[1]-X.shape[1],'p',chi2.sf(J,1))
assert Z.shape[1]-X.shape[1]==1
# Independent projection formula confirms the 2SLS point estimate.
Xp=Z@np.linalg.lstsq(Z,X,rcond=None)[0]
check=np.linalg.solve(Xp.T@X,Xp.T@y)
assert np.allclose(check,b1)

* Synthetic teaching data. Stata and NumPy RNG streams differ.
set obs 3000
gen double z1=rnormal()
gen double z2=rnormal()
gen double c=rnormal()
gen double x=.5+.6*z1+.4*z2+.7*c+rnormal(0,.5)
gen double u=(.7*c+rnormal(0,.5))*(1+.5*abs(z1))
gen double y=1+1.5*x+u
ivregress 2sls y (x=z1 z2), vce(robust)
estat firststage
estat endogenous
ivregress gmm y (x=z1 z2), wmatrix(robust) vce(robust)
estat overid
* J nonrejection is not proof of validity; constant included: L=3 K=2.

5 · 专属练习与参考答案

IV回归的R²为何可能为负？

展开答案与依据

IV没有最小化结构残差平方和，可能比常数均值预测拟合更差。这不是拒绝识别设计的充分理由。
