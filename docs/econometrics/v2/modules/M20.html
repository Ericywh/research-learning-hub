胜算与边际效应

概率p的胜算为p/(1−p)。Logit系数改变对数胜算，概率边际效应还取决于基线概率。

具体例子：p=0.2时胜算0.25；胜算翻倍后概率为0.5/1.5≈0.333，不是0.4。

梯度与导数

导数是一个输入微变时函数的局部变化率；梯度把多参数的各偏导数排成向量。

具体例子：g(b)=exp(b)，导数仍为exp(b)；g(b₁,b₂)的误差取决于两个偏导及b₁、b₂的协方差。

期望

随机变量的概率加权平均。条件期望E[Y｜X=x]表示在X取给定值时的总体平均，而非某一个人的必然结果。

具体例子：工资只有4000和8000且概率各一半，期望为6000；并不要求有人恰好挣6000。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

Logit系数作用于对数胜算，不直接等于概率变化。连续变量边际效应为βⱼp(1−p)；二元变量应计算取1与0的离散预测差。AME在每个观测位置计算效应再平均，通常不同于平均协变量位置的效应。固定X的Delta推断将AME视为β的函数并求完整梯度；若目标包括随机总体X分布的不确定性，还需额外处理经验分布变异。Probit更换为正态链接，两者系数尺度不能直接比较。

2 · 公式与统计前提

AMEⱼ=n⁻¹Σβⱼpᵢ(1−pᵢ)

含交互和变换项时要对整个预测函数求导。描述性AME不自动是干预效应。

进阶讲义 · AME的完整梯度

推导与成立条件

Logit中p_i=Λ(x_i′β)。无交互的连续变量效应a_i=β_j p_i(1−p_i)，其梯度为单位向量e_j乘p_i(1−p_i)，加β_j p_i(1−p_i)(1−2p_i)x_i。平均梯度与系数协方差结合给固定设计Delta方差。

工作例题与研究判断

二元处理必须分别设D=1和0，保留其他变量并平均预测差。含交互项时还要同时更新交互列，不能只替换D这一列。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
from scipy.optimize import minimize
from scipy.special import expit
rng=np.random.default_rng(20261027);n=2500
X=np.column_stack([np.ones(n),rng.normal(size=(n,2))])
y=rng.binomial(1,expit(X@np.array([-.4,.8,-.5])))
def loss(b):return np.sum(np.logaddexp(0,X@b)-y*(X@b))
def grad(b):return X.T@(expit(X@b)-y)
def hess(b):
    p=expit(X@b);return (X.T*(p*(1-p)))@X
opt=minimize(loss,np.zeros(3),jac=grad,hess=hess,method='Newton-CG',options={'xtol':1e-10})
assert np.max(abs(grad(opt.x)))/n<1e-7
fit=sm.Logit(y,X).fit(disp=False)
assert np.allclose(opt.x,fit.params,atol=1e-6)
p=expit(X@opt.x);A=hess(opt.x)/n;s=X*(y-p)[:,None];B=s.T@s/n
V=np.linalg.solve(A,B)@np.linalg.inv(A)/n
def ame(b):
    p=expit(X@b);return np.mean(b[1]*p*(1-p))
step=1e-5;G=np.array([(ame(opt.x+np.eye(3)[j]*step)-ame(opt.x-np.eye(3)[j]*step))/(2*step) for j in range(3)])
print('MLE',opt.x,'score norm',np.linalg.norm(grad(opt.x)))
print('sandwich HC0 SE',np.sqrt(np.diag(V)))
print('AME x1 fixed-X',ame(opt.x),'Delta SE',np.sqrt(G@V@G))
