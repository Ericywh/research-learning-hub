M25 · 静态面板：FE、FD与RE

先修：M03,M10 · 核心讲义v1 · 按理解进度分次学习，概念先于公式与代码

推导前提图示代码练习验收映射

先把概念讲清楚，再读公式

本课可分两次学习：先读以下解释和例子；能说清含义后，再读原理与公式，代码可以第三次再做。暂时看不懂公式，不必跳过概念直接复制命令。

组内变换

每个变量减去同一个体的时间均值，去掉个体不随时间变化的部分。

具体例子：某人教育始终16年，减个人均值后为0，因此不能靠其组内变化识别教育系数。

固定效应

每个个体或时期拥有自己的截距，用于吸收指定层级不变的差异；不是把估计系数强行固定为某个数。

具体例子：追踪同一人多年，个人固定效应吸收不变背景，但无法消除每年变化且与政策相关的冲击。

外生性

解释变量与误差之间满足特定正交或条件均值限制。不同模型要求不同，不是“变量来自系统外面”的日常说法。

具体例子：若能力影响工资，又与教育相关，遗漏能力后E[u｜教育]可能不为零。仅换稳健SE不能解决。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

固定效应用同一个体随时间的变化，分别对y和x减去个体均值后消除时间不变效应，也无法估计完全不变的变量系数。静态FE常依赖严格外生性E[u_it|X_i1,…,X_iT,α_i]=0，政策受过去冲击影响时可能不成立。FD同样消除固定效应但改变误差相关结构；RE还要求个体效应与X适当不相关。Hausman不拒绝不是RE假设已证明，检验解释依赖估计与协方差设定。

2 · 公式与统计前提

y_it−ȳ_i=β′(x_it−x̄_i)+(u_it−ū_i)

固定效应不消除时变混杂；短面板加入滞后因变量后不能套静态FE论证。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import pandas as pd
import statsmodels.api as sm
rng=np.random.default_rng(20261027);N=200;T=8
id=np.repeat(np.arange(N),T);t=np.tile(np.arange(T),N)
a=rng.normal(size=N);x=np.repeat(.5*a,T)+rng.normal(size=N*T)
y=2*x+np.repeat(a,T)+.2*t+rng.normal(size=N*T)
df=pd.DataFrame({'id':id,'t':t,'x':x,'y':y})
dm=df[['x','y']]-df.groupby('id')[['x','y']].transform('mean')
# Balanced panel: demeaned time controls remove the shared deterministic trend.
fit=sm.OLS(dm.y,np.column_stack([dm.x,t-(T-1)/2])).fit(cov_type='cluster',cov_kwds={'groups':id})
print('FE slope',fit.params.iloc[0],'cluster SE',fit.bse.iloc[0])

5 · 专属练习与参考答案

为什么个体FE不能单独估计不随时间改变的性别系数？

展开答案与依据

组内变换后变量为零，与个体固定效应完全共线，缺乏组内识别信息。
