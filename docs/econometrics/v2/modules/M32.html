带宽与核权重

带宽决定断点附近用多远的数据；核权重决定邻域内哪些观测贡献更大。二者是不同设置。

具体例子：带宽5分只用55到65分。三角核给靠近60分者更高权重；缩小带宽通常减少偏差，也减少信息。

置信区间

由数据按一个程序构造的区间。95%覆盖率指相同规则重复抽样时，约95%的区间覆盖固定真值。

具体例子：某次区间是否含真值已确定但未知；频率学派不把95%直接说成该固定参数落入本次区间的概率。

运行变量与断点

运行变量决定阈值规则；RDD比较阈值附近左右的结果极限，而非全样本两侧均值。

具体例子：成绩60分获资格，59.9与60.1附近者更可比；但仍需排除其他规则也在60分同时跳变。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

缩小带宽降低平滑偏差却减少样本，MSE最优带宽常残留不可忽略偏差。稳健偏差修正不仅减去估计偏差，还把偏差估计变异计入区间。教学局部WLS可说明左右极限，但不是CCT推断；正式分析应采用rdrobust等相应实现。密度检验检查阈值处运行变量异常，预定协变量连续性检验检查其他跳跃，这些只能发现部分威胁，不证明完全无操纵。

2 · 公式与统计前提

τ̂_bc=τ̂−Biaŝ(τ̂)；区间需计入偏差估计变异

禁止按显著性挑带宽；离散运行变量和质量点需额外处理。应同时报告有效样本及带宽敏感性。

进阶讲义 · 偏差修正为何改变标准误

推导与成立条件

局部线性截距的平滑偏差通常随h²变化，方差数量级为1/(nh)。按均方误差选择的带宽使偏差相对标准误可能不可忽略。偏差修正使用额外局部拟合估计主导偏差；修正量本身随机，区间需计入其方差与协方差。

工作例题与研究判断

只减去一个偏差估计再沿用原标准误不是完整稳健偏差修正。应报告主带宽、偏差带宽、核、阶数、有效样本及质量点处理。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
rng=np.random.default_rng(20261027);n=12000
r=rng.uniform(-1,1,n);above=(r>=0).astype(int)
d=rng.binomial(1,.2+.5*above)
y=1+2*d+.6*r+.3*above*r+rng.normal(size=n)
for h in [.2,.4,.6]:
    keep=abs(r)<h;rr=r[keep];aa=above[keep]
    X=np.column_stack([np.ones(keep.sum()),aa,rr,aa*rr]);w=1-abs(rr)/h
    fy=sm.WLS(y[keep],X,weights=w).fit(cov_type='HC1')
    fd=sm.WLS(d[keep],X,weights=w).fit(cov_type='HC1')
    print('h',h,'n',keep.sum(),'outcome jump',fy.params[1],'treatment jump',fd.params[1],'fuzzy ratio',fy.params[1]/fd.params[1])
print('Local-linear point estimates; not CCT robust bias-corrected intervals or density tests')

set obs 12000
gen double r=runiform(-1,1)
gen byte above=r>=0
gen byte d=runiform()<(.2+.5*above)
gen double y=1+2*d+.6*r+.3*above*r+rnormal()
foreach h in .2 .4 .6 {
    gen double w=1-abs(r)/`h' if abs(r)<`h'
    regress y i.above##c.r [aw=w] if abs(r)<`h', vce(robust)
    scalar jump_y=_b[1.above]
    regress d i.above##c.r [aw=w] if abs(r)<`h', vce(robust)
    display "Fuzzy local Wald = " jump_y/_b[1.above]
    drop w
}
