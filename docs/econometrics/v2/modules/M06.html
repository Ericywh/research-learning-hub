M06 · 精确t/F与渐近Wald检验

先把概念讲清楚，再读公式

本课可分两次学习：先读以下解释和例子；能说清含义后，再读原理与公式，代码可以第三次再做。暂时看不懂公式，不必跳过概念直接复制命令。

联合检验

同时检验多项参数限制，计算时考虑各估计量之间的协方差。

具体例子：“教育和经验系数同时为零”是一个联合命题，不等于分别做两次检验再数显著结果。

零假设与p值

零假设是待检验的参数限制。p值是在零假设与模型条件成立时，出现同样或更极端统计量的概率。

具体例子：p=0.03不等于零假设为真概率3%，也不等于效应很大；还需效应量、区间与研究设计。

置信区间

由数据按一个程序构造的区间。95%覆盖率指相同规则重复抽样时，约95%的区间覆盖固定真值。

具体例子：某次区间是否含真值已确定但未知；频率学派不把95%直接说成该固定参数落入本次区间的概率。

符号查阅（不要求一次学完）

n表示样本量，i给观测编号；Σ表示对观测加总，E[·]表示总体期望，竖线“|”表示给定条件。β、θ通常是未知总体参数，b、带帽符号通常是样本估计。撇号′表示矩阵转置，⁻¹表示逆矩阵，√n表示样本量的平方根；→p与→d分别表示概率收敛和依分布收敛，不能当作普通等号。

1 · 核心问题与推导

经典有限样本t和F分布依赖条件正态、同方差及设计矩阵满秩等条件。换成异方差稳健协方差后，常用检验通常成为渐近近似。Rβ=r包含q条独立约束，Wald统计量以约束偏差的协方差将其标准化，极限为χ²(q)。逐个t检验不能替代联合检验，因为估计系数通常相关。p值是零假设下观测到同样或更极端统计量的概率，不是零假设为真的概率，也不是效应重要程度。

2 · 公式与统计前提

W=(Rb−r)′[R V̂(b) R′]⁻¹(Rb−r)

少量聚类、弱识别和高杠杆会影响近似；HC1不是有限样本精确保证。

进阶讲义 · 精确检验与Wald的联系

推导与成立条件

正态同方差模型下，限制与非限制残差平方和之差除以q，再除以非限制残差方差，得到F(q,n−k)。同一模型下W=qF，但用估计误差方差构造的W有限样本并非精确χ²。异方差稳健Wald依赖渐近正态及协方差一致性。

工作例题与研究判断

一个限制下W=t²；两侧t检验与相应F检验一致。多个限制下需检查R满行秩，否则直接求逆失效。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
rng=np.random.default_rng(20261027)
n=800
z=rng.normal(size=n); x=.6*z+rng.normal(size=n)
y=1+2*x+.8*z+rng.normal(size=n)
X=np.column_stack([np.ones(n),x,z])
b=np.linalg.lstsq(X,y,rcond=None)[0]
Z=np.column_stack([np.ones(n),z])
rx=x-Z@np.linalg.lstsq(Z,x,rcond=None)[0]
ry=y-Z@np.linalg.lstsq(Z,y,rcond=None)[0]
fwl=rx@ry/(rx@rx)
P=X@np.linalg.solve(X.T@X,X.T)
assert abs(fwl-b[1])<1e-10
assert np.max(np.abs(P@P-P))<1e-10
assert np.max(np.abs(X.T@(y-X@b)))<1e-8
fit=sm.OLS(y,X).fit(cov_type='HC1')
print('OLS',b,'FWL',fwl,'HC1 SE',fit.bse)
print('Joint Wald',fit.wald_test(np.array([[0,1,0],[0,0,1]]),scalar=True))

5 · 专属练习与参考答案

展开答案与依据

可以。联合检验取决于完整协方差以及估计向量的方向，不能从单个p值直接推断。
