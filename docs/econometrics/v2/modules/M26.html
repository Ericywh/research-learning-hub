M26 · 动态面板与差分GMM

先修：M16,M25 · 核心讲义v1 · 建议45分钟，实验及延伸另计

推导前提图示代码练习验收映射

1 · 核心问题与推导

滞后结果与组内误差相关，使固定T的动态FE存在Nickell偏误，改标准误不能解决。对动态方程一阶差分消除个体效应；若原始u无序列相关，y_i,t−2及更早水平在相应前定条件下可作差分方程工具。差分误差通常有AR(1)，该检验拒绝不意外；AR(2)拒绝则威胁常用工具。系统GMM增加水平方程矩，需额外初始条件或平稳限制，不能当作自动改进。

2 · 公式与统计前提

Δy_it=ρΔy_i,t−1+Δu_it；E[y_i,t−sΔu_it]=0，s≥2

工具数会随T增长，应限制滞后、压缩工具并报告数量。Hansen不拒绝不证明工具有效。

3 · 图示与研究含义

图为概念示意；数值结论以运行代码和明确的数据来源为准。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
from scipy.linalg import block_diag
rng=np.random.default_rng(20261027);N=1000;T=7;rho=.6
a=rng.normal(size=N);y=np.zeros((N,T+1))
y[:,0]=a/(1-rho)+rng.normal(size=N)
for t in range(1,T+1):y[:,t]=rho*y[:,t-1]+a+rng.normal(size=N)
# Restricted lag-2 level instruments, collapsed across time: one moment per unit.
# Educational one-step difference GMM; NOT full Arellano-Bond diagnostics/system GMM.
dx=[];dy=[];zs=[]
for i in range(N):
    dx.append(np.diff(y[i])[0:T-1]);dy.append(np.diff(y[i])[1:T]);zs.append(y[i,0:T-1])
dx=np.array(dx);dy=np.array(dy);zs=np.array(zs)
A=np.mean(np.sum(zs*dx,axis=1));B=np.mean(np.sum(zs*dy,axis=1));b=B/A
score=np.sum(zs*(dy-b*dx),axis=1)
se=np.sqrt(np.mean(score**2)/N)/abs(A)
print('Restricted difference GMM',b,'cluster sandwich SE',se,'true rho',rho)
print('No overidentification df, AR test or system moments supplied; see Stata xtabond lab')

* Synthetic teaching data. Stata and NumPy RNG streams differ.
set obs 1000
gen long id=_n
gen double a=rnormal()
expand 8
bysort id: gen long t=_n
xtset id t
gen double y=a/(1-.6)+rnormal() if t==1
forvalues j=2/8 {
    replace y=.6*L.y+a+rnormal() if t==`j'
}
xtreg y L.y, fe vce(cluster id)
* Genuine Arellano-Bond difference GMM, restricted instrument lags.
xtabond y, lags(1) maxldep(2) vce(robust)
estat abond
* This is not system GMM. Do not invent a Hansen statistic if not available.

5 · 专属练习与参考答案

为什么不能用y_i,t−1作为Δy_i,t−1的工具？

展开答案与依据

它包含u_i,t−1，而Δu_it含−u_i,t−1，两者相关；更早水平需在对应限制下使用。
