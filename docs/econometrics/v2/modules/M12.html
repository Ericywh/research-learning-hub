杠杆与共线性

杠杆衡量某观测的解释变量位置有多特殊；共线性衡量变量列有多相似。二者均不等于内生性。

具体例子：身高与体重高度相关可能增加各自系数的SE；一个特别高的人可能有高杠杆，但未必是错误数据。

秩

矩阵中真正提供不同方向信息的列数。列满秩表示没有一列能由其他列精确拼出。

具体例子：同时放身高厘米与身高米，第二列是第一列的固定倍数，无法分别识别两个系数。

方差与协方差

方差衡量一个变量绕均值的波动；协方差衡量两个变量是否倾向同向偏离各自均值。协方差受单位影响。

具体例子：米换成厘米会改变协方差数值，不会凭此改变因果关系；相关系数将协方差按标准差缩放。

1 · 核心问题与推导

VIF刻画一列变量被其他列线性预测的程度，不检验因果模型。高杠杆来自设计位置，大残差结合高杠杆才可能构成强影响，不能自动删除。时间序列得分相关时，HAC按核权重汇总滞后得分协方差，带宽反映偏差方差权衡；HC1无法替代这一处理。若过程存在单位根，单纯更换HAC标准误不会恢复平稳回归的渐近理论。诊断应围绕具体假设，而不是把检验清单当作模型正确性的证明。

2 · 公式与统计前提

VIFⱼ=1/(1−Rⱼ²)；hᵢᵢ=xᵢ′(X′X)⁻¹xᵢ

VIF阈值不是普适删变量准则；异常观测处理需基于质量核查与透明规则。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor
rng=np.random.default_rng(20261027);n=600
x=rng.normal(size=n);z=x+.1*rng.normal(size=n)
u=np.zeros(n)
for t in range(1,n):u[t]=.6*u[t-1]+rng.normal()
X=np.column_stack([np.ones(n),x,z]);y=1+2*x+u
fit=sm.OLS(y,X).fit()
print('VIF x',variance_inflation_factor(X,1))
print('Max leverage',fit.get_influence().hat_matrix_diag.max())
print('HC1',fit.get_robustcov_results(cov_type='HC1').bse)
print('HAC lag4',fit.get_robustcov_results(cov_type='HAC',maxlags=4).bse)

5 · 专属练习与参考答案

VIF=10时该变量被其余变量回归的R²是多少？

展开答案与依据

R²=0.9。高共线主要影响精度，不能单凭此认定估计有因果偏差。
