平稳、单位根与协整

平稳过程的分布特征不随时间任意漂移；随机游走常有单位根。协整指非平稳序列存在平稳线性组合。

具体例子：若x为随机游走而y=2x+平稳噪声，则y−2x可平稳；两个独立随机游走高R²不等于存在协整。

抽样分布

固定总体及抽样规则，反复抽取同样大小样本，每次计算估计量，所有可能结果形成的分布。

具体例子：把1000次样本均值画直方图，画的是均值的抽样分布，不是1000个人工资的分布。

外生性

解释变量与误差之间满足特定正交或条件均值限制。不同模型要求不同，不是“变量来自系统外面”的日常说法。

具体例子：若能力影响工资，又与教育相关，遗漏能力后E[u｜教育]可能不为零。仅换稳健SE不能解决。

1 · 核心问题与推导

随机游走冲击永久累积，两个独立随机游走也可能出现高R²和显著t值。ADF在适当确定项与滞后差分下检验单位根，常数、趋势设定影响临界值。协整要求多个非平稳序列存在平稳线性组合，单序列自回归不是协整检验。Engle–Granger残差检验使用专用分布，不能将估计残差直接套普通ADF临界值。协整下ECM将短期差分与滞后长期偏离连接起来。

2 · 公式与统计前提

Δy_t=α(y_t−1−θx_t−1)+Σφ_jΔy_t−j+Σψ_jΔx_t−j+ε_t

不拒绝单位根可能源于低功效，结构突变和滞后选择会影响结果。HAC不能修复伪回归。

进阶讲义 · 协整与误差修正的关系

推导与成立条件

两个I(1)序列若y−θx平稳，则长期偏离可进入差分方程作为调整项。估计长期关系后的残差具有估计引起的特殊分布，残差单位根检验需专用临界值。若不存在协整，直接把水平变量放入普通回归可能得到伪显著。

工作例题与研究判断

先确定常数趋势项及滞后策略，再报告检验。不能用不拒绝单位根证明一定I(1)，也不能用单条平稳残差图替代协整检验。

# Teaching experiment, synthetic data unless explicitly stated. Seed 20261027.
import numpy as np
from statsmodels.tsa.stattools import adfuller,coint
import statsmodels.api as sm
rng=np.random.default_rng(20261027);n=800
x=rng.normal(size=n).cumsum();e=np.zeros(n)
for t in range(1,n):e[t]=.5*e[t-1]+rng.normal()
y=2*x+e
print('ADF x',adfuller(x,regression='c',autolag='AIC')[:2])
print('EG cointegration',coint(y,x,trend='c',autolag='aic')[:2])
long=sm.OLS(y,sm.add_constant(x)).fit();ec=long.resid[:-1]
fit=sm.OLS(np.diff(y),np.column_stack([np.ones(n-1),ec,np.diff(x)])).fit(cov_type='HAC',cov_kwds={'maxlags':4})
print('ECM const, adjustment, short-run',fit.params)

set obs 800
gen long t=_n
tsset t
gen double x=rnormal()
replace x=x[_n-1]+rnormal() if _n>1
gen double e=rnormal() in 1
replace e=.5*e[_n-1]+rnormal() if _n>1
gen double y=2*x+e
dfuller x, lags(4)
regress y x
predict double ec, residuals
newey D.y L.ec D.x, lag(4)
* Do NOT use ordinary dfuller ec critical values as an Engle-Granger test.

5 · 专属练习与参考答案

y、x均I(1)，y−2x为I(0)，说明什么？

展开答案与依据

以(1,−2)协整。ECM调整系数为负在适当稳定条件下表示长期偏离被向均衡修正。
