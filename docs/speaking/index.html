公众表达与脱稿演讲系统训练

24周、168课，每天10—15分钟，第7天为轻量复盘。此页面仅为课程目录。

发音辨正与低压力开口

第1周｜基线评估与开口安全

  1. 录制60秒表达基线
  2. 区分卡壳、口吃与思路中断
  3. 听辨n与l
  4. 体会n与l的气流差异
  5. n/l词语和短句练习
  6. 60秒介绍一个熟悉话题
  7. 第1周复盘：只选一个改进点

第2周｜普通话r与n/l迁移

  1. 听辨r与l的声音差别
  2. 普通话r的自然舌位
  3. r/l对比词听说训练
  4. r在连续词语中的发音
  5. n/l/r混合词练习
  6. 90秒讲述一次真实经历
  7. 第2周复盘：难音清单

第3周｜前后鼻音辨正

  1. 听辨an与ang
  2. 听辨en与eng
  3. 听辨in与ing
  4. 前后鼻音的自然收尾位置
  5. 鼻音对比词与短句
  6. 描述一幅图并使用目标词
  7. 第3周复盘：听辨与发音分别计分

第4周｜发音向自然讲话迁移

  1. 找到个人最常混淆的10个词
  2. 目标音从单词过渡到句子
  3. 自然语速朗读而不追求快
  4. 卡顿后如何继续表达
  5. 1分钟自然讲话中的目标音练习
  6. 2分钟综合表达基线复测
  7. 第4周评估：清晰度和讲话负担

观点生成与结构化表达

第5周｜快速生成观点

  1. 从问题中找核心判断
  2. 用一句话说清立场
  3. 区分观点与事实
  4. 回答为什么的两层理由
  5. 观点—理由—例子三段式
  6. 60秒回答一个陌生问题
  7. 第5周复盘：观点是否明确

第6周｜观点展开与论据

  1. 举出可核实的具体例子
  2. 用对比解释观点
  3. 从个例避免过度概括
  4. 学会承认信息不足
  5. 用因果与相关的区别作例子
  6. 90秒解释一个专业概念
  7. 第6周复盘：删掉无关内容

第7周｜清晰的现场结构

  1. 总—分—总的最小结构
  2. 问题—分析—建议结构
  3. 现象—原因—应对结构
  4. 按重要性而非时间堆砌观点
  5. 开头10秒直接给结论
  6. 2分钟结构化发言
  7. 第7周复盘：提纲不超过5词

第8周｜从想好再说到边说边组织

  1. 10秒内提炼三关键词
  2. 没有思路时先界定问题
  3. 思路中断后的自然过渡
  4. 如何避免反复自我纠正
  5. 即兴回答中加入适度停顿
  6. 2分钟抽题即兴陈述
  7. 第8周评估：独立组织能力

评委即席点评与有效反馈

第9周｜评委点评的基本框架

  1. 明确点评与复述的区别
  2. 从亮点—不足—建议开始
  3. 选择真正重要的一项优点
  4. 提出有依据的一项问题
  5. 建议如何具体且可执行
  6. 90秒模拟课堂汇报点评
  7. 第9周复盘：点评是否有实质内容

第10周｜评委的证据与判断

  1. 建立评价维度而非凭感觉
  2. 如何评价选题价值
  3. 如何评价逻辑与论证
  4. 如何评价方法与证据
  5. 把评价和建议明确连接
  6. 2分钟模拟项目评审点评
  7. 第10周复盘：每个判断有依据吗

第11周｜追问、质疑与回应

  1. 把模糊疑问变为清楚问题
  2. 尊重但不回避关键缺陷
  3. 如何提出一个有效追问
  4. 不确定时怎样审慎表达
  5. 如何控制点评时间
  6. 模拟一次点评加一个追问
  7. 第11周复盘：减少套话

第12周｜评委点评综合训练

  1. 学生答辩的2分钟点评
  2. 学术报告的2分钟点评
  3. 教学竞赛的2分钟点评
  4. 科研立项的2分钟点评
  5. 根据表现调整评价重点
  6. 完整3分钟模拟评委点评
  7. 第12周阶段测评：结构与内容

关键词提纲与脱稿演讲

第13周｜脱稿表达的最小提纲

  1. 区别逐字稿与关键词提纲
  2. 5个关键词组织完整表达
  3. 开场30秒传达目的
  4. 用问题引入主题
  5. 避免机械背诵开头
  6. 2分钟只看提纲演讲
  7. 第13周复盘：离稿依赖程度

第14周｜演讲论点的展开

  1. 一个重点只讲一件事
  2. 观点之后怎样举例
  3. 数字与研究结果如何通俗说明
  4. 用类比但不牺牲准确性
  5. 设计听众能记住的结尾
  6. 3分钟主题演讲
  7. 第14周复盘：删掉一个冗余点

第15周｜过渡与现场修复

  1. 段落之间自然转场
  2. 忘词时不强迫逐字回忆
  3. 被打断后的内容回归
  4. 时间不够时优先保留结论
  5. 现场发现表述错误如何修正
  6. 3分钟无逐字稿演讲
  7. 第15周复盘：完成优于零停顿

第16周｜三至五分钟脱稿汇报

  1. 3分钟汇报如何规划结构
  2. 把完整稿压缩成提示卡
  3. 用录制发现信息密度问题
  4. 让语速和停顿服务理解
  5. 用一次排练替代反复重录
  6. 完成5分钟脱稿汇报
  7. 第16周阶段测评：独立性

公众情境适应与现场应答

第17周｜从独练到面对听众

  1. 建立个人情境难度阶梯
  2. 向熟人表达一分钟观点
  3. 向熟人完成两分钟点评
  4. 听众在场时继续表达
  5. 不把脸红心跳判定为失败
  6. 面对1至2人讲3分钟
  7. 第17周复盘：参与而非完美

第18周｜现场问答能力

  1. 回答前先确认问题
  2. 30秒直接回答主问题
  3. 面对复杂问题分层回应
  4. 不知道答案如何回应
  5. 不同意见下保持内容聚焦
  6. 模拟3轮随机提问
  7. 第18周复盘：回避行为记录

第19周｜评委现场的互动

  1. 点评前快速写三个关键词
  2. 前一位评委说过后如何补充
  3. 时间突然缩短如何压缩点评
  4. 对方回应后如何继续追问
  5. 避免对人评价而只评作品
  6. 模拟多人评审轮流发言
  7. 第19周复盘：有效互动

第20周｜中等压力下稳定表达

  1. 加入轻微时间限制的表达
  2. 面对镜头即时抽题
  3. 小组讨论中主动发言
  4. 明显卡顿时保留发言权
  5. 被质疑时先确认争点
  6. 面对2至5人完成5分钟汇报
  7. 第20周阶段测评：情境迁移

学术表达与综合实战

第21周｜学术汇报核心表达

  1. 60秒讲清研究问题
  2. 解释研究贡献但避免夸大
  3. 说明数据来源与限制
  4. 用通俗语言解释模型
  5. 区分识别假设与结果
  6. 3分钟研究计划汇报
  7. 第21周复盘：学术准确性

第22周｜学术评审与方法点评

  1. 研究问题是否可检验
  2. 变量定义是否清晰
  3. 模型是否适合问题
  4. 因果识别是否充分
  5. 稳健性检验与替代解释
  6. 3分钟模拟论文评审点评
  7. 第22周复盘：指出关键缺陷

第23周｜多场景快速切换

  1. 教学比赛点评的结构迁移
  2. 答辩点评的结构迁移
  3. 会议发言的结构迁移
  4. 突发提问时如何先分清问题
  5. 不同听众下调整专业深度
  6. 5分钟综合演练含问答
  7. 第23周复盘：最有效的两项技巧

第24周｜毕业实战与后续维护

  1. 重录第1天基线话题
  2. 目标音在真实表达中复测
  3. 三分钟无准备即席点评
  4. 五分钟脱稿学术汇报
  5. 模拟临场追问与卡顿恢复
  6. 完整5至10分钟终期演讲
  7. 第24周总评：制定后续维护方案

执行规则

每课单一能力点，按“学习2分钟—专项3分钟—表达5至7分钟—反馈1至3分钟”练习。周末轻量复盘5至10分钟。发声费力时降低难度；不以零卡顿为训练要求。

每节按真实完成情况发布，未发布课程仅显示目录，个人录音不自动公开。
