公众表达与脱稿演讲系统训练

口才优先修订版 · 24周168课 · 每日10—15分钟 · 每周第7课轻量复盘

修订版：2026-10-21。以口才、即兴点评及脱稿演讲为训练主体。

总计24周、6章、168课。普通日10—15分钟，周复盘日5—10分钟。课程目录按真实交付进度推进，漏课优先补足。

常规练习：1分钟核心技能讲解＋2分钟整理2—3个关键词＋5—8分钟开口练习＋2分钟回听反馈。每天只解决一个主要问题。

发音辨正：不再单列章节或正式课次。若仍有需要，每周自选两天，各增加最多2分钟n/l/r或前后鼻音听辨与词句练习；合计最多4分钟。若发音并非当前障碍，可完全跳过。

偶发口吃：仅在实际卡顿时练习停顿、改述和继续表达，不以口吃次数为主要考核指标，不采用强迫挤声或机械口部操。如后续出现持续性发声阻塞或明显困扰，再考虑个别化专业评估。

学习重点：即兴思维与观点组织约40%，评委点评与现场应答约30%，脱稿演讲与公众实战约25%，可选发音专项约5%。这些百分比为粗略资源分配而非经过验证的最优治疗剂量。

快速反馈：每4周检查一次同类型任务的清晰度、结构完整性、是否抓住要点、离稿程度与回避倾向；前2周便开始模拟评委点评，不等待发音完全标准。

归档约定：Notion私人页面保留完整原始课程记录，GitHub公开原创课程文本；不公开用户个人音频、口吃情况或私密评审记录。原学习中心第06号PSM-DID课程继续保留，本课程在独立分支目录内记录，不覆盖既有内容。

第1章｜快速开口与清晰表达

第1周｜开口基线与短表达

  1. 60秒自然表达基线（已发布第001课）
  2. 不写逐字稿讲清一件事
  3. 用一句话给出观点
  4. 用一个理由支持观点
  5. 卡壳后从核心意思继续
  6. 录制90秒观点陈述
  7. 第1周复盘：观点与讲话负担

第2周｜提前进入评委点评

  1. 点评前找到一个真实亮点
  2. 点评前找到一个关键问题
  3. 把问题改写成可执行建议
  4. 亮点—问题—建议的60秒点评
  5. 用关键词代替逐字稿
  6. 录制90秒学生汇报点评
  7. 第2周复盘：是否言之有物

第3周｜现场表达的基本结构

  1. 开口10秒先说结论
  2. 一个观点只配一个主要理由
  3. 区分核心信息与枝节
  4. 用一个例子解释抽象观点
  5. 把长句拆成易懂短句
  6. 2分钟结构化表达
  7. 第3周复盘：删去多余内容

第4周｜第一次脱稿小演讲

  1. 用三个关键词制作提纲
  2. 开头30秒说明要点
  3. 两个段落之间自然过渡
  4. 忘词时换说法而非强背
  5. 用最后一句收束主题
  6. 3分钟关键词脱稿演讲
  7. 第4周评估：与基线比较

第2章｜即兴思维与观点组织

第5周｜迅速产生可讲的观点

  1. 抽题后10秒确定主张
  2. 从受众关切找切入点
  3. 从对比关系提出判断
  4. 选择最有信息量的一点
  5. 把宽泛观点缩成具体问题
  6. 90秒随机题目陈述
  7. 第5周复盘：结论是否明确

第6周｜理由与证据表达

  1. 事实、判断和推测怎么区分
  2. 两条理由如何避免重复
  3. 引用一个具体事例支持观点
  4. 遇到证据不足如何限定表述
  5. 数字怎么讲才容易理解
  6. 2分钟观点加证据训练
  7. 第6周复盘：有无过度断言

第7周｜让表达生动但不冗长

  1. 30秒讲清事件经过
  2. 使用冲突或问题组织叙述
  3. 用前后对比解释变化
  4. 用类比说明专业概念
  5. 删去无关细节
  6. 两分钟故事化说明一个观点
  7. 第7周复盘：听众能否复述要点

第8周｜没有准备也能组织内容

  1. 用三个关键词现场搭框架
  2. 没想好时先明确问题边界
  3. 遇到追问先回答主问题
  4. 回答中途偏题如何拉回
  5. 两分钟限时表达不追求零停顿
  6. 完成三次随机抽题回答
  7. 第8周阶段评估：即兴组织

第3章｜评委即席点评与专业反馈

第9周｜评委点评的判断标准

  1. 把复述报告转变为评价
  2. 亮点为什么成立
  3. 找出最值得讨论的一项不足
  4. 提出可以执行的改进路径
  5. 尊重发言者但直指作品问题
  6. 90秒完成一轮正式点评
  7. 第9周复盘：评价依据与建议

第10周｜评委如何精准提问

  1. 从研究目标找到疑问
  2. 从逻辑链条找到薄弱点
  3. 从数据证据找到缺口
  4. 将评价变成一个有效问题
  5. 对方回应后如何追问
  6. 2分钟点评加1个追问
  7. 第10周复盘：问题是否聚焦

第11周｜不同活动的点评技巧

  1. 学生演讲的结构与内容点评
  2. 论文答辩的研究问题点评
  3. 课堂教学展示的有效性点评
  4. 项目申报的可行性点评
  5. 竞赛作品的创新与证据点评
  6. 2分钟随机场景评委点评
  7. 第11周复盘：评价维度是否匹配

第12周｜评委点评的临场实战

  1. 前一位评委已经说过怎么办
  2. 只给60秒如何压缩点评
  3. 意见与他人不一致怎么表达
  4. 指出问题同时保留建设性
  5. 用简洁结尾归纳核心建议
  6. 模拟3分钟正式评委点评
  7. 第12周测评：观点、依据、建议

第4章｜关键词脱稿与主题演讲

第13周｜从逐字稿到关键词提纲

  1. 识别自己对逐字稿的依赖
  2. 把一段长稿压缩成5个关键词
  3. 用论点而非句子做提纲
  4. 看提纲而不是读提纲
  5. 忘词后保持内容方向
  6. 完成3分钟提纲演讲
  7. 第13周复盘：脱稿程度

第14周｜把短发言发展成演讲

  1. 确定一个清楚的听众目标
  2. 选择不超过三个主论点
  3. 为主论点设计例子
  4. 复杂内容如何分层解释
  5. 删掉与目标无关的内容
  6. 完成4分钟主题演讲
  7. 第14周复盘：重点是否突出

第15周｜开场、转场与结尾

  1. 用一句问题开启演讲
  2. 用事实开启演讲
  3. 不用空泛套话引入主题
  4. 用过渡句连接分论点
  5. 结尾如何回到核心问题
  6. 录制完整4分钟演讲
  7. 第15周复盘：过渡是否自然

第16周｜五分钟脱稿演讲

  1. 5分钟分配时间与信息量
  2. 将逐字稿缩成提示卡
  3. 少量排练而不是机械背稿
  4. 控制语速而不强迫慢说
  5. 超时后保留核心结论
  6. 完成5分钟脱稿演讲
  7. 第16周测评：逻辑、时长与听懂率

第5章｜面对听众的互动与应变

第17周｜从单人练习走向听众

  1. 设计个人现场难度阶梯
  2. 对熟悉的人表达一分钟观点
  3. 向一位听众完成点评
  4. 听众注视时保持表达
  5. 接受少量停顿和现场修正
  6. 对2人讲3分钟
  7. 第17周复盘：回避是否减少

第18周｜高质量现场问答

  1. 听完问题后先提炼核心
  2. 30秒给出直接回答
  3. 一问含多个子问题时如何拆分
  4. 不知道答案时如何审慎应答
  5. 被打断后回到核心观点
  6. 随机问题三连答
  7. 第18周复盘：回应是否直接

第19周｜压力下保持表达

  1. 轻微限时的现场组织练习
  2. 面对摄像头即时抽题
  3. 对不同意见先确认争点
  4. 紧张时把关注点转向内容
  5. 卡顿后继续传达完整意思
  6. 模拟有听众的5分钟汇报
  7. 第19周复盘：发言完成度

第20周｜讨论、主持与轮流发言

  1. 小组讨论中何时插入观点
  2. 接续别人意见而不重复
  3. 表达不同意见的清晰结构
  4. 主持点评时如何引入下一位
  5. 现场时间不足时如何收束
  6. 模拟多人评审轮流发言
  7. 第20周测评：真实互动

第6章｜学术点评、答辩与综合实战

第21周｜学术表达的清楚与准确

  1. 60秒讲明白研究问题
  2. 说明理论机制但不空泛
  3. 简要介绍数据与样本
  4. 用普通语言解释识别思路
  5. 研究结论如何界定适用范围
  6. 3分钟研究设计汇报
  7. 第21周复盘：专业而易懂

第22周｜计量与统计研究的点评

  1. 变量定义与测量是否合理
  2. 相关关系能否支持因果结论
  3. 识别假设如何质疑
  4. 统计推断常见表述问题
  5. 如何指出稳健性检验的局限
  6. 3分钟论文方法点评
  7. 第22周复盘：意见是否可检验

第23周｜正式评审与答辩实战

  1. 面对申报项目如何即时点评
  2. 面对论文答辩如何追问
  3. 面向非专业听众解释模型
  4. 专家质疑时先回应关键争点
  5. 用90秒形成完整评审意见
  6. 五分钟评审模拟含问答
  7. 第23周复盘：聚焦一个核心问题

第24周｜毕业复测与个人维护

  1. 重做首日60秒表达测试
  2. 重做第二周90秒点评
  3. 随机抽题完成3分钟即兴讲话
  4. 完成一次5分钟学术脱稿汇报
  5. 与真实听众进行问答或点评
  6. 完整5至10分钟综合演讲
  7. 第24周总评与后续维护计划
