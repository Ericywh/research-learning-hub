澄清误会时先复述事实

先说清双方实际说过什么，再区分事实与理解，把解释落到一个可共同核对的动作。

18分钟完整训练同题首录与重录陌生情境迁移双示范练后展开

第2章·第11节｜全课程第032课 / 126课 · 第5周 · 18分钟

主题：澄清误会时先复述事实。以下对话和统计表均为原创模拟，非真实工作记录；百分比口径尚未确认，不预设谁算错。

一、今天只练一个动作

听到“你是不是在否定我的工作”时，不立即反驳“你误会了”，而是先把双方实际说过的话摆清楚，再区分已知事实与对方的理解，最后提出一个能共同完成的核对动作。目的不是争论谁记得更准确，而是让讨论回到同一个具体问题。

本题三词提纲：群消息—分母口径—共同核对。“群消息”对应实际说过的话；“分母口径”对应尚未确认的细节；“共同核对”对应下一步。

词穷时自问：我当时原话是什么？对方把这句话理解成了什么？我们下一步能一起核对哪一个具体事实？

二、明确题目与可朗读材料

情境：学院教学小组准备周五展示一份学生实习情况汇总。林老师上周整理了86份问卷。表2写着“参加过实习：46人，58%”，但表中没有标注这个百分比使用的分母。46÷86约为53.5%，如果采用其他有效样本口径，百分比可能不同，目前不能据此判定表格错误。

发言对象与任务：林老师在群里认为你否定了整份统计工作。请面对林老师及在场同事，用75—90秒澄清：先复述自己在群里说过的事实，再承认对方可能听到的意思与自己本意不同，最后说明只想核对哪一项口径，以及何时、如何核对。对方追问后，用20—30秒回应。

产出：同题首录、追问回应、修改后重录、陌生情境迁移录音、四项独立自评。录音和评分仅由本人保留。

你在群里的原话：

“表2写‘参加过实习’46人、58%，我暂时没找到百分比所用的分母。周五展示前能否一起核一下统计口径？”

林老师的回应：

“你这样说，是不是觉得我上周做的整份统计都不可信？我花了两天整理，你一句话就否定了？”

林老师的后续追问：

“既然只是问分母，为什么不私下问我，偏要发在群里？”

可直接朗读的口语素材：

“这次争议有两层。群消息中明确提到的是表2的46人和58%，以及百分比所用的分母没有标注；同事听到的却可能是‘整份统计不可信’。前者是可以核对的文字和数字，后者是对话语含义的理解。澄清时先准确复述原话，再说明自己想确认的范围，最后约定一起查看统计说明和原表，避免在没有核实前判断谁对谁错。”

三、18分钟逐段训练

  1. 0—3分钟｜完整输入与理解。0:00—1:20朗读情境、群消息、林老师的两次回应；1:20—2:10朗读口语素材；2:10—3:00合上材料，口头说出“已经确定的两件事”和“尚未确定的一件事”。不要推断对方的真实情绪，也不要断言58%一定算错。
  2. 3—6分钟｜三词搭结构。3:00—4:00记“群消息—分母口径—共同核对”，用自己的话解释各词；4:00—5:00把“你理解错了，我没否定你”改成一句先复述事实的自然口语；5:00—6:00口头排出“原话—范围—行动”三段，想好如何回答“为什么发群里”。不写逐字稿。
  3. 6—11分钟｜独立首录与回听。6:00—6:20准备；6:20—7:50录75—90秒澄清；7:50—8:00读追问；8:00—8:30录20—30秒回应；8:30—10:10回听两段录音；10:10—11:00标出一句像辩解的话、一处没有讲清的事实和一句最需要修改的表达。
  4. 11—16分钟｜修改重说与陌生迁移。11:00—11:45修改最薄弱的一句；11:45—13:15重录75—90秒；13:15—13:45比较两次开头；13:45—14:20阅读下方聚餐情境；14:20—15:20不看原提纲，独立录45—60秒；15:20—16:00回听，检查有没有把事实和猜测混为一谈。
  5. 16—18分钟｜独立评分与练后对照。16:00—17:00按“原话准确、区分理解、核对具体、追问回应”四项各打0—2分，记录一句改进；17:00—18:00才主动展开下方两份参考表达及各自关键词。参考只用于对照，不要求背诵。

四、陌生情境迁移

原创生活模拟：你给朋友发消息：“周六聚餐我可能八点半才能到，七点赶不上。”朋友回复：“你不想来就直说，别找借口。”实际上你没有说不参加，也还没有确认是否能八点半到。

任务：面对朋友，用45—60秒先复述你发过的原话，再说明“到得晚”和“不想参加”之间的区别，最后提出一个双方能确认的安排，例如先问聚餐预计几点结束。不要承诺自己尚未确定的到达时间，也不要照搬教学小组的三词提纲。

五、先独立自评

四项各0—2分，0分未做到，1分部分做到，2分清楚做到：原话准确、区分理解、核对具体、追问回应。先给分、记下最想修改的一句，再展开参考。

参考一｜先复述原话，再缩小争议范围

首次回应：

“林老师，我先把我在群里说的话再说清楚。我提到的是表2写了46人、58%，但我没有看到百分比的分母说明，所以问能不能在周五展示前一起核对口径。我没有说整份统计不可信，也没有评价你上周整理工作的质量。我能理解这句话放在群里，可能让你觉得自己的工作被公开质疑了，这一点我之前没有解释充分。现在我真正想确认的是：58%是不是用了与86份问卷不同的有效样本数？如果是，我们在表下注明口径就能让听众看懂；如果不是，再一起查原始汇总表。今天找十分钟把这一项对清楚，展示时就不会留下疑问。”

追问回应：

“这个问题涉及周五大家共同使用的展示材料，我当时想让负责展示的人也看到待核对项。但我可以先私下和你核实，再把确认后的口径发到群里。下次我会把‘待核对’写得更明确，避免让人误以为我已经下了判断。”

参考一关键词（5个）：

  • 46人、58%：对应群消息中已知的数字事实。
  • 未标分母：对应需要确认的具体细节。
  • 并未否定整表：对应澄清判断范围。
  • 有效样本数：对应一种需要核实、不能预设为真的解释。
  • 十分钟对表：对应明确的后续行动。

参考二｜先接住对方的理解，再共同核对

首次回应：

“我听到你担心的是，我在群里提出表2的问题，会不会让其他人觉得你整份统计都做得不好。我想把这个担心和我原本提出的问题分开说。我的原话只指出了‘46人、58%’这两个数字，以及我没看到百分比的分母说明。因为总问卷是86份，直接用86作分母和使用某个有效样本作分母，得到的比例可能不同；现在还不知道表2采用哪种口径，所以我不想先判断谁算错了。我们可以先看表2的统计说明和汇总底表，确认58%究竟对应多少有效样本。若口径合理，就补一句说明；若需要修订，再一起改。这样既尊重你已经完成的工作，也能保证展示时把数字讲准确。”

追问回应：

“你说得有道理，群里直接提数字问题，容易被理解成公开质疑。我当时是想让展示前的待核对事项不被漏掉。接下来我先和你核实原表，确认以后只在群里发核对结果，不把未经确认的判断扩散出去。”

参考二关键词（5个）：

  • 公开质疑的担心：对应先准确复述对方可能的理解。
  • 群里原话：对应已说过的事实。
  • 86份问卷：对应已知背景和计算口径问题。
  • 汇总底表：对应共同核对的具体材料。
  • 确认后通报：对应后续沟通安排。

四项细化自评标准

  1. 原话准确：是否复述了“46人、58%、分母未注明”，而没有自行添加“统计错误”或“整表不可信”？
  2. 区分理解：是否分清群消息的字面事实、林老师的理解和自己想确认的范围，没有用“你想多了”压过对方？
  3. 核对具体：是否说明要看统计说明、有效样本数或汇总底表，并提出可执行的核对动作？
  4. 追问回应：是否回应“为什么发群里”，说明当时目的，同时给出下次更合适的沟通办法？

两份参考都回答同一道题。参考一从原话和边界切入，参考二先复述对方的担心；都不把58%预先认定为错误。关键词用于恢复逻辑，不要求背诵。
