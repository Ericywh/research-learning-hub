第2章·第01节｜如何自然打开一次对话

全课程第022课 / 共126课 · 第4周 · 18分钟（核心15分钟＋练后迁移3分钟）

从共同情境自然开口，让第一次见面的交流能够继续；不靠突兀盘问，也不需要刻意套近乎。

🎯 今日问题｜先独立回答

具体情境

你在高校跨院系教学研究方法工作坊的茶歇时间，第一次遇到一位老师。你们都站在活动议程板旁，对方正看着“课堂数据与教学改进”环节。

今天要正面回答的问题

你会怎样自然地向这位老师开口，并在对方两次回应后接续交谈？

口头练习要求

在60—75秒内模拟自己的三次发言：先用共同场景开启对话，再回应对方的具体信息，最后用一个容易回答的问题让交流继续。不要虚构自己做过的研究或认识对方。

🗣️ 完整模拟材料｜对方的两次回应

这是原创模拟情境，非真实人物对话。两句回应按顺序使用，不必另外寻找搭档。

对方回应一｜在你的开场白之后

“我主要做教学研究，今天想听听课堂数据怎么用。”

对方回应二｜在你的第二次发言之后

“我们平时收集学生反馈，但还没想好怎么分析。”

录音时看到对应提示，可停顿约一秒再继续发言；不用模仿或录制对方的声音。

🧭 今日方法｜三个关键词

观察 → 关联 → 轻问

观察：留意双方正在关注的议程板。

关联：说出与“课堂数据与教学改进”有关的一点自然联系。

轻问：提出范围较小、对方容易回答的问题。

卡住时自问：对方刚刚说了哪个具体词？我能顺着“课堂数据”或“学生反馈”问一个更小的问题吗？

⏱️ 15分钟训练｜按顺序完成五步

  1. 0—3分钟｜读题与素材：读完情境和对方的两句固定回应。记住“观察—关联—轻问”，不写逐字稿。
  2. 3—6分钟｜第一次录音：准备30秒；录制60—75秒的三次发言。两句固定回应只作为提示，看到后停顿一秒再说。
  3. 6—9分钟｜回听标记：回听录音，检查开场是否自然、是否接住对方的话、提问是否容易回答；找出最别扭的一句话。
  4. 9—12分钟｜修改并重录：只修改最别扭的一句话，再录60—75秒；保留两次固定回应的内容，不突然改变话题。
  5. 12—15分钟｜先自评后对照：根据下方四项标准独立评估第二次录音，再主动展开两份规范参考结果。

✅ 四项自评标准｜查看答案之前完成

自然开场：前15秒提到双方共同情境，没有突兀询问姓名、职务或私人信息。

接续能力：两次回应都接住对方刚刚说的具体内容，不把交流变成自我介绍。

提问质量：至少提出一个具体、容易回答、不过度盘问的问题。

表达条件：三次发言合计60—75秒，自然、有礼，不编造个人经历。

练习顺序：先完成两遍录音并独立自评，再展开下方两份参考。示范不是唯一正确答案，不需要背诵。

🧩 15—18分钟｜独立迁移与关键词回顾

15—16分钟｜自己提炼：先保留两段60—75秒录音和独立自评，再把自己三次发言分别压缩为“观察—接话—轻问”三个关键词。改变第一句话的切入角度，用相同的两句固定回应再说60—75秒，回听最后的问题是否具体。

16—18分钟｜回听并对照：不看范文，先口头讲出自己三个关键词，再回听新一遍录音，核对是否回答“从工作坊共同情境自然开场”。完成独立评价后展开参考结果；关键词只作为结构提示，不当作逐字稿。

参考一｜从共同议程轻松开场

你｜第一次发言

您好，我看您也在关注下午的“课堂数据与教学改进”环节。我对这个话题也挺感兴趣，您是想听哪一方面？

对方｜固定回应一：我主要做教学研究，今天想听听课堂数据怎么用。

你｜第二次发言

原来您主要做教学研究。课堂数据的范围其实挺广，像作业完成情况、课堂互动记录，都可能提供一些线索。您现在更关心收集数据，还是怎么把数据用起来？

对方｜固定回应二：我们平时收集学生反馈，但还没想好怎么分析。

你｜第三次发言

学生反馈是个很好的切入点。要是反馈里既有评分也有文字意见，分析思路可能就不太一样。您们目前收集的主要是问卷评分，还是开放式意见呢？

参考二｜从共同疑问引出交流

你｜第一次发言

您好，刚才看到您在看这个环节的安排。我也在想，课堂数据到底怎样才能真正帮助教学。您平时会接触这类问题吗？

对方｜固定回应一：我主要做教学研究，今天想听听课堂数据怎么用。

你｜第二次发言

那咱们关注点还挺接近的。我觉得一个难处是，数据看起来不少，但不一定知道它能回答什么问题。比如学生说“课程太难”，可能是内容难，也可能是节奏快。

对方｜固定回应二：我们平时收集学生反馈，但还没想好怎么分析。

你｜第三次发言

如果已经有学生反馈，我可能会先看看大家集中提到了哪些具体问题，再决定是否需要做更细的统计分析。您收到的反馈里，有没有哪类意见反复出现？

两种方法有什么不同？

参考一从共同议程切入，通过较具体的追问推进交流；参考二先提出共同疑问，再接住“学生反馈”的内容深入讨论。

四项对照标准

  1. 开场与工作坊议程直接相关。
  2. 两次回应都围绕对方原话，没有突然换题。
  3. 结尾留下一个具体、低负担的问题。
  4. 没有虚构个人经历或双方关系。

两份示范仅供练后比较，不是必须背诵的标准台词。

参考关键词一：共同议程—数据使用—反馈类型。提炼依据：按双方共同看到的议程接话，最后询问学生反馈的具体形式。

参考关键词二：共同疑问—数据分析难点—反复意见。提炼依据：从共同困惑接到对方的学生反馈，再用小问题延续交流。
