先认同合理处再补充观点

把“你对我错”的争论转成双方能讨论的问题：听准合理处，补充决策约束，提出可执行的下一步。

TODAY'S QUESTION · 具体任务

你要对谁说什么

情境：学院刚结束一场90分钟的教学研讨会，约45位教师参加。筹备组需要在三天内形成一份简短总结，重点决定下次研讨会的主题和时间安排。一位同事提出发放15题反馈问卷，你认为可以把最需要的三题设为必答，其他意见自愿补充。你们没有以往问卷的作答率数据，也没有证据证明题目少一定能提高回复率。

对象与问题：面对同事提出的15题问卷，请在75—90秒内先准确认可他担心遗漏意见的理由，再补充“三天内形成总结、优先决定下次主题与时间”的约束，提出一个双方可以讨论的问卷安排；同事追问后，用20—30秒继续回应。发言对象是提出建议的同事，其他筹备成员在场。

原创模拟材料，非真实工作记录。个人录音和评分只由本人保管。

READY-TO-USE · 现成素材

先听懂对方，再接话

同事第一轮发言

“我建议会后发一份15题问卷。内容问得全面一些，才能知道大家对主题、时间、主持和现场安排的看法。只问三题，我担心漏掉重要意见。”

同事第二轮追问

“可是如果不问场地和主持这些细节，怎么知道大家到底哪里不满意？下次改进不就缺依据了吗？”

可直接朗读的情境说明

这次研讨会已经结束，筹备组需要在三天内形成简短总结，主要为下次活动的主题和时间安排提供依据。问卷要不要覆盖更多细节，大家有不同考虑。目前没有以前的回复数据，所以只能讨论问卷设计的目的和取舍，不能先断定哪一种效果更好。

THINKING ROUTE · 三词提纲

先认同，再补充

本课练习的顺序是：先说准对方的合理考虑，再补充他尚未纳入的决策约束，最后把分歧缩成双方能回答的问题。认可的是“希望收集完整意见”这一目标，不必假装赞成“15题全部必答”这一方案。

覆盖意见—三天总结—三题必答

“覆盖意见”对应同事希望信息完整的合理处；“三天总结”对应眼前要完成的决策；“三题必答”对应你提出的分层收集方案。只记这三个词，不写逐字稿。

词穷时自问：对方真正想避免遗漏的是什么？我们三天后必须作出哪两个决定？哪些问题需要人人回答，哪些可以自愿补充？

18-MINUTE PRACTICE · 分钟级流程

按顺序独立完成

0—3分钟

1. 完整输入与问题理解

0—1分30秒朗读情境、同事两轮原话；1分30秒—2分30秒关稿口述：他为什么想问15题、三天内必须决定什么；最后30秒辨认分歧是“问卷是否要全面”，还是“哪些题必须人人回答”。

3—6分钟

2. 三词搭结构与接续

前60秒只记“覆盖意见—三天总结—三题必答”；接着60秒用自己的话说出“我同意你担心……，我想补充……”，再用60秒提出一个可讨论的问题，例如“哪些问题是本次总结必须用到的？”不要预写完整答案。卡住时问：对方真正想避免遗漏的是什么？我们三天后必须作出哪两个决定？哪些问题需要人人回答，哪些可以自愿补充？

6—11分钟

3. 独立首录、追问与回听

准备20秒，录75—90秒首轮回应；读同事第二句后录20—30秒追问回应。用约2分钟回听，标出是否准确承认对方顾虑、有没有说清新约束、有没有提出可以共同判断的问题；剩余时间记录一句最需要修改的话。

11—16分钟

4. 修改重说与陌生话题迁移

前1分钟只修改最薄弱的一句，随后用75—90秒重录同题；再花30秒比较两次开头。阅读下方植物园情境30秒，不看本题提纲，独立说45—60秒并录音；最后约30秒回听，检查是否仍能先认同合理处再补充。

16—18分钟

5. 独立自评与练后对照

先用约1分钟给“认可准确、补充切题、问题可讨论、方案可执行”四项各打0—2分，并写下一句要改的原话；剩余约1分钟才主动展开下方两份完整示范、各自关键词和四项细化标准。示范用于比较，不要求背诵。

TRANSFER · 换题迁移

陌生话题：周末几点出门

周六一家人准备去近郊植物园，已经预约11点的导览，单程车程约40分钟。一位家人建议早上7点出门，理由是希望避开中午的炎热；另一位家人提醒，孩子前一晚有活动，太早起床会比较累。你不知道当天实际人流和气温。请对主张7点出门的家人说45—60秒：先认可避热的考虑，再补充休息与11点预约这两个条件，提出一个大家可以讨论的出发时间及确认办法。

迁移题不预给三词答案，练习从新材料中自己找到合理处、约束和讨论问题。

参考一｜从本次总结需要什么信息切入

首次回应

“你担心只问三题会漏掉重要意见，这个考虑有道理。尤其是主题、时间之外，现场安排也可能有值得改进的地方。我想补充一个现实限制：我们三天内就要写出总结，而且这次最需要确定的是下次讨论什么、安排在什么时间。我不太建议把15题都设成必答。能不能先把‘下次想听的主题’‘时间是否合适’‘最想改进的一点’作为三道核心题，其他关于主持、场地的细节保留为选答？我们先一起看一下，哪些信息是三天后作决定必须用到的，再决定哪些题必答。这样既没有放弃收集意见，也能把问卷和这次要做的决定对上。”

同事追问后的回应

“你说的这些细节可以保留，我也不主张不问。我的意思是先区分‘这次总结必须掌握’和‘后续改进可以补充’的信息。要不我们把15题过一遍，逐项确定必答还是选答，而不是现在就删掉？”

参考一关键词（5个）：

  1. 遗漏意见：准确认可对方担心信息不完整
  2. 三天总结：补充时间与决策约束
  3. 主题与时间：说明核心问题的用途
  4. 三题必答：提出具体分层方案
  5. 逐项定必答：把争论变成共同决策的问题

参考二｜从问卷用途和优先级切入

首次回应

“我赞同你想把反馈收得更完整，特别是主持和场地方面，如果完全不留反馈渠道，确实容易错过一些具体问题。不过我想先问一句：这份问卷最主要是帮助我们三天后定下次研讨会的主题和时间，还是准备做一份比较全面的活动评估？如果主要是前者，我倾向于把主题选择、时段偏好和最需要改进的地方放在前面，作为每个人都能回答的核心部分；其余问题放在后面自愿填写。如果我们确实需要做全面评估，再讨论哪些细节必须收集。这样咱们讨论的就不是‘15题好还是3题好’，而是每一道题将用来支持什么决定。”

同事追问后的回应

“你提醒得对，场地和主持的信息也有用。我建议给这两类问题保留开放填写的位置，并在汇总时单独整理。至于要不要全部必答，我们可以按这次总结的用途逐题讨论，先不假定问卷短就一定有人愿意填。”

参考二关键词（5个）：

  1. 完整反馈：认可对方的信息覆盖目标
  2. 问卷用途：提出需要先澄清的核心问题
  3. 三天决策：说明本次任务边界
  4. 核心与选答：提供分层处理方式
  5. 逐题对应决定：给出双方可共同采用的判断标准

四项细化自评标准

  1. 认可准确：是否明确说出对方担心漏掉主持、场地等重要意见，而不是空泛地说“你说得对”？
  2. 补充切题：是否说清三天内要完成的总结和下次主题、时间两项决定，没有臆测问卷回复率？
  3. 问题可讨论：是否把“15题还是3题”改成“哪些信息必须用于本次决策、哪些可以选答”这样双方能回答的问题？
  4. 方案可执行：是否提出核心题、补充题或逐项筛选的办法，并正面回应同事关于细节遗漏的追问？

两份参考都回答同一道问卷分歧题；参考一从本次总结出发，参考二从问卷用途出发。不要求背诵，不假设哪种问卷回复率一定更高。
