第042课｜第6周复盘：需求是否说清｜18分钟

正式情境与任务

周一，你和同事林老师准备周五90分钟的六组学生研究交流会。你负责主持卡，林老师负责核实学生标题与点评人员。两组最终标题、一位点评老师出席情况尚未确认。你希望周三12:00前获得一张状态表，包含已确认、待确认、联系人和下次反馈时间；不要求全部确认。林老师说：“我周三上午连着上课，不能保证中午之前全部落实。你是不是把所有事情都推给我？”随后追问：“如果到周四还有人不回复，主持卡怎么做？”

产出：90秒主回应、30秒追问、修改后90秒重录、45—60秒迁移录音和独立评分。

可朗读素材

“我想确认一下我们需要交接的究竟是什么。我需要的是周三中午之前的一份信息状态，而不是所有事项的最终结果。你上课忙，可以只标出哪些已经确认、哪些还需要联系，我负责把表格整理成主持卡。周四如果仍有缺项，我们先留空并向组织小组报告，不用猜测补全。你看能不能由我先建表，你在方便时补充？”

三词提纲：状态表（请求）—课务冲突（顾虑）—缺项备选（后续）。卡住时问：需要什么、为什么困难、谁决定下一步？

18分钟逐分训练

  1. 0:00—3:00｜朗读完整情境和两轮原话90秒；朗读素材45秒；关稿用45秒复述“谁需要什么、对方顾虑、尚未确认的事项”。
  2. 3:00—6:00｜60秒组织三词“状态表—课务冲突—缺项备选”；60秒把“你必须中午给我”改成清楚可协商的请求；60秒说清交接表的四栏及责任分工。
  3. 6:00—11:00｜准备20秒，录制90秒主回应；读追问10秒，录制30秒回答；回听110秒，标记是否误把状态表说成全部确认、是否回应上课顾虑；最后40秒修改一句。
  4. 11:00—16:00｜45秒修改，90秒同题重录，30秒比较；45秒阅读陌生情境，60秒录制迁移，30秒回听。
  5. 16:00—18:00｜先60秒独立给四项评分并记录一句改进；后60秒展开双示范，对照关键词与自评依据。

参考一｜先明确交接请求

“林老师，我想先说清楚，我需要的不是你周三中午把所有标题和点评人员都落实，而是一份当前状态表。你周三上午课多，我理解这个时间点对你不方便。之所以希望提前看到状态，是因为我周三下午要做主持卡初稿，需要知道哪些内容能写、哪些要留空。我们可以把工作拆开：我先建四栏表，列出事项、目前状态、联系人和下次反馈时间；你有空时补上已收到的回复，尚未回复的直接标待确认。若周三中午确实赶不上，你先告诉我能交接的时间，我按已确认内容做初稿。你看这样是否更容易安排？”

追问：“如果周四仍有人不回复，我不会擅自填入标题或点评人。我会把缺项清单提交组织小组讨论处理办法，主持卡先保留占位，并在正式发布前核对最终状态。”

参考一关键词：“状态表”（核心请求）；“周三课程”（对方顾虑）；“主持卡初稿”（主要理由）；“四栏清单”（操作细节）；“留空上报”（缺项备选）。

参考二｜先梳理双方分工

“我听到你的顾虑有两个：周三上午没有足够时间逐个联系，以及担心所有确认任务都落到你身上。我想澄清一下分工。你负责对外联系，我负责整理主持材料；我现在请求的是一次状态同步，不是要求你保证对方一定回复。两组标题和一位点评老师的情况还没确定，这些信息若被写成定案，会让主持卡失真。我可以今天先把现有顺序和缺项列出来，发给你核对。你只需要在周三方便的时间更新回复状态；我们再约定周四的最后核对节点。这样能把任务分清楚，也保留调整空间。你觉得哪个时间适合同步？”

追问：“到周四还没有结果，就明确标注未确认并交组织小组决定是否调整流程。我们不会自己编造标题，也不提前宣布点评人到场。”

参考二关键词：“两项顾虑”（接话情境）；“联系与整理”（责任分工）；“三项未定”（事实依据）；“周四核对”（时间节点）；“组织小组决定”（处理边界）。

细化自评依据

  1. 是否说清需要的是状态同步而非保证全部确认？
  2. 是否回应对方上课和工作分担的顾虑？
  3. 是否给出表格内容、负责人及具体交接节点？
  4. 是否说明周四仍未确认时不虚构信息的处理办法？
