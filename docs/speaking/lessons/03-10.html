第052课｜让叙述有时间与因果顺序

理清事件先后，准确解释行动原因。个人录音和评分不公开。

18分钟60—75秒首录陌生迁移

一、正式练习题

原创模拟高校工作情境，非真实工作记录。你负责整理学生学术交流会材料，周四16:00前须将最终议程交给主持人。以下事件未按时间排列：

A 15:30：核对全部六组汇报题目，将最终议程发给主持人。

B 10:00：发现两组学生报名表与PPT首页题目不一致。

C 14:00：两组学生分别确认最终题目，据此修改议程。

D 10:30：无法判断最终版本，标记两处待确认，联系学生核实。

E 12:00：等待回复期间，完成其他四组材料核对及议程排版。

负责组织的同事问：“听说上午有两组学生的材料出了问题，后来是怎么处理的？有没有影响议程提交？”

准备15秒，脱稿讲述60—75秒，说明发现、核实原因、等待期间的工作、解决及提交结果。保存首录、重录、陌生迁移和独立评分。

二、朗读素材（独立原创模拟）

昨天上午，我原本打算先去银行办事，再去附近的书店。出门前查了一下，发现银行当天上午的营业时间有临时调整，要晚一个小时才开始办理业务。

因为不想在那里空等，我就先去了书店，买完需要的书以后，又在附近吃了早餐。等银行开始营业，我再过去办理业务。虽然原来的行程顺序变了，但两件事情都在上午完成了。

这次主要是根据营业时间调整了做事顺序，没有必要因为一项安排发生变化，就把整个上午的计划都取消。

读两遍，第二遍留意因果与时间连接，合上材料用30秒复述。

三、三词提纲与接续句式

题目不一致：起因。

核实与并行：行动及等待期间的安排。

按时提交：结果。

时间线：10:00发现 → 10:30核实 → 12:00其他四组 → 14:00确认修改 → 15:30提交。

因果线：版本不一致 → 无法确定 → 联系核实、暂不定稿 → 确认后修改。等待期间可以处理其他材料，最终在截止前提交。

句式：“因为当时还没办法确定……所以我先……”“在等对方回复的这段时间，我先把……”“等……确认以后，我就……最后……”

卡住自问：接下来发生什么？为什么这样做？最终解决了吗？

四、18分钟训练

00:00—03:00：0:00—1:00读正式题；1:00—2:00朗读素材两遍；2:00—3:00关稿30秒复述，再口头排序五项事件。

03:00—06:00：3:00—4:00检查先后；4:00—5:00搭三词骨架，说明核实与并行原因；5:00—6:00练三个衔接句，不写稿。

06:00—11:00：6:00—6:15准备；6:15—7:30首录60—75秒；7:30—9:00回听标记跳跃与原因不清；9:00—10:00重说两个混乱句；10:00—11:00口头解释核实、等待、提交关系。

11:00—16:00：11:00—11:45修改；11:45—13:00重录；13:00—13:45比较；13:45—14:15压缩为30秒工作汇报；14:15—14:40读迁移题；14:40—14:50准备；14:50—15:50录60秒；15:50—16:00标记回听位置。

五、时间与因果辨析

“上午发现题目不一致，下午学生进行了确认”是先后；“因为无法确认最终版本，所以先联系学生核实”有明确行动原因；“因为完成其他四组排版，所以学生下午回复”缺乏因果依据。根据关系选择后来、与此同时、因为、等到。

六、陌生迁移

原创模拟：周末邀请两位朋友到家吃饭，约18:00开饭。11:00采购食材；15:00发现烤箱无法启动，因故障原因未知，暂不使用，检查哪些菜可以改用炒锅制作；16:00确定调整后菜单，完成清洗准备；17:30几道菜陆续做好；18:00朋友到达，按时开饭。第二天没参加的朋友问：“你昨天不是说烤箱突然坏了吗？后来晚饭怎么安排的？”

10秒准备，60秒讲述，撤掉原提纲。说明改变做法的原因、调整与结果，不虚构故障原因或修复情况。

八、完成录音及独立自评后展开：双示范、关键词与细化依据

参考一｜按时间顺序完整讲述

上午整理交流会议程的时候，我发现有两组学生的汇报题目不一致，报名表上写的是一个版本，PPT首页上又是另一个版本。

因为当时没办法确定哪个才是最终题目，我就先把这两处标记为待确认，同时联系学生，让他们核实一下。

在等学生回复的这段时间，我没有停下其他工作，而是先把另外四组的材料核对了一遍，也把议程的基本格式排好了。

下午两点左右，两组学生分别确认了最终题目，我就根据他们的回复修改议程。随后又把六组汇报题目整体检查了一遍，下午三点半发给了主持人。

原定是下午四点之前提交，所以这次虽然中间多了一道核实程序，但没有耽误最后的交付。

关键词：两个版本（起因）；待确认（核实原因与行动）；另外四组（并行工作）；两点回复（关键进展）；三点半提交（结果）。

参考二｜结果先行，再说明解决过程

没有影响提交，最终议程下午三点半就已经发给主持人了，比原定截止时间早了半个小时。

上午主要遇到的问题是，两组学生的报名表和PPT首页上的汇报题目不一致。我不确定他们后来有没有修改题目，所以没有直接选其中一个版本，而是先联系学生确认。

等待回复的时候，我把可以确定的部分先做完，包括另外四组材料的核对和议程排版。这样，未确认的题目就没有阻断其他工作。

下午两点收到两组学生的确认以后，我把最终题目补进去，再重新核对全部六组的汇报题目，确保议程使用的是学生确认的版本。

最后三点半提交了。整个过程主要多了一步题目核实，其他准备工作仍然继续推进。

关键词：提前半小时（结果先行）；报名表与PPT（问题细节）；学生确认（定稿条件）；先做确定部分（并行安排）；六组复核（最终行动）。

四项细化自评依据

1. 是否准确说明发现、核实、并行处理、确认、提交的顺序？

2. 是否解释不能直接选版本及等待时继续工作的原因？

3. 是否避免把其他四组排版说成学生回复的原因？

4. 是否说明15:30提交、未超过16:00截止时间，60—75秒自然完成？

两份同题，路径不同。不要求背诵。

请先完成两轮评分并勾选确认，再打开参考。
