说服不同受众如何调角度

常规18分钟。核心建议保持一致，理由、开头和执行细节随听众关注点调整。先录音、回听、独立自评，后展开双示范。所有情境均为原创模拟，非真实工作记录。

一、正式练习题

学院周五下午举办90分钟学生研究交流会，六组学生汇报。你协助主持材料，建议各组在周四中午前提交一份150字以内的简要提要，列出研究问题、采用的方法、主要发现或阶段性进展三项。尚无最终结果可如实标注，不要求重新制作PPT或提交正式报告。

预期用途是帮助主持人提前了解研究内容、帮助学生检查信息清晰度；实际效果尚未验证。

听众A｜学生代表

“我们这周还要准备汇报PPT，为什么还要交150字的东西？这不是多做一份作业吗？”

听众B｜活动负责人

“现在六组学生的材料已经不少了，再收一份提要，谁来汇总？如果有人迟交，岂不是又多一道流程？”

任务：对学生代表、活动负责人分别口头表达60—75秒，说明同一建议、主要理由及可执行办法。不得改变周四中午、150字、三个字段的条件，不能夸大收益。

产出：两段首录、修改后重录、45—60秒陌生情境迁移与独立自评。录音和评分仅由自己保管。

二、完整口语素材

面向学生：“如果这件事会要求大家重新做一套材料，那确实不合适。我的想法是尽量利用你们已经准备好的PPT，用150字以内概括研究问题、方法和目前进展。没有最终结论，就如实写当前进展。不用另做正式报告，也不用为了凑结果写自己还没有完成的内容。”

面向负责人：“如果要增加这项材料，最好先把收集和汇总责任定清楚。六组学生可以统一提交到同一张表格，每组只填三个字段。我可以负责整理和核对，不再让不同老师分别催收。对于尚未提交的部分，先明确标注，避免把缺项误认为已经确认。”

朗读两段，对比它们如何分别回答“是不是增加工作量”和“新增流程如何落实”。

三、两组三词提纲与词穷接续

面对学生
  • 已有PPT：不重新制作
  • 150字：限定任务负担
  • 真实进展：不用编造结论
面对负责人
  • 统一表格：单一收集渠道
  • 我来汇总：明确责任
  • 迟交标注：处理缺项

卡住时问自己：他最担心什么？我怎样具体回应？哪个执行细节还没有说清？

四、18分钟逐分训练

  1. 00:00—03:00｜素材输入与理解0:00—1:20读情境和两位听众的原话；1:20—2:20朗读完整素材；2:20—3:00关稿复述各位听众最关心的两个问题。
  2. 03:00—06:00｜搭结构与选择关键词3:00—4:00确定核心建议及不变条件；4:00—5:00形成学生版“理解负担—简化任务—说明真实进展”；5:00—6:00形成负责人版“协调成本—统一收集—处理缺项”。
  3. 06:00—11:00｜独立首录与回听6:00—6:20准备；6:20—7:35录学生版60—75秒；7:35—7:50转换听众；7:50—9:05录负责人版60—75秒；9:05—10:30回听并比较角度；10:30—11:00各写一句需要修改的话。
  4. 11:00—16:00｜修改重说与迁移11:00—11:45修改两种开头；11:45—13:45两位听众各重录约60秒；13:45—14:15比较理由与措施；14:15—14:40读陌生情境；14:40—15:40独立录45—60秒；15:40—16:00回听，检查是否改变事实。
  5. 16:00—18:00｜独立评分与练后对照16:00—17:00完成四项独立评分并记录改进；17:00—18:00主动展开最后的隐藏参考区，对照两份示范和关键词。

五、陌生情境迁移

原创生活模拟：你与四位朋友准备周末徒步，建议周五晚上前每人在群里确认基本装备及是否参加。一位朋友说：“出来玩还要交清单？搞得像上班一样。”组织者说：“大家自己准备就行，统一确认会不会增加我整理消息的麻烦？”天气、交通尚未核实。

迁移任务：不用原提纲，用45—60秒先回应普通朋友，说明如何简单确认装备；再回应组织者，提出减少整理负担的方法。不能声称确认装备便一定安全，或把天气、交通说成已经核实。

六、独立自评

先完成录音后评分，再展开下一部分。每项0未做到、1部分做到、2清楚做到。评分只保留在当前页面，不上传。

1. 识别两类听众的不同顾虑
2. 两次建议及事实保持一致
3. 针对不同听众调整理由
4. 给出各自关心的执行办法

七、双示范、对应关键词及细化自评

参考一｜先回应对方顾虑，再说明具体安排

对学生代表：“我理解你们的顾虑。这周已经要准备PPT，如果又要求重新写一份正式报告，确实会增加不少工作。我的建议其实很简单：周四中午前，每组从已有PPT里提取三项内容，用不超过150字说明研究问题、方法和目前的发现或进展。

如果研究还没做完，就写到哪一步，不用为了交提要临时编一个结论。这样做主要是方便主持人提前了解各组在讲什么，也给大家一个检查自己核心信息是否清楚的机会。我不会要求你们额外制作新PPT。

如果你们觉得哪个字段不好填写，我们可以一起把填写说明改清楚，尽量避免重复工作。”

对活动负责人：“您担心的是增加收集工作，这一点我也考虑到了。如果要推行，我建议先把责任和时间节点固定下来，避免让几位老师分别催收。

六组学生统一在周四中午前提交150字以内的提要，只填写研究问题、方法和当前发现或进展。我来制作统一表格、汇总内容，并在周四下午核对缺项。没有交的组先标注未提交，不会自行补写。

整理好的版本只作为主持准备材料，不要求学生再改一份正式报告。对迟交或未定稿的情况，我们提前说明处理原则，再由组织方决定是否需要进一步跟进。您看这样分工是否可行？”

参考一关键词与示范的对应关系
PPT已准备学生已有工作和额外负担
150字提取核心建议、减少重复制作
如实写进展未完成研究时的处理
统一表格负责人关心的操作安排
缺项标注迟交时的风险处理

参考二｜先说明共同目标，再解释不同成本

对学生代表：“我想请大家交这个简要提要，是希望我们在正式交流之前，先把每组到底研究什么讲清楚。六组学生的方向可能不一样，主持人如果能提前看到研究问题和方法，现场介绍时就有比较具体的依据。

我知道大家现在正在做PPT，所以不建议另写完整材料。周四中午前，从现有内容中整理150字以内就可以，按研究问题、方法、目前发现或进展三项填写。如果还没有结果，就说明正在进行的部分。

这项准备不应该变成一次额外的成果考核。你们也可以借这个过程检查一下，别人只看这150字，能不能理解你们的研究重点。你觉得这样的工作量能否接受？”

对活动负责人：“我希望主持人在介绍六组学生时，有一份内容一致、便于查阅的简要材料。现在各组PPT形式不同，直接逐份查看不太方便，所以我建议收集一份统一格式的150字提要。

这项建议能不能执行，关键在于不能把整理任务转嫁给组织老师。我负责建立三个字段的表格，并在周四中午截止后统一检查；学生只需要从原有PPT提取信息，不另做正式报告。

对于没有及时提交或仍未定稿的部分，我会单独列出，不把它们写成已经确认的事实。周四下午把汇总表和缺项情况交给您，是否需要补充联系由组织方判断。这样能为主持准备提供材料，也方便控制新增流程。”

参考二关键词与示范的对应关系
研究重点面向学生的共同目标
三项内容核心要求及任务边界
150字自检学生可以尝试的实际用途
统一格式面向负责人的主要理由
周四汇总负责人的交接时间和操作

四项细化自评

  1. 是否针对学生的额外负担和负责人的协调成本分别回应，而不是重复同一段话？
  2. 是否保持周四中午、150字以内、三个字段等事实与要求一致？
  3. 是否对学生解释怎样利用已有PPT，对负责人明确统一收集和汇总责任？
  4. 是否说明尚未完成研究、迟交和缺项的处理，没有夸大提要效果？

两套完整示范均覆盖正式题的两位听众。关键词只帮助组织内容，不要求背诵。

八、完成标准

同一建议面对不同人，10秒内选择不同切入点，各连续表达约60秒，并保持事实一致。课程发布不代表学员实际完成练习，录音与分数不会上传。
