拒绝请求而不伤关系

先回应对方的实际需要，再清楚说明自己不能承担的部分，最后提出一项确实能够兑现的替代帮助。

18分钟完整训练首录与追问回应回听修改与迁移双示范练后展开

第2章·第12节｜全课程第033课 / 126课 · 第5周 · 18分钟

训练重点：拒绝时不含糊、不指责、不作无法兑现的承诺。所有人物与情境均为原创模拟。

一、明确题目与发言对象

具体情境：周三下午，学院同事陈老师在办公室对你说：“周五上午我要参加一个临时会议，你能不能替我主持9:00—10:30的学生实习汇报？我把流程发你，你照着走就行。”

你的真实安排：周五9:00—10:00已有一场不能改期的课程；10:00—10:30需要处理课后学生咨询。你不能主持整场，也不能承诺10点后一定赶到。

对方追问：陈老师接着问：“就帮这一次，你能不能把学生咨询往后推？”

完整任务：面对陈老师，用75—90秒明确拒绝主持整场，说明真实时间冲突，不评价对方的请求是否合理，并提出一项自己确实能做的协助动作；再用20—30秒回应对方关于推迟学生咨询的追问。

练习产出：首次回应录音、追问回应录音、修改后的同题录音、陌生情境迁移录音，以及四项独立自评。不要替对方录音，也不要虚构可以调整的时间。

可直接朗读的口语素材：

“我知道你是临时碰到时间冲突，希望有人帮忙把学生汇报顺利进行。我周五九点到十点有课，课后还有学生咨询，没法承担九点到十点半的整场主持。我可以今天帮你把主持流程和学生顺序整理成一页清单，方便你联系能够全程到场的同事。如果你愿意，我们现在就把需要交接的事项列出来。”

二、本课方法｜临时冲突—已有课程—流程清单

临时冲突：先表明理解对方遇到临时会议、需要有人接手的现实困难。

已有课程：把不能承担的时间范围说清楚。不要只说“我可能不太方便”，也不要把拒绝包装成尚未确定的考虑。

流程清单：提出一项自己确实能完成的替代帮助，例如整理主持流程、学生顺序和交接事项；不承诺自己无法保证的现场主持。

卡住时自问：对方具体需要我做什么？我不能答应哪一段？我现在能提供哪一种不需要失约的帮助？

这三个词只用于恢复表达顺序，不需要逐字说出，也不要求背诵范文。

三、18分钟逐段训练

  1. 0—3分钟｜输入与理解。0:00—1:20朗读完整情境和陈老师的请求、追问；1:20—2:10朗读口语素材；2:10—3:00合上材料，复述对方的需要、自己的两项时间约束，以及自己不能承诺的事项。
  2. 3—6分钟｜搭建回应结构。3:00—4:00用“临时冲突—已有课程—流程清单”组织三段；4:00—5:00把“我可能不太方便”改成一句清楚、礼貌、不含糊的拒绝；5:00—6:00准备回答“能不能把学生咨询推后”，不写逐字稿。
  3. 6—11分钟｜独立首录与回听。6:00—6:20准备；6:20—7:50录制75—90秒首次回应；7:50—8:00读出陈老师的追问；8:00—8:30录制20—30秒答复；8:30—10:10回听，标出模糊承诺、过度解释或没有回应对方需要之处；10:10—11:00写下最需要修改的一句话。
  4. 11—16分钟｜修改、重说与陌生迁移。11:00—11:45修改最薄弱的一句；11:45—13:15重录75—90秒；13:15—13:45比较两次是否都清楚拒绝整场；13:45—14:20阅读下方朋友搬家情境；14:20—15:20不看原提纲录制45—60秒新回应；15:20—16:00回听，检查有没有给出无法兑现的承诺。
  5. 16—18分钟｜独立自评后对照。16:00—17:00四项各打0—2分，并记录一句改进；17:00—18:00再主动展开下方同一个折叠区中的两份完整示范、各自关键词与自评标准。

四、陌生情境迁移｜朋友临时请你帮忙搬家

原创生活模拟：朋友周四晚上问你：“周六帮我搬家吧，上午九点到下午一点，开车一起搬完。”你周六上午已经答应陪家人去医院复诊，下午两点以后才有空；你没有车。

迁移任务：面对朋友，用45—60秒明确说明不能参加上午的搬家，不透露不必要的家庭隐私，提出一种自己确实能兑现的协助方式，例如下午两点以后帮忙整理物品。不要假定朋友一定接受，也不要暗示自己可以开车。

五、独立自评｜先给自己打分

完成首录、追问回应、重录和迁移录音后，先按四项各0—2分独立评分，总分8分，并记下一句最需要修改的表达。具体评分依据与两份示范放在下方同一默认隐藏折叠区；评分前不要展开。

录音和评分由本人保存；本网页不录音、不上传个人声音或评分。

🔒 完成首录、追问回应、重录、迁移和独立自评后，展开两份示范、各自关键词与自评标准 ⌄

参考一｜清楚说明时间边界

“陈老师，我明白你是临时要参加会议，担心周五的学生汇报没人主持。我想帮你把这件事安排妥当，但九点到十点我有课，十点之后还有学生咨询，所以九点到十点半这整场我没法接下来。我不想先答应，到了当天又让你临时找人。这样吧，我今天可以帮你把汇报顺序、每位学生的时间和主持提醒整理成一页流程清单，你拿着清单联系能够全程到场的老师，交接会容易些。如果需要，我今天下班前可以和你一起检查一遍流程。”

追问回应：“学生咨询已经安排好了，我不适合临时推迟，也不能保证十点后赶到。整场主持我确实承担不了，但今天整理流程这件事我可以负责。”

参考一关键词（5个）：

  • 临时会议：对应对方遇到的情境和实际需要。
  • 九点有课：对应拒绝的主要理由。
  • 学生咨询：对应十点后的具体时间约束。
  • 整场不能接：对应清楚明确的拒绝结论。
  • 流程清单：对应能够兑现的替代帮助。

参考二｜从交接风险解释拒绝

“你这次需要的是一个能从九点一直在场、把学生汇报完整衔接起来的人。我周五九点到十点有教学安排，后面还有学生咨询，没法保证连续在场。如果我只接一部分，反而可能需要你再找一个人中途交接，所以我不能答应主持整场。我们可以换个办法：我今天帮你拟一份主持开场词、学生出场顺序和突发情况联系人表。你找好能够全程在场的同事后，我可以提前把这几项和他说明，减少他临时接手的准备负担。这样不耽误我已有的安排，也能帮你把需要交接的事情做扎实。”

追问回应：“我理解你想尽量少麻烦别人，但把学生咨询临时推后仍不能保证整场衔接。我可以负责前期材料准备，现场主持需要另找一位能够全程在场的老师。”

参考二关键词（5个）：

  • 全程在场：对应请求的核心要求。
  • 连续时间不足：对应不能承担整场的主要理由。
  • 中途交接：对应只接一部分可能产生的实际风险。
  • 主持开场词：对应具体可交付的协助内容。
  • 提前说明：对应降低交接成本的行动。

练后自评标准

  1. 边界清楚：是否明确说出不能主持整场，避免用“再看看”“应该可以”等模糊表达？
  2. 回应需要：是否承认对方临时需要人手的困难，没有责备或评价对方？
  3. 替代可行：是否只承诺自己确实能完成的流程准备、材料整理或交接工作？
  4. 追问回应：是否直接回答能否推迟学生咨询，而非重复道歉或转移话题？

两份示范都回答同一道题。参考一先说明时间边界，参考二先解释整场交接风险；关键词只用于恢复表达结构，不要求背诵。
