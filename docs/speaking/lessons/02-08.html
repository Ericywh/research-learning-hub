委婉而清楚地表示不同意

先回应对方的合理顾虑，再清楚说明分歧，提出可讨论的替代安排。

18分钟完整训练真实开口与回听陌生情境迁移双示范默认隐藏
18-MINUTE TRAINING · 029

第2章·第08节｜全课程第029课 / 共126课 · 第5周 · 18分钟

主题：委婉而清楚地表示不同意。训练先回应对方的考虑，再说出自己的不同判断，给出具体理由与可执行替代方案。所有情境为原创模拟，不代表真实工作记录。

一、今天要解决的问题

别人提出一个看似合理的安排，你心里不同意，却容易出现两种情况：只说“也行吧”，最后没有表达真实意见；或者直接说“这样不合理”，让对方觉得自己的考虑被否定。

本课练习的不是把反对意见包装成客套话，而是让对方准确听到你的判断，同时保留继续协商的空间。

本题使用理解顾虑 → 明确分歧 → 提出替代三步。委婉是说话方式，清楚是意见内容，两者缺一不可。

二、今日任务与完整模拟材料

情境：你和五位同事共同筹备一次学院活动。距离最终确认议程还有三天，负责人提议明天下午开一场30分钟的全员进度会。

发言对象：提出建议的同事，其他筹备成员也在场。

明确问题：你认为不必为所有已确认事项再开一次30分钟会议，但预算中的场地费用还有两种方案尚未决定，确实需要同步讨论。请在60—90秒内表达不同意见，提出可执行的替代安排；对方追问后，再用20—30秒回应。

产出：首次同题录音、修改后录音、陌生情境迁移录音、自评与一句修改记录。录音由本人保留。

可直接朗读的情境材料

同事第一轮发言：

“我想明天下午把六个人都叫来，开半小时进度会。这样大家能知道各项准备到哪一步，也不容易漏掉事情。我担心只在群里发消息，有人看了也不回复。”

你掌握的模拟事实：

活动地点与开始时间已确认，宣传文字已定稿，报名表已经建立。这三项信息已写进共享表。尚未决定的是场地费用：方案A较便宜，但设备需要另外协调；方案B费用较高，包含现场设备。两种方案都还没有得到最终批准。所有人明天下午并不都方便参会；如果只讨论场地方案，相关三位成员可安排约10分钟的线上讨论。你没有证据证明书面同步一定更有效，也不能假设所有同事都会按时回复。

同事第二轮追问：

“可是如果不开全员会，万一有人没看到最新进度怎么办？到时候出了问题，还是要返工。”

请用自己的话作答，不必照搬材料中的句子，也不要把“会议浪费时间”作为未经核实的事实。

三、把不同意见说清楚

先承认对方的合理顾虑。 对方担心信息遗漏，这是值得回应的具体问题。可以说“我也担心有人错过更新”，不必说“你这个办法很好”来假装赞同。

用一句话表明真正的分歧。 例如：“不过，我不太赞成让六个人再开一次完整的30分钟进度会。”不能只说“我有一点不同看法”而不交代不同在哪里。

把理由和替代办法接起来。 已确认的三项事项可以书面同步；未决的场地费用需要相关人员讨论。替代安排应说明谁参与、用什么方式、何时确认，以及如何让其余成员收到结果。

卡住时自问：“我反对的究竟是‘开会’本身，还是‘让所有人花30分钟重复已确认事项’？”把分歧范围缩小，往往更容易提出可执行的方案。

四、18分钟训练流程

  1. 0—3分钟｜输入与理解。完整朗读同事的提议、模拟事实及追问。关掉原文，口头说出对方最担心什么、哪些事项已经确认、唯一待决定的事项是什么。不要提前查看参考示范。
  2. 3—6分钟｜搭结构。用三个关键词组织本题：遗漏顾虑—场地未决—分层同步。“遗漏顾虑”对应对方的担心，“场地未决”对应需要讨论的真实问题，“分层同步”对应你的替代办法。用90秒整理，再用90秒试说开头与分歧句，不写逐字稿。
  3. 6—11分钟｜首次独立开口与回听。准备20秒，录制60—90秒的完整回应；随后朗读第二轮追问，再录20—30秒补充。回听两段，标出是否清楚说出了不同意见，是否有一句话过于生硬或含糊。剩余时间记录一处具体修改。
  4. 11—16分钟｜修改重说与迁移。前约2分30秒修改最薄弱的一句并重录同题；后约2分钟完成下方陌生情境，准备20秒、表达45—60秒，尽量不用预设关键词；最后约30秒回听并比较两次的分歧是否都说清楚。
  5. 16—18分钟｜独立自评。按“理解顾虑、明确分歧、理由切题、方案可行”四项各给0—2分，记录一句下次可直接执行的改进意见。评分完成后再展开两份示范与各自关键词。

五、陌生情境迁移｜汇报幻灯片怎么安排

你和一位同事准备向不熟悉项目的老师做五分钟汇报。同事说：“我建议把六张统计图都放在同一页，这样听众一眼就能看到全部结果，也省得来回翻页。”

模拟事实：六张图涉及不同指标，图例与坐标轴较多；其中两张直接支撑本次汇报的主要结论，另外四张属于补充分析。你还没有进行正式听众测试，不能断言某种排版一定更有效。

任务：不用书面提纲，在45—60秒内回应同事。需要承认他希望信息完整的考虑，清楚表达你不赞成把六张图挤在同一页，并提出具体替代办法。不要用“这样肯定没人看得懂”等没有证据的断言。

六、练后参考与自评标准

🔒 完成同题首录、修改重说、陌生迁移及独立自评后，展开双示范、各自关键词与四项标准

参考一｜从工作效率与待决事项切入

首次回应：

“我理解你担心有人漏看消息，最后影响准备进度，这个问题确实要处理。不过，我不太赞成明天下午让六个人再开完整的半小时进度会。现在地点、时间和宣传文字这些已经确认，相关信息也在共享表里，大家可以先书面核对。真正需要讨论的是场地费用的两种方案：便宜的需要另行协调设备，贵一些的包含设备。我建议先请相关三位同事线上讨论十分钟，把取舍和待批准事项列清楚，再把结论发到群里，请所有人确认是否还有遗漏。这样既保留必要的讨论，也不用把已确认的内容全部重新讲一遍。”

追问回应：

“这个担心有道理，所以不能只发消息就算完成。我建议把需要确认的事项和回复截止时间写清楚；到时间仍没有回复的，再由负责人单独联系。未获批准的场地方案继续标注为待定。”

参考一关键词（5个）：

  • 漏看消息：对应对方的主要顾虑。
  • 不赞成全员会：对应明确分歧。
  • 三项已确认：对应事实理由。
  • 场地两方案：对应真正待讨论的问题。
  • 三人短会加回执：对应替代安排与防遗漏措施。

参考二｜从信息可靠性与参与范围切入

首次回应：

“你提到的风险我也在意，尤其是信息发出去了却没人确认，确实可能影响后面的安排。我的想法和你有一点不同：我不建议把六个人都集中起来开三十分钟的常规进度会。我们可以先把已定的地点、时间、宣传内容做成一份很短的状态清单，让每个人逐项确认；需要讨论的场地费用则单独处理，因为两种方案在成本和设备安排上各有待确认之处。我更倾向于让直接负责场地和预算的三位同事先开十分钟线上会，形成明确的待批事项，再向全组同步。这样既能让信息有回执，也把现场讨论留给还没有答案的问题。”

追问回应：

“如果有人没看到，确实不能默认他已经知情。我们可以设一个回复节点，对未确认的人逐一提醒。要是后来出现新的跨组分歧，再决定是否需要全员讨论，不必现在把全员会作为唯一办法。”

参考二关键词（5个）：

  • 确认缺口：对应对方担心的风险。
  • 反对常规全员会：对应明确立场。
  • 状态清单：对应已确认信息的处理方式。
  • 成本与设备：对应场地方案的具体取舍。
  • 逐项回执：对应风险控制与后续协商。

四项自评标准

  1. 理解顾虑：是否准确回应对方担心的“消息被忽略”，而非先否定对方？
  2. 明确分歧：是否清楚说出自己不赞成“六人30分钟常规进度会”，而不是含糊地表示保留意见？
  3. 理由切题：是否区分已确认事项与待决定的场地费用，没有虚构实施效果？
  4. 方案可执行：是否说明参与人员、同步方式、确认节点，并回应“有人没看消息”的追问？

每项0—2分，总分8分。两份参考表达均为原创模拟，不是唯一正确答案，不要求背诵。
