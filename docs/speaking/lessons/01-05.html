第1周18分钟绕口令直接照做
本课任务 · TODAY'S QUESTION

今天只完成这一件事

【模拟论文答辩情境】一名学生研究“论文复现练习与统计学学习成绩的关系”，计划比较有无复现练习的两个班级，但没有交代干预前的成绩和分班方式。【明确问题】你会怎样先肯定选题价值，再提醒研究者补充关键证据？【口头任务】任选本课提供的一组成段绕口令练习2分钟，然后用60秒完成“具体亮点—证据问题—一项建议”的点评；中途卡壳时允许短暂停顿，从核心意思接着说。
SPEECH SOUNDS · 五组分级绕口令

任选一组，练习完整段落

五组原创练习，分别针对 n/l、r/l 和三组前后鼻音。当天只选一组，其他内容留作日后练习；点击标题展开全文。

01刘奶奶和李奶奶n / l · 入门

刘奶奶拎牛奶，李奶奶拿梨来。 刘奶奶把牛奶放在南门里， 李奶奶把梨篮留在南门外。 南门里有牛奶，南门外有梨篮， 刘奶奶和李奶奶别拿错了奶和梨。

02老罗和老李r / l · 进阶

老罗绕路找老李，老李沿路找老罗。 老罗绕到柳林里，老李来到榕树旁。 柳林里不见老李，榕树旁不见老罗。 两人回到老路口，乐得连连说： 以后找人认准路，别再绕来绕去。

03林林听铃in / ing · 进阶

林林走进新林亭，新林亭里挂铜铃。 林林听铃叮当响，听完铃声进新林。 新林亭里的铃声清， 林林听得真分明。

04陈晨进城en / eng · 进阶

陈晨清晨进城门，城门门口亮红灯。 陈晨站在门前等，等到晨风吹动灯。 门前等的人是陈晨， 城门亮的灯是红灯。

05山上杉与山下塘an / ang · 综合

山上有三棵杉，山下有三口塘。 山上的杉望着山下的塘， 山下的塘映着山上的杉。 数清三棵杉，再数三口塘， 别把山上的杉，说成山下的塘。

2分钟练习法

慢读30秒 → 正常读30秒 → 不看原文复述30秒 → 再读30秒纠正。不要为了赶进度而加速，也不必念完全部五组。

LOGIC · 逻辑与内容展开

开口前的三个思考步骤

框架：核心判断 → 理由 → 建议

怎么组织：暂停1—2秒也可以，抓住“我想强调的是……因为……所以建议……”三段意思。

词穷时：忘词时从刚才最重要的判断接续，不必从头再讲。

占用本课原有准备时间，不额外增加时长。

DAILY PRACTICE · 5 STEPS

照着做，18分钟完成

0—2分钟2分钟

1 · 准备与理解

从五组选一，慢读、正常读、离稿复述、再读纠正，各约30秒；不用追求快。

2—4分钟2分钟

2 · 开始练习

准备一个60秒论文点评，关键词是“研究问题、证据支持”。

4—6分钟2分钟

3 · 独立表达

自然点评60秒；想不起来时停顿后换种说法继续。

6—8分钟2分钟

4 · 再次运用

重点提醒

绕口令只是辅助辨音，不是口吃治疗；自然停顿不算失败。

今日成果

一段停顿后也能继续表达两个关键判断的60秒点评。

DEEP PRACTICE · 深化表达

新增8分钟｜总计18分钟

先完成原基础10分钟，再进行以下任务：

  1. 10—13分钟：从自己的录音提炼三词，并为每个关键词补充一条事实或例子。
  2. 13—16分钟：学生追问“具体还需要哪种证据”时，用60秒给出明确答复。 练习60—90秒，换一种说法再说一次。
  3. 16—18分钟：查看隐藏的双版本示范关键词，删掉一句重复话。

不会接下一句时，问：为什么？有什么具体例子？有哪些条件？

AFTER PRACTICE / 对照区
查看两个规范参考结果先自己说，再点击展开⌄

省略号表示自然停顿，不是必须模仿的卡顿。 参考表达不代表唯一正确答案。

参考表达一

我觉得这项研究有一个值得肯定的地方，就是它关注的问题比较明确，也有现实意义。接下来我想强调的重点是……研究者还需要把证据说明得更充分一些。比如，使用的数据能不能真正回答这个问题？有没有其他因素影响结果？如果能补充这些说明，听众就更容易判断结论的可信度。总体上，我认可这个研究方向，也建议进一步完善论证。

参考表达二｜用提问自然接续

我觉得这个题目有一定实际意义，因为它关注论文复现练习与统计学习表现的关系。不过，我想追问一个关键问题：两个班在安排练习之前的学习基础是否相近？如果原来的水平不同，结课成绩差异就不能简单归因于复现练习。所以我建议先补充分班规则、干预前成绩以及其他教学条件。如果讲到这里停顿一下，也可以继续说：我最关心的其实是，这些证据能不能支撑对教学效果的判断。

参考关键词一：选题意义—证据不足—补充说明

参考关键词二：教学问题—班级可比—具体追问

对照要点

  1. 先表达肯定，再明确转入一个问题。
  2. 出现短暂停顿后，用核心意思自然接续。
  3. 没有因为忘词而反复从第一句重讲。
