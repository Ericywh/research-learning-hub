第7周复盘：是否思路清晰

正式18分钟。10秒准备，首次90秒独立录音、回听、修改重录、陌生迁移与独立自评；练习后才展开双示范。

一、正式复盘题

原创模拟高校教学情境，非真实工作记录。你负责一门本科课程。最近几位学生在课程群重复询问作业提交方式和课程资料位置，也有学生私下咨询个人学习困难。

同事A建议：下周起每周三安排20分钟线上集中答疑，回应具有共性的问题。同事B担心：学生提问时间并不固定，仅有每周三答疑可能耽误帮助。目前没有系统记录提问数量、类型、时间分布，也没有调查学生对固定答疑的需求。

教研室主任问：“你是否赞成从下周开始设置每周一次、20分钟的线上集中答疑？请说明你的判断、主要理由，以及具体怎样安排。”

听众：教研室主任与其他任课教师。正式任务：10秒准备，90秒独立表达；明确立场、两个不同理由、一个实际限制及可执行办法。不以“各有道理”回避判断。

成果：首次90秒、重录90秒、陌生题60秒及两组独立自评。录音与评分仅由本人保管，不上传网页。

二、完整朗读素材与问题理解

“一项教学安排是否值得采用，要结合它实际想解决的问题来判断。比如，有些学生的问题可以统一解释，有些问题却与个人学习情况有关，需要单独沟通。设计新的答疑方式时，既要考虑教师组织工作的便利，也要考虑学生什么时候能够得到回应。我们可以根据已经掌握的情况先提出方案，但在缺少反馈时，不宜直接断言某种安排一定更有效。更稳妥的做法是明确适用范围，试用以后再根据具体问题调整。”

这段是表达素材而非正式答案。读完后合上材料，口头区分已知事实、未知信息和主任需要的决定。注意“方便、省事”有可能重复同一个理由，不能根据几位学生重复提问推断多数学生都需要线上答疑。

三、三词提纲与90秒结构

重复询问已知问题与情境
个别咨询需要照顾的差异
安排边界当前选择及执行

三词提醒事实、限制和行动，并不预先规定赞成或反对。卡住时问：我到底建议什么？要解决谁的什么问题？实际执行还缺哪项安排？

时间表达任务
0—15秒直接说出立场
15—40秒第一个理由与具体情境
40—65秒第二个不同理由或限制
65—90秒行动、信息缺口与自然收束

四、18分钟逐分钟训练

  1. 00:00—03:00｜输入与理解0:00—1:20阅读正式情境；1:20—2:10朗读素材；2:10—3:00合上材料，口头复述已知事实、未知信息和主任要求的决定。
  2. 03:00—06:00｜搭结构3:00—4:00看三词并确定立场；4:00—5:00选择两个不重复的理由；5:00—6:00练习立场转理由以及一句行动建议。随后停止看提示。
  3. 06:00—11:00｜首录与回听6:00—6:10准备10秒；6:10—7:40独立录制90秒；7:40—9:20回听并记录展开顺序；9:20—10:20检查立场、重复及事实边界；10:20—11:00决定最需修改的一句。
  4. 11:00—16:00｜修改重说和迁移11:00—11:45修改结构；11:45—13:15同题重录90秒；13:15—14:00比较两次录音；14:00—14:20读陌生题；14:20—14:30准备10秒；14:30—15:30独立录60秒；15:30—16:00回听。
  5. 16:00—18:00｜独立评分与练后对照16:00—17:00为首次与重录分别评分、记一句改进；17:00—18:00主动展开唯一参考区，对照两种判断及各自关键词。

保留两次录音，不用重录覆盖首录。判断的目标是逻辑清楚、依据适当，而不是机械说满字数。

六、陌生话题迁移

原创模拟生活情境。你和三位朋友计划周末短途出行。有人建议周五晚上统一确定出发时间，之后不再调整；一位朋友认为便于安排交通，另一位要等周五下班才能确认是否参加。尚未订交通工具，也没有查清具体班次。

任务：准备10秒，独立录60秒。你更支持提前锁定时间还是保留调整空间？向朋友说明明确选择、一个主要理由、一个限制及可执行办法。不能虚构班次、价格或朋友已同意。

本题不再看三词提纲。

八、完成录音与独立自评后展开：双示范＋各自关键词＋自评依据

参考一｜支持先试行每周20分钟集中答疑

“主任，我倾向于从下周开始试行每周三20分钟的线上集中答疑，但同时保留学生提出个别问题的渠道。

一个原因是，现在已经出现了几位学生重复询问作业提交方式和课程资料位置的情况。这类问题具有共性，统一解释有机会让更多学生获得同样的信息，也方便教师把容易产生误解的地方说明白。

另一个考虑是，集中答疑可以成为我们发现共性问题的一个固定窗口。比如，若几位学生都不清楚同一项作业要求，我们就可以检查课程说明是否需要补充，而不是仅仅重复回答。

不过，学生遇到困难的时间不固定，也有一些问题涉及个人学习情况，因此不能要求所有问题都等到周三解决。我建议先试行两周，集中回答共性问题，同时继续保留必要的单独咨询渠道。每次记录主要问题和学生反馈，再决定是否继续。

这样既能尝试统一答疑，也为不适合集中处理的问题留下空间。”

参考二｜暂不固定答疑，先整理共性问题

“主任，我目前不建议立即设置每周三固定20分钟的线上答疑。我更倾向于先把已有的共性问题整理清楚，再根据学生实际需要决定是否增加固定时段。

第一个考虑是，现在能确认的情况主要是几位学生重复询问作业提交方式和课程资料位置。对于这些问题，我们可以先在课程群发布一份简明说明，把提交入口、资料位置和常见疑问集中写清楚。这项工作可以马上进行，也便于以后查阅。

第二个考虑是，学生的提问并不完全相同。有人咨询共性安排，也有人遇到个人学习困难。后者通常需要结合具体情况交流，统一答疑未必适合解决所有问题。

另外，我们还不知道学生最常在什么时候提问，也不知道有多少人愿意参加周三的线上答疑。我的建议是先整理问题、补充课程说明，并在接下来两周记录提问类型和时间，再征求学生意见。如果发现确实有较多适合集中回答的需求，再确定固定答疑时段。

所以，我支持改进答疑方式，但暂时不支持立即固定每周三的线上会议。”

四项细化自评依据

  1. 是否开头明确支持试行或暂不固定，且始终围绕这个立场展开？
  2. 两个理由是否增加不同信息，没有用方便、省事、效率高重复作理由？
  3. 是否只使用几位学生提问这一事实，未虚构大多数学生的偏好？
  4. 是否有具体的答疑渠道、整理方式、试行安排或反馈记录，并说明后续决定依据？

两份完整示范分别支持不同立场，关键词只帮助核对思路，不要求背诵。
