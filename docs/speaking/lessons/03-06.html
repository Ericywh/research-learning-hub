完成90秒陌生话题陈述

正式18分钟。给题后准备10秒，独立表达90秒；先录音、回听、迁移和自评，后打开双示范。

一、正式任务：两种提问安排选哪种？

原创模拟教研情境，非真实活动记录。 学院举办90分钟学生研究交流会，有六组学生。方案A：每组汇报后立即提问2分钟；方案B：六组讲完后安排12分钟集中提问。两方案提问总时长均为12分钟，其余安排不变。尚无系统反馈。

活动负责人问：“你更支持每组汇报后立即提问，还是全部讲完再集中提问？请说清选择和理由。”

发言对象：负责人及筹备同事。要求：准备10秒、独立口述90秒。明确选择，说明两个不重复理由、一个实际执行问题及处理建议。可折中，但必须给出操作方案；不能仅说各有利弊。

产出：首录90秒、同题重录90秒、陌生题60秒及独立自评。录音与评分由本人保管，不上传网站。

二、完整口语素材与问题理解

“讨论一项安排是否合理，我通常会先看它要解决什么问题，再看执行时会遇到哪些限制。不同方案往往各有适用条件，但我们仍然可以根据当前目标作出选择。比如，时间是否充足、参与者是否容易理解流程、负责人能否执行，都可以成为判断依据。确定倾向以后，最好说明具体怎么做，以及哪些情况需要再调整。”

朗读后合上材料，说出：判断活动方案时最看重什么？如果被问“到底怎样安排”，你会给出什么实际步骤？素材不是正式题目的答案。

  2. 3:00—6:00｜结构与关键词3:00—4:00理解四段节奏；4:00—5:00判断两个理由是否不同；5:00—6:00练习10秒选择立场，组织三词，不写逐字稿。
  3. 6:00—11:00｜首录及回听6:00—6:10正式准备10秒；6:10—7:40录音90秒；7:40—9:40回听，查重复、跑题或突然中断；9:40—11:00改写最弱理由，使其包含实际情境。
  4. 11:00—16:00｜改说与迁移11:00—11:50修改结构；11:50—13:20重录同题90秒；13:20—14:00回听比较；14:00—14:20阅读陌生题；14:20—14:30准备10秒；14:30—15:30迁移录音60秒；15:30—16:00回听记录。

五、陌生情境迁移

原创模拟工作情境。 学院为新入职教师准备教学经验交流，四位教师各分享8分钟。方案A：四人先讲完，再集中讨论；方案B：每人讲完立即简短提问。目前参与者偏好未知，整场问答时间尚未确定。

问题：作为筹备教师，你倾向哪种安排？准备10秒，口头说60秒，说明选择、一个理由、一个潜在问题及处理办法。

迁移题不提供新的三词提纲。不得假定两个方案总时长相同，也不虚构教师意见。

七、完成录音与自评后展开：双示范、对应关键词及评分依据

参考一｜支持每组结束后立即提问

“我更倾向于保留每组汇报结束后立即提问的安排。

第一个理由是，问题和刚听到的汇报内容能够直接对应。比如某组刚介绍完研究方法，听众如果对样本选择有疑问，马上提出，汇报者就可以结合刚才的内容解释，不必等到其他五组都讲完之后再重新交代背景。

第二个理由是，这样能给每组学生保留一个相对明确的互动机会。六组全部讲完后集中提问，如果现场的问题主要围绕某一两个主题，其他小组未必都有机会回应。当然，这只是需要考虑的安排风险，不能据此断言集中提问一定会忽略其他组。

立即提问也有困难，就是每组只有两分钟，主持人需要控制时间。我建议每组保留一到两个简短问题，超出时间的内容放到会后交流，并提前告知学生和听众。

因此，我支持每组结束后提问，同时由主持人明确控时，让提问和相应汇报更紧密地衔接。”

参考一关键词对应表达
即时提问核心立场
样本选择对应汇报内容的例子
六组机会第二理由：互动机会
两分钟限制执行约束
主持控时具体建议

参考二｜支持六组结束后集中提问

“我更倾向于六组全部讲完之后，安排12分钟集中提问。

主要是考虑这次活动有六组学生，研究内容可能存在相互关联的地方。如果听众先听完全部汇报，就有机会比较不同小组的研究问题或方法，再提出跨小组的问题。例如，两组都研究同一种现象，但使用不同数据，听众可以围绕研究设计提出一个共同问题，请两组分别回应。

另一个考虑是活动节奏。把提问放在最后，主持人可以先集中推进六组汇报，再专门管理讨论环节，避免每组结束时都要进行一次提问和汇报之间的切换。不过，这种安排是否更流畅，需要实际观察，不能只凭设想下结论。

集中提问的风险是，听众可能忘记前面某组的具体内容，提问也可能集中在少数小组。我建议主持人在各组汇报时记下主题关键词，集中讨论时先邀请针对具体小组的问题，再安排跨小组比较，并适当照顾不同组的回应机会。

所以，我支持集中提问，但前提是主持人提前设计问题组织方式，而不是把12分钟完全交给自由抢答。”

参考二关键词对应表达
集中12分钟核心立场
不同数据跨组比较的例子
减少切换第二理由：活动流程
前组遗忘潜在问题
主持引导应对办法

四项细化自评依据

  1. 开头是否直接选择逐组或集中提问，没有长时间回避判断？
  2. 两个理由是否涉及不同机制，如研究理解与互动机会、跨组比较与活动流程？
  3. 是否准确使用六组、两分钟、12分钟等已知条件，避免虚构效果？
  4. 是否有针对所选方案的具体实施措施，并在90秒左右自然收束？

两份答案同题但立场不同，不要求背诵。
