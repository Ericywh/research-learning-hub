第044课｜用“因为—所以”讲清判断

明确判断 → 因为有具体事实和理由 → 所以提出相应行动。把“我觉得这样好”变成别人能理解、能够讨论的完整论证。

一、正式训练题

原创模拟，非真实工作记录

周一上午，学院六位老师召开学生研究交流会筹备会议，口头明确三项工作：

  • 你在周三17:00前整理六组学生展示顺序。
  • 周老师在周四12:00前核实点评老师能否出席。
  • 陈老师在周四16:00前发送正式议程。

会后群聊只有零散讨论消息，没有单独分工确认；一位同事提前离开，没有听到最后两项安排。

主持人建议：从下周起，每次工作例会后都由会议记录人发一条“任务—负责人—截止时间”的确认消息。

张老师：“会上已经说过，为什么还要再发一次？以后岂不是每次都多一道程序？”

正式问题：面对张老师和其他教师，你是否赞成每次例会后都发送确认消息？开头10秒明确立场，随后70—80秒解释理由，结合三项任务举例，提出明确执行范围。

追问：“如果会后又临时调整分工，原来那条确认消息不就过时了吗？”

再录20—30秒，回应版本管理问题。

产出：首次90秒主回应、追问录音、修改后重录、陌生情境45—60秒录音及四项自评。个人录音和评分自行保管，不上传。

二、朗读素材和提纲

一次会议中，大家可能已经口头明确分工，但有些人没有听完整场，有些任务也散落在聊天记录里。到了实际执行时，单靠回忆就不容易查清负责人和截止时间。针对这种情况，我倾向于会后留下简短的书面确认。因为需要核对的是具体任务，所以消息不必写成完整会议纪要，只要说明谁负责、做什么、什么时候反馈。至于这种办法能否减少后续沟通成本，还要看实际执行情况。
判断

赞成简短确认

因为

信息零散、有人漏听

所以

集中确认任务

“因为这样更好，所以我赞成”只是重复评价；“因为有人漏听，所以发消息一定能提升效率”把未经验证的效果说成了事实。建议改为：“因为有同事没听到最后的分工，所以我建议在群里集中确认负责人和时间，方便大家核对。”

三词提纲

信息分散问题依据
三项分工具体例子
单条确认行动建议

这组三词适合赞成简短确认的立场。你也可以反对一律发送或有条件支持，但必须回答“是否每次都发”。

卡住时自问：观察到什么具体问题？为什么支持我的立场？建议执行的范围是什么？有没有把预计效果说得太肯定？

三、18分钟逐分训练

  1. 00:00—03:00 · 素材输入与理解

    0:00—1:15朗读情境、对方的两轮问题；1:15—2:10朗读素材；2:10—3:00合上材料复述三项分工、两个沟通问题，区分事实与预测。

  2. 03:00—06:00 · 搭结构与选择关键词

    3:00—4:00用两种说法各练一次20秒“态度—因为”，比较哪一种具体；4:00—5:00替换“提高效率”等抽象理由；5:00—6:00准备“所以”之后的发送人、格式和更新方式。

  3. 06:00—11:00 · 首录、追问、回听

    6:00—6:20准备；6:20—7:50录90秒主回应，前10秒明确态度；7:50—8:00读追问；8:00—8:30录追问；8:30—10:15回听；10:15—11:00修改一处理由不具体或“所以”跳跃的句子。

参考一｜赞成每次对明确分工做简短确认

主回应

“我赞成每次工作例会结束后，对会上形成的具体分工发一条简短确认，但不需要把会议内容重写一遍。

因为今天就出现了两个实际问题：群里的讨论比较零散，还有一位同事没听到最后两项安排。如果我们只依靠会上口头说过，后来核对谁负责、什么时候完成就比较麻烦。

比如这次，我周三五点前整理学生顺序，周老师周四中午前核实点评人，陈老师周四下午四点前发正式议程。这三件事放在同一条消息里，大家就能对照自己的任务检查。

所以我建议由会议记录人会后发一条确认，只列任务、负责人和截止时间。有疑问的同事直接在这条下面提出。我们先这样执行几次，再看实际使用情况，没必要先保证它一定提高效率。”

追问回应

“如果分工发生调整，就由负责通知的人在原消息下补充变更，并写明新安排和更新时间。需要大家依据最新版本执行时，再明确标注以哪条消息为准。这样旧信息不会被误当成最终安排。”

参考一关键词（5个）

关键词真正对应的内容
零散讨论主要问题依据
提前离会情境事实
三项分工举例支撑
记录人确认可执行方案
原消息更新追问中的版本管理

参考二｜有条件赞成，按有无待办分工决定

主回应

“我赞成需要落实任务的会议留一条分工确认，但不建议所有例会无论有没有新安排，都固定多发一次消息。

因为记录的价值在于帮助大家核对后续行动。像今天这样的会议，已经约定了学生顺序、点评人核实和正式议程发布三项任务，而且有同事没有听完整场，集中写下来确实有实际用途。

但如果某次例会只交流工作进展，没有新增负责人或者截止时间，再发一条内容重复的确认消息，未必值得。

所以我的建议是设置一个简单规则：只要会上新增或改变了任务分工，就由记录人当天发一条任务清单；没有变化，就不另发。这样既回应了遗漏信息的问题，也照顾张老师担心增加程序的顾虑。至于效果，我们执行后再检查。”

追问回应

“临时调整也按同一个规则处理：只有负责人、任务或期限发生变化才补发更新，写清改了哪一项，并通知受影响的同事。不需要把整份会议内容再发一遍。”

参考二关键词（5个）

关键词真正对应的内容
任务核对核心理由
三项待办情境事实
无新增分工范围例外
有变化才发条件性行动
补发变更追问回应

四项细化自评依据

  1. 是否在前10秒回答“每次例会后是否都要发”，而不是只谈沟通的重要性？
  2. “因为”之后是否具体说出信息分散、提前离会或三项分工，而非重复自己的结论？
  3. “所以”之后是否有与理由匹配的发送条件、负责人和执行办法？
  4. 是否避免把方便核对夸大为已经证明提高效率，并回应临时调整后的版本管理？

两份示范都针对同一道题，观点的适用范围不同。关键词用于组织语言，不要求背诵。
