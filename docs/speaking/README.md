# 公众表达与脱稿演讲系统训练｜24周168课

本课程为独立的新设口才专项课程；原学习中心第06号 PSM-DID 完整存档，不覆盖、不改号。

周期24周、六章、168课。普通日10—15分钟，第7日轻量复盘5—10分钟。

每课：2分钟核心方法，3分钟针对练习，5—7分钟真实开口，1—3分钟记录。

发音听辨、目标音产生、词句练习与自然表达逐级迁移；对持续口吃不作医学疗效承诺，必要时咨询言语语言治疗师。

一课一个技能，阶段测试按实际交付进度推进；缺课先补，不按日历冒充已完成。

仅发布课程文字及示例，不自动公开个人录音、口吃细节和私人评语。
