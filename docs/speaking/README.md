## 思路框架和词穷接续训练（2026-10-21针对性修订）

- **最优先改善的能力：**面对问题能选定讲话结构，迅速抓三个关键词，并持续用理由、例子、事实或建议展开；不把词穷简单归因于词汇少，不把背诵或绕口令当作核心解决方案。
- **三套基本框架：**表达观点用“结论→理由→例子”；解释问题用“是什么→为什么→怎么办”；讲经历用“背景→经过→结果”。复杂专业点评再使用“亮点→关键问题→可执行建议”，必要时明确结论边界。
- **所有正常训练课：**在原有准备时间内给与当天题目紧密对应的三词提纲，并给一条“卡住时问自己什么”的接续提示；直接提供具体素材，先有自主回答，再听/看完整参考结果。不是让学生机械背诵框架名称；从2026-10-22起每课总长调整至15—20分钟，原始基线/复测部分不变。
- **循序减少提示：**初期可以看关键词，逐步只在脑中组织，再安排相近话题和陌生话题迁移；检查能否迅速得出判断、展开相关理由和例子、避免重复与跑题。
- **保护基线和复测：**第001、007、014、021课的原题、原准备条件和原录音时长不变，任何框架分析仅放在测试录音与自评之后、默认隐藏；不能以参考答案提前提示。第001—022课的原核心题目保留不重编号，新增5—10分钟或3分钟的测后巩固，使单课总长约18分钟；第007课GitHub旧页同步仍受既有写入安全检查限制，不能声称已同步。
- **记忆支持：**已在聊天创建“三个基本表达框架”三张互动记忆卡，供自主复习，课程网页无需假装它有同一套进度记录。
