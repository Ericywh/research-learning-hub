- 每节课程的主要开口练习必须提供**与该节具体题目对应**的完整规范参考结果，作为学员录音后自评的对照材料，不以抽象评价口号或空泛套话代替完整示范；日常沟通应使用自然口语，专业点评遵守事实与证据边界。
