HOW TO USE

每一天，先开口，再分析

早课 · 18分钟

按当课题面独立录音，保存首录和自评，再作针对性重说与陌生情境迁移。双示范与各自关键词默认收起；正式测评前不查看练后教学、预写答案或搭档分支。

晚课 · 最长18分钟

读完整案例，在具体句子中理解理论；在原练习时段加入一次短口述。普通课读一条参考路径即可，第二条可选。案例、分析、错误对照和练习直接展示，只有参考答案收起。

五项各0—2分的原量表继续使用，信息准确性保留。起答反应、无信息重复、恢复或提示依赖另记一项，不混入原10分。新录音不覆盖旧录音，已经接触过的题目注明复测。

查阅共用练法与评分标尺 →搭档用随机分支卡 →查看评审意见如何处理 →

搭档在第一段结束后才给未知反馈。单人随机读卡记为半即兴模拟；没有未看提纲的听众时，主旨复述记未测。
