# 第一周课程修订说明

本轮只重构第01—07天既有14课，以演讲、汇报、临时受邀发言中的连续表达为目标。修订不新增课次，也不证明学习者已完成复练。第8—63天沿用此前版本，18周历史课程独立保留。

| 天 | AM真实表达 | PM案例与理论 | 早 / 晚建议用时 |
| --- | --- | --- | --- |
| 01 | 先留下真实的一分钟 | 一句主旨怎样带动整段发言 | 18 / 15分钟 |
| 02 | 开头给出判断，再把意思讲完整 | 结论先说，怎样避免草率和空泛 | 18 / 14分钟 |
| 03 | 把一条理由讲到听众能够理解 | 从判断到依据，中间缺了哪一步 | 18 / 15分钟 |
| 04 | 用具体过程把一个判断讲清楚 | 细节怎样帮助听众理解，而不冲淡主旨 | 18 / 15分钟 |
| 05 | 只凭三词完成有依据的点评 | 关键词怎样提示意思，而不是触发背稿 | 18 / 14分钟 |
| 06 | 中断以后，从当前意思接回去 | 区分忘词、思路丢失与事实纠正 | 18 / 15分钟 |
| 07 | 先独立完成周测，再分析与修订 | 用录音证据确定下一步练什么 | 18 / 16分钟 |

所有晚课最长18分钟，包含练习、必要回听及答案阅读，外部原作可选。正常停顿不等于卡壳；本周不以语速、字数或无停顿作为主要评价。

## 测评与记录

第1天保持原题、30秒准备、60秒首录；第7天保持原题、30秒准备、90秒首录。首次表达与独立评分保存后才展开教学、示范和修订，不以练后分数覆盖首测。第7天原题曾在旧第2天迁移中出现；新版第2天已更换题目，既往接触情况仍须注明。新题另记准备和发言条件，不把不同任务的分差解释为确定训练效果。

原五项0—2分自评标尺继续使用，仅作个人操作性观察。原始音频和评分由学习者自行保管。AM/PM原有浏览器完成标识不变，不自动勾选或重置。

## 内容与维护

`week1-content.json` 保存14课正文，`rebuild-week1.py` 生成静态课页及清单；可用 `--mode am` 或 `--mode pm` 限定范围。PM旧批量生成器结束时调用PM专用重建，以免覆盖本周新内容。`week1.css` 只作用于本周页面，完成标记逻辑沿用原键名。所有参考默认折叠，第1/7天另设测后教学折叠。

组织方法属于教学设计，不宣称固定三词或18分钟配比具有普遍最优效果。课程区分论证与修辞原则、一般学习实验和特定口头汇报试验，来源及适用限制随课注明。
