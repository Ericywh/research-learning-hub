请求应让对方容易行动

完整案例、拆解技巧、对照错误、独立改写，次日早课验证。

PM · 晚间静默18分钟第18天无声学习

🌙 晚间静默深度课｜经典案例 → 技巧拆解 → 错误对比 → 独立改写 → 次日早课验证

教学主题：请求应让对方容易行动。本课用18分钟完成深度阅读、静默分析与独立书面改写，不要求发声。晚课记录与早间真实录音分开。

0—4分钟｜① 经典案例：完整表达与具体情境

课程原创情境：你需要同事周五前确认一份活动安排，但对方本周任务繁忙。

完整问题：提出具体、可拒绝、带时间节点的请求。

经典表达案例（课程原创教学范例，并非历史名人引文）

这份活动安排还有两处需要您确认：开始时间和分工名单。若方便，周五中午前给我反馈就可以；如果来不及，也请告诉我。

观察任务：标出第一句怎样回应提问、哪部分提供了依据、哪一句说明必要条件。思考：如果删掉其中一项，听众会失去什么？案例用于理解技巧，而非背诵。

4—8分钟｜② 拆解表达技巧：逐句还原有效机制

原理：有效请求同时交代做什么、为什么、何时完成及回应通道，避免模糊催促或情绪施压。

判断依据：先回应对方刚提供的信息，再给出低负担的追问。自然交流不是连续提问：它需要让对方看到你听懂了什么，也需要保留对方拒绝、简答或转移话题的空间。

逐层拆解

  1. 回应问题：“这份活动安排还有两处需要您确认：开始时间和分工名单。”让听众获得该题的核心判断或重点，而不是先听漫长铺垫。
  2. 展开依据：若方便，周五中午前给我反馈就可以； 如果来不及，也请告诉我。 注意这里的内容是否真正服务于第一句。
  3. 抽取结构：两项确认 → 周五节点 → 允许协调。逐项指出这三个具体关键词在原文中各自发挥什么作用。
  4. 核查边界：题目未提供的数字、动机和因果证据不得自行补充；必要时将确定性判断改成条件性判断。

8—11分钟｜③ 对比错误表达：判别缺失的信息

原课典型错误：只发“尽快处理一下，谢谢”。

错误话术示例：“尽快处理一下，谢谢”

有针对性的比较：优质案例有“两项确认”作为入口，以“周五节点”推进；错误案例让听众无法核查理由、区分新信息或判断适用条件。写下错误发生的具体位置、遗漏的信息和一处最小修改，不能只写“表达不够好”。

11—16分钟｜④ 独立改写：不看示范完成两轮迁移

任务A（3分钟）：合上经典案例。针对“你需要同事周五前确认一份活动安排，但对方本周任务繁忙。”，将上述错误表达改写为一段60—100字的自然口语稿，开头要回答“提出具体、可拒绝、带时间节点的请求。”，至少有一项具体理由或可执行步骤，并注明一项限制。写完删去一处多余铺垫，不能抄范文。

任务B（2分钟）：请求导师审阅一页摘要时，如何调整语气和截止时间？ 分别写出主场景与新场景的3个关键词，并注明哪一项必须调整。不要凭空创造新的案例事实。

交付物：一段自主改写稿、两组三词提纲、一条错误诊断。完成前不展开以下参考区。

练后展开｜两份完整参考及各自3个关键词

参考路径一：这份活动安排还有两处需要您确认：开始时间和分工名单。若方便，周五中午前给我反馈就可以；如果来不及，也请告诉我。

关键词一：两项确认—周五节点—允许协调

参考路径二：为了按时发通知，想请您周五前看一下日程和负责人两项内容。若您时间紧，我们可以先确认影响发布的部分。

关键词二：发通知—关键内容—优先处理

两条路径的实质差异：路径一以“两项确认”起步，沿 两项确认 → 周五节点 → 允许协调 展开；路径二从“发通知”切入，沿 发通知 → 关键内容 → 优先处理 组织。注意它们在观点、依据和适用条件上的不同，而非机械拼接两份答案。

错误对照：只发“尽快处理一下，谢谢”。。再读自己的改写，核对是否真正补上遗漏的信息。

四项自评：回应是否贴题；理由或例子是否具体；事实与推测是否区分；语言是否比原错误表达更清楚。

16—18分钟｜⑤ 次日早课验证：形成可观测的口头表现

次日早课：第19天「拒绝请求保留关系」。检验三件事：是否直接回应新问题、是否有一条具体支撑、是否说清不能推断的内容。

把今天的技巧用于早课原题，完成首轮独立录音后再回听核对。不要用今晚的静默表现代替真实开口记录。

离开页面前：不打开参考区复看，用自己的话写下一项明早应观察的行为及一项需要改进的具体问题。今晚懂得原理不等于明早已经说得出来。

完成依据：PM保留案例拆解、错误对比、自主改写和验证指标；AM另行完成并保存独立录音与自评，两者不得互相替代。
