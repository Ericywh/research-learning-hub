无提示表达基线

完整案例、拆解技巧、对照错误、独立改写，次日早课验证。

PM · 晚间静默18分钟第01天 / 共63天无需发声

🌙 晚间静默深度课｜经典案例 → 技巧拆解 → 错误对比 → 独立改写 → 次日早课验证

教学主题：无提示表达基线。本课用18分钟完成深度阅读、静默分析与独立书面改写，不要求发声。晚课记录与早间真实录音分开。

测评保护：本晚课仅在早间首次无提示录音与自评完成后学习，后续改写不得覆盖原始测评。

0—4分钟｜① 经典案例：完整表达与具体情境

课程原创情境：在教研讨论中，有人问：一份研究报告最重要的质量标准是什么？

完整问题：给出一个标准、一个理由，不写稿，准备30秒、首次录音60秒。

经典表达案例（课程原创教学范例，并非历史名人引文）

我最看重问题与证据是否匹配。一个研究可以选题新颖，但如果数据和方法无法回答原问题，结论就需要保留。

观察任务：标出第一句怎样回应提问、哪部分提供了依据、哪一句说明必要条件。思考：如果删掉其中一项，听众会失去什么？案例用于理解技巧，而非背诵。

4—8分钟｜② 拆解表达技巧：逐句还原有效机制

原理：基线测量要记录真实起点，测前提示会污染可比性；先保存原始音频，再分析结构。

判断依据：先准确回答问题，再挑选一条核心理由和一个具体例子。短时表达的主要负担不是词汇数量，而是同时想内容与句式造成的工作记忆拥挤；三词提纲应提示信息，不应预先写成句子。

逐层拆解

  1. 回应问题：“我最看重问题与证据是否匹配。”让听众获得该题的核心判断或重点，而不是先听漫长铺垫。
  2. 展开依据：一个研究可以选题新颖，但如果数据和方法无法回答原问题，结论就需要保留。 注意这里的内容是否真正服务于第一句。
  3. 抽取结构：问题 → 证据 → 边界。逐项指出这三个具体关键词在原文中各自发挥什么作用。
  4. 核查边界：题目未提供的数字、动机和因果证据不得自行补充；必要时将确定性判断改成条件性判断。

8—11分钟｜③ 对比错误表达：判别缺失的信息

原课典型错误：测前背范文或在第一次录音前看关键词。

错误话术示例：“我先把参考提纲看完，再做所谓的无提示录音。”

有针对性的比较：优质案例有“问题”作为入口，以“证据”推进；错误案例破坏无提示测评的操作顺序。写下错误发生的具体位置、遗漏的信息和一处最小修改，不能只写“表达不够好”。

11—16分钟｜④ 独立改写：不看示范完成两轮迁移

任务A（3分钟）：合上经典案例。针对“在教研讨论中，有人问：一份研究报告最重要的质量标准是什么？”，将上述错误表达改写为一段60—100字的自然口语稿，开头要回答“给出一个标准、一个理由，不写稿，准备30秒、首次录音60秒。”，至少有一项具体理由或可执行步骤，并注明一项限制。写完删去一处多余铺垫，不能抄范文。

任务B（2分钟）：如果改问“如何评价项目申请书”，你会怎样换一种标准？ 分别写出主场景与新场景的3个关键词，并注明哪一项必须调整。不要凭空创造新的案例事实。

交付物：一段自主改写稿、两组三词提纲、一条错误诊断。完成前不展开以下参考区。

练后展开｜两份完整参考及各自3个关键词

参考路径一：我最看重问题与证据是否匹配。一个研究可以选题新颖，但如果数据和方法无法回答原问题，结论就需要保留。

关键词一：问题—证据—边界

参考路径二：我会先看结论有没有充分依据。例如观察到变化并不等于证明某项措施导致了变化，因此必须检查设计和其他解释。

关键词二：结论—其他解释—审慎判断

两条路径的实质差异：路径一以“问题”起步，沿 问题 → 证据 → 边界 展开；路径二从“结论”切入，沿 结论 → 其他解释 → 审慎判断 组织。注意它们在观点、依据和适用条件上的不同，而非机械拼接两份答案。

错误对照：测前背范文或在第一次录音前看关键词。。再读自己的改写，核对是否真正补上遗漏的信息。

四项自评：回应是否贴题；理由或例子是否具体；事实与推测是否区分；语言是否比原错误表达更清楚。

16—18分钟｜⑤ 次日早课验证：形成可观测的口头表现

次日早课：第02天「十秒明确立场」。检验三件事：是否直接回应新问题、是否有一条具体支撑、是否说清不能推断的内容。

把今天的技巧用于早课原题，完成首轮独立录音后再回听核对。不要用今晚的静默表现代替真实开口记录。

离开页面前：不打开参考区复看，用自己的话写下一项明早应观察的行为及一项需要改进的具体问题。今晚懂得原理不等于明早已经说得出来。

完成依据：PM保留案例拆解、错误对比、自主改写和验证指标；AM另行完成并保存独立录音与自评，两者不得互相替代。

本课学习状态

完成后可标记，也可随时撤销并重新学习。

LEARNING METHOD

晚间技巧课的完成依据

一页案例拆解、一段自主改写、两组三词结构和一条次日口头验证指标。

每节15—20分钟，常规18分钟。参考结果在完成独立练习后展开；静默思考不替代口头实训。
