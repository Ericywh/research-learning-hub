SPEAKING STUDY · PM · DAY 03 / 63

让理由真正支持观点

完整案例、拆解技巧、对照错误、独立改写，次日早课验证。

PM · 晚间静默18分钟第03天 / 共63天无需发声

🌙 晚间静默深度课｜经典案例 → 技巧拆解 → 错误对比 → 独立改写 → 次日早课验证

教学主题：让理由真正支持观点。本课用18分钟完成深度阅读、静默分析与独立书面改写，不要求发声。晚课记录与早间真实录音分开。

0—4分钟｜① 经典案例：完整表达与具体情境

课程原创情境：学院考虑在期中后增加一次课程反馈调查，部分老师认为调查太频繁。

完整问题：你赞成增加调查吗？只选择一个最关键的理由说明。

经典表达案例（课程原创教学范例，并非历史名人引文）

我支持增加一次简短调查，因为课程尚未结束，教师仍有机会根据反馈调整讲授节奏，而不只是事后总结。

观察任务：标出第一句怎样回应提问、哪部分提供了依据、哪一句说明必要条件。思考：如果删掉其中一项，听众会失去什么？案例用于理解技巧，而非背诵。

4—8分钟｜② 拆解表达技巧：逐句还原有效机制

原理：一个有效理由应解释为什么立场合理，而不是把观点改写一遍。

判断依据：先准确回答问题，再挑选一条核心理由和一个具体例子。短时表达的主要负担不是词汇数量，而是同时想内容与句式造成的工作记忆拥挤；三词提纲应提示信息，不应预先写成句子。

逐层拆解

  1. 回应问题：“我支持增加一次简短调查，因为课程尚未结束，教师仍有机会根据反馈调整讲授节奏，而不只是事后总结。”让听众获得该题的核心判断或重点，而不是先听漫长铺垫。
  2. 展开依据：案例后续语句为判断补充理由、例子或执行步骤。 注意这里的内容是否真正服务于第一句。
  3. 抽取结构：期中调查 → 可及时调整 → 改进机会。逐项指出这三个具体关键词在原文中各自发挥什么作用。
  4. 核查边界：题目未提供的数字、动机和因果证据不得自行补充；必要时将确定性判断改成条件性判断。

8—11分钟｜③ 对比错误表达：判别缺失的信息

原课典型错误：用“因为我认为这样更好”充当理由。

错误话术示例：“因为我认为这样更好”

有针对性的比较：优质案例有“期中调查”作为入口，以“可及时调整”推进；错误案例让听众无法核查理由、区分新信息或判断适用条件。写下错误发生的具体位置、遗漏的信息和一处最小修改，不能只写“表达不够好”。

11—16分钟｜④ 独立改写：不看示范完成两轮迁移

任务A（3分钟）：合上经典案例。针对“学院考虑在期中后增加一次课程反馈调查，部分老师认为调查太频繁。”，将上述错误表达改写为一段60—100字的自然口语稿，开头要回答“你赞成增加调查吗？只选择一个最关键的理由说明。”，至少有一项具体理由或可执行步骤，并注明一项限制。写完删去一处多余铺垫，不能抄范文。

任务B（2分钟）：把理由改为“提高学生参与度”，需要什么具体解释才有说服力？ 分别写出主场景与新场景的3个关键词，并注明哪一项必须调整。不要凭空创造新的案例事实。

交付物：一段自主改写稿、两组三词提纲、一条错误诊断。完成前不展开以下参考区。

练后展开｜两份完整参考及各自3个关键词

参考路径一：我支持增加一次简短调查，因为课程尚未结束，教师仍有机会根据反馈调整讲授节奏，而不只是事后总结。

关键词一：期中调查—可及时调整—改进机会

参考路径二：我不主张直接增加问卷。若此前反馈还没被处理，再加一次调查可能增加学生负担；应先说明已有反馈如何使用。

关键词二：已有反馈—回应不足—避免额外负担

两条路径的实质差异：路径一以“期中调查”起步，沿 期中调查 → 可及时调整 → 改进机会 展开；路径二从“已有反馈”切入，沿 已有反馈 → 回应不足 → 避免额外负担 组织。注意它们在观点、依据和适用条件上的不同，而非机械拼接两份答案。

错误对照：用“因为我认为这样更好”充当理由。。再读自己的改写，核对是否真正补上遗漏的信息。

四项自评：回应是否贴题；理由或例子是否具体；事实与推测是否区分；语言是否比原错误表达更清楚。

16—18分钟｜⑤ 次日早课验证：形成可观测的口头表现

次日早课：第04天「一个例子胜过空话」。检验三件事：是否直接回应新问题、是否有一条具体支撑、是否说清不能推断的内容。

把今天的技巧用于早课原题，完成首轮独立录音后再回听核对。不要用今晚的静默表现代替真实开口记录。

离开页面前：不打开参考区复看，用自己的话写下一项明早应观察的行为及一项需要改进的具体问题。今晚懂得原理不等于明早已经说得出来。

完成依据：PM保留案例拆解、错误对比、自主改写和验证指标；AM另行完成并保存独立录音与自评，两者不得互相替代。

本课学习状态

完成后可标记，也可随时撤销并重新学习。

LEARNING METHOD

晚间技巧课的完成依据

一页案例拆解、一段自主改写、两组三词结构和一条次日口头验证指标。

每节15—20分钟，常规18分钟。参考结果在完成独立练习后展开；静默思考不替代口头实训。
