时间顺序与因果顺序分开

完整案例、拆解技巧、对照错误、独立改写，次日早课验证。

PM · 晚间静默18分钟第32天无声学习

🌙 晚间静默深度课｜经典案例 → 技巧拆解 → 错误对比 → 独立改写 → 次日早课验证

教学主题：时间顺序与因果顺序分开。本课用18分钟完成深度阅读、静默分析与独立书面改写，不要求发声。晚课记录与早间真实录音分开。

0—4分钟｜① 经典案例：完整表达与具体情境

课程原创情境：班级先增加自习时间，之后平均成绩提高。

完整问题：如何叙述这段变化而不直接推断自习造成提高？

经典表达案例（课程原创教学范例，并非历史名人引文）

我们先调整了自习安排，之后看到平均成绩提高。这些变化在时间上先后发生，但是否由自习安排导致，还需要比较其他条件。

观察任务：标出第一句怎样回应提问、哪部分提供了依据、哪一句说明必要条件。思考：如果删掉其中一项，听众会失去什么？案例用于理解技巧，而非背诵。

4—8分钟｜② 拆解表达技巧：逐句还原有效机制

原理：‘先发生’只证明时间顺序，不能自动解释原因；讲故事时可以描述观察与可能解释，避免无证据的单因果结论。

判断依据：分别识别事实、由事实提出的解释、仍需满足的条件；故事题另辨明起因、行动和变化。例子负责说明判断的含义，不能靠虚构细节填补因果链条。

逐层拆解

  1. 回应问题：“我们先调整了自习安排，之后看到平均成绩提高。”让听众获得该题的核心判断或重点，而不是先听漫长铺垫。
  2. 展开依据：这些变化在时间上先后发生，但是否由自习安排导致，还需要比较其他条件。 注意这里的内容是否真正服务于第一句。
  3. 抽取结构：自习安排 → 成绩变化 → 不能直接归因。逐项指出这三个具体关键词在原文中各自发挥什么作用。
  4. 核查边界：题目未提供的数字、动机和因果证据不得自行补充；必要时将确定性判断改成条件性判断。

8—11分钟｜③ 对比错误表达：判别缺失的信息

原课典型错误：把‘之后’直接说成‘正因为’。

错误话术示例：“之后’直接说成‘正因为”

有针对性的比较：优质案例有“自习安排”作为入口，以“成绩变化”推进；错误案例让听众无法核查理由、区分新信息或判断适用条件。写下错误发生的具体位置、遗漏的信息和一处最小修改，不能只写“表达不够好”。

11—16分钟｜④ 独立改写：不看示范完成两轮迁移

任务A（3分钟）：合上经典案例。针对“班级先增加自习时间，之后平均成绩提高。”，将上述错误表达改写为一段60—100字的自然口语稿，开头要回答“如何叙述这段变化而不直接推断自习造成提高？”，至少有一项具体理由或可执行步骤，并注明一项限制。写完删去一处多余铺垫，不能抄范文。

任务B（2分钟）：换成‘引入工具后效率提高’辨别哪些是事实哪些是推测。 分别写出主场景与新场景的3个关键词，并注明哪一项必须调整。不要凭空创造新的案例事实。

交付物：一段自主改写稿、两组三词提纲、一条错误诊断。完成前不展开以下参考区。

练后展开｜两份完整参考及各自3个关键词

参考路径一：我们先调整了自习安排，之后看到平均成绩提高。这些变化在时间上先后发生，但是否由自习安排导致，还需要比较其他条件。

关键词一：自习安排—成绩变化—不能直接归因

参考路径二：课程中增加自习时间后，学生成绩有所变化。我们可以先描述这个过程，再说明可能还有考试难度或生源等其他因素。

关键词二：先后顺序—其他条件—审慎描述

两条路径的实质差异：路径一以“自习安排”起步，沿 自习安排 → 成绩变化 → 不能直接归因 展开；路径二从“先后顺序”切入，沿 先后顺序 → 其他条件 → 审慎描述 组织。注意它们在观点、依据和适用条件上的不同，而非机械拼接两份答案。

错误对照：把‘之后’直接说成‘正因为’。。再读自己的改写，核对是否真正补上遗漏的信息。

四项自评：回应是否贴题；理由或例子是否具体；事实与推测是否区分；语言是否比原错误表达更清楚。

16—18分钟｜⑤ 次日早课验证：形成可观测的口头表现

次日早课：第33天「让抽象故事有一个画面」。检验三件事：是否直接回应新问题、是否有一条具体支撑、是否说清不能推断的内容。

把今天的技巧用于早课原题，完成首轮独立录音后再回听核对。不要用今晚的静默表现代替真实开口记录。

离开页面前：不打开参考区复看，用自己的话写下一项明早应观察的行为及一项需要改进的具体问题。今晚懂得原理不等于明早已经说得出来。

完成依据：PM保留案例拆解、错误对比、自主改写和验证指标；AM另行完成并保存独立录音与自评，两者不得互相替代。
