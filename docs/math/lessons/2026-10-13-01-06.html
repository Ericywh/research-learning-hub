第1章·第6节｜随机变量与随机向量的区别及联系

全课程第6课 / 共73课 · 2026-10-13 · 预计学习8分钟

全课程第6课 / 共73课 · 2026年10月13日 · 预计学习8分钟 核心问题： 数据表里的数值已经确定，为什么统计模型仍要使用“随机向量”？

一、从数据矩阵走向概率模型

前五课讨论向量、矩阵与线性映射，重点是给定数字以后怎样计算。本课转向统计推断：观测之前，数据可能取不同数值；观测之后，才得到具体结果。 例如，某家企业下一年的研发投入与绿色专利数量在事前尚不确定。可以用两个随机变量分别描述它们，再将两者放在同一个随机向量中。随机向量不是“随机排列的数字”，而是多个随机变量组成的整体。

二、定义与必要条件

设 X 是一个实值随机变量，样本空间为 Ω。若 X、Y 定义在同一个概率空间上，则：

\[\boxed{Z=\begin{pmatrix}X\\Y\end{pmatrix}:\Omega\to\mathbb R^2}\]

称 Z 为二维随机向量。严格地说，随机变量及随机向量都需满足相应的可测性条件。 随机变量只有一个数值分量；随机向量有多个分量。 各分量可能相关，也可能独立，不能仅凭它们组成向量就作出独立性判断。 对离散随机向量，联合概率刻画分量同时取值的可能性：

\[\boxed{p_{X,Y}(x,y)=P(X=x,\;Y=y)}\]

它比两个单独的边际分布包含更多关于变量共同变化的信息。

三、手算案例：一次掷骰子产生两个随机变量

以下是公平六面骰子的理论教学案例。定义 X=1 表示点数为偶数，否则为0；Y=1 表示点数大于3，否则为0。一次掷骰子同时决定 X 和 Y。

骰子点数 1 2 3 4 5 6
X：偶数 0 1 0 1 0 1
Y：大于3 0 0 0 1 1 1

两个变量各有一半概率等于1：P(X=1)=P(Y=1)=1/2。但它们同时等于1的情况只有点数4和6，所以：

\[P(X=1,Y=1)=\frac26=\frac13\ne\frac12\times\frac12\]

因此 X与Y不独立。如果实际掷出4，随机向量的一次实现值就是 z=(1,1)ᵀ；实现值不再是尚未观测的随机结果。

四、统计与计量经济学应用

在企业面板研究中，可用随机向量 Zᵢ=(Rᵢ,Gᵢ)ᵀ 表示企业的研发投入和绿色创新结果；收集数据后得到具体观测值 zᵢ。将多个观测值排成矩阵，是数据组织；规定随机向量的联合分布或条件矩，则属于统计建模。矩阵乘法正确，不意味着随机性、样本选择或识别假设自动成立。

五、两分钟自测

第1题｜概念题： 随机向量的两个分量必须相互独立吗？一次观测得到的数值向量与随机向量有什么区别？ 第2题｜计算题： 在上述骰子案例中，求 P(X=1,Y=0)。

查看两题参考答案

第1题： 不必独立。随机向量描述观测前可能出现的联合结果；观测值向量是某一次已经实现的具体数值。 第2题： 只有点数2满足“偶数且不大于3”，所以 P(X=1,Y=0)=1/6。
