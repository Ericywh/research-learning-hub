研究碳密集型企业对监管、竞争及声誉碳风险的认知，是否与投资偏离正常水平的程度相关。文章贡献是基于制度理论细化CRA文本代理指标，并尝试连接外部融资约束与内部治理两条路径。计量创新不在普通的双向固定效应本身。

二、研究设计、估计量与识别假设

研究单位为2012—2024年中国A股碳密集型上市企业—年度。碳风险认知CRA来自社会责任报告；投资效率用实际投资与预期投资偏离的绝对值INV衡量。企业FE及年份FE排除了不随时间变的企业异质性与年度共振冲击。基准系数是给定条件的相关参数，并非作者已论证的ATT/ATE。企业投资规划、融资状态、管理层更替、环保披露策略可能使CRA与投资偏差同时变化；公司披露报告的选择亦可能影响样本构成。应审查用于Richardson模型的预期投资拟合是否存在共同的结构性偏差。

三、核心模型、固定效应和标准误

\[Invest_{it}=\alpha+\boldsymbol\theta^{\top}Z_{i,t-1}+\delta_{industry}+\lambda_t+u_{it}\]

先以Richardson预期投资模型估计正常投资，其中Z包括滞后成长机会、杠杆、现金流、年龄、规模、收益率及投资水平等。结果变量取残差绝对值：

\[INV_{it}=|\hat u_{it}|,\qquad INV_{it}=\alpha+\beta CRA_{it}+\boldsymbol\gamma^{\top}X_{it}+\mu_i+\lambda_t+\varepsilon_{it}\]

INV越小才意味着投资偏离越低，不能按正向效率评分理解。原文表3括号负数与“标准误”表述存在不一致，数值更接近t统计量；复现前必须查明。企业固定效应、年份固定效应并不足以排除同时发生的时变投资机会与披露变化。

Stata · 自行推导、未执行
use "authorized_firm_year_clean.dta", clear
isid firm_id year
xtset firm_id year
gen double INV = .
levelsof year, local(yrs)
foreach yy of local yrs {
    quietly regress invest L.growth_q L.lev L.cash ///
      L.age L.size L.ret L.invest i.industry if year==`yy'
    tempvar u
    quietly predict double `u' if e(sample), resid
    quietly replace INV = abs(`u') if e(sample)
    drop `u'
}
global X SIZE LEV ROE GROWTH AGE SOE TOP BOARD INDEP ///
    DUAL FCF CASH TMTPAY MFEE
reghdfe INV CRA $X if !missing(INV,CRA), ///
    absorb(firm_id year) vce(cluster firm_id)
count if e(sample)

七、复现障碍、审稿及改进建议

优先核查逐年度Richardson拟合、行业虚拟变量处理、缺失值与尾部季度规则，以及CRA文本训练语料、分词、Word2Vec和TF-IDF参数。省域气候政策不确定性等工具可能直接影响投资与融资条件，需论证排除限制。文中以融资约束和治理水平解释机制，应先做严格时间先后与不同结局规格，不能把逐步回归直接当成因果中介。需要检查披露选择偏差、企业内部CRA有效变异、文本指标与实际碳风险管理行动的区分。
