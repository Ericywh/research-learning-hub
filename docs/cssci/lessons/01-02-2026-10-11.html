论文研究数字技术应用是否伴随上市企业技术生态位的拓展。技术生态位宽度并非企业专利总量，而是专利分布在不同技术类别中的有效领域数量。文章借助数字技术可供性理论，区分资源整合与主体协同两类机制，并考察市场动态性和知识产权保护强度的调节效应。真正可学之处在于将专利IPC结构指标、上市企业年报数字化词频及创新合作网络等数据连接起来，而不是把通常的固定效应回归包装为全新的因果识别设计。

二、研究设计、估计量、识别变异和关键假设

研究单位为企业—年度，样本时间2010—2023年。解释变量DTA来自年报数字技术词典的文本频次，被解释变量ETN由各年度专利技术类别份额计算。两向固定效应下的系数主要使用同一企业跨年份DTA变化和ETN变化的共同变异，剔除企业不随时间变化的特征和所有企业共有的年份冲击。

基准估计量是条件线性投影系数β，不是作者明确建立在潜在结果框架上的ATT或ATE。若要作因果解释，需要假设在控制企业、年份和协变量后，仍不存在同时影响年报数字技术措辞与技术布局的未观测时变因素。研发战略、管理层更替、业务结构、专利申请激励及披露政策可能违反这一条件。

文中另用Bartik工具变量：企业2010年数字技术基础份额乘以剔除企业所在城市后的其他城市第三产业增加值实际变化率。其相关性可检验，但排除限制要求该交互变量不经宏观需求、创新资源和本地产业结构等其他通道直接影响企业专利布局。强第一阶段不等于排除限制成立。

三、计量模型、固定效应和标准误

\[ETN_{it}=\left(\sum_{j=1}^{r}p_{ijt}^{2}\right)^{-1}\]

其中p为企业i在t年专利中第j类主IPC四位技术领域所占份额；r为企业覆盖的领域数。必须固定专利申请口径、IPC主分类截取方式和同一件专利去重规则；当年零专利样本没有合法的份额分母。

\[ETN_{it}=\beta_0+\beta_1DTA_{it}+\boldsymbol\gamma^{\top}X_{it}+\mu_i+\lambda_t+\varepsilon_{it}\]

企业固定效应μ和年份固定效应λ构成基准规格；X含Size、Age、Capital、Top1、Debt、ROA、Growth、RD。原文表4在企业层面聚类调整标准误，括号给t值。β1描述DTA增加一单位时ETN的条件线性变化。由于DTA是ln(关键词词频+1)，不可机械解释为任意情况下词频增加1%产生0.184%的ETN增长。

五、Stata参考代码：自行推导，未经运行

这段程序演示专利主IPC四位领域的Levins倒数及双向固定效应。非作者原始Stata程序，不代表已运行或得到论文表4结果。 文件、专利字段和财务字段名都是待替换占位符。实际运行前需先核验专利申请日期、类型、IPC去重、公司的证券代码沿革、DTA词典及缩尾口径。

Stata · 自行推导 · 未运行
* 一行一件已筛选的有效专利；仅为未运行的参考程序
use "patent_valid.dta", clear
isid firm_id year patent_id
gen str4 ipc4 = substr(upper(strtrim(primary_ipc)),1,4)
drop if missing(ipc4)
bysort firm_id year: gen n = _N
bysort firm_id year ipc4: gen nj = _N
gen p2 = (nj/n)^2
bysort firm_id year ipc4: keep if _n==1
bysort firm_id year: egen H = total(p2)
gen ETN = 1/H if H>0
bysort firm_id year: keep if _n==1
keep firm_id year ETN
tempfile etn
save `etn'

* 财务与年报文本已依同一企业年度口径清洗、合并
use "firm_year_authorized.dta", clear
isid firm_id year
merge 1:1 firm_id year using `etn', keep(match) nogen
gen DTA = ln(keyword_count+1) if keyword_count>=0
xtset firm_id year
global X Size Age Capital Top1 Debt ROA Growth RD
reghdfe ETN DTA $X, absorb(firm_id year) vce(cluster firm_id)

* 敏感性：上一年度词频与当期生态位
reghdfe ETN L.DTA $X, absorb(firm_id year) vce(cluster firm_id)

这段代码没有重现作者全部样本规则、Bartik工具变量、匹配权重或多项机制检验；reghdfe等依赖须在合规Stata环境中自行配置，运行前还要验证企业年度内专利的唯一键。

对IV更关键的疑问不在统计量大小，而是2010年数字技术基础与外部城市服务业增长交互后，会否同时预测区域技术机会。1704观测的IV样本与15623观测的基准样本不宜未经共同样本核对直接比较两个系数。

作者还报告替换技术生态位指数、额外控制项及行业剔除等稳健性规格；这些检验不能证明全部不可观测时变混杂已消除。机制结果应表述为与资源整合、协同网络相一致的条件相关证据，不宜直接确认为因果中介链。

七、复现障碍、学术审稿意见与改进建议

  • 最优先的复现步骤：用获授权的专利申请明细复算主IPC四位份额与ETN，逐公司逐年核对专利数量和缺失；再从年报自行复建DTA词频，并比较基准表4的N、均值和回归结果。
  • 识别审稿重点：报告企业内DTA的有效变异；披露年报叙事与实际数字技术投资的测量差异；控制企业特定长期趋势并讨论估计精度变化。企业FE不能自动消除并发研发战略冲击。
  • 工具变量审查：披露2010年份额不可获得的企业如何筛选，复算剔除本城市增长率，比较IV样本内OLS；在可能情况下进行替代初始份额、行业趋势及地区共同冲击检验，并明确其无法直接验证的排除限制。
  • 稳健性审查：考察剔除零专利所导致的样本选择、极低专利量造成的指数波动、匹配平衡和聚类层级；检验技术类别细分口径及申请人与专利归属映射。
  • 证据状态：官方期刊完整HTML正文和部分表格已经核验；incoPat/CSMAR原始数据、作者完整代码未取得；以上参考程序尚未运行，未完成数值复现。
