一、论文信息、研究问题与贡献

论文研究地区信贷空间配置效率与企业全球价值链位置，并分析技术创新渠道。作者依据地区间信贷边际收益均衡条件构造全局配置效率指标，而非简单使用地区信贷规模或企业融资约束。

本课的IV重点是：自然地理变量看似外生，但与经济活动变量交乘后，排除限制仍需逐条论证。

二、工具变量、识别变异与因果假设

\[Z_{it}=LandSupply_{it}\times Slope_i\]

LandSupply为城市年度土地供给，Slope为地形坡度。相关性逻辑是土地供给影响地方融资能力，坡度影响土地开发难度。

排除限制要求该交互项不能通过工业用地价格、开发区扩张、基础设施、招商和出口产能等渠道直接影响GVC位置。第一阶段强并不等价于这一条件成立。

三、核心模型、固定效应、系数与标准误

\[GVC_{ijt}=\alpha+\beta Faeall_{it}+\gamma'X_{ijt}+\mu_j+\lambda_t+\varepsilon_{ijt}\]
\[Faeall_{it}=\pi Z_{it}+\delta'X_{ijt}+\mu_j+\lambda_t+v_{ijt}\]

模型吸收企业和年份固定效应。原文表2报告稳健t统计量，但公开文本未明确基准规格的聚类层级。由于核心解释变量和工具变量均在城市层面变化，复现时应特别检查城市层面聚类与Moulton问题。

五、Stata参考代码：共同样本与2SLS

Stata · 教学示例 · 非作者原码
use "authorized_firm_city_year.dta", clear
isid firm_id year
xtset firm_id year

gen double iv_land_slope = land_supply * terrain_slope ///
    if !missing(land_supply, terrain_slope)

global X Fund Fdi Net Cost Pay Manage Profit

reghdfe Gvcposition Faeall $X, ///
    absorb(firm_id year) vce(cluster city_id)

ivreghdfe Gvcposition $X (Faeall = iv_land_slope), ///
    absorb(firm_id year) cluster(city_id) first

gen byte sample_iv = e(sample)
reghdfe Gvcposition Faeall $X if sample_iv, ///
    absorb(firm_id year) vce(cluster city_id)

共同样本FE是解释OLS/IV系数差异时必须做的基本诊断。

七、复现障碍、审稿意见与改进

  • 土地供给可能通过用地成本、产业园扩张、基础设施和招商直接影响GVC位置，排除限制需额外证据。
  • 核心变量处于城市层面，应优先检查城市聚类和空间相关稳健推断。
  • FE与IV样本差异明显，必须报告共同样本FE。
  • 还需核对信贷效率指标、土地供给单位、坡度定义和工业企业数据库匹配规则。
