精读入库标准

每期正式报告均以全文可读为前提，完整覆盖：论文基本信息、贡献、模型与识别、数据、核心变量、Stata代码、复现条件与审稿评价。复现代码必须标明作者原码或根据研究设计自行推导；只有实际运行核对后才能标注数值复现成功。

当前公开范围：本公开仓库收录已核实的论文书目与经授权公开的自行撰写七模块精读导读；2026-10-09旧期私人导读暂未公开。期刊PDF、付费数据库、Notion私人页面和未经授权的作者数据或代码均不复制到站点。

长期维护规则

  1. 每次选文前核查来源期刊CSSCI资格、正式出版信息及全文可访问性。
  2. 将新纪录追加到 docs/cssci/catalog.js，严格标注已核实状态；用日期、主题、方法和数据结构归档。
  3. 公开单篇完整导读存于 docs/cssci/lessons/，文件存在且七模块齐备后才将对应 article_url 标注为 published。
  4. 每日课程任务负责在授权范围内写入Notion和GitHub；GitHub Actions负责目录与HTML校验、自动部署及公开站点抽检。三种状态必须分别记录，失败不得宣称成功。
