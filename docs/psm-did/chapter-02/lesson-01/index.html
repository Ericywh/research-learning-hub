MODULE 01

两类比较混在一起

先处理批次可以在后处理批次尚未处理时与之比较；但后处理批次开始处理后，传统TWFE也会用已处理的早批次作对照。若早批次效应继续增长，这种比较将政策效应变化误当成反事实趋势。

MODULE 02

权重的准确说法

Goodman-Bacon分解中的标准两组两期DID比较权重非负；这些比较内部含有不合适的已处理对照。将TWFE写成组别—时间处理效应的加权和时，某些效应权重可能为负。不能把两个层面的权重混为一谈，也不能说所有交错TWFE一定有偏。

MODULE 03

何时TWFE仍有解释

处理效应同质且相关识别条件成立时，TWFE可以有合适解释。异质性和动态效应使其偏离研究者想要的ATT聚合。问题是估计目标与隐含比较不一致，而不是软件回归本身报错。

MODULE 04

一个反例练习

设早批次处理后效应从1增长到3，晚批次刚处理效应为1。晚批次前后变化与早批次同期变化作差，得到1−(3−1)=−1，即使所有真实效应均为正也可能得到负比较。公共模拟面板同时输出TWFE和有效对照ATT(g,t)，用于观察两者目标的差别。

核心公式

$$\widehat\tau_{TWFE}=\sum_{g,t}w_{gt}ATT(g,t)$$
本课的研究任务

学习重点不是记住命令，而是能解释“交错实施为何改变TWFE的解释”中估计目标、识别假设与数据实现之间的关系。依次阅读基础讲解、推导与案例，再结合公共程序检查实际输出。

深入研读 · 01

从残差化处理变量看隐含权重

在没有额外协变量的简单TWFE中，回归分子为残差化处理变量与结果的内积。一个已经处理很久的城市可能具有负的残差化处理值，于是其处理效应以负贡献进入总系数。

$$\widehat\tau={\sum_{it}\widetilde D_{it}Y_{it}\over\sum_{it}\widetilde D_{it}D_{it}}$$

负贡献不是数据里真的存在负处理强度，而是双向去均值形成的比较结构。检查每个单元的残差处理值可以帮助理解问题；完整分解还需要遵循指定权重定义，不能把这个观察直接冒充Bacon数值分解。

深入研读 · 02

构造一次错误的已处理对照

假设早批次在晚批次启动前的效应为1、启动后的效应为3；晚批次从0升至1。此时晚批次变化1减去早批次变化2，得到−1。两批次真实效应均非负，错误比较仍可能是负数。

若早批次效果在这段时间恰好恒定，其增量为零，使用已处理对照未必在这个例子中造成偏差。因此不能把“出现已处理比较”与“任何条件下都必定有偏”画等号；危险来自比较结构与效应异质性共同作用。

深入研读 · 03

选择替代估计器时先定义问题

希望知道每批城市某年的效果，就估计ATT(g,t)；希望描述暴露时间路径，就按事件期聚合；希望预测缺失的未处理结果，可以研究插补方法。不同方法可能使用不同趋势限制、控制组和加权目标。

Sun与Abraham讨论的是异质处理效应下传统事件研究系数的跨时期污染；Callaway与Sant’Anna从组别—时间参数出发组织识别与聚合。两条路径相关但不等同，不能把所有现代方法都称为同一个“交错稳健回归”。

研究练习与解析

早批次效应从1到3，晚批次从0到1；以早批次作对照的DID为何为负？

展开解析

晚批次变化1，早批次变化2，差为−1。这是动态处理效应进入对照变化导致的错误比较。
