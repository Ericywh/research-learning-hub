全课程第4课 / 共10课 · 中国公开数据 · 零基础版

本节核心问题：怎样利用城市政策前特征估计成为试点的概率，再选择相似的对照城市？本课继续采用2014年首批“宽带中国”示范城市（城市群）政策与《中国城市统计年鉴》公开整理的城市面板数据。

一、为什么不能只按工资匹配？

城市是否被纳入首批试点并非随机抽签。官方公告记载2014年首批39个城市（城市群），经过城市申报、省级预审和专家评审。若只按照2013年工资寻找对照城市，可能忽略GDP、人口及产业结构差异。PSM将若干政策前特征汇总为预测概率，再据此寻找可比城市。

二、倾向得分、Logit与Probit

倾向得分（Propensity Score）是给定处理前协变量时，城市入选试点的条件概率。令D=1为首批试点、D=0为其他城市，X为2013年GDP、人口、第三产业占比与原有工资：

\[p(X_i)=P(D_i=1\mid X_i)\]

Logit（逻辑回归）把协变量的线性预测值通过逻辑函数转换为0到1之间的概率：

\[\widehat p_i = \frac{\exp(X_i^\top\widehat\beta)}{1+\exp(X_i^\top\widehat\beta)}\]

Probit则采用标准正态分布的累积分布函数。两者都用于二元因变量，即“是否入选”（0/1）的预测。预测概率0.72不是72%的工资效果，也不证明城市是随机抽签入选。模型系数本身也不能直接当作概率增量。

三、最近邻匹配如何操作？

最近邻匹配（Nearest-Neighbor Matching）通过比较倾向得分距离，寻找最相近的对照城市。定义试点城市i与候选对照城市j之间的距离：

\[d(i,j)=|\widehat p_i-\widehat p_j|\]
教学构造示例倾向得分与A的距离
试点城市A0.72—
非试点城市B0.700.02
非试点城市C0.680.04
非试点城市D0.550.17
非试点城市E0.200.52

一对一最近邻匹配选择城市B；一对三最近邻匹配选择B、C、D。请注意，这些数字都是人工构造的，并非实际政策样本的计算结果。即使得分相近，也需要检查GDP、人口等原始协变量是否真正平衡。

四、卡尺匹配、共同支持和有放回

卡尺（Caliper）是允许的最大匹配距离。在本课的概率距离尺度中，若设卡尺0.05，则只有距离不超过0.05的对照城市符合条件；如果所有候选者都超出卡尺，该试点城市不能进入卡尺匹配样本。0.05只是教学演示，不是通用最优值。Austin（2011）针对连续结局的模拟研究提出使用倾向得分logit变换值标准差的0.2倍作为一种候选卡尺，尺度与本例不同。

共同支持（Common Support/Overlap）要求处理组有相近的可比对照。缺少支持的试点城市可能被剔除，这会改变估计目标人群。有放回匹配（With Replacement）允许同一个非试点城市多次成为不同试点城市的对照；无放回匹配（Without Replacement）则最多使用一次，可能依赖匹配顺序。

五、匹配方式对照

方式基本规则主要注意事项
一对一最近邻选1个最近对照最近不代表足够近
一对三最近邻选3个最近对照较远的第3个可能降低质量
一对一卡尺最近距离≤设定阈值样本可能显著减少
有放回对照城市可被反复选中后续需处理复用权重
无放回对照城市最多使用一次结果可能受匹配顺序影响

六、同一份国内数据：Stata和Python实操

从CityEdu-Eco公开面板导入2013年数据，生成试点标记；先用同一组政策前协变量分别估计Logit和Probit分数，然后仅根据Logit分数做一对一最近邻、概率距离0.05卡尺及一对三最近邻三种匹配。两套代码保持同一名单和筛选原则。Stata保存带中文变量与类别标签的.dta；Python输出带中文列名的CSV。

重要数据口径：2014名单包含长株潭城市群、昆山、延边和阿坝自治州、阿拉尔等非典型地级市单元。本节先对能够直接按地级市名称对应的城市设置处理组，不把未核验的单位强行合并；这仅是教学样本映射，正式研究需要逐个对照官方名单和年鉴单位。两端程序未经过Stata/Python双端运行验证，不能报告未经核实的真实匹配结果。

Python源代码（中文列名）

import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
from sklearn.neighbors import NearestNeighbors

# 真实中国公开城市年鉴整理数据；仅用2013年政策前特征
url = "https://raw.githubusercontent.com/Cause-114/CityEdu-Eco/main/data/panel.csv"
df = pd.read_csv(url)
df = df.loc[df["year"] == 2013].copy()
assert not df["city_key"].duplicated().any()
# 与Stata一致的地级市教学映射；自治州及县级口径待审核
pilots = """北京 天津 上海 长沙 株洲 湘潭 石家庄 大连 本溪
哈尔滨 大庆 南京 苏州 镇江 金华 芜湖 安庆 福州 厦门 泉州
南昌 上饶 青岛 淄博 威海 临沂 郑州 洛阳 武汉 广州
深圳 中山 成都 攀枝花 贵阳 银川 吴忠""".split()
df["treat"] = df["city_key"].isin(pilots).astype(int)
cols = ["gdp", "population", "tertiary_pct", "wage"]
df = df.dropna(subset=cols).copy()
df = df.loc[(df[["gdp", "population", "wage"]] > 0).all(axis=1)].copy()
df["ln_gdp"] = np.log(df["gdp"])
df["ln_pop"] = np.log(df["population"])
df["ln_wage"] = np.log(df["wage"])
formula = "treat ~ ln_gdp + ln_pop + tertiary_pct + ln_wage"
# Logit和Probit都产生0到1之间的预测概率
logit = smf.logit(formula, data=df).fit(disp=False)
probit = smf.probit(formula, data=df).fit(disp=False)
df["p_logit"] = logit.predict(df)
df["p_probit"] = probit.predict(df)
print(df.groupby("treat")[["p_logit", "p_probit"]].agg(["count", "mean", "min", "max"]))
# 使用Logit分数；只保留共同支持范围内的处理组城市
ctrl = df.loc[df["treat"] == 0].copy().reset_index(drop=True)
trt = df.loc[df["treat"] == 1].copy().reset_index(drop=True)
assert not ctrl.empty and not trt.empty, "处理组或候选对照组为空"
lo, hi = ctrl["p_logit"].min(), ctrl["p_logit"].max()
trt = trt.loc[trt["p_logit"].between(lo, hi)].copy().reset_index(drop=True)
assert not trt.empty, "共同支持区间内没有处理组城市"
# 一对三最近邻、有放回；第一个最近邻用于一对一和卡尺匹配
assert len(ctrl) >= 3, "对照城市少于3个，不能做一对三"
nn = NearestNeighbors(n_neighbors=3, metric="euclidean")
nn.fit(ctrl[["p_logit"]])
dist, loc = nn.kneighbors(trt[["p_logit"]])

def make_pairs(k: int, caliper: float | None = None) -> pd.DataFrame:
    rows = []
    for i in range(len(trt)):
        for rank in range(k):
            distance = float(dist[i, rank])
            if caliper is not None and distance > caliper:
                continue
            j = int(loc[i, rank])
            rows.append({"试点城市": trt.loc[i, "city_key"],
                         "对照城市": ctrl.loc[j, "city_key"],
                         "试点倾向得分": float(trt.loc[i, "p_logit"]),
                         "对照倾向得分": float(ctrl.loc[j, "p_logit"]),
                         "倾向得分距离": distance,
                         "匹配顺位": rank + 1})
    return pd.DataFrame(rows, columns=["试点城市", "对照城市",
           "试点倾向得分", "对照倾向得分", "倾向得分距离", "匹配顺位"])

pairs_1 = make_pairs(1)              # 最近邻，一对一，有放回
pairs_cal = make_pairs(1, 0.05)       # 一对一卡尺匹配（概率尺度）
pairs_3 = make_pairs(3)              # 一对三最近邻，有放回
for title, frame, path in [
    ("一对一最近邻", pairs_1, "中国城市_一对一最近邻匹配.csv"),
    ("卡尺0.05", pairs_cal, "中国城市_卡尺005匹配.csv"),
    ("一对三最近邻", pairs_3, "中国城市_一对三最近邻匹配.csv"),
]:
    print(title, "成功匹配的试点城市数：", frame["试点城市"].nunique())
    frame.to_csv(path, index=False, encoding="utf-8-sig")
# 输出匹配关系，不估计DID/ATT；下节检查协变量平衡。

七、三个常见误区

误区1：Logit和Probit哪个分类准确率高，哪个就一定适合匹配。错误。PSM重点是协变量平衡、共同支持和合理的研究设计，而非单纯预测分类。

误区2：卡尺越小一定越好。错误。卡尺过窄虽然限制匹配距离，却可能剔除大量试点、改变估计对象并增加估计不稳定性。

误区3：匹配结束就证明政策有因果效应。错误。还需检查匹配质量和条件平行趋势，明确潜在政策预期、2015—2016年后续试点以及结果变量的暴露时间。2014年名单于10月公布，因此2014全年工资不应当作完整一年的处理后结果。

八、两分钟自测（恰好两题）

概念题：某试点城市在一对一卡尺匹配中找不到距离不超过0.05的对照城市。应当强行选择最近的城市吗？

计算题：试点城市得分0.72，三个非试点城市得分分别是0.70、0.68和0.55。若设置概率距离卡尺0.05，哪些城市合格？如果采用一对一最近邻最终选择谁？

参考答案

概念题答案：不应强行接受违反卡尺的匹配。该试点城市在既定规则下无法匹配，可以退出该方案，研究者应记录样本损失，并审查共同支持与方案的稳健性。

计算题答案：距离分别为0.02、0.04、0.17，B和C符合0.05卡尺；一对一最近邻选距离0.02的B。
