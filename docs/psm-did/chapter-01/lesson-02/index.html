核心问题： 如果试点城市原本比非试点城市更发达，怎样改善两组的可比性？

一、为什么需要PSM？

2014年首批“宽带中国”示范城市（城市群）由工信部、国家发展改革委依据城市申报、省级预审和专家评审选出，共39个城市（城市群）。这不是随机分配。若试点城市GDP、人口、产业结构及工资在政策前便存在系统差异，政策后工资差异不能直接归因于政策。

选择偏差（Selection Bias）：处理分配与原有特征有关，使处理组和对照组直接比较可能偏离政策效果。混杂因素（Confounder）：同时与是否入选试点以及工资有关的变量，例如政策前经济规模、产业结构、原有工资水平。

二、PSM、倾向得分与匹配

PSM是Propensity Score Matching（倾向得分匹配法）。先利用处理前观察到的变量预测成为首批试点的概率，再为试点城市寻找得分相近的非试点城市。

$$p(X_i)=P(D_i=1\mid X_i)$$

其中D=1代表2014首批试点，X为2013年GDP、人口、第三产业比重和工资。p=0.72是模型预测的条件概率，不表示政策采用随机抽签，也不是政策效应。

人工数值案例（非实证结果）：试点城市A的得分0.72，非试点城市B、C分别为0.69、0.18。两者与A的距离分别为0.03与0.54，最近邻规则会优先考虑B。正式匹配还需考虑卡尺和共同支持。

示意：谁与试点城市A更相似？

试点城市 A0.72
非试点城市 B0.69得分差距 0.03
非试点城市 C0.18得分差距 0.54

人工构造倾向得分，仅解释最近邻匹配直觉，不是实际城市的估计值。

三、为什么倾向得分可能有效？

Rosenbaum与Rubin（1983）的倾向得分理论认为，在正确设定和理论条件下，真实倾向得分是一种平衡得分（Balancing Score）：在给定相同真实得分时，两组的可观测协变量分布具有可比性。但估计得分相似不保证有限样本的GDP、人口等都平衡，必须做匹配诊断。

四、单独PSM常用的两个识别条件

条件独立性（Conditional Independence / Unconfoundedness）：单独依赖PSM识别政策因果效应时，通常要求控制政策前X后，处理分配与潜在结果独立。

$$(Y_i(0),Y_i(1))\perp D_i\mid X_i$$

符号⊥表示统计独立。这个要求非常强，无法靠回归结果直接验证：如地方治理能力、隐性政策计划同时影响试点选择和工资，且未被观测，PSM仍有偏差。

共同支持（Common Support / Overlap）：具有类似特征的单位应有接受或不接受处理的可能性。

$$0<p(X_i)<1$$

如果某些试点城市没有相似的非试点城市，可能被排除出匹配样本；此后ATT可能只针对保留的处理组，而不再代表全部试点城市。

PSM-DID下一课将以条件平行趋势为核心识别条件，不能将单独PSM的条件独立性与PSM-DID的假设混淆；匹配不替代平行趋势。

五、匹配和加权区别

最近邻匹配（Nearest Neighbor Matching）：为试点城市找倾向得分距离最近的对照城市。有放回指一个非试点城市可多次成为其他试点城市的匹配对象；无放回指最多使用一次。

加权（Weighting）：调整城市在统计平均值中的权重，使比较组在观测特征上更接近试点组。匹配和加权都须检验协变量平衡（Covariate Balance）。

六、双软件：使用同一份2013年中国城市公开数据

数据来源：CityEdu-Eco公开CSV；数据字典；2014首批试点官方名单。选用2013年GDP、人口、第三产业比重及工资作为处理前X。2013年已实施全国宽带战略，后续还要考察政策预期效应。

Logit（逻辑回归）：预测0/1结果概率的一类模型。这里使用Stata官方logit命令和Python statsmodels中的相同回归公式，估计每个城市被选为首批试点的概率。本课只计算分数，具体匹配算法下节之后系统讲解。

logit treat ln_gdp ln_population tertiary_pct ln_wage
predict double pscore if e(sample), pr
label variable pscore "倾向得分（预测试点概率）"

bysort treat: summarize pscore

Python程序：使用相同的模型变量和筛选原则。

import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

# 与Stata采用同一个公开CSV、同一政策前2013年
url = "https://raw.githubusercontent.com/Cause-114/CityEdu-Eco/main/data/panel.csv"
df = pd.read_csv(url)
df = df.loc[df["year"] == 2013].copy()
assert not df["city_key"].duplicated().any()

# 官方首批名单的教学级城市映射，县级/城市群口径须复核
pilots = """
北京 天津 上海 长沙 株洲 湘潭 石家庄 大连 本溪
延边朝鲜族自治州 哈尔滨 大庆 南京 苏州 镇江 金华
芜湖 安庆 福州 厦门 泉州 南昌 上饶 青岛 淄博
威海 临沂 郑州 洛阳 武汉 广州 深圳 中山 成都
攀枝花 阿坝藏族羌族自治州 贵阳 银川 吴忠 阿拉尔
""".split()
df["treat"] = df["city_key"].isin(pilots).astype(int)
cols = ["gdp", "population", "tertiary_pct", "wage"]
df = df.dropna(subset=cols).copy()
df = df.loc[(df[["gdp", "population", "wage"]] > 0).all(axis=1)].copy()
df["ln_gdp"] = np.log(df["gdp"])
df["ln_population"] = np.log(df["population"])
df["ln_wage"] = np.log(df["wage"])

# Logit预测被纳入2014首批试点的条件概率
formula = "treat ~ ln_gdp + ln_population + tertiary_pct + ln_wage"
model = smf.logit(formula, data=df).fit(disp=False)
df["pscore"] = model.predict(df)
print(df.groupby("treat")["pscore"].agg(["count", "min", "mean", "max"]))
df.to_csv("中国城市_2013年倾向得分教学样本.csv",
          index=False, encoding="utf-8-sig")
# 此处没有匹配后政策ATT，也没有因果估计

实证边界： 2014公告包含长株潭城市群、县级昆山、自治州等，不能机械地与地级市记录一一对应；本课使用明确标为教学级的城市名称映射，尚未逐一完成统计口径审计。两套代码未实际在Stata、Python中同时运行，不能报告未经核实的倾向得分或样本量，更不能把匹配分数当作政策因果效应。

七、三个重要误区

  1. 得分接近就代表所有城市特征相同。 错误；仍需检验原始协变量的标准化均差等平衡诊断。
  2. PSM能消除所有选择偏差。 错误；不能自动排除不可观测混杂。
  3. 匹配完之后做DID便无需平行趋势。 错误；匹配不替代条件平行趋势、无预期等识别条件。

八、两分钟自测

概念题： 倾向得分0.80是否代表80%的政策效果？为什么？

计算题： 某试点城市得分0.64，三个非试点城市分别为0.61、0.48、0.79，最近邻规则优先选择哪一个？

参考答案

概念题： 不是。0.80是依据政策前特征预测的被处理概率，不是效果或ATT。

计算题： 距离依次为0.03、0.16、0.15，因此首选得分0.61的城市；正式匹配还要满足共同支持及卡尺等要求。
