# 第2课 多期面板、TWFE与聚类推断

## 多期不是简单增加观测

共同实施时点下，令 D_it=1{G_i=g}1{t≥g}。城市固定效应吸收城市不变项，年份固定效应吸收所有城市共同冲击。平衡面板的静态TWFE通常汇总多个处理后效应；若动态效应变化，系数并非某一个具体年份的ATT。

## 回归设定与坏控制

本课程共同批次演示只保留2014批次和窗口内未列入试点的可比城市，排除后续批次。主规格不放政策后的GDP、人口或产业结构，它们可能是中介。需要条件平行趋势时，应采用政策前协变量及适当时间交互，或直接使用条件DID估计器；简单加入当期X不自动解决识别。

## 城市聚类与有效样本量

同一城市跨年误差相关，逐行异方差稳健标准误通常不足。聚类层级应跟随处理分配和误差依赖：城市层级只是起点；若政策在省级协调或存在空间相关，应研究更高层级推断。聚类数少时常规渐近近似偏弱，可研究wild cluster bootstrap，不能以城市—年总行数代替独立信息量。

## 可执行规格

## 组内变换如何吸收固定效应

平衡面板下，对每个变量减去城市均值和年份均值，再加回总均值，城市与年份加性固定项会消失。残差化后用结果对处理变量回归，就是Frisch–Waugh–Lovell定理在双向固定效应中的应用。

$$\widetilde Y_{it}=Y_{it}-\bar Y_i-\bar Y_t+\bar Y,\qquad\widehat\tau={\sum\widetilde D_{it}\widetilde Y_{it}\over\sum\widetilde D_{it}^2}$$

若处理变量在残差化后完全没有变异，参数无法识别。全国同一年所有城市都受处理时，处理指标与年份效应共线；增加城市或加入更多年份固定效应并不能恢复这个缺失的比较。

## 聚类协方差究竟合并了什么

先把每个城市全部年份的残差得分加总，再在城市之间计算外积，便允许同城跨年任意相关。常规逐行稳健方差只保留单行外积，丢掉同城跨年协方差。后者若为正，就容易低估不确定性。

$$\widehat V=(X^{\prime}X)^{-1}\left(\sum_i X_i^{\prime}\widehat u_i\widehat u_i^{\prime}X_i\right)(X^{\prime}X)^{-1}$$

这里X是残差化设计矩阵。有限样本修正依赖软件如何计算吸收固定效应的自由度，因此不同软件的标准误可能略有差异。需要核对的不只是cluster选项，还有聚类数量、是否使用t近似及自由度规则。

## 把一个估计规格写成可审阅的设计

先明确分析只包括首批城市和窗口内未入选城市，再固定2010—2018完整样本，最后定义did。不要先按当年did=0筛对照，这会混入后续批次的处理前观测，并改变城市组成。

讨论中至少区分三种对象：不加协变量的平均对比、控制前定变量后形成的条件对比、控制政策后中介得到的直接效应式回归。第三种并不因为控制变量更多就更可信。

## 研究练习

全国所有城市同年启动，控制城市与年份效应后能否识别政策系数？

解析：不能。处理变量与年份虚拟变量共线，残差化处理变量为零；必须寻找额外的有效比较结构。

## 代码阅读

```python
s = d[d.g.isin([0, 2014])].copy()
s['did'] = ((s.g == 2014) & (s.year >= 2014)).astype(int)
fit = twfe(s, ['did'])
print(fit.params, fit.bse)  # 城市聚类协方差
```
