      课程核心问题： 为什么可先以PSM选择更可比的对照城市，再用DID比较政策前后结果变化？

      一、两种方法分别做什么？

      PSM（Propensity Score Matching，倾向得分匹配）使用政策实施前的GDP、人口、产业结构与原有工资等特征，预测是否入选试点，选择与试点城市更相似的非试点城市。DID（Difference-in-Differences，双重差分）比较两组工资的前后变化，扣除共同时间变化。合起来，就是在更可比的城市样本上估计DID。

      研究继续采用2014年首批“宽带中国”示范城市政策。工信部、国家发改委2014年10月9日公告首批39个城市（城市群），经过申报、预审和专家评审，非随机分配。工信部原公告。

      二、用教学数据手算匹配前后DID

      以下全部数字为人为构造，并非中国城市真实工资均值。 假设2013年/2014年试点城市A工资分别为40000元/45000元，任意选出的非试点城市C分别为26000元/28000元，则未经匹配的DID=(45000-40000)-(28000-26000)=3000元。

      如果按政策前GDP、人口、第三产业占比与原工资找到与A更接近的非试点城市B，其工资从39000元增加到43000元，则匹配后的DID=(45000-40000)-(43000-39000)=1000元。

      两个结果不同，是因为比较对象变了；不能据此认为1000一定更接近真实因果效应。匹配只改善观测到的特征的可比性，不能保证未观测趋势相同。

      三、匹配后估计谁的效应？

      ATT是Average Treatment Effect on the Treated（处理组平均处理效应），目标是对实际入选试点的城市估计平均政策效应。若每个保留试点城市恰好对应一个对照城市，简单匹配DID为：

      $$\widehat{ATT}_{M-DID}=\frac{1}{N_T^*}\sum_{i=1}^{N_T^*}(\Delta Y_{Ti}-\Delta Y_{Ci})$$

      其中$N_T^*$表示成功匹配且进入估计的试点城市数，$\Delta Y_{Ti}$是试点城市工资变化，$\Delta Y_{Ci}$是与它匹配的对照城市工资变化。多个对照城市或重复匹配时，必须明确权重。有些试点城市可能没有共同支持而被剔除，因此估计的目标群体可能从全部试点城市变成保留的试点城市。

      四、关键识别条件：条件平行趋势

      条件平行趋势（Conditional Parallel Trends）要求：给定政策前特征$X$后，如果没有政策，试点组和对照组的平均结果变化应相同。数学表达为：

      $$E[Y_1(0)-Y_0(0)\mid D=1,X=x]=E[Y_1(0)-Y_0(0)\mid D=0,X=x]$$

      $Y_t(0)$是不受政策时的潜在工资，$D$表示是否入选试点，$X$包括政策前GDP、人口等。只看匹配后的均值接近无法证明该假设；未观测到的产业冲击、地方治理变化仍可能使两组无政策趋势不同。

      共同支持（Overlap）：有类似政策前特征的处理组和对照组都存在，能够找到合理对照；无预期效应（No Anticipation）：被选城市不应在用于基期的结果中已经对将来入选作出会影响估计的响应；无干扰（No Interference）：一个城市的政策处理不会显著改变作为对照的另一城市结果。实际研究应审查潜在溢出、同期政策及样本组成。

      五、PSM-DID具体流程

      1. 先定义政策和研究对象。 处理组为2014首批试点，非试点为候选对照城市；核对城市群、县级市、自治州与统计口径。
      2. 只用政策前特征做PSM。 例如2013年GDP、人口、服务业比重和工资，不用2014年工资或可能被政策改变的变量预测入选。
      3. 检查共同支持、匹配质量和平衡性。 找不到可比城市时需调整样本或方案；匹配距离小并不自动说明各个协变量平衡。
      4. 在匹配后的同一批城市计算DID。 保持试点和匹配对照的2013年、2014年工资，求各城市的变化，再比较处理组与对照组的变化。
      5. 谨慎推断。 匹配的复用权重、城市聚类、政策分配层级和样本选择会影响标准误和可信程度。不能把普通OLS的显著性或简单匹配差值当作因果证明。

      六、中国公开数据与软件演示

      数据来自CityEdu-Eco根据《中国城市统计年鉴》整理的中国城市年度面板CSV，字段说明见中文数据字典。本节只使用2013年与2014年两期，在2013年估计倾向得分后，做一对一最近邻、有放回匹配，取匹配对工资变化之差的平均。这里的有放回表示同一非试点城市可以被多个试点城市选为对照；最近邻是指倾向得分绝对差最小。

      重要限制： 2014年首批名单于10月公布，2014年的全年工资不能代表完整暴露一年后的政策结果。2015、2016年有后续试点批次，延长窗口必须处理新增试点污染对照组。2013年国家宽带战略已经启动，也需考虑预期与既有投资。因此本课代码只是算法教学，不给出未经验证的真实政策因果结论。

      Stata：从真实中国城市数据计算教学版匹配DID；中文变量及0/1类别标签。

      clear all
set more off
* 2013=处理前，2014=名单公布年；仅用于两期教学
import delimited "https://raw.githubusercontent.com/Cause-114/CityEdu-Eco/main/data/panel.csv", clear varnames(1) encoding("UTF-8")
keep if inlist(year, 2013, 2014)
isid city_key year
* 定义首批试点（城市群及县级城市口径有待逐项审计）
gen byte treat = 0
local pilots "北京 天津 上海 长沙 株洲 湘潭 石家庄 大连 本溪 延边朝鲜族自治州 哈尔滨 大庆 南京 苏州 镇江 金华 芜湖 安庆 福州 厦门 泉州 南昌 上饶 青岛 淄博 威海 临沂 郑州 洛阳 武汉 广州 深圳 中山 成都 攀枝花 阿坝藏族羌族自治州 贵阳 银川 吴忠 阿拉尔"
foreach c of local pilots {
    replace treat = 1 if city_key == "`c'"
}
label define treated_zh 0 "非2014首批试点" 1 "2014首批试点"
label values treat treated_zh
label variable treat "是否属于2014首批宽带示范城市"
label variable wage "城市在岗职工平均工资（元）"
egen cityid = group(city_key), label
label variable cityid "城市编号（中文城市名）"
* 将城市-年份长表变为每城市一行的宽表
keep cityid city_key year treat wage gdp population tertiary_pct
reshape wide wage gdp population tertiary_pct, i(cityid) j(year)
* 只匹配两年工资完整、2013年协变量完整的城市
keep if !missing(wage2013,wage2014,gdp2013,population2013,tertiary_pct2013)
keep if gdp2013>0 & population2013>0 & wage2013>0
gen double d_wage = wage2014 - wage2013
label variable d_wage "城市2013至2014年工资变化（元）"
gen double ln_gdp = ln(gdp2013)
gen double ln_pop = ln(population2013)
gen double ln_wage = ln(wage2013)
label variable ln_gdp "2013年GDP自然对数"
label variable ln_pop "2013年人口自然对数"
label variable ln_wage "2013年工资自然对数"
* 仅根据政策前特征估计倾向得分
logit treat ln_gdp ln_pop tertiary_pct2013 ln_wage
predict double pscore if e(sample), pr
label variable pscore "2014首批入选倾向得分"
* ATT共同支持：处理城市分数须处于对照城市的范围内
quietly summarize pscore if treat == 0, meanonly
local lo = r(min)
local hi = r(max)
keep if treat==0 | inrange(pscore, `lo', `hi')
* 形成对照城市候选库：将每个对照城市与试点城市配对
preserve
    keep if treat==0
    keep cityid pscore d_wage
    rename cityid control_id
    rename pscore control_pscore
    rename d_wage control_change
    tempfile controls
    save `controls'
restore
keep if treat==1
keep cityid pscore d_wage
cross using `controls'
gen double distance = abs(pscore - control_pscore)
bysort cityid (distance control_id): keep if _n==1
* 一对一最近邻匹配、有放回；计算匹配对的DID
gen double pair_did = d_wage - control_change
label variable pair_did "每对城市的匹配后工资双重差分（元）"
quietly summarize pair_did
display "教学版匹配后DID点估计（元） = " %12.3f r(mean)
save "中国城市_PSM-DID_匹配对教学数据.dta", replace
* 不进行显著性检验：匹配后的常规标准误不可靠

      Python：相同年份、样本筛选、Logit协变量与一对一有放回最近邻匹配。

      import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
from sklearn.neighbors import NearestNeighbors

# 两期中国城市真实公开面板
url = "https://raw.githubusercontent.com/Cause-114/CityEdu-Eco/main/data/panel.csv"
df = pd.read_csv(url)
df = df.loc[df["year"].isin([2013, 2014])].copy()
assert not df.duplicated(["city_key", "year"]).any()
pilots = '''
北京 天津 上海 长沙 株洲 湘潭 石家庄 大连 本溪 延边朝鲜族自治州
哈尔滨 大庆 南京 苏州 镇江 金华 芜湖 安庆 福州 厦门 泉州
南昌 上饶 青岛 淄博 威海 临沂 郑州 洛阳 武汉 广州 深圳
中山 成都 攀枝花 阿坝藏族羌族自治州 贵阳 银川 吴忠 阿拉尔
'''.split()
# 2013协变量与2014结果按城市合并
pre = df.loc[df["year"] == 2013, ["city_key","wage","gdp","population","tertiary_pct"]]
pre = pre.rename(columns={"wage":"wage2013","gdp":"gdp2013",
                          "population":"population2013",
                          "tertiary_pct":"tertiary_pct2013"})
post = df.loc[df["year"] == 2014, ["city_key","wage"]]
post = post.rename(columns={"wage":"wage2014"})
panel = pre.merge(post, on="city_key", how="inner", validate="one_to_one")
panel["treat"] = panel["city_key"].isin(pilots).astype(int)
needed = ["wage2013","wage2014","gdp2013","population2013","tertiary_pct2013"]
panel = panel.dropna(subset=needed).copy()
panel = panel.loc[(panel[["gdp2013","population2013","wage2013"]]>0).all(axis=1)].copy()
panel["d_wage"] = panel["wage2014"] - panel["wage2013"]
panel["ln_gdp"] = np.log(panel["gdp2013"])
panel["ln_pop"] = np.log(panel["population2013"])
panel["ln_wage"] = np.log(panel["wage2013"])
# 与Stata同一Logit模型；模型本身并不解决选择偏差
model = smf.logit("treat ~ ln_gdp + ln_pop + tertiary_pct2013 + ln_wage",
                  data=panel).fit(disp=False)
panel["pscore"] = model.predict(panel)
controls = panel.loc[panel["treat"] == 0].copy()
treated = panel.loc[panel["treat"] == 1].copy()
# 仅在对照组倾向得分支持范围内保留处理组
lo, hi = controls["pscore"].min(), controls["pscore"].max()
treated = treated.loc[treated["pscore"].between(lo, hi)].copy()
assert len(treated) > 0 and len(controls) > 0, "缺少共同支持，停止匹配"
# 一对一最近邻匹配，有放回；本课不设卡尺
nn = NearestNeighbors(n_neighbors=1)
nn.fit(controls[["pscore"]])
distance, idx = nn.kneighbors(treated[["pscore"]])
matched_controls = controls.iloc[idx.ravel()].reset_index(drop=True)
matched_treated = treated.reset_index(drop=True)
pairs = pd.DataFrame({
    "试点城市": matched_treated["city_key"],
    "对照城市": matched_controls["city_key"],
    "倾向得分距离": distance.ravel(),
    "试点组工资变化": matched_treated["d_wage"],
    "对照组工资变化": matched_controls["d_wage"]
})
pairs["配对DID"] = pairs["试点组工资变化"] - pairs["对照组工资变化"]
print("教学版匹配后DID点估计（元）：", pairs["配对DID"].mean())
print("成功匹配的处理城市数：", len(pairs))
pairs.to_csv("中国城市_PSM-DID_匹配对教学数据.csv", index=False, encoding="utf-8-sig")
# 不把匹配后简单标准误或该点估计当作可靠因果结论

      七、三个常见误区

      1. 匹配成功就自动满足平行趋势。 错。PSM能改变政策前可观测特征的分布，却不能直接检验没有政策时的反事实变化。
      2. PSM-DID一定比单独DID好。 错。错误模型、质量差的匹配、丢弃大量试点或引入不合适变量可能使估计更差。
      3. 只要匹配前后政策估计不一样，就证明存在因果偏差。 错。变化可能同时来自样本组成、权重及对照组选择的改变，并非可直接识别偏差大小。

      八、两分钟自测（恰好两题）

      概念题： 为什么PSM-DID已经在GDP和工资上做了匹配，仍然需要条件平行趋势？

      计算题： 某试点城市2013年工资50000元、2014年56000元；匹配到的非试点城市分别为48000元、53000元。计算匹配后的DID。

      参考答案

      概念题： 匹配只能改善已经观测的政策前特征相似性；不可观测的经济冲击仍可能让两组无政策时的工资变化不同。

      计算题： 试点组工资增长6000元，对照组增长5000元，匹配后的DID=1000元。这个数字仍需识别假设才能解释为政策效应。

      九、第一章知识结构与实证核对清单

      本章三节连接为：DID——通过两次差分构造反事实；PSM——利用处理前特征改善比较组；PSM-DID——在匹配后的样本中利用条件平行趋势估计ATT。

      实证核对：政策时间准确；名单与城市统计口径核实；协变量全部为处理前信息；处理组与对照组有共同支持；匹配前后平衡性检验；条件平行趋势与政策溢出分析；匹配权重和样本损失透明；统计推断与分批试点处理符合设计。
