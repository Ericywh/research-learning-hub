一、真实国内政策与公开数据

本课改为2014年首批“宽带中国”示范城市（城市群）政策：工信部、国家发展改革委于2014年公布39个示范城市（城市群），如北京、南京、苏州、武汉和成都等。研究问题：入选示范城市是否改变城市在岗职工平均工资？ 这只是研究问题，不是既得出的因果结论。

MODULE 02 / 10

二、零基础专有名词

处理组（Treatment Group）：实际入选2014年首批政策的城市；“处理”指政策干预，不是数据清洗。

对照组（Control Group）：2014年尚未入选的城市，用来提供反事实变化的参考。2015、2016年会有后来试点，延长窗口时必须剔除、重分类或使用多期DID。

结果变量（Outcome Variable）：政策可能影响的具体指标，这里是在岗职工平均工资，不代表所有居民收入。

反事实（Counterfactual）：如果入选试点的城市没有入选，2014年工资本来会是多少？它无法与已经发生的结果在同一城市同时观察。

因果效应（Causal Effect）：实际入选政策后的结果与其没有入选时反事实结果的差异，不等于简单的前后增长。

DID（Difference-in-Differences，双重差分法）：先求每组前后变化，再将处理组变化减去对照组变化。

MODULE 03 / 10

三、2×2手算教学案例（非真实数据）

组别 2013年政策前 2014年政策后 工资变化
试点城市组 40000元 45000元 +5000元
非试点城市组 35000元 38000元 +3000元

若试点城市未入选政策时也会增加3000元，则2014年反事实工资为40000＋3000＝43000元，而实际为45000元。两者相差2000元：

$$\widehat{DID}=(45000-40000)-(38000-35000)=2000\text{元}$$

图示（文字路径）：试点组实际：40000→45000；试点组无政策反事实：40000→43000；对照组：35000→38000；2014年政策组实际与反事实的垂直差距为2000元。

第一次差分消除不随时间改变的水平差异；第二次差分扣除对照组也经历的平均变化。DID衡量的是额外增长，而非单纯谁的工资更高。

MODULE 04 / 10

四、ATT与平行趋势

ATT（Average Treatment Effect on the Treated，处理组平均处理效应）：对于实际上入选政策的城市，入选政策后相对于其未入选政策时的平均差距。

$$ATT=E[Y_1(1)-Y_1(0)\mid D=1]$$

其中$Y_1(1)$是接受政策后的工资，$Y_1(0)$是同一城市不接受政策时的潜在结果，$D=1$是处理组，$E$表示求平均，“$\mid$”表示在给定处理组的条件下。

平行趋势（Parallel Trends）：如果政策没有发生，处理组和对照组的平均工资变化应当相同，而不要求两组政策前工资水平相同：

$$E[Y_1(0)-Y_0(0)\mid D=1]=E[Y_1(0)-Y_0(0)\mid D=0]$$

需要额外考察政策预期、其他同期冲击、政策溢出和样本构成。2014年首批名单于秋季公布，2014年全年工资只包含很短的事后暴露期，且2013年已有国家宽带战略。用2013/2014两个年份只作入门演示，不能将初步估计直接宣称为全年政策因果效应。

MODULE 05 / 10

五、两期DID回归与交互项

$$Y_{it}=\alpha+\beta Treat_i+\gamma Post_t+\delta(Treat_i\times Post_t)+\varepsilon_{it}$$

$Y_{it}$是城市工资，$Treat_i$标记是否首批试点，$Post_t$标记2014年，二者相乘是交互项（Interaction Term），只在“试点且政策后”取1。其回归系数$\delta$是DID点估计。回归系数是从样本中估计的数字；能否解释为因果效果取决于识别假设，而非回归命令。

六、Stata：读取真实中国数据并写入中文标签

下列代码按Stata 17及以上版本编写。变量名保留英文字母以确保兼容性，通过label variable及label define/label values设置中文变量标签及类别标签。代码尚未实际运行核验。

clear all
set more off
* 可直接从GitHub公开数据源读入；若联网失败，先下载panel.csv
import delimited "https://raw.githubusercontent.com/Cause-114/CityEdu-Eco/main/data/panel.csv", clear varnames(1) encoding("UTF-8")
keep if inlist(year, 2013, 2014)
label data "中国城市宽带中国示范政策教学数据"
label variable city_key "城市名称"
label variable year "统计年份"
label variable wage "在岗职工平均工资（元）"
label variable gdp "地区生产总值（亿元）"
label variable population "人口（百万人）"
label variable tertiary_pct "第三产业占GDP比重（%）"
* 根据2014年首批公告设置试点城市；长株潭按三市映射；昆山归入苏州口径
gen byte treat = 0
local pilots "北京 天津 上海 长沙 株洲 湘潭 石家庄 大连 本溪 延边朝鲜族自治州 哈尔滨 大庆 南京 苏州 镇江 金华 芜湖 安庆 福州 厦门 泉州 南昌 上饶 青岛 淄博 威海 临沂 郑州 洛阳 武汉 广州 深圳 中山 成都 攀枝花 阿坝藏族羌族自治州 贵阳 银川 吴忠 阿拉尔"
foreach c of local pilots {
    replace treat = 1 if city_key == "`c'"
}
gen byte post = (year == 2014)
label variable treat "是否属于2014年首批示范城市"
label variable post "是否属于政策后年份"
label define treat_lab 0 "非首批试点" 1 "首批试点"
label define post_lab 0 "2013年政策前" 1 "2014年政策后"
label values treat treat_lab
label values post post_lab
gen byte did = treat * post
label variable did "首批试点与政策后交互项"
drop if missing(city_key, wage)
isid city_key year
egen cityid = group(city_key), label
label variable cityid "城市编号（对应中文城市名）"
bysort cityid: keep if _N == 2
table treat post, statistic(mean wage)
regress wage i.treat##i.post, vce(cluster cityid)
save "中国城市_宽带中国DID教学数据.dta", replace

命令说明： import delimited导入CSV；label variable定义中文变量标签；label define和label values显示中文0/1类别；gen生成变量；regress做普通最小二乘（OLS）回归。vce(cluster cityid)允许同一城市内部误差相关，但不保证整个政策层级的推断可靠。

七、Python：同数据、同规则的对照程序

Python完整代码
import pandas as pd
import statsmodels.formula.api as smf

url = "https://raw.githubusercontent.com/Cause-114/CityEdu-Eco/main/data/panel.csv"
df = pd.read_csv(url)
df = df[df["year"].isin([2013, 2014])].copy()
pilots = """
北京 天津 上海 长沙 株洲 湘潭 石家庄 大连 本溪 延边朝鲜族自治州
哈尔滨 大庆 南京 苏州 镇江 金华 芜湖 安庆 福州 厦门 泉州
南昌 上饶 青岛 淄博 威海 临沂 郑州 洛阳 武汉 广州 深圳
中山 成都 攀枝花 阿坝藏族羌族自治州 贵阳 银川 吴忠 阿拉尔
""".split()
df["treat"] = df["city_key"].isin(pilots).astype(int)
df["post"] = (df["year"] == 2014).astype(int)
df["did"] = df["treat"] * df["post"]
df = df.dropna(subset=["city_key", "wage"])
assert not df.duplicated(["city_key", "year"]).any()
n = df.groupby("city_key")["year"].transform("nunique")
df = df[n == 2].copy()
means = df.groupby(["treat", "post"])["wage"].mean()
print("两组两期工资均值：", means)
did = (means.loc[1, 1] - means.loc[1, 0]) - (means.loc[0, 1] - means.loc[0, 0])
print("DID估计值（元）：", did)
model = smf.ols("wage ~ treat * post", data=df).fit(
    cov_type="cluster", cov_kwds={"groups": df["city_key"]}
)
print("回归交互项系数：", model.params["treat:post"])
df.to_csv("中国城市_宽带中国DID教学数据.csv", index=False, encoding="utf-8-sig")

MODULE 08 / 10

八、三个重要误区

  1. 试点城市工资增长得更多就一定是政策有效：错误；仍可能存在政策选择偏差与差异化冲击。
  2. 政策前两组平均工资不同就不能使用DID：错误；平行趋势要求反事实变化相同，不要求水平相同。
  3. DID回归有交互项就完成因果识别：错误；仍要论证平行趋势、无预期、溢出与合理统计推断。
MODULE 09 / 10

九、两分钟自测

概念题： 苏州政策后工资上涨，为什么不能据此证明是宽带政策带来的？

计算题： 试点组工资从50000元增至56000元，非试点组从42000增至46000元，DID为多少？

参考答案： (1) 上涨可能来自宏观与产业变化，无法直接观察无政策时的反事实；(2) (56000-50000)-(46000-42000)=2000元。只有识别条件成立才能作因果解释。
