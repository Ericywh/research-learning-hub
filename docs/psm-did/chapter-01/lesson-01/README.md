# 第1课 潜在结果、反事实与两期DID

## 从研究问题到估计目标

研究问题是城市入选宽带示范是否改变工资，而不是入选城市是否工资更高。令 G 为首次入选年，Y_t(0) 为不入选的潜在结果，Y_t(1) 为入选后的潜在结果。两期处理组 ATT 针对实际接受处理者，不等于全国城市平均效应。工资取对数时，系数是对数点；100×(exp(ATT)−1) 才是对应百分比变化。

## 差分代数与反事实

处理组工资从40000升至45000，对照组从35000升至38000。DID为2000元；隐含的处理组反事实为43000元。先差分去掉固定水平差异，再跨组差分去掉共同变化。这个算例的平行趋势是额外假设，四个均值本身无法验证。

## 识别条件

一致性要求处理定义明确；无预期要求基期不受未来政策影响；平行趋势要求未处理潜在结果的平均变化相同；还需适当处理城市间溢出、同期政策和样本构成变化。固定效应只吸收加性不变异质性与共同时间冲击，不能自动控制城市特异的时变冲击。

## 手算、回归与目标人口

两组两期饱和回归的交互项等于均值DID。不同规模城市采用等权或人口权重对应不同目标。缺失城市可能改变目标人口，不能将完整样本ATT无条件推广至全部城市。先报告城市数、年份、处理定义和结果单位，再报告系数。

自测：两组政策前工资不同是否直接否定DID？

答案：不能；水平差异可由固定项解释，关键是未处理变化的反事实趋势。

## 从可观测差分中分离选择偏差

把处理组的观测变化写为政策效应与未处理趋势之和，再减去对照组变化，得到下面的分解。它说明DID并不是天然消除了所有选择偏差，而是将问题转化为两组反事实趋势是否一致。

$$DID=ATT+\{E[\Delta Y(0)\mid D=1]-E[\Delta Y(0)\mid D=0]\}$$

政策前水平不同不必然有偏；若高工资城市即使没有政策也增长更快，固定水平差异消除后仍会留下趋势偏差。反过来，政策前均值相同也不能推出未来反事实趋势相同。识别讨论必须解释为什么所选对照能够代表处理城市在没有政策时的变化，而不能停在“控制了固定效应”。

## 用四个单元均值还原回归系数

令回归为Y=α+βD+γPost+τ(D×Post)+ε。对照组政策前均值等于α，处理组政策前为α+β，对照组政策后为α+γ，处理组政策后为α+β+γ+τ。因此τ恰好等于双重差分。这个等价性依赖两组两期饱和设定；加入协变量、不等权重或多期以后，不能直接把交互项解释为同一个四均值算例。

在40000→45000与35000→38000的算例中，处理组增长5000元，对照组增长3000元。若处理组未处理趋势实际是4000元，则真实ATT只有1000元，DID的2000元包含1000元趋势偏差。请注意，偏差来自无法观测的反事实，而不是计算步骤错误。

## 结果尺度决定平行趋势的含义

工资水平DID要求未处理工资的绝对增量平行；对数DID要求未处理对数工资的平均变化平行。前者接近“每年多涨同样多元”，后者接近“增长率相近”，两者不是同一假设。对数变换也会改变零值和缺失值的处理及目标人口。

将平均对数变化指数化，不能自动称为平均工资水平的百分比因果效应，因为平均与指数运算不可交换。课程对数回归的直接对象是平均对数工资效应；在效应同质等附加条件下，才有更简单的水平比例解释。

## 研究练习

若处理组无政策时增长4000元，对照组增长3000元，观测处理组增长5000元，求ATT与DID的偏差。

解析：ATT=1000元，DID=2000元，偏差=1000元。固定效应不会消除这项差异趋势。

## 代码阅读

```python
treated_change = 45000 - 40000
control_change = 38000 - 35000
did = treated_change - control_change
print(did)  # 2000元；因果解释仍需平行趋势
```
