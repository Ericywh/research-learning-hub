纠正评审的以下论断：

- 基期结果不属于普遍禁止的协变量；均值回归取决于结果过程与选择机制。删除工资不能保证无偏或平衡。
- 加入交互项、核匹配或IPW不能保证所有SMD低于0.05；失败应调整设计或承认支持不足。
- 扩大窗口不自动解决公告当年暴露不足或后续队列污染。全国2013战略可能导致提前反应。
- Bacon两期比较权重与ATT单元权重不同。交错TWFE不在所有情形下失效。
- 评审2015名单混入2016城市并遗漏真实2015城市，2016名单完全缺失；改用三批官方公告。重庆区级试点不映射为全市处理。
- 评审Python DR的简化IF未计入一般第一阶段估计影响。改用联合矩条件与数值Jacobian sandwich；不将任一工作模型正确的点一致性自动等同于简化推断有效。
- 匹配频次加权回归的城市聚类SE不自动解决估计权重和匹配不确定性；teffects解析方差也有其适用条件。
- 任意城市置换不具有试点随机分配的可交换性，仅作参照分布。事前不显著不证明平行趋势。
- Python组别—时间实现明确为无条件DID，不冒称完整条件CS-DID；聚合保留共同对照引起的协方差。
