# 数据与政策队列

panel.csv来自 https://github.com/Cause-114/CityEdu-Eco/blob/main/data/panel.csv ，2026-10-28通过GitHub读取的教学快照。原项目二次整理中国城市统计年鉴；本课程未独立核验原始年鉴。变量单位以原项目DATA_NOTES.md为准。代码计算文件SHA256并写入审计日志；不要静默替换快照。

policy_units.csv保存117个官方公告单元，其中长株潭拆为三条映射记录，因此行数119。2014来源为工信部2014年第61号公告，落款2014-09-26；2015为第65号公告，落款2015-10-14；2016为第40号公告，落款2016-07-22。source_url逐行保留，policy_unit按公告名称去行政后缀。

采用公告批次年，未宣称完整年暴露。长株潭展开至长沙、株洲、湘潭；昆山嵌套苏州，按首次暴露去重。重庆四个区级试点无法对应全市工资，排除重庆；永城2015与其上级商丘2016存在地域混合，排除商丘。福州公告含平潭，城市统计口径仍需正式研究核查。自治州与县级市不强行并入邻近城市；未匹配名称输出到audit.json。

g=0表示未列入这三批公告，不是从未受宽带建设或其他政策影响。保留所有名单中的自治州及县级单元供核查；不把缺失源面板的政策城市凭空补成数据。窗口2010—2018与前定2013协变量用于教学，不消除2013战略预期、试点内生选择、地区溢出和数据缺失选择。
