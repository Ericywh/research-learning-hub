公告与地域映射

保存2014、2015、2016官方名单原始行政单元、来源和映射。长株潭展开为长沙、株洲、湘潭；苏州与昆山重复暴露按首次批次去重；重庆区级试点不能把重庆全市标为处理，默认排除；永城为县级试点，其上级商丘2016入选，默认排除商丘以避免混合暴露。自治州等须核查源面板是否覆盖。

MODULE 02

可复现数据链

课程快照保存panel.csv及SHA256，原来源为CityEdu-Eco，属于二次整理数据，未独立核验年鉴原表。只使用2010—2018工资及2013协变量完整的平衡面板；输出原始行数、缺失排除、地域排除、城市与队列数量。g=0仅表示核查这三批名单后未列入，不表示从未受全国宽带政策影响。

MODULE 03

一键运行与输出

运行 python analysis/run.py --mode demo --out results/demo 可生成已知机制模拟面板并完成TWFE、事件研究、ATT(g,t)、平衡、DR、安慰剂与图表；--mode real 使用快照与公告映射。两种模式写入独立目录并标注，绝不把模拟结果混为真实政策结论。Stata在analysis目录运行 do run.do，默认同样使用模拟CSV，real模式显式指定。

MODULE 04

研究报告应交代什么

交付估计表、事件系数图、平衡表及Love图、置换图和审计JSON。TWFE、匹配、DR与交错ATT针对不同时间与样本时不应拼成同一目标的四列稳健性证明。收官任务是解释每列的目标、识别条件、样本损失和推断方法，再讨论结果能否支持工资因果效应。
