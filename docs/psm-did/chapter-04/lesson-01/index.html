MODULE 01

时间安慰剂

只在真正未处理时期设伪时点，例如2011到2013，检查同期组间变化。显著结果提示差异趋势或测量问题；不显著不能证明主结果有效。提前反应存在时，靠近政策的时期不能作为安慰剂的干净未处理窗口。

MODULE 02

置换的解释

默认500次城市标签置换保持处理城市数量，用两期DID系数作统计量，双侧尾部比例使用(1+超越次数)/(B+1)。宽带试点不是随机分配，任意城市交换不满足可交换性；因此该图仅是参照分布，不能自动称为有效随机化p值。正式随机化推断需要可信的分配机制及相应分层、聚类约束。

MODULE 03

同期政策与溢出

梳理智慧城市、电子商务及其他数字基础设施政策的时间与地域，避免将政策组合效果解释为单项效果。排除重叠政策城市会改变目标人口；加入政策后中介会改变估计对象。邻近城市受网络扩散时，需要重新定义暴露与干扰结构。

MODULE 04

敏感性分析

应检查窗口、公告年排除、首次完整年定义、城市样本、固定效应结构、权重极值与基期选择。平行趋势偏离的敏感性区间需明确允许的偏离集合；稳健性不是尽可能多地得到显著系数。公共程序保存种子、500次置换和时间安慰剂数值。

核心公式

$$p_{ref}={1+\sum_{b=1}^B1\{|T_b|\ge |T_{obs}|\}\over B+1}$$
本课的研究任务

学习重点不是记住命令，而是能解释“安慰剂、敏感性与识别威胁”中估计目标、识别假设与数据实现之间的关系。依次阅读基础讲解、推导与案例，再结合公共程序检查实际输出。

深入研读 · 01

把敏感性分析写成偏差函数

设未处理趋势的组间差异为δ，则观测DID等于ATT+δ。研究者可在一个事先说明的δ集合上报告ATT范围，而不是只做一串重新回归。

$$ATT=DID-\delta,\qquad\delta\in[\delta_L,\delta_U]$$

例如教学估计DID=0.04，若领域知识认为反事实趋势偏差最多±0.03，单就识别偏差而言ATT范围为[0.01,0.07]；这还没有包含抽样不确定性。不要把偏差区间与统计置信区间直接混称为95%区间。

深入研读 · 02

安慰剂失败究竟否定什么

时间安慰剂若显著，可能说明原分组本来就有差异趋势，也可能意味着伪时点处有另一冲击。它是设计诊断，不是自动给主估计扣除某个偏差的修正器。若伪时点使用不同对照与样本，其诊断对象也随之变化。

随机标签置换要区分两件事：生成一个“如果标签随意重排”的参照分布，与在真实分配机制下构造有效检验。宽带试点的城市选择不是可随意交换的；500次置换尾部比例不能自动解释为政策效应的有效p值。

深入研读 · 03

把同期政策与溢出纳入研究设计

若数字基础设施建设具有邻近扩散，未入选城市也可能被处理城市影响。此时无干扰假设失效，简单ATT需要重新界定是直接暴露效应、包含间接效应的总效应，还是相对较低暴露城市的效应。

排除邻接城市可以减少某些污染，也会改变对照与目标；加入距离或省份趋势不能保证解决干扰。应先提出暴露映射与可能的空间依赖，再选择样本和推断方法。稳健性表的功能是检验具体替代解释，不是以列数证明可信。

研究练习与解析

观测DID=0.04，允许趋势偏差为±0.03，能否宣称95%区间为[0.01,0.07]？

展开解析

不能。这只是给定偏差集合下的识别范围，尚未结合抽样分布；95%覆盖需要额外的推断构造。
