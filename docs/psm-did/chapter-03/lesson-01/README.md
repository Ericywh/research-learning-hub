# 第6课 条件平行趋势与均值回归风险

## PSM-DID识别什么

PSM基于可观测X寻找可比性；DID仍依赖给定X的未处理变化平行趋势。横截面的水平条件独立与条件平行趋势不同，不能相互替代。匹配不会消除未观测时变混杂，也不能修复缺失政策队列。

## 基期结果不是普遍禁用项

按含暂时噪声的极端单期结果匹配，可能使所选对照随后自然回归均值。风险由结果生成过程、选择机制和序列相关决定。Daw与Hatfield的结论不是永远禁止基期Y；在某些条件平行趋势模型中结果历史确实有识别作用。应依据DAG、政策选择过程和多期历史比较规格。

## 协变量冻结与敏感性

默认在2013冻结GDP、人口、第三产业占比，不把基期工资机械放入PS。删除工资不保证消除偏误。可对更早基期、多年平均、结果趋势等预先指定敏感性分析，但不能依据最终效应显著性挑选模型。政策前变量也可能已经受预期影响。

## 共同支持改变目标

ATT需要处理组X取值上有对照支持。修剪处理组后，估计对象变为被保留处理城市的ATT。报告原处理数、重叠内处理数、匹配成功数与被重复使用的对照数；不能把修剪后ATT继续标为全体试点ATT。

自测：删除基期工资能保证无均值回归偏误吗？

答案：不能；取决于选择机制与结果过程。
