MODULE 01

PSM-DID识别什么

PSM基于可观测X寻找可比性；DID仍依赖给定X的未处理变化平行趋势。横截面的水平条件独立与条件平行趋势不同，不能相互替代。匹配不会消除未观测时变混杂，也不能修复缺失政策队列。

MODULE 02

基期结果不是普遍禁用项

按含暂时噪声的极端单期结果匹配，可能使所选对照随后自然回归均值。风险由结果生成过程、选择机制和序列相关决定。Daw与Hatfield的结论不是永远禁止基期Y；在某些条件平行趋势模型中结果历史确实有识别作用。应依据DAG、政策选择过程和多期历史比较规格。

MODULE 03

协变量冻结与敏感性

默认在2013冻结GDP、人口、第三产业占比，不把基期工资机械放入PS。删除工资不保证消除偏误。可对更早基期、多年平均、结果趋势等预先指定敏感性分析，但不能依据最终效应显著性挑选模型。政策前变量也可能已经受预期影响。

MODULE 04

共同支持改变目标

ATT需要处理组X取值上有对照支持。修剪处理组后，估计对象变为被保留处理城市的ATT。报告原处理数、重叠内处理数、匹配成功数与被重复使用的对照数；不能把修剪后ATT继续标为全体试点ATT。

核心公式

$$E[\Delta Y(0)\mid D=1,X]=E[\Delta Y(0)\mid D=0,X]$$
本课的研究任务

学习重点不是记住命令，而是能解释“条件平行趋势与均值回归风险”中估计目标、识别假设与数据实现之间的关系。依次阅读基础讲解、推导与案例，再结合公共程序检查实际输出。

深入研读 · 01

横截面CIA与条件平行趋势的区别

CIA限制政策后潜在结果水平与处理状态的关系；条件平行趋势只限制未处理变化。一个城市固定不可观测的生产率优势会破坏水平可比，但在其作用不随时间变化时，仍可能允许变化可比。

反过来，匹配后GDP和人口接近也不保证未观测增长冲击相同。若政策专门选择预期工资将增长的城市，PS预测模型再准确，也不能消除这种未观测时变选择。论证应指向政策选择过程，而不是PS模型拟合优度。

深入研读 · 02

用暂时冲击解释均值回归

设结果由城市长期水平μ、暂时冲击ε以及共同时间项组成。若两组长期水平不同，按同一基期观测Y强行匹配，往往选出冲击方向不同的城市。冲击随后部分消退，即使无政策也会产生不同变化。

$$Y_{i0}=\mu_i+\varepsilon_{i0},\qquad E[\varepsilon_{i1}\mid\varepsilon_{i0}]=\rho\varepsilon_{i0}$$

当ρ较小，选中极端基期冲击后回落更明显；当ρ接近1，冲击更持久，回落较弱。多年平均可降低独立测量噪声，但不消除持久冲击、提前反应或选择趋势。是否调整基期结果必须建立在结果过程和选择机制的假设上。

深入研读 · 03

共同支持与外推的边界

ATT要求处理组特征所在区域有对照，而不要求每个对照区域都有处理。把无支持处理城市删除后，报告的是保留城市的效应；处理组被剔除的原因及特征应单列。

真实丰富匹配规格保留31/37首批城市。即使三项均值平衡较好，6个被排除城市仍不在匹配ATT的目标内。把匹配结果与全37城DR结果直接比较时，样本差异与估计方法差异混在一起，不能单凭接近就断言稳健。

研究练习与解析

基期结果含测量误差时，用三年均值匹配是否足以消除均值回归？

展开解析

不足。平均可能减小独立测量噪声，但持久冲击、提前反应与选择趋势仍存在；需要说明误差序列相关及政策选择机制。
