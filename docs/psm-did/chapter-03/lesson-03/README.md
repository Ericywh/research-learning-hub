# 第8课 匹配推断与双重稳健DID

## 匹配后的标准误

Stata teffects psmatch 对差分结果估计ATET，在其光滑性、重叠和抽样条件下使用匹配解析方差。它不是任何PSM-DID、卡尺修剪或聚类设计的通用修复器。频次加权面板回归加城市聚类SE通常只反映给定权重的回归不确定性，不自动包含匹配设计与估计PS的不确定性。

## 双重稳健的边界

设ΔY为两期对数工资增量，m0(X)=E(ΔY|D=0,X)，p(X)=P(D=1|X)。DR以处理组与倾斜加权对照组的残差均值差估计ATT。在条件平行趋势、无预期和重叠下，p或m0任一模型正确可得到一致点估计；两者都错没有保护。

## 点估计稳健不等于推断稳健

评审的Python简化影响函数忽略一般Logit/OLS估计产生的项，不能直接报告为解析SE。公共代码把Logit得分、对照OLS正规方程及ATT矩条件堆叠，用数值Jacobian与城市独立观测的sandwich估计联合M估计方差。它不是交叉拟合机器学习版本；近分离、极端权重或奇异Jacobian需报错。

## 软件实现与可比性

Stata提供teffects psmatch、teffects ipwra差分结果ATET及csdid调用；Python提供显式DR矩估计，二者第一阶段拟合不同，有限样本结果不要求逐位一致。比较时固定样本、基期、结果变换、对照组与ATT目标。最近邻估计不能直接使用普通n-out-of-n bootstrap。

自测：DR点估计一致是否足以保证简化IF标准误正确？

答案：不足；必须计入第一阶段影响或采用有相应理论保证的拟合方式。
