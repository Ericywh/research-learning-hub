# 第8课 匹配推断与双重稳健DID

## 匹配后的标准误

Stata teffects psmatch 对差分结果估计ATET，在其光滑性、重叠和抽样条件下使用匹配解析方差。它不是任何PSM-DID、卡尺修剪或聚类设计的通用修复器。频次加权面板回归加城市聚类SE通常只反映给定权重的回归不确定性，不自动包含匹配设计与估计PS的不确定性。

## 双重稳健的边界

设ΔY为两期对数工资增量，m0(X)=E(ΔY|D=0,X)，p(X)=P(D=1|X)。DR以处理组与倾斜加权对照组的残差均值差估计ATT。在条件平行趋势、无预期和重叠下，p或m0任一模型正确可得到一致点估计；两者都错没有保护。

## 点估计稳健不等于推断稳健

评审的Python简化影响函数忽略一般Logit/OLS估计产生的项，不能直接报告为解析SE。公共代码把Logit得分、对照OLS正规方程及ATT矩条件堆叠，用数值Jacobian与城市独立观测的sandwich估计联合M估计方差。它不是交叉拟合机器学习版本；近分离、极端权重或奇异Jacobian需报错。

## 软件实现与可比性

Stata提供teffects psmatch、teffects ipwra差分结果ATET及csdid调用；Python提供显式DR矩估计，二者第一阶段拟合不同，有限样本结果不要求逐位一致。比较时固定样本、基期、结果变换、对照组与ATT目标。最近邻估计不能直接使用普通n-out-of-n bootstrap。

答案：不足；必须计入第一阶段影响或采用有相应理论保证的拟合方式。

## DR估计量的两个工作模型

令r=ΔY−m0(X)。处理组平均r与倾斜加权对照平均r之差给出DR估计。若结果模型正确，两组未处理残差的条件均值为零；若PS正确，权重将对照X分布校准到处理组，即使结果模型错设，其误差也在两项中抵消。

$$\tau_{DR}={E[Dr]\over E[D]}-{E[(1-D)p(X)r/(1-p(X))]\over E[(1-D)p(X)/(1-p(X))]}$$

这里的双重稳健并不允许平行趋势、无预期或重叠任意失效。它针对两个辅助工作模型的错设，不能把政策分配内生性或对照污染变成可以忽略的问题。两模型都对时还可研究局部效率性质，但效率与一致性是不同结论。

## 联合M估计如何纳入第一阶段

将Logit得分、对照组结果回归正规方程、权重均值、处理比例和ATT方程堆叠为矩条件。对全部参数联合求解后，用Jacobian将每条观测的矩扰动传递到ATT。

$$\widehat V(\widehat\theta)={1\over n}\widehat A^{-1}\widehat B\widehat A^{-\prime},\quad A=E[\partial m_i(\theta)/\partial\theta^{\prime}]$$

只对最终残差加权式求标准差，通常把估计得到的p与m0当成已知，漏掉第一阶段影响。公共程序采用有限维光滑模型与数值Jacobian；若替换成树模型或高维正则化，不能原样保留这套推断，必须研究正交化、交叉拟合与收敛率条件。

## 读一组真实估计而非寻找显著性

2013—2016线性DR约−0.00164，SE约0.02281；丰富规格约−0.00061，SE约0.02007。它们说明当前样本与规格下点估计接近零且区间较宽，不能据此证明政策无效。

政策作用可能异质、被年均测量稀释，或因选择、干扰和缺失产生偏差。研究应先讨论目标时期、处理强度、测量定义及识别条件，再决定如何解释零附近的估计；不能通过不断更改PS直到显著来“完善模型”。

## 研究练习

PS模型正确但结果回归错设时，DR一致性是否意味着可以忽略PS第一阶段方差？

解析：不是。点估计的稳健性不自动给出有效方差；需要完整影响函数、联合矩估计或具有相应推断保证的方法。
