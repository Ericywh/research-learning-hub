贯穿课程的中国公开数据

教学案例基于2014年首批“宽带中国”示范城市（城市群）政策以及《中国城市统计年鉴》公开整理的城市面板数据。官方名单与城市统计口径需要另外核对。

  • 中国城市年度面板CSV数据
  • 数据口径与字段说明
  • 2014年首批示范城市政策公告

研究与识别边界

该课程为方法教学，不等同于已经完成可发表的政策因果研究。2014年政策公布时间较晚，随后2015—2016年仍有新增试点，正式估计前需要处理城市群映射、政策暴露时间、潜在对照组污染以及前期匹配后仍未充分平衡的协变量。

建议按课程顺序学习，将软件运行结果和严格的研究识别核验分开记录。
